# VRIO 框架 VRIO

## 这是什么

**VRIO**：逐项追问某资源/能力是否：**V**aluable（利用机会或化解威胁）、**R**are（少有竞争对手拥有）、**I**mitate 成本高/难模仿（含因果模糊、历史、社会复杂）、**O**rganized（组织流程、激励、结构能否兑现）。四者齐全才更可能支撑**持续**竞争优势；缺一则降级为暂时优势、均势或劣势。

它来自资源基础观（RBV），与外部产业分析（五力）互补：五力看环境利润池，VRIO 看你是否有可兑现的独特资源。

## 什么时候用

- "我们的核心竞争力到底是什么"
- "VRIO / 资源审计 / 难模仿吗"
- 并购尽调、战略会议盘点能力清单

**不要**当主模型：

- 行业利润压力 → [`porters-five-forces`](../porters-five-forces/SKILL.md)
- 壁垒类型与超额回报持续性（投资叙事）→ [`economic-moat`](../economic-moat/SKILL.md)
- 内外部匹配行动 → [`swot`](../swot/SKILL.md)

## 怎么用（执行步骤）

1. **列出候选资源/能力。** 具体到可观察（「排他性渠道合同」「实时调度算法团队」），禁止「企业文化好」。
2. **逐条过 V。** 若明天失去它，机会/威胁应对是否明显变差？否 → 非战略资源。
3. **过 R。** 主要对手是否已普遍拥有？是 → 最多竞争均势。
4. **过 I。** 对手复制要多久/何成本？考虑购买、挖人、逆向。易模仿 → 暂时优势。
5. **过 O。** 流程、激励、权限是否支持发挥？常失败点：有资产无组织。
6. **输出结论与动作。** 持续优势候选：加倍组织兑现；仅 V：不必当护城河叙事；弱 O：先改组织再吹资源。

## 例证

**算法+数据闭环**：有价值且因数据积累难模仿，但若激励不支持投入则 O 失败——揭示组织支持。

**「我们人很好」**：难过 R/I ——揭示空泛能力无效。

**（与护城河）**：品牌/转换成本等护城河类型，可用 VRIO 从内部审计是否真正稀缺难模仿。

## 什么时候不适用（边界）

- **环境剧变使 V 归零**：资源过时，先重做五力/场景。
- **无内部信息**：外部投资者可能更直接用护城河启发式。
- **把 VRIO 当评分游戏**：凑「全是是」无证据。

## 常见误用

- **有资产即优势**：缺 O → 补组织。
- **与五力互斥**：应互补。
- **和护城河重复建两套矛盾结论**：统一证据，护城河讲类型，VRIO 讲审计问题。
- **保密当难模仿唯一解**：流程与文化复杂往往更关键。

## 相关模型

- **与[护城河](../economic-moat/SKILL.md)**：护城河分类壁垒；VRIO 问资源四问。投资叙事走护城河；内部能力审计走 VRIO——可互证。
- **与[五力](../porters-five-forces/SKILL.md)**：外部结构 vs 内部资源。
- **与[SWOT](../swot/SKILL.md)**：优势项应用 VRIO 压力测，避免洗衣单。
- **与[飞轮](../flywheel/SKILL.md)**：能力是否进入自我加强闭环。
- **与[蓝海](../blue-ocean/SKILL.md)**：新曲线仍需问新能力是否 VRIO。

## 记忆钩子

资源要过四关：**有用、少见、难抄、组织用得上**。
