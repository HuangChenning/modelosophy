# 事后聪明偏误 Hindsight Bias

## 这是什么

**得知结果后，觉得结果比事先更“必然/可预测”，并往往改写自己的事前信念。**

表现为：“泡沫破裂谁都看得出”、事故复盘人人成先知。危害：低估噪声与不确定性，苛责决策者，也学不到真实的事前信息集。

## 什么时候用

- 复盘会议充斥“早该如何”
- 投资日志被事后改口

**不要**当主模型：

- 事前置信是否校准 → [`overconfidence`](../overconfidence/SKILL.md)
- 只搜支持叙事的证据 → [`confirmation-bias`](../confirmation-bias/SKILL.md)

## 怎么用（执行步骤）

1. **冻结事前档案。** 找时间戳：邮件、纪要、预测市场、交易日志。无档案则显式标“事前信念不可核实”。
2. **分列三栏。** 事前可知信息 / 事后才知信息 / 结果。禁止把第三栏的洞见写进第一栏。
3. **打“必然性”分。** 让复盘者在看结果前（或对照档案）给可能性打分；看结果后再打一次；若必然性大幅上升且无新证据，标事后聪明。
4. **改学习问题。** 问“事前流程哪一步可改进”，不问“谁蠢到看不出来”。输出：可执行的事前检查清单。

## 例证

**历史事件“必然论”**：教科书把结局写得顺理成章——揭示**叙事平滑抹掉了事前分支**。

**事故问责**：在不知报警延迟数据时苛责一线——揭示司法/组织中的事后聪明。

## 什么时候不适用（边界）

- **有预注册预测**：可直接对照，不必猜是否事后聪明。
- **疏忽已由事前规程定义**：违反明确清单可以问责，不是“事后显得显然”。

## 常见误用

- **禁止一切复盘**：要禁的是改写事前信息集，不是禁学习。
- **=确认偏误**：确认偏误可发生在事前；事后聪明特指结果揭晓后的必然性幻觉。

## 相关模型

- **与[过度自信](../overconfidence/SKILL.md)**：一个事前估满，一个事后改口称早就满。
- **与[幸存者偏差](../survivorship-bias/SKILL.md)**：只看见成功路径会强化“必然”。
- **与[归因理论](../attribution-theory/SKILL.md)**：事后常把结果归因到决策者特质。
