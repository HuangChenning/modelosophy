# 导师制 Mentorship

## 这是什么

**导师制**：在一段约定关系里，经验较多者对经验较少者提供**方向校准、示范、反馈与网络/机会**，使学习者在真实任务中更快形成可交付能力。有效导师制是**可执行协议**，不是「有个前辈偶尔喝咖啡」。

与纯课程不同：导师介入的是**情境中的判断**（什么重要、哪里翻车、下一口吃什么）。与管理考核也可重叠，但本模型聚焦学习成长，而非 HR 绩效表。

**鉴别**：[`zpd`](../zpd/SKILL.md) 提供「独立/支架/做不到」难度诊断；导师制提供**关系与节奏容器**。[`learning-by-teaching`](../learning-by-teaching/SKILL.md) 是学习者侧策略；导师制是双边结构。

## 什么时候用

- "怎么找导师 / 怎么带新人"
- "师徒制 / mentorship 如何设计"
- 转岗、学徒期、研究指导、行业引路

**不要**当主模型：

- 只要某一技能的训练块设计 → [`deliberate-practice`](../deliberate-practice/SKILL.md)
- 只要单次任务难度带 → [`zpd`](../zpd/SKILL.md)
- 只要自己讲给空气听 → [`feynman-technique`](../feynman-technique/SKILL.md)

## 怎么用（执行步骤）

1. **写清 90 天学习结果。** 可观察产出（作品、独立职责、可演示技能），禁止「多交流」。双方书面确认。
2. **约定接触节奏与介质。** 例：双周 45 分钟 + 异步批注；无节奏 → 易沦为闲聊。判据：下一次约会日期已落历。
3. **选真实任务作载体。** 导师在真实交付上示范/旁注/复盘，少做纯讲座。任务难度用 ZPD：需支架但不能全程代做。
4. **反馈结构化。** 每次：1 个保持、1 个改进、1 个下步实验；禁止只有评价无下一动作。
5. **计划渐撤。** 支架从「一起做」→「你做我看」→「你做后复盘」→「按需问」；写明撤出信号（连续两次独立达标）。
6. **季末双向复盘。** 目标达成？关系成本？续约/换导师/结束；避免无限期模糊依附。

## 例证

**编程 mentor**：PR 批注 + 双周设计评审，优于只推荐书单——揭示**任务内反馈**。

**失败的「名人导师」**：一年见一面合影——无协议无任务，不是导师制。

**（局限）**：导师领域错配或激励冲突（抢功）时，协议再完美也失效——先解决匹配与利益。

## 什么时候不适用（边界）

- **无任何可共享任务域**：无法示范判断时，先课程/社区，再 mentorship。
- **心理咨询需求**：情绪危机走专业帮助，勿把导师当治疗师。
- **强依赖损害独立**：该撤不撤 → 强制渐撤或换同侪练习。
- **组织明文禁止的私下利益输送**：遵守合规。

## 常见误用

- **只找头衔不找匹配**：领域/风格不合 → 用 90 天目标反选。
- **导师代做**：学员无作品 → 违反渐撤，改「你做我看」。
- **无反馈标准**：感觉很好 → 每次落到 1 个改进动作。
- **与 ZPD 对立**：导师制容器内仍要用 ZPD 判难度。

## 相关模型

- **与[最近发展区 ZPD](../zpd/SKILL.md)**：ZPD 定单次任务支架；导师制定关系节奏与渐撤。
- **与[刻意练习](../deliberate-practice/SKILL.md)**：导师常是高质量反馈源；练习设计仍可显式化。
- **与[学习中教](../learning-by-teaching/SKILL.md)**：高年级带低年级时，教者也在学——双边都可受益。
- **与[T 型技能](../t-shaped-skills/SKILL.md)**：导师帮校准横杠该补哪些接口。
- **与[元认知](../metacognition/SKILL.md)**：会谈中练习「我卡在策略还是知识」。

## 记忆钩子

导师制是带日期的协议加真实任务，不是通讯录里的大神。
