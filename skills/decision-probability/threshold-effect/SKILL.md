# 阈值效应 Threshold Effect

## 这是什么

**阈值效应**：输入/努力/剂量与结果之间存在**临界水平**——低于阈值时结果接近无效或另一种机制，跨过阈值后响应显著增强（或骤然变差）。决策含义：资源应集中以**跨过有效阈值**，或刻意**远离危险阈值**，而不是在阈值以下均匀撒胡椒面。

与**临界点/临界质量（tipping point）**分流：tipping point 强调系统稳态相变与正反馈铺开；本模型强调**剂量—反应或规则触发的门槛**（达标、起效、熔断线），不一定涉及流行扩散。

## 什么时候用

- "是不是没到阈值所以无效"
- "阈值效应 / 过线才算 / 最低有效剂量"
- "预算分散导致都在门槛下"
- 用药/训练/广告触达/合规积分/SLA 奖惩等有明确门槛的场景

**不要**当主模型：

- 流行扩散、临界质量、宏观相变叙事 → [`tipping-point`](../../systems-complexity/tipping-point/SKILL.md)
- 只谈网络爆发与飞轮 → [`flywheel`](../../strategy-competition/flywheel/SKILL.md) / [`metcalfes-law`](../../systems-classic-effects/metcalfes-law/SKILL.md)
- 保险丝式限损结构 → [`antifragility`](../../learning-growth/antifragility/SKILL.md)

## 怎么用（执行步骤）

1. **命名响应曲线形态。** 假设：平坦→陡升、阶跃、U 形等。写出可观察的 Y。
2. **识别候选阈值变量 X。** 剂量、频次、覆盖天数、评分、资本充足率……必须可测。
3. **用证据定位门槛。** 历史分段、实验、领域标准、监管线；给区间而非假装精确到小数。
4. **决策：冲过、维持带、或远离。** 冲过：集中资源达线；危险阈值：加缓冲；假阈值：不要为故事烧钱。
5. **检查多阈值与交互。** 两个门槛同时满足才触发时，按瓶颈排序（可链 TOC）。
6. **设监测。** 接近阈值的预警与跨线后的机制是否仍成立（阈值漂移）。

## 例证

**广告/触达**：每周曝光低于记忆阈值时转化≈0，跨线后抬升。揭示：**均摊预算可能永久停在无效区**。

**最低有效血药浓度**（教学向）：血药浓度低于最低有效浓度（MEC）时疗效接近无效，跨过后才起效——揭示「差一点」不是线性差一点。

**绩效考核强制分布线**：刚好在线上下激励行为扭曲。揭示：阈值也会制造**博弈与堆线**。

## 什么时候不适用（边界）

- **响应实际近似线性**：硬找阈值是过度拟合。
- **阈值不可观测且无代理**：先改指标。
- **与相变故事强行合并**：有正反馈宏观翻转时转 tipping-point。

## 常见误用

- **把目标 KPI 线神化成自然阈值**：可能只是管理约定。
- **与临界点混用**：扩散相变 ≠ 剂量门槛。
- **未达阈值仍加码叙事**：「再坚持就会质变」而无 X 定义。
- **忽略跨线后的平台或毒性**：过线也可能变坏。

## 相关模型

- **与[临界点](../../systems-complexity/tipping-point/SKILL.md)**：**硬区分。** 临界点=稳态翻转/临界质量；阈值效应=剂量或规则门槛。用户说「临界质量/引爆」走 tipping-point；说「起效剂量/达标线」走本模型。
- **与[帕累托](../../systems-classic-effects/pareto-principle/SKILL.md)**：帕累托谈不均等贡献；阈值谈跨线前后机制不同。可连用：把资源抽向能过线的少数项。
- **与[约束理论](../../cognitive-thinking-tools/theory-of-constraints/SKILL.md)**：多门槛时先打通瓶颈门槛。
- **与[敏感性分析](../sensitivity-analysis/SKILL.md)**：输出在阈值附近往往极敏感——敏感分析可帮定位门槛。
- **与[计划谬误](../planning-fallacy/SKILL.md)**：工期/预算「差一点交付」常落在无效区，需按阈值重排计划。

## 记忆钩子

撒胡椒面停在门槛下 = 零；**先问有效阈值在哪，再决定冲或撤。**
