# 飞轮 Flywheel

## 这是什么

飞轮隐喻：推动一个重轮，前几圈极费力，但若存在**自我加强的因果闭环**，动量会累积，后来每单位努力带来更大位移。Collins 用它描述从优秀到卓越的积累；商业上常指增长飞轮——例如更多卖家 → 更全选品 → 更好体验 → 更多流量 → 更多卖家。

关键不在励志，而在：**你能否写出 4–7 个互相推动的环节，且每一环有可观测指标**。没有闭环的“坚持”，只是线性苦干。

## 什么时候用

- 设计增长/产品/组织能力的加速结构；
- 诊断“很努力但飞轮不转”；
- 用户直接说飞轮 / flywheel。

**不要**当主模型：只问钱或习惯是否指数增长（复利）；只问存量流量（系统思维可先用）；待办排序（艾森豪威尔）。

## 怎么用（执行步骤）

1. **画出候选闭环（不是清单）。** 用箭头连接：A 提升 B，B 提升 C，C 回到 A。若画成一排口号，推倒重来。
2. **给每环一个可测指标。** 无法测量的环是愿望。标出当前最弱的一环（瓶颈）。
3. **检查延迟与泄漏。** 哪一环的增强要很久才到下一环？顾客/能量从哪漏走？延迟过长时，前期费力是预期内，但需中间领先指标。
4. **决定推哪一格。** 优先加强瓶颈环或减少泄漏，而不是平均用力。与系统思维杠杆一致。
5. **对照复利与路径依赖。** 若只有“继续投时间”，用复利检查再投入；若飞轮其实锁死有害路径，用路径依赖/反脆弱评估要不要刹车。

## 例证

**电商双边飞轮（示意）**：选品 → 体验 → 流量 → 卖家入驻 → 选品。揭示闭环与瓶颈（若物流体验破裂，流量环断开）。

**内容学习飞轮**：输出 → 反馈 → 认知升级 → 更高质量输出。若只学不输出，环断，不是“还没坚持够”。

**（原书卡片）坚持就会转**：励志向。必须补上因果闭环与指标，否则与任何努力叙事无法区分。

## 什么时候不适用（边界）

- **一次性项目**：无重复圈，用计划/PDCA 即可。
- **负飞轮**：差评 → 流失 → 更差服务；要先打断，再谈加速。
- **伪飞轮**：把无关 KPI 画成圆圈。

## 相关模型

- **与[复利](../../finance-investing-models/compounding/SKILL.md)**：复利给数学形式；飞轮给商业/组织因果故事。常一起成立，但检验方式不同。
- **与[系统思维](../../systems-classic-effects/systems-thinking/SKILL.md)**：飞轮是增强回路的一种叙事包装；复杂延迟与调节回路仍用系统思维。
- **与[路径依赖](../../systems-classic-effects/path-dependence/SKILL.md)**：飞轮动量也可能锁住次优标准。
- **与[PDCA](../../efficiency-execution/pdca/SKILL.md)**：飞轮设计后，用 PDCA 迭代每一环的改进。
