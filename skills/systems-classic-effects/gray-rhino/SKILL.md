# 灰犀牛 Gray Rhino

## 这是什么

**灰犀牛**（Michele Wucker）：与黑天鹅相对——**高度明显、概率不低、冲击大**，却因政治、惯性、激励或侥幸而被忽视或拖延，直到冲撞。

机制核心是**治理与注意力失败**，不是信息为零。

## 什么时候用

- "技术债/合规债人人都知道"
- "气候/债务/安全隐患报告写了三年"
- "讨论为什么不行动而不是不知道"

**不要**当主模型：
- 真正事后惊奇的尾部 → [`black-swan`](../black-swan/SKILL.md)
- 慢到未察觉 → [`boiling-frog`](../boiling-frog/SKILL.md)
- 需要系统杠杆 → [`systems-thinking`](../systems-thinking/SKILL.md)

## 怎么用（执行步骤）

1. **确认可见性。** 谁已经书面/口头预警？若无，可能不是灰犀牛。
2. **写冲击与时间窗。** 最坏损失、可能触发的条件与大致窗口。
3. **诊断拖延机制。** 激励错位、问责模糊、短任期、预算政治——点名，不空喊“不重视”。
4. **设触发器与主人。** If-then：指标到 X 则启动方案 Y；指定人名与日期。
5. **小步强制启动。** 先做不可逆成本较低的减暴露动作，打破“再等等”。

## 例证

**金融危机前的杠杆狂欢**：多方预警仍加码（视具体案例）。揭示**可见却不作为**。

**年年提的安全整改**：检查后依旧。揭示组织灰犀牛。

**Wucker 术语对照黑天鹅**：揭示公共讨论中的分类价值。

## 什么时候不适用（边界）

- **信息真正缺失的极端**：黑天鹅侧。
- **已在全力处置**：标签无增量。
- **争议性概率**：专家严重分裂时，先争证据再贴灰犀牛。

## 常见误用

- **事后贴标**：任何灾难都称早看见 → 要事前记录。
- **与煮青蛙混用**：青蛙是未察觉；灰犀牛是察觉仍拖。
- **恐吓清单膨胀**：一百头灰犀牛等于没有优先级。

## 相关模型

- **与[黑天鹅](../black-swan/SKILL.md)**：不知/难知 vs 已知拖延。
- **与[温水煮青蛙](../boiling-frog/SKILL.md)**：麻木未见 vs 见而不动。
- **与[二阶思维](../second-order-thinking/SKILL.md)**：拖延的二阶常是更大冲击。

## 记忆钩子

犀牛已在跑道上——写 if-then 和负责人，别再“再观察观察”。
