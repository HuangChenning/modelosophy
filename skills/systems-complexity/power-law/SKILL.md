# 幂律 Power Law

## 这是什么

**幂律**：某量 x 的概率大致满足 P(x) ∝ x^(-α)（在一定区间）。图像：log-log 上近似直线；含义是**极端值比正态分布预期的「更常见」**，均值/方差可误导。

操作对照：

| 形态 | 尾部 | 决策含义 |
|---|---|---|
| **幂律/胖尾** | 极端事件贡献大 | 保护/押注尾部；均值不够 |
| **正态/薄尾** | 极端极罕见 | 均值±σ 常够用 |

严格拟合常有争议——**「是否显著胖尾、少数是否主导」**往往比贴标签更重要。

## 什么时候用

- "是不是少数客户/漏洞/节点贡献了大半"
- "幂律 / 胖尾 / Zipf / 和正态不一样"
- 城市规模、词频、财富、引用、故障损失、内容播放量

**不要**当主模型：
- 只要网络 hub 与优先连接机制 → [`scale-free-network`](../scale-free-network/SKILL.md)
- 只要时间管理 80/20 口诀 → [`pareto-principle`](../../systems-classic-effects/pareto-principle/SKILL.md)
- 只要长尾商业策略叙事 → [`long-tail`](../../systems-classic-effects/long-tail/SKILL.md)
- 假设误差对称可加总 → [`normal-distribution`](../normal-distribution/SKILL.md)

## 怎么用（执行步骤）

1. **定义随机变量。** 什么的分布？（损失额、度数、收入）。判据：单位与样本边界写清。
2. **看排序贡献。** 前 1%/10% 占总量多少？判据：算出累计份额；若接近均分则不像幂律主导。
3. **对照薄尾基准。** 若用正态/均值思维，极端是否被系统性低估？判据：至少举一个「均值安全、尾部致命」点。
4. **谨慎谈指数。** 无足够样本勿宣布 α；用「胖尾候选」即可推进决策。
5. **选尾部策略。** 抑制：截断、保险、冗余、限仓；利用：押注超级节点/爆款机制。判据：策略明确针对尾部而非均值。
6. **监测机制是否制造幂律。** 优先连接、赢家通吃、病毒传播——机制变则分布变。

## 例证

**地震能量 / 城市人口**：经典候选幂律域；均值城市规模几乎无政策意义。揭示：尾部城市/事件支配资源。

**线上内容播放**：头部爆款 vs 长尾；广告预算若按「平均播放」会错。揭示：与正态假设冲突。

**（原书卡片）**：避免只喊「幂律世界」；落到份额表与尾部动作。

## 什么时候不适用（边界）

- **小样本硬拟合**：N 很小谈幂律指数 → 误导。
- **有硬上界的过程**：物理截断使尾部变薄。
- **已是明确正态误差模型且尾部不重要**：用正态更省。

## 常见误用

- **一切不均 = 幂律**：先看累计份额与生成机制。
- **与无标度网络混用**：网络度数幂律是特例；本模型可覆盖非网络量。
- **用均值管理胖尾风险**：→ 改尾部指标（极值/最大单点暴露）。

## 相关模型

- **与[正态分布](../normal-distribution/SKILL.md)**：薄尾对称 vs 胖尾；先判形态再选模型。
- **与[无标度网络](../scale-free-network/SKILL.md)**：无标度是度数幂律+hub 机制；幂律是更一般的分布透镜。
- **与[帕累托法则](../../systems-classic-effects/pareto-principle/SKILL.md)**：80/20 是经验口吻；幂律给分布与尾部决策。
- **与[长尾](../../systems-classic-effects/long-tail/SKILL.md)**：长尾谈需求曲线商业含义；幂律谈统计形态。

## 记忆钩子

先看头部占比，再谈均值——胖尾里平均值是安慰剂。
