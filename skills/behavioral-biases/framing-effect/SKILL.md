# 框架效应 Framing Effect

## 这是什么

**客观等价（或近似等价）的信息，因表述框架不同，导致偏好翻转或强度变化。**

亚洲疾病问题：同一统计结果写成“救活”或“死亡”，群体风险选择翻转。营销里“95%瘦肉”vs“5%脂肪”、政策里“奖励”vs“惩罚”同理。框架常通过激活收益/损失编码起作用，与损失规避紧密相连，但本条的操作焦点是：**改写表述并观察偏好是否跳变**。

## 什么时候用

- 同一方案两套文案，受众态度相反
- 医疗/投资沟通在正负框架间选择

**不要**当主模型：

- 首个数字牵引估计 → [`anchoring`](../anchoring/SKILL.md)
- 要完整概率权重与四重模式 → [`prospect-theory`](../prospect-theory/SKILL.md)

## 怎么用（执行步骤）

1. **写出客观结果表。** 用人数、金额、概率等中性语言列结果，去掉情感动词。
2. **生成至少两个框架。** 例如获得/损失、占比/基数、短期/长期口径；确保数学上尽量等价。
3. **盲测偏好。** 让用户（或分段样本）在未见另一框架时选择；若排序翻转，记录框架效应强度。
4. **对齐决策目标再选框架。** 自我决策：选能对齐真实终态的中性/双侧框架。影响他人：披露等价性，避免单侧操纵；医疗等场景遵循知情同意规范。

## 例证

**亚洲疾病问题**：揭示**纯描述差异即可翻转风险态度**。

**信用卡“折扣 vs 附加费”**：等价价差因框架改变接受度——揭示商业定价话术。

## 什么时候不适用（边界）

- **框架改变了信息**：若一个说法多透露了基率/时间窗，不是纯框架效应。
- **伦理红线**：故意用不完整框架误导受依赖方，不在本 skill 授权范围。

## 常见误用

- **“会框架=会骗人”**：顾问用途是双侧展示与自检。
- **与锚定混称**：锚是起点数字；框架是得失/正负包装。

## 相关模型

- **与[损失规避](../loss-aversion/SKILL.md)**：损失框架常激活更陡痛感。
- **与[前景理论](../prospect-theory/SKILL.md)**：框架是编辑阶段的关键操作。
- **与[诱饵效应](../decoy-effect/SKILL.md)**：通过加入选项改选择，而非改同一选项的措辞。
- **与[双系统](../../thinking-models/dual-process/SKILL.md)**：框架多走快系统情感通道。
