# 福格行为模型 Fogg Behavior Model（B=MAP）

## 这是什么

BJ Fogg 的行为模型：一个具体行为 B 在某一刻发生，当且仅当**动机（Motivation）、能力（Ability）、提示（Prompt）**同时足够。写作 **B = MAP**（早期文献/教材常写 B=MAT，T=Triggers，与 Prompt 同角色）。图示上有一条行动线：提示是否触发行动是二元的（落在线上方即成功、线下方即失败），不存在"提示强弱"的连续过渡——动机与能力越高，把人推过行动线所需的提示门槛越低；动机低且事很难时，无论提示多强都会落在线下方而失败。

设计含义：**动机最不可靠**——情绪、场景一变就垮。可持续策略通常是：把行为拆到足够小以抬高 Ability，挂在已有日程锚点上给 Prompt，再用即时庆祝巩固，而不是空喊“逼自己有动力”。

与心流的分工：本模型回答“**会不会做出这一下**”；[`flow`](../../learning-growth/flow/SKILL.md) 回答“做的过程是否进入挑战-技能匹配的体验通道”。能做到俯卧撑，不等于练举重时处于心流。

## 什么时候用

- 习惯养成、产品转化、提醒设计：想做却总没做；
- 需要判断缺的是动机、能力还是提示；
- 直接提福格 / B=MAP / B=MAT / 微习惯 / tiny habits。

**不要**当主模型：
- 焦虑/无聊、挑战技能不匹配 → [`flow`](../../learning-growth/flow/SKILL.md)；
- 待办优先级 → [`eisenhower-matrix`](../../efficiency-execution/eisenhower-matrix/SKILL.md)；
- 沟通先讲目的 → [`golden-circle`](../../cognitive-thinking-tools/golden-circle/SKILL.md)；
- 战略态势 → [`swot`](../../strategy-competition/swot/SKILL.md)。

## 怎么用（执行步骤）

1. **写清目标行为的一句话定义。** 时间、地点、可观察动作（“每晚刷牙后用牙线清洁一颗牙”），禁止模糊愿望（“变得健康”）。
2. **三问诊断缺口。** 当下是否*想*做（M）？是否*能轻易*做（A：时间、体力、金钱、脑力、日程匹配）？是否在关键时刻被*提示*到（P）？缺哪个补哪个；常同时缺多个。
3. **优先抬 Ability，而不是鸡血 M。** 把行为缩小到“没有动机也能做”的尺度；去除摩擦（工具预置、缩短步骤）。动机波动时，小行为仍能存活。
4. **设计 Prompt 类型。** 人物内在提示（饿）、情境提示（便利贴/推送）、行动提示（锚点习惯后立刻做）。行动锚点通常最稳。注意：刷屏式提示会脱敏并制造压力。
5. **微习惯闭环（可选但推荐）。** 锚点出现 → 做微行为 → **即时庆祝**（制造成功情绪，助后续自动化）。成功后再渐进加码，避免一上来用动机硬扛高难度。

## 例证

**没去跑步的三岔口**：不想（自认不需要）/ 不能（熬夜乏力）/ 未提示（被饭局带走）。同一“没做成”，处方完全不同——揭示**先诊断 MAP 缺口**。

**牙线一颗牙**：能力降到极低后，弱动机 + 刷牙锚点即可发生；再扩展。揭示微习惯靠 Ability×Prompt，不靠持久激情。

**产品推送轰炸**：提示很多但行为难、动机弱 → 落在行动线下方，只剩骚扰。揭示提示不是越多越好。

**（原书卡片）B=MAT +「逆转人生」**：结构可用；T 与现今 Prompt 同义。卡片收尾励志化与“说服用户”单向操控语气是局限——能力设计应减少摩擦，而非把人当纯被转化对象；伦理上对成瘾式触发保持警惕。

## 什么时候不适用（边界）

- **目标行为有害或违法**：不帮优化成瘾、欺凌、欺诈触发。
- **系统/资源硬约束**：没钱、没权限、法规禁止时，不是“提示不够”。
- **把一切组织失败收成个人 MAP**：流程、激励、编制问题要用系统/战略工具。
- **与心流混淆**：已能稳定发生但仍痛苦/无聊，转 flow 调挑战-技能，而不是继续加提示。
- **动机操纵边界**：健康教育可提高动机；暗黑模式利用恐惧/羞辱提高 M 不在本 skill 推荐范围。

## 常见误用

- **不诊断缺口，统一开"提高动机"的药方**：无论实际缺的是能力还是提示，都用打鸡血、立 flag 的方式硬提动机——而动机恰恰是三者里最不稳定的一个 → 走步骤2 先诊断，步骤3 优先降 Ability。
- **把提示当万能钥匙，越推越狠**：以为行为没发生是因为提醒不够，不断加大 Prompt 强度（更多推送/更响的提醒），反而让人脱敏甚至反感 → 例证3 已揭示提示不是越多越好，先查 M/A 是否才是真正瓶颈。
- **一上来设计大而难的目标行为，指望动机撑住**：跳过步骤3 的行为拆小，直接要求"每天一小时"，动机一旦波动整个习惯就崩 → 应把行为缩到没有动机也能做的尺度再逐步加码。
- **把行为没发生笼统归为"不够自律"**：不拆分 M/A/P 三个独立变量，用意志力/品格问题一概而论 → 走步骤2，具体定位缺的是哪一个。

## 相关模型

- **与[心流](../../learning-growth/flow/SKILL.md)**：发生 vs 体验通道；先 MAP 让行为出现，再谈匹配与专注。
- **与[复利](../../finance-investing-models/compounding/SKILL.md)**：微行为重复可积累，但须再投入与存活条件成立。
- **与[PDCA](../../efficiency-execution/pdca/SKILL.md)**：MAP 诊断单次行为；PDCA 管改进循环怎么转下一圈。
- **与[艾森豪威尔矩阵](../../efficiency-execution/eisenhower-matrix/SKILL.md)**：重要性决定该不该养成；福格决定如何让它发生。
- **与[马斯洛需求层次](../maslow-hierarchy/SKILL.md)**：动机来源可对照需求类别，但福格不依赖严格层级定律。
- **与[情境领导](../situational-leadership/SKILL.md)**：福格管行为 MAP；情境领导管督导强度与准备度匹配。
