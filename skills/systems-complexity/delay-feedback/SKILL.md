# 延迟反馈 Delay Feedback

## 这是什么

**延迟反馈**：闭环中从行动到可观察结果（或到状态真正改变）存在**时滞**。延迟会让调节回路表现为：**过冲 → 回调 → 再过冲**（振荡），或让增强回路在「看起来还没事」时已埋下失控。

口令：问题往往不是极性画错，而是**你按「当下读数」猛调，读数却是过时的**。

## 什么时候用

- "指标一压就反弹 / 越调越晃"
- "政策/补货/招人总慢半拍"
- "delay / 时滞 / 反馈延迟 / 振荡"

**不要**当主模型：
- 只要分清正负反馈 → [`feedback-loops`](../../systems-classic-effects/feedback-loops/SKILL.md)
- 要画完整 CLD → [`causal-loop-diagram`](../causal-loop-diagram/SKILL.md)
- 要算浴缸累积 → [`stock-and-flow`](../stock-and-flow/SKILL.md)
- 只要临界翻转 → [`tipping-point`](../tipping-point/SKILL.md)

## 怎么用（执行步骤）

1. **画出闭环并标极性。** 无闭环则不是延迟反馈问题。判据：至少一条调节或增强环。
2. **标每一段延迟。** 感知延迟、决策延迟、执行延迟、物理/管道延迟——单位用天/周。判据：每段有估计区间，不写「有点慢」。
3. **找主导延迟。** 哪一段最长且处在调节路径上？判据：点名一段。
4. **解释过冲机制。** 用「按过时读数加力」叙述一回合振荡。判据：能讲清为何第二次动作与第一次相反。
5. **改控制策略。** 选项：降增益（少猛调）、加预测/先行指标、缩短感知延迟、加缓冲库存、分阶段释放。判据：写出将采用的一条并说明如何减振。
6. **设监测。** 同时看「动作」与「滞后结果」两列时间序列，避免只盯结果。

## 例证

**供应链牛鞭**：订单延迟+库存调节 → 上游振幅放大。揭示：延迟+局部优化制造振荡。

**组织 KPI 季末突击**：考核延迟使日常欠账，期末过冲质量。揭示：缩短反馈或改领先指标。

**（原书卡片）**：勿只说「要有耐心」；落到延迟分段与降增益。

## 什么时候不适用（边界）

- **开环一次性项目**：无反馈闭环。
- **延迟可忽略的快过程**：实时控制且时滞 << 决策周期。
- **主因是激励扭曲而非时滞**：先改激励。

## 常见误用

- **延迟 = 借口不作为**：要缩短可缩短的感知/决策延迟。
- **与临界点混用**：振荡≠相变翻转。
- **只加更多调控层**：常加大延迟；优先降增益与先行指标。

## 相关模型

- **与[反馈回路](../../systems-classic-effects/feedback-loops/SKILL.md)**：对方辨极性；本模型专攻时滞与振荡。
- **与[因果回路图](../causal-loop-diagram/SKILL.md)**：CLD 上标注 delay 符号；本模型给干预策略。
- **与[存量与流量](../stock-and-flow/SKILL.md)**：延迟常来自存量惯性；可连用定量。
- **与[系统基模](../system-archetypes/SKILL.md)**：增长上限/反应不足等故事常含延迟。
