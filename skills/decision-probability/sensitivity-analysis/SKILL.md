# 敏感性分析 Sensitivity Analysis

## 这是什么

**敏感性分析**：系统性地改变模型中的输入、假设或权重，观察**输出指标与推荐行动**如何变化——目的不是制造更多表格，而是回答：「我的结论绑在哪些少数假设上？这些假设的合理扰动会不会翻转决策？」

决策树里的「改概率再算一遍」是其局部用法；本 Skill 把它提升为**显式稳健性门控**。

## 什么时候用

- "做一下敏感性 / 哪个变量最要命"
- "结论稳不稳？假设错一点会怎样"
- "tornado 图、弹性、临界假设"
- 模型已有、即将据此投入资源或对外承诺

**不要**当主模型：

- 要看联合不确定性下的整段分布 → [`monte-carlo`](../monte-carlo/SKILL.md)
- 多阶段决策/买信息结构本身 → [`decision-tree`](../decision-tree/SKILL.md)
- 深度不确定、分布不可辩护 → [`scenario-planning`](../scenario-planning/SKILL.md)
- 还没有可计算模型 → 先建 EV/树/简单账，再敏感

## 怎么用（执行步骤）

1. **固定基准情形（base case）。** 写下当前输入与推荐行动 A。判据：可复现。
2. **列出候选驱动假设。** 概率、成本、增长率、折现率、权重等；标来源与合理区间（不是任意 ±50%）。
3. **单因素扫描（OAT）。** 在合理区间内变动一个输入，记录输出与「是否仍选 A」。画出或列出排序（tornado 直觉）。
4. **定位翻转点。** 对最敏感项，找使决策翻转的临界值；问「该值是否落在可信区间内？」
5. **必要的双因素/情景组合。** 仅对高敏感且可能相关的对做组合；避免组合爆炸。
6. **输出稳健结论。** 「在区间 S 内推荐 A；若 X 低于 x\* 则改 B；需优先收集关于 X 的信息」。

## 例证

**投资 NPV**：折现率与永续增长最敏感；翻转点落在争议区间 → 决策改为「先降不确定性再承诺」。揭示：敏感性指导**信息价值**。

**决策矩阵权重**：改权重导致方案排名对调 → 暴露偏好未对齐。揭示：可与 [`decision-matrix`](../../cognitive-thinking-tools/decision-matrix/SKILL.md) 连用。

**疫情/供应链**：提前期假设 ±20% 使服务水平崩盘 → 库存策略重做。揭示：找脆点优于精修均值。

## 什么时候不适用（边界）

- **模型错误**：敏感的是错误结构 → 先修机制。
- **输入区间无根据**：±乱扭制造恐慌或假稳健。
- **已决定只沟通叙事**：用情景可能更有效。

## 常见误用

- **只报弹性系数、不谈决策翻转**：分析与行动脱节。
- **与蒙特卡洛等同**：MC 是联合抽样分布；敏感性常先做、更可解释。
- **同时乱改所有输入**：无法归因。
- **把「不敏感」当「正确」**：可能整体偏置。

## 相关模型

- **与[蒙特卡洛](../monte-carlo/SKILL.md)**：先敏感找关键驱动，再对驱动做 MC；或 MC 后用敏感解释「谁在推尾部」。
- **与[决策树](../decision-tree/SKILL.md)**：树上概率/收益的敏感性是标准收尾；本模型强调翻转与信息优先。
- **与[期望值](../expected-value/SKILL.md)**：EV 基准算完必须过敏感性门，否则假精确。
- **与[情景规划](../scenario-planning/SKILL.md)**：情景改的是世界叙事；敏感改的是模型旋钮。
- **与[基率](../base-rate/SKILL.md)**：最敏感的概率输入优先用基率校准。

## 记忆钩子

先问**「什么东西一变，我就改主意？」**——找得到翻转点，才算做完分析。
