# 基钦周期 Kitchin Cycle

## 这是什么

**约 3–5 年（常称约 40 个月）的短周期，主要与库存调整相关。**

提出者/源流：Joseph Kitchin（1920s）；库存周期。需求意外变化→企业误判→库存积压或过低→随后减产/补库，形成短波。叠加在中长期周期之上。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "「是不是该补库存了」"
- "「去库结束没」"

**不要**在以下情况套用本模型：

- 十年 CAPEX → juglar
- 康波 → kondratiev

## 怎么用（执行步骤）

每一步给出可操作判据；禁止只换说法重复结论。

1. **读库存—销售比与库存变动。** 上升去库/下降后补库等经典相位。
2. **对照新订单与生产。** 订单先导，生产与库存滞后。
3. **判断相位。** 主动去库、被动去库、补库、过热。
4. **给短周期作业假设。** 2–6 季度；声明可被外生冲击打断。

## 例证

**Kitchin 短波观察**：揭示库存驱动。

**疫情后补库行情**：揭示短周期剧烈版。

**经销商去库拖累开工**：揭示微观库存加总为宏观波动。

## 什么时候不适用（边界）

- **即时生产与供应链改革**：库存缓冲变薄，波幅形态变。
- **服务业占比高**：库存信号弱。

## 常见误用

- **日历拜物**：固定 40 个月翻牌。
- **忽略大冲击**：战争/疫情主导时库存逻辑次要。

货架多了又少了，工厂跟着打短工——这就是库存的呼吸。
