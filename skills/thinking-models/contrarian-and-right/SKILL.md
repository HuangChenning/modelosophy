# 正确与非共识 Contrarian and Right

## 这是什么

投资与认知上的硬条件：**与共识不同，并且是对的**。Howard Marks 强调：已反映在价格里的共识正确，买不到超额；要超额须第二层思考——看到别人没看到的，且判断准确。Peter Thiel 的提问版：“有什么重要的真理，很少人同意你？”——重点在**重要 + 真理**，不是为反对而反对。

单独“非共识”失败率很高（多数反共识是错的）。单独“正确但人人可见”往往无超额（已定价/已内卷）。两者合取才是稀缺位。

## 什么时候用

- 投资、创业、研究选题：声称自己看到了别人没看到的；
- 团队里有人靠抬杠建立身份，需要鉴别；
- 直接提非共识 / contrarian / “正确与非共识”。

**不要**当主模型：
- 证据搜寻只找支持自己的 → [`confirmation-bias`](../../behavioral-biases/confirmation-bias/SKILL.md)；
- 只听成功反共识故事 → [`survivorship-bias`](../../behavioral-biases/survivorship-bias/SKILL.md)；
- 从物理/约束重算 → [`first-principles`](../first-principles/SKILL.md)。

## 怎么用（执行步骤）

1. **写清共识陈述。** 一句话：“目前多数人/市场价格隐含相信 ____。”无共识基线就谈不上非共识。
2. **写清你的不同预测。** 必须是可观察结果（价格、份额、技术指标、时间盒），不是气质标签（“他们太贪”）。
3. **单列正确性检验。** 何种证据会让你认错？现在已有哪些独立证据（非情绪、非身份）？若无法证伪，降级为偏好而非判断。
4. **估计共识强度与己方边。** 边来自信息、分析框架、时间视野还是激励不同？没有边的反共识 = 噪音。
5. **决策上分离表达与下注。** 可以口头保留异议；真金/声誉下注前要求步骤 3 达标。伦理与安全领域禁止“为反而反”。

## 例证

**已定价的好消息**：人人都知的利好打进价格后，再“共识看多”往往无超额。揭示**正确但非稀缺**不够。

**空仓式永久唱空**：在长期向上的资产上反复“非共识看空”而无时间表与证伪条件——可能只是身份。揭示非共识≠智慧。

**少数派技术判断**：在可复现基准上证明方法更优，尽管审稿人起初不信——符合“非共识且可检验正确”。

**（原书卡片）特立独行/反共识**：易把人格浪漫化；本 skill 强制补上“正确/可证伪”门闩，并承认多数时候共识实用（交通规则、无菌操作）。

## 什么时候不适用（边界）

- **高共识高正确的安全规范**：不鼓励反共识闯红灯。
- **无法承担错误成本时**：杠杆押注非共识须先看归零风险（反脆弱/仓位）。
- **把少数派身份当目标函数**：优化“看起来独特”会系统变错。
- **事后诸葛**：结果对了再自称非共识——应用事前记录预测。

## 相关模型

- **与[确认偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：非共识主张更易陷入只搜支持证据；必须主动找反证。
- **与[幸存者偏差](../../behavioral-biases/survivorship-bias/SKILL.md)**：反共识赢家传记抽掉失败者。
- **与[第一性原理](../first-principles/SKILL.md)**：边常来自硬约束重算，而非抬杠。
- **与[护城河](../economic-moat/SKILL.md)**：投资上非共识正确仍要问壁垒能否持续。
