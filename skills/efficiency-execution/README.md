## Skills

- **[eisenhower-matrix](./eisenhower-matrix/SKILL.md)** — 用艾森豪威尔紧急×重要矩阵帮用户分配时间与注意力：先区分紧急与重要，优先投入重要但不紧急 （第 II 象限）以防救火成为常态；紧急且重要立刻做，紧急不重要授权或压缩，不紧急不重要删掉。 Use when user says “事情太多不知先
- **[pdca](./pdca/SKILL.md)** — 用 PDCA（计划-执行-检查-处理）做持续改进循环：Plan 定假设与度量，Do 小范围执行，Check/Study 对照学习，Act 标准化或调整后进入下一圈；不是一次性瀑布。Use when user says “PDCA”“戴明环”
