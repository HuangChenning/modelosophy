# 9 大辅助分析工具使用指南

在华为 MCR 客户洞察体系中，通用分析模型用于辅助深化特定维度的分析结论。本指南提供各工具的使用场景与三向映射表。

---

## 1. 辅助工具速查与操作简述

| 工具名称 | 核心作用 | 客户分析中的操作步骤 |
|---------|---------|-------------------|
| **PEST** | 扫描政治/经济/社会/技术宏观环境 | 梳理政策监管、经济周期、技术革新对客户业务的影响 |
| **波特五力** | 分析行业竞争结构与利润潜力 | 评估买方议价权、供应商议价权、替代品威胁对客户价值链的压迫 |
| **SWOT** | 梳理我方 vs 竞品的 S/W/O/T | 将我方优势与客户机会匹配，制定攻坚突破口 |
| **VRIO** | 评估核心竞争力的不可替代性 | 从 Value(价值)、Rarity(稀缺)、Inimitability(难以模仿)、Organization(组织落地) 评估替换成本 |
| **SPAN** | 市场吸引力×竞争地位四象限矩阵 | 评估客户所在细分领域的投资回报前景 |
| **FAN** | 财务健康度与付酬能力评估 | 检查客户营收、毛利率、现金流与资产负债率 |
| **Gartner 曲线** | 技术成熟度阶段定位 | 定位客户关注的技术所处阶段（萌芽/过热/低谷/复苏/成熟） |
| **竞争雷达图** | 多维度可视化竞争对标 | 选定 6-8 个维度对我方与竞品进行打分对比 |
| **TAM/SAM/SOM** | 市场空间与需求潜力测算 | 计算总潜在市场 $\to$ 可服务市场 $\to$ 可获得市场 |

---

## 2. 工具-场景-维度三向映射表

| 客户洞察维度 | 最核心主工具 | 辅助分析工具 |
|-------------|-------------|-------------|
| **1. 业务全景研究** | 客户生意说明书框架 | **PEST** (宏观)、**波特五力** (行业)、**Gartner 曲线** (技术趋势)、**FAN** (财务)、**TAM/SAM/SOM** (市场) |
| **2. 决策链洞察** | UB/SP/TB/EB 四角色模型 | **马斯洛需求层次** (个人动机)、**沟通风格模型** (交互策略)、**关系五级评分** (信任度) |
| **3. 竞争格局分析** | 竞争雷达图 | **SWOT** (优劣势突破)、**$APPEALS 对标** (产品对标) |
| **4. 客户价值识别** | 三维评估体系 (付费/潜力/粘性) | **FAN** (付费能力)、**TAM/SAM/SOM** (潜力)、**VRIO** (替换粘性)、**SPAN** (机会筛选) |
| **5. 客户需求挖掘** | $APPEALS 八维度模型 | **四层需求模型** (显性$\to$生态)、**SPIN 提问法** (需求引导) |
