# Beta 与 Alpha Beta and Alpha

## 这是什么

**β**：资产收益对基准（常为市场）变动的敏感度。**α**：在给定定价/基准模型下，回归截距——风险调整后的平均超额。

口语“有没有 alpha”必须回答：**相对哪条基准、哪套模型、哪段样本、扣没扣费用**。无此四问的 alpha 是广告词。

## 什么时候用

- "这基金是真牛还是牛市带飞？"
- "我想加一点市场暴露 / 我想要纯 alpha"
- "alpha、beta 怎么区分？"

**不要**在以下情况套用本模型：

- 评价单位总波动报酬 → [夏普比率](../sharpe-ratio/SKILL.md)
- 设计整套均衡定价 → [CAPM](../capm/SKILL.md) / [三因子](../fama-french-three-factor/SKILL.md)

## 怎么用（执行步骤）

1. **指定基准与模型。** 市场指数？三因子？行业中性？写进一句话。
2. **估计 β（或因子载荷）与 α。** 报告置信区间；样本太短则标注不可靠。
3. **费用与杠杆标准化。** 毛 α、净 α 分列；杠杆会放大 β 也放大噪声。
4. **稳定性检查。** 分阶段回归：α/β 是否只在某一牛市成立？
5. **决策翻译。** 若只要市场暴露——低成本买 β；若声称 α——要求可重复流程与容量，否则降级为故事。

## 例证

**指数基金**：目标 β≈1、α≈0（扣费略负）。揭示大多数人需要的是**廉价 β**。

**高水位故事**：某策略牛市 α 高、熊市消失——可能是未建模的风险暴露。揭示模型设定决定 α 含义。

## 什么时候不适用（边界）

- **基准错误**：用错指数会制造假 α。
- **非线性/择时**：单期线性 β 不够。
- **容量为零的纸面 α**：无法规模化交易。

## 常见误用

- **"正收益=正 alpha"**：牛市里 β 就会带来正收益。
- **把运气样本当技能**：多重检验与费用后多数 α 消失。

## 相关模型

- **与[CAPM](../capm/SKILL.md)** / **[三因子](../fama-french-three-factor/SKILL.md)**：提供 α 的参照方程。
- **与[有效市场假说](../efficient-market-hypothesis/SKILL.md)**：稳定净 α 稀缺是 EMH 的实践表达。
- **与[夏普比率](../sharpe-ratio/SKILL.md)**：夏普不区分 β 来源；本模型做分解。
