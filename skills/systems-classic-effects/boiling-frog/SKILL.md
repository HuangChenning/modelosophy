# 温水煮青蛙 Boiling Frog（渐进麻木）

## 这是什么

**温水煮青蛙**：若威胁以足够缓慢的速度上升，当事人可能**持续适应新基线**而错过撤离窗口——用作组织与个人风险沟通的隐喻。

重要限制：真实青蛙在加热中往往会逃；该故事科学性存疑。本 Skill **只保留可操作内核**：缓变 + 基线漂移 + 警报阈值失效。不要当生物学事实引用。

## 什么时候用

- "指标一年差 1% 没人喊停"
- "文化一点点变坏"
- "债务/体重/延迟缓慢爬升"

**不要**当主模型：
- 突发极端冲击 → [`black-swan`](../black-swan/SKILL.md)
- 明显高概率大风险被无视 → [`gray-rhino`](../gray-rhino/SKILL.md)
- 小失序信号放任 → [`broken-windows`](../broken-windows/SKILL.md)

## 怎么用（执行步骤）

1. **选定慢变量。** 必须可测：逾期率、NPS、负债率、响应时长——禁止纯感觉。
2. **固定历史基线。** 用 12–36 个月前的水平作对照，对抗“新常态”漂移。
3. **设硬阈值与采样节奏。** 例如每季强制回顾：触发阈值则升级决策，不靠日常体感。
4. **做“突然看见”实验。** 把慢变压缩成图表或对外对标，检查是否仍觉得可接受。
5. **预写撤离/纠偏动作。** 阈值触发后执行什么（涨价、止损、重组）——事先写好，防当场再适应。

## 例证

**技术债缓慢堆积**：每次“先这样”可接受，两年后交付崩溃。揭示**基线漂移**。

**客户满意度季降 0.5**：无单季危机，数年流失。揭示慢变量需要硬阈值。

**隐喻本身**：科普常引用但实验不成立——揭示**故事有效、事实需标注**。

## 什么时候不适用（边界）

- **阶跃冲击**：突然监管/事故，不是煮青蛙。
- **已有尖叫声的灰犀牛**：问题已被多人指出仍不动，机制是忽视/政治，不只是感觉适应。
- **健康适应**：对噪音等刺激的正常习惯化，未必是风险。

## 常见误用

- **当生物事实**：写进报告称青蛙会被煮死 → 改为“渐变麻木隐喻”。
- **恐吓万能**：任何拖延都叫煮青蛙 → 要有慢变量证据。
- **与灰犀牛混用**：灰犀牛强调明知故延；青蛙强调未察觉。

## 相关模型

- **与[灰犀牛](../gray-rhino/SKILL.md)**：灰犀牛=可见却拖；青蛙=慢到没看见。
- **与[破窗效应](../broken-windows/SKILL.md)**：破窗是失序信号；青蛙是阈值麻木。
- **与[系统动力学](../system-dynamics/SKILL.md)**：慢变量与延迟是系统动力学语言。
