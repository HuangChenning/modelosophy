# SCQA 结构化叙事框架 (scqa-framework)

## 这是什么

SCQA 结构化叙事框架由麦肯锡顾问芭芭拉·明托在《金字塔原理》中提出，是一种风靡全球的商务沟通、汇报与写作开场模型。通过引入**情境 (Situation)、冲突 (Complication)、问题 (Question)、解答 (Answer)** 四个逻辑要素，模拟人类天然喜爱的“讲故事”逻辑，快速吸引注意力并建立共识。

---

## 什么时候用

- 当需要为商务演示、PPT 汇报、产品发布会设计吸睛开场时。
- 当需要撰写具有说服力的商业建议书、项目立项报告或邮件时。
- 当需要向领导或客户推介新方案，需先唤起对方对痛点/风险的关注时。

---

## 怎么用

### 1. 四大核心要素解析

```
[S 情境 (Situation)] ──> [C 冲突 (Complication)] ──> [Q 问题 (Question)] ──> [A 解答 (Answer)]
 (建立共同已知背景)       (引入变数/痛点/矛盾)       (引出核心关切疑问)       (给出结论与方案)
```

- **S (Situation) 情境**：陈述大家熟知、无争议的背景或现状，建立沟通的安全区与共同认知。
- **C (Complication) 冲突**：引入打破现状稳定平衡的变数、障碍或痛点，制造悬念与认知张力。
- **Q (Question) 问题**：基于冲突提炼出最核心的疑问——“面对这一冲突，我们该怎么办？”
- **A (Answer) 解答**：抛出你的核心结论、方案或行动建议。

---

### 2. 四大灵活变体模式

根据沟通对象与场景偏好，灵活调整四要素的排列顺序：

| 模式 | 排序 | 核心特点与适用场景 |
|------|------|───────────────────|
| **标准式 (讲故事)** | **S - C - Q - A** | **循序渐进**：适合公开演讲、文章写作、引导听众逐步进入语境。 |
| **开门见山式 (看效率)** | **A - S - C - Q** | **结论先行**：适合向上级高管汇报，先给结论满足效率要求（配合金字塔原理）。 |
| **突出忧虑式 (拉警报)** | **C - S - A - Q** | **痛点驱动**：适合危机公关、说服变革，先抛出严重风险激发危机感。 |
| **突出信心式 (聚人心)** | **Q - S - C - A** | **挑战驱动**：适合团队动员、誓师大会，先抛出重大挑战激发团队必胜信心。 |

---

## 例证

- **标准式 (S-C-Q-A) 示例（项目立项汇报）**：
  - **S (情境)**：“过去 3 年，我们公司的线上电商业务保持了 30% 的稳定年增长。”
  - **C (冲突)**：“然而从上个季度开始，获客成本大幅上升 50%，导致整体净利润率首次出现亏损。”
  - **Q (问题)**：“如何在不增加营销预算的前提下，扭转利润下滑并提升老客复购率？”
  - **A (解答)**：“我们建议全面启动私域流量运营与会员忠诚度计划，预计可降低 35% 的获客成本。”

---

## 什么时候不适用

- **纯技术代码/数学公式推导**：纯逻辑推导或物理原理说明无需套用故事冲突，直接陈述公式与逻辑即可。
- **紧急危机抢险处置**：当发生重大安全生产故障时，必须直接发布明确指令，禁止使用 S-C-Q-A 进行慢吞吞的故事铺垫。

---

## 常见误用

- **误用 1：把 S (情境) 写得太长太复杂**
  - *纠正*：S 的作用仅仅是建立共识基准。如果 S 写得太啰嗦，听众会失去耐性。S 必须是简洁且对方无可争议的事实。
- **误用 2：缺乏真实的 C (冲突)**
  - *纠正*：没有冲突就没有戏剧张力。如果只说“现状很好 (S)，我们要继续努力 (A)”，这就退化成了平淡的流水账，无法引发关注。
- **误用 3：Q (问题) 与 A (解答) 张冠李戴**
  - *纠正*：Q 必须紧扣 C 引发的核心矛盾；A 必须直接回答 Q，不能答非所问。

---

## 边界条件

- SCQA 属于沟通表达与叙事开场结构，不替代具体的分析诊断工具（如 SWOT、五力）。
- 在开门见山式 (A-S-C-Q) 中，A 必须高度精炼，切忌在开头抛出一个模糊含混的回答。
