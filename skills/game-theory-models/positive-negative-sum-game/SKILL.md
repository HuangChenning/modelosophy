# 正和与负和博弈 Positive- / Negative-Sum Game

## 这是什么

**正和：互动可创造净增量；负和：对抗消耗使总量变小。**

相对零和：正和强调互利盈余（贸易、协作研发）；负和强调战争、恶性价格战、诉讼消耗等“双输变小”。定性服务策略选择：做大蛋糕、止损退出或改规则，而非默认你死我活。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "能不能做成正和"
- "这是不是两败俱伤的负和"
- "合作能否创造增量"

**不要**在以下情况套用本模型：

- 严格支付和为常数 → ../zero-sum-game/SKILL.md
- 结构是囚徒式背叛占优 → ../prisoners-dilemma/SKILL.md
- 投资再平衡纪律 → 非本分类（finance）

## 怎么用（执行步骤）

1. **定义“总量”指标。** 利润之和、剩余、安全、时间——先钉度量，禁止空喊正负和。
2. **比较互动前后总量。** 可增 → 正和空间；必耗且无创造 → 负和风险；近似不变 → 常/零和。
3. **拆解创造与分配。** 正和仍要分蛋糕（合作博弈/夏普利）；负和优先停损或改支付。
4. **输出。** 正/负/零和判定 + 下一步：创造、分配或退出。

## 例证

**贸易创造剩余**：双方估值不同交换后剩余上升。揭示正和来自互补而非口号。

**恶性诉讼/价格战**：法律费与利润蒸发使行业剩余下降。揭示负和要先停火机制。

## 什么时候不适用（边界）

- **口号正和**：无度量的“共赢”无效。
- **分配冲突**：总量正和时局部仍可零和争夺。

## 常见误用

- **用正和掩盖剥削**：增量存在仍可能分配极不公；需另做分配分析。
- **把一切竞争当负和**：竞争可扩大创新正和。

## 相关模型

- **与[零和博弈](../zero-sum-game/SKILL.md)**：和为常数走对方。
- **与[合作博弈与联盟](../cooperative-games/SKILL.md)**：正和如何分走对方。

## 记忆钩子

先问总量变大、变小还是不变。
