# 价值效应 Value Premium

## 这是什么

**价值效应 / 价值溢价**：按低估值指标排序的组合，长期平均往往优于高估值组合（经典与 HML 相关）。解释分裂为**风险补偿**（廉价者更惨）与**行为错误定价**（过度外推成长）。存在长时段失效与回撤。

## 什么时候用

- "买便宜货长期是不是有优势？"
- "价值因子还有没有用？"
- "价值效应是什么？"

**不要**在以下情况套用本模型：

- 单只股票倍数解读流程 → [市盈率市净率](../pe-pb-valuation/SKILL.md)
- 三因子回归技术细节 → [Fama-French 三因子](../fama-french-three-factor/SKILL.md)

## 怎么用（执行步骤）

1. **选定价值指标。** E/P、B/P、EV/EBITDA 等；行业中性与否。
2. **看长期溢价与回撤。** 平均正不等于路径舒服；写出最长水下期。
3. **过滤陷阱。** 盈利操纵、永久衰退、高杠杆濒死——低倍数不是票。
4. **对照拥挤与体制。** 利率、成长霸权期价值可能长期落后。
5. **组合表达。** 若采纳，用规则化敞口+再平衡，而非故事选股口号。

## 例证

**经典 HML 溢价**：长期存在但 2010 年代部分市场艰难。揭示溢价有**时代风险**。

**价值陷阱煤企/银行**：低 PB 伴随坏账。揭示便宜的原因可能是正确定价的风险。

## 什么时候不适用（边界）

- **会计账面无意义的商业模式**。
- **强制短窗口考核**：价值策略常需要时间。

## 常见误用

- **"价值投资=买低 PE"**：忽略质量与陷阱。
- **用三年跑输宣判价值死亡**。

## 相关模型

- **与[市盈率市净率](../pe-pb-valuation/SKILL.md)**：指标工具层。
- **与[Fama-French 三因子](../fama-french-three-factor/SKILL.md)**：HML 建模层。
- **与[动量与反转](../momentum-reversal/SKILL.md)**：可与价值组成多空风格。

## 记忆钩子
