# 拍卖理论 Auction Theory

## 这是什么

**不同拍卖规则（英式、荷式、密封一价/二价等）改变出价策略与卖家收益。**

Vickrey 二价密封：真实报价是弱优势；一价密封需遮掩（bid shading）；收益等价在理想条件下成立，现实有风险厌恶、关联价值、合谋等破裂点。链接机制设计。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "这种拍卖怎么出价"
- "二价是不是说实话"
- "拍卖规则选哪种"

**不要**在以下情况套用本模型：

- 稳定匹配算法 → ../matching-theory/SKILL.md
- 一般激励兼容机制 → ../mechanism-design/SKILL.md
- 零和最小最大 → ../minimax-theorem/SKILL.md

## 怎么用（执行步骤）

1. **识别拍卖格式。** 公开升价/降价、密封一价/二价、是否有保留价。
2. **写价值模型。** 私有价值还是共同/关联价值？风险态度？
3. **给策略启发式。** 二价→如实；一价→按对手人数与信念遮掩；英式→呆至价值。
4. **标失灵。** 合谋、赢家诅咒、保留价过高。输出：格式 + 出价原则 + 风险。

## 例证

**Vickrey 贴纸**：二价密封真实报价优势。揭示规则可对齐诚实。

**频谱/网络广告拍卖**：格式影响收入与效率。揭示机制选择。

## 什么时候不适用（边界）

- **合谋与欺诈**：不协助围标。
- **共同价值**：赢家诅咒需信息调整。

## 常见误用

- **所有拍卖都说实话**：仅特定格式。
- **忽略保留价与入口规则**：策略随规则变。

## 相关模型

- **与[机制设计](../mechanism-design/SKILL.md)**：更一般的逆向设计。
- **与[贝叶斯博弈](../bayesian-games/SKILL.md)**：估值私有信息基础。
