# 最近发展区 ZPD

## 这是什么

**最近发展区（ZPD）**：学习者独立解决问题的水平，与在更有能力者（老师、同伴、工具）帮助下能达到的水平之间的差距。教学应落在这一带：太易无成长，太难即使有帮助也无效。

配套概念是**支架（scaffolding）**：临时支持（提示、示范、分解），随能力提升而撤除。ZPD 回答「难度与帮助放哪」；刻意练习回答「如何对弱点做有反馈训练」。

## 什么时候用

- "教别人/自学时难度总不对"
- "最近发展区 / ZPD / 支架教学"
- 辅导、带新人、课程设计、家长辅导作业

**不要**当主模型：

- 只要专注体验匹配 → [`flow`](../flow/SKILL.md)
- 只要训练块与反馈设计 → [`deliberate-practice`](../deliberate-practice/SKILL.md)
- 只要记忆间隔 → [`spaced-repetition`](../spaced-repetition/SKILL.md)

## 怎么用（执行步骤）

1. **测独立水平。** 给一个代表性任务，观察无帮助下能完成到哪。记录「独立成功边界」。
2. **试探辅助成功边界。** 提供最小帮助（一个提示/半成品模板），看能否完成更难任务。两者之间即 ZPD 候选。
3. **把学习目标放进 ZPD。** 目标应：独立做不到，但有支架后多数步骤能走通。判据：错误可纠正而非全面崩溃。
4. **设计可撤支架。** 从高支架（示范）→ 中（提示清单）→ 低（仅检查点）→ 无。写明撤除条件（连续两次独立成功）。
5. **观察情感与认知负荷。** 持续恐慌或放弃 → 降难或加支架；持续无聊 → 升难或撤支架。
6. **迁移检验。** 换同类新题，无支架是否仍能？不能则支架撤太早或目标超 ZPD。

## 例证

**数学辅导**：孩子独立只会计算题；给「先画图」支架后能解应用题——揭示任务落在 ZPD；直接丢奥题则超出。

**新人 code review**：结对写第一周，第二周只审设计，第三周独立——揭示**渐撤支架**。

**（局限）**：ZPD 难精确测量；文化与动机影响「有帮助时能否做」——需迭代试探而非一次定终身。

## 什么时候不适用（边界）

- **无互动、无支架资源**：纯自学且无材料分解时，先造外部支架（例题、清单）。
- **高危任务不容错**：医疗手术等不能靠「试探 ZPD」；用模拟与认证路径。
- **只要心流爽感**：ZPD 可为心流创造条件，但目标是发展而非体验。

## 常见误用

- **永远高支架**：代做导致学不会 → 必须计划撤除。
- **与心流混用**：只调「爽」不测独立边界 → 先测三带。
- **一次测验定终身**：ZPD 随学习移动，需再测。
- **把失败全怪学生**：可能是任务超 ZPD 或支架错型。

## 相关模型

- **与[心流](../flow/SKILL.md)**：心流≈挑战与技能匹配的体验；ZPD≈发展带与支架。要体验走心流；要教学难度走 ZPD。
- **与[刻意练习](../deliberate-practice/SKILL.md)**：ZPD 选难度带；刻意练习设计反馈训练。常连用。
- **与[元认知](../metacognition/SKILL.md)**：学习者自判「卡在哪」可辅助定位 ZPD。
- **与[成长型思维](../growth-mindset/SKILL.md)**：信念支持挑战；ZPD 提供恰难任务。

## 记忆钩子
