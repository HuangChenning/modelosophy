# 幸存者偏差 Survivorship Bias

## 这是什么

幸存者偏差是一种选择偏差：当你只观察经过某种筛选后仍然可见的个体，并据此推断总体或因果，就会系统性地**忽略被筛掉的那一部分**。失败者、退市公司、坠毁的飞机、没出版的稿件——它们本应进入分母，却从样本里消失了。

经典结构：看见幸存过程 B 的个体 A 都有特质 C，就推断“要幸存必须有 C”——同时忽略有 C 却未幸存、以及无 C 却因别的原因幸存的案例。

它与易得性启发常结伴：幸存者更容易被报道、被写成书，因而更好想起来；但机制上，本模型盯的是**样本如何被生成**，易得性盯的是**记忆如何被提取**。

## 什么时候用

- 从成功明星/基金/公司清单倒推“必胜方法”；
- 用仍存在的公司的历史回报代表策略期望；
- 只访谈在职员工或毕业校友做结论；
- 用户直接担心幸存者偏差。

**不要**当主模型：
- 主要问题是新闻生动导致高估频率（易得性启发）；
- 按已有信念只点开支持文章（确认性偏差）；
- 需要算互斥选项代价（机会成本）。

## 怎么用（执行步骤）

1. **说出筛选机制。** 谁会进入你的视野？上市、出版、存活 N 年、媒体报道、自愿接受访谈……写清“进不了样本的条件”。
2. **补分母：失败与未入选在哪。** 尽量找：退市与破产名单、同起点队列的随访、尝试者总数、基准率。没有完整名单时，至少给出“不可见部分可能有多大”的区间，并降低因果断言强度。
3. **区分相关与因果。** 幸存者共有的特质可能是结果而非原因（富者更易被报道为勤奋）。问：在失败组里，该特质是否同样普遍？若不知道，禁止当处方。
4. **修正指标。** 基金业绩用存活基金平均会高估；改用含已关闭基金的数据集，或明确声明“条件于仍存活”。创业建议同样要条件于“在已成功者中”。
5. **保留可用信息，收窄结论。** 案例仍可用于产生假说与机制直觉；输出应改成“在幸存者中常见，是否必要未知”或“需对照失败组验证”，而不是“所以你也必须……”。

## 例证

**Wald 与返航飞机弹孔（二战研究传统）**：返航飞机弹孔集中的部位，直觉是加强那里；正确思路是：能带着这些弹孔飞回，说明那些部位非致命，更该补强的是**弹孔很少的部位**——因为击中那里的飞机往往没回来。揭示的是：可见损伤分布被幸存条件扭曲。

**基金与指数**：只统计仍开放的基金过去十年收益，会抬高主动管理的表观表现；纳入已清算基金后优势常缩小或消失。揭示“平均成功”取决于是否包含死者。

**退学创业神话**：从少数退学成功者推断“退学可取”，忽略同龄退学失败者与未退学成功者。分母缺失使故事有激励性、无推断效力。

**（原书卡片）筛选机制示意图**：结构清楚。勿推向“凡成功经验皆无价值”——偏差纠正是补样本与降因果强度，不是虚无主义。

## 什么时候不适用（边界）

- **样本近乎全覆盖**：若队列随访完整，不是幸存者偏差问题。
- **问题本就条件于幸存**：例如“已上市的公司如何做投资者关系”——总体是幸存者，问的就是条件问题；仍要防把条件结论推广到创业全体。
- **与随机噪声混淆**：一次失败不是“被筛选掉的真相”，需要机制与规模。

## 相关模型

- **与[易得性启发](../availability-heuristic/SKILL.md)**：易得性管“好不好想起来”；本模型管“样本缺了谁”。常先补分母，再谈媒体曝光。
- **与[确认性偏差](../confirmation-bias/SKILL.md)**：确认偏差是主动筛证据；幸存者偏差可以在无动机时仍发生——世界替你筛了。
- **与[复利](../compounding/SKILL.md)**：成功学故事里的“长期坚持”常抽掉破产路径；谈复利必须同时谈存活与负复利。
- **与[奥卡姆剃刀](../occams-razor/SKILL.md)**：从残缺样本归纳的“简单成功法则”往往是特设故事，优先降级验证。
