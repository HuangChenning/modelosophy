# 利基战略 Niche Strategy

## 这是什么

**利基战略（集中战略）**：把竞争范围**故意收窄**到特定客群、产品线或地理市场，并在该窄范围内追求**成本优势或差异化**（焦点成本 / 焦点差异），用专注换取在利基内的优越地位，同时**显式放弃**服务「所有人」。

对应波特通用战略中的 **Focus**。与「定位」不同：利基先选**战场边界**；定位再解决心智格子。与「差异化/成本领先」不同：后两者默认在**广阔市场**竞争。

## 什么时候用

- "我们做小而美细分 / 垂直行业"
- "利基 / 集中化 / 不要全国铺开"
- 资源不足以支撑全市场战略

**不要**当主模型：

- 全市场低成本 → [`cost-leadership`](../cost-leadership/SKILL.md)
- 全市场可感知差异 → [`differentiation-strategy`](../differentiation-strategy/SKILL.md)
- 只谈心智句不谈市场边界 → [`positioning`](../positioning/SKILL.md)
- 战略钟上的混合价位路径 → [`strategic-clock`](../strategic-clock/SKILL.md)

## 怎么用（执行步骤）

1. **定义利基边界。** 客群/场景/地域/规格何者收窄。判据：边界可用纳入/排除规则写出。
2. **验证利基经济性。** 规模是否撑起成本结构；顾客是否有独特需求愿付。判据：有粗算 TAM/可达份额与单位经济；「情怀利基」标风险。
3. **选择焦点类型。** 焦点成本或焦点差异（或二者在窄市场的具体组合）。判据：写清相对利基内对手的优势机制。
4. **设计放弃清单。** 不接哪些客户、不做哪些功能、不去哪些渠道。判据：放弃清单为空 = 假利基。
5. **设扩大诱惑的闸门。** 何时可相邻扩展（常连安索夫），何时禁止。判据：有扩展准则与否决权。
6. **监控利基被入侵或消失。** 大公司降维、需求主流化。判据：有预警指标。

## 例证

**垂直行业软件**：放弃通用市场，做深合规与工作流——揭示焦点差异在窄市场的回报。

**假利基**：自称细分却接所有标讯 ——揭示无放弃清单则被拖回全面战争。

**利基被主流化**：小众需求变大众后焦点成本被巨头碾压——揭示利基有生命周期。

## 什么时候不适用（边界）

- **利基过小无法生存**：先验证经济性或换战场。
- **监管要求普遍服务**：无法合法放弃。
- **平台需要密度**：过度收窄会杀网络效应 → 平台战略优先。

## 常见误用

- **利基=没野心**：利基是范围选择，仍要竞争优势。
- **与定位混用**：先边界后心智。
- **偷偷扩大范围**：侵蚀焦点 → 用闸门。
- **忽略利基内竞争**：窄市场仍可能红海。

## 相关模型

- **与[差异化战略](../differentiation-strategy/SKILL.md)**：全市场差异 vs 利基内差异。
- **与[成本领先](../cost-leadership/SKILL.md)**：全市场成本 vs 利基内成本。
- **与[定位](../positioning/SKILL.md)**：利基选战场；定位占心智。
- **与[战略钟](../strategic-clock/SKILL.md)**：战略钟看性价比路径；利基先锁范围。

## 记忆钩子

利基 = **故意变窄 + 放弃清单**——窄不是目的，在窄处建立可防守优势才是。
