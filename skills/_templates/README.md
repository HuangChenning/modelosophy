# Skill 正文模板（Phase 0 · 已锁定）

本目录存放**可执行思维模型 / 经济学域 Skill** 的正文模板，供新建 Batch 时复制，**不是**可被 Agent 触发的 Skill（文件名刻意不用 `SKILL.md`）。

| 文件 | 用途 |
|---|---|
| [`EXECUTABLE_SKILL.md`](EXECUTABLE_SKILL.md) | 锁定章节结构 + frontmatter 占位 |

**适用范围**：`thinking-models/` 与六个学科分类（`econ-*` / `behavioral-biases` / `finance-investing-models` / `game-theory-models` / `systems-classic-effects`）下的新建可执行 Skill。

**不适用**：`business/org-it-intel-report` 等带脚本/报告产物的调研 Skill（沿用其既有结构）。

## 锁定章节（顺序固定）

| # | 章节 | 必填 | 说明 |
|---|---|---|---|
| — | YAML frontmatter | 是 | `name` / `description`（中英触发 + 排除）/ `metadata.version`（新建用 `v0.x-draft`） |
| 1 | `# 中文名 English` | 是 | 标题 |
| 2 | `## 这是什么` | 是 | 定义 + 机制 + 提出者 |
| 3 | `## 什么时候用` | 是 | 触发 + **不要**套用 |
| 4 | `## 怎么用（执行步骤）` | 是 | 可操作判据，禁止空转表述 |
| 5 | `## 例证` | 是 | ≥1 个有信息量案例；原书卡片若有则垫底并标局限 |
| 6 | `## 什么时候不适用（边界）` | 是 | 失效条件 |
| 7 | `## 常见误用` | **推荐** | 新建优先独立成节；可与边界合并但不得空 |
| 8 | `## 相关模型` | 是 | 只链真实路径 + 区分判据 |
| 9 | `## 记忆钩子` | 可选 | 一句口诀；无把握可删整节 |

## 原「9 字段知识卡」→ 如何吸收

废弃知识卡作为主交付；有用信息写入上表章节，**不另建卡文件**：

| 原字段 | 吸收位置 | 强度 |
|---|---|---|
| 名称 | 标题 + `name` | 必填 |
| 提出者 | 「这是什么」或 `metadata.source` | 必填 |
| 一句话定义 | 「这是什么」段首（≤30 字为宜） | 必填 |
| 原理机制 | 「这是什么」随后 2–4 句 | 必填 |
| 经典案例 | 「例证」 | 必填（可与现实应用共节） |
| 现实应用 | 「例证」 | 推荐 ≥1 |
| 常见误用 | 「常见误用」（或并入边界） | **推荐非空** |
| 相关概念 | 「相关模型」 | 必填 |
| 记忆钩子 | 「记忆钩子」 | 可选 |

## 定稿前自检（苏格拉底式 · 摘要）

1. 定义推到极端会否荒谬？
2. 每步是否有可操作判据？
3. 边界是否被步骤偷偷违反？
4. 同一术语是否偷换？
5. 与兄弟 Skill 是否误触发？「相关模型」是否写清分流？

完整约束见仓库 `CLAUDE.md`（本机）与根目录 [`ROADMAP.md`](../../ROADMAP.md)。

## 复制步骤

1. 在目标分类下新建 `skills/<category>/<slug>/`
2. 复制 `EXECUTABLE_SKILL.md` → `SKILL.md`，填空并删除 `{{...}}` 占位
3. 研究审计写本机 `docs/books/<slug>/`（不进 GitHub）
4. 后处理：`evals/` + `quick_validate`；更新该分类 `README.md` 列表
