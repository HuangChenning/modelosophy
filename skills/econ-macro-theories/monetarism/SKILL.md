# 货币主义 Monetarism

## 这是什么

**通胀归根结底是货币现象；政策宜规则化，少搞相机刺激。**

提出者/源流：Milton Friedman 等（芝加哥学派，1950s–70s）。长期中货币中性：多发货币主要抬名义量（物价），难抬真实产出。短期有影响，但时滞长且不稳定，故弗里德曼主张稳定货币增长规则，反对「微调」。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "「通胀会不会是印太多钱」"
- "「央行该不该定规则而不是每次开会拍脑袋」"
- "「滞胀时需求刺激为何失败」"

**不要**在以下情况套用本模型：

- 短期流动性危机的紧急注资（如金融危机）——可与金融稳定工具配合，勿教条拒绝一切流动性
- 纯财政政策乘数争论主战场在凯派/乘数，不在本模型

## 怎么用（执行步骤）

每一步给出可操作判据；禁止只换说法重复结论。

1. **分离名义与真实。** 写出：观察到的是 CPI/名义 GDP 飙升，还是真实产出崩溃？货币主义主攻名义锚。
2. **追踪广义货币与信用。** 看 M2/信用扩张是否显著领先通胀；同时记录供给冲击（避免单因子归因）。
3. **评估政策规则 vs 相机抉择。** 现行框架是通胀目标/泰勒型规则，还是频繁「营救式」转向？列出时滞风险。
4. **给处方边界。** 若货币过快：收紧路径 + 沟通锚；若真实供给冲击：避免只靠货币「制造繁荣」。输出：货币因素权重 / 非货币因素。

## 例证

**弗里德曼—施瓦茨《美国货币史》**：揭示大萧条中货币收缩的角色，挑战「只怪实体」叙事。

**1970s 滞胀**：揭示凯派需求微调在通胀预期抬头时失灵，推高货币主义影响力。

**Volcker 紧缩**：揭示压通胀需可信的货币紧缩，成本是短期失业。

## 什么时候不适用（边界）

- **金融创新改变货币定义**：影子银行使「哪个 M」难盯——规则要随制度更新。
- **零利率下限**：传统货币数量渠道受阻时可谈非常规工具，但仍要通胀锚。

## 常见误用

- **一切通胀只怪央行**：忽视战争/疫情供给冲击 → 双因子记账。
- **把货币中性当成短期也中性**：短期真实效应存在；勿否认周期稳定职能。

## 相关模型

- **与[费雪方程](../fisher-equation/SKILL.md)**：MV=PQ 是货币数量论教学骨架；货币主义是其政策化。
- **与[菲利普斯曲线](../phillips-curve/SKILL.md)**：货币主义强调长期垂直菲利普斯曲线（自然率）。
- **与[泰勒规则](../taylor-rule/SKILL.md)**：现代规则型政策的操作化亲戚。
- **与[凯恩斯主义](../keynesianism/SKILL.md)**：短期需求管理 vs 长期货币锚——先看通胀与预期。
- **与[购买力平价](../purchasing-power-parity/SKILL.md)**：长期货币—物价。
- **与[现代货币理论](../modern-monetary-theory/SKILL.md)**：强调货币/名义锚；与 MMT 冲突点在通胀机制与制度。
