# 情境领导 Situational Leadership

## 这是什么

情境领导：有效领导行为随下属在**某一具体任务**上的准备度而变，而不是固定“强势/放权”人格。准备度粗分为：

| 准备度 | 典型状态 | 匹配风格 |
|---|---|---|
| D1 | 低能力 × 高意愿（新手兴奋） | **S1 指令**：高指令、低支持，讲清做什么/怎么做 |
| D2 | 低–部分能力 × 低意愿（受挫） | **S2 教练**：高指令、高支持，既教又鼓 |
| D3 | 中高能力 × 变动意愿（能干但犹豫） | **S3 支持**：低指令、高支持，共商、倾听、鼓励自主 |
| D4 | 高能力 × 高意愿 | **S4 授权**：低指令、低支持，目标清晰后放手 |

“指令”= 任务行为（结构、标准、时限）；“支持”= 关系行为（倾听、鼓励、共同决策）。准备度会随任务变：同一人做报表可能是 D4，做演讲可能是 D1——**按任务评，不按人贴永久标签**。

## 什么时候用

- 带人：不知该手把手还是该授权；
- 复盘“我放权了但事情掉地上 / 我管太死对方没成长”；
- 用户直接说情境领导 / D1–D4 / S1–S4。

**不要**当主模型：
- 个人微习惯发生与否 → [`fogg-behavior-model`](../fogg-behavior-model/SKILL.md)；
- 组织文化深层假设 → [`iceberg-model`](../../systems-complexity/iceberg-model/SKILL.md)；
- 需求层级动机理论全文 → [`maslow-hierarchy`](../maslow-hierarchy/SKILL.md)。

## 怎么用（执行步骤）

1. **钉住任务，不钉住人格。** 写清“哪一件交付/哪一种场景”。禁止“他就是 D2 型人”。
2. **分评能力与意愿。** 能力：会不会做（知识、技能、经验）；意愿：想不想做/有无信心。两边都要有证据，不靠印象。
3. **映射到 D 再选 S。** 用上表；若证据不足，先小范围试探（观察一次尝试）再定，避免一次定终身。
4. **执行风格时保持可逆。** 准备度上升则减指令、调支持；回落（新工具、新标准）则临时加回 S1/S2。风格是状态机，不是人设。
5. **输出约定，不输出性格鉴定。** “对本任务：当前按 S2——每日卡点检查 + 结对教一步；两周后按演示结果再评 D。”

## 例证

**新销售打陌生电话**：产品知识不足但冲劲足 → D1 → S1：话术脚本、每日通话量、当场纠错。若直接 S4“你看着办”，失败率高——揭示**意愿高不能代替能力**。

**老手拒绝新 CRM**：会业务但抵制工具（能力尚可、意愿低）→ 偏 D2/D3 交界 → 需要高支持说明收益与参与设计，单靠 S1 压服易表面合规。揭示意愿问题不能只加指令。

**（原书卡片）D1–D4 与 S1–S4 象限**：映射方向正确；局限是易背成口号“灵活领导”，未强调任务特异性与准备度可变，也未警告把 D 当人格标签。

## 什么时候不适用（边界）

- **合规/安全红线**：高风险操作不能因“培养意愿”而放开 S4。
- **制度与激励失灵**：编制不足、指标扭曲时，先改系统，勿只调领导口吻。
- **临床/病理**：不把低意愿诊断成精神问题。
- **一对多极端异质**：大团队需分层或流程化，不能幻想一人对每人实时完美 S 切换。

## 相关模型

- **与[福格行为模型](../fogg-behavior-model/SKILL.md)**：福格管行为 MAP；情境领导管督导强度与准备度匹配。
- **与[马斯洛需求层次](../maslow-hierarchy/SKILL.md)**：可解释部分意愿来源，但不替代 D/S 任务诊断。
- **与[周哈里窗](../johari-window/SKILL.md)**：反馈盲区工具；本模型是任务督导风格选择。
- **与[PDCA](../../efficiency-execution/pdca/SKILL.md)**：准备度与风格应进入检查—调整圈，避免一次定型。
