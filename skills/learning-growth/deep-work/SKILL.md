# 深度工作 Deep Work

## 这是什么

**深度工作**：在无干扰状态下，对认知要求高的任务进行专注执行，以更高效率产出难复制的价值。相对概念是浅层工作（邮件、碎片协调、低认知切换）。

Newport 强调：深度能力稀缺且可训练；关键不是「感觉忙」，而是**保护连续专注块**并减少注意力残差（attention residue）。本 Skill 交付日程与环境规程；任务内容仍由目标/刻意练习定义。

**归属**：学习成长主条；[`efficiency-execution`](../../efficiency-execution/README.md) 只互链本路径。

## 什么时候用

- "总被消息打断，写不完/想不深"
- "深度工作 / deep work / 专注块怎么排"
- 研究、写作、架构设计、复杂分析等需要连续认知的任务

**不要**当主模型：

- 只要短时专注番茄计时 → [`pomodoro`](../../efficiency-execution/pomodoro/SKILL.md)
- 只要任务收集与下一步行动 → [`gtd`](../../efficiency-execution/gtd/SKILL.md)
- 紧急重要分流 → [`eisenhower-matrix`](../../efficiency-execution/eisenhower-matrix/SKILL.md)
- 练习内容设计 → [`deliberate-practice`](../deliberate-practice/SKILL.md)

## 怎么用（执行步骤）

1. **选出唯一深度任务。** 写成可完成的认知产出（「完成第 2 节论证草稿」），禁止「处理一下工作」。判据：结束后有可展示物。
2. **锁定连续块（建议 60–90 分钟起）。** 在日历标忙；块内目标只有这一项。短于 25 分钟的碎片不算深度块。
3. **清除干扰源。** 通知静音、关闭非必要标签页、告知同事「块结束前勿扰」。判据：块内切换次数是否可数且接近 0。
4. **开工仪式与收工记录。** 开始写「本块成功标准」；结束写「完成了什么/残留什么」。降低注意力残差。
5. **用节奏策略之一。** 禁欲式（固定深度日程）、双峰式（上下午各一块）、节奏式（每天固定时段）或新闻记者式（见缝插针但有仪式）——选一种坚持两周再调。
6. **量化浅层配额。** 给邮件/会议设批次窗口，避免全天渗透。判据：深度小时/周是否可统计。

## 例证

**研究写作**：关网 90 分钟只写一节——揭示**连续块**比「整天挂在文档上」更有效。

**程序员上下文切换**：会议碎片化导致残差；改为上午深度编码、下午通信——揭示浅层工作需批次化。

**（局限）**：护理、现场应急等角色无法长时隔离；应改「微深度」或岗位设计，而非道德指责。

## 什么时候不适用（边界）

- **工作本质是协调/响应**：深度块比例应下调，改 GTD/看板流。
- **任务未定义**：先澄清产出，再深度——否则专注于空转。
- **耗竭与睡眠债**：强制深度会降质；先恢复。
- **只需计时器习惯**：番茄可作为进入仪式，但深度工作看块长度与干扰，不看铃响次数。

## 常见误用

- **伪深度**：戴耳机仍刷聊天 → 以切换次数为准。
- **把忙碌当深度**：会议填满日历 → 统计真正无扰块。
- **与番茄等同**：25 分钟响铃≠深度工作定义。
- **忽视任务难度**：简单行政活塞进深度块 → 浪费稀缺注意力。

## 相关模型

- **与[番茄工作法](../../efficiency-execution/pomodoro/SKILL.md)**：番茄管短周期计时与休息；深度工作管无扰高认知块。要计时习惯走番茄；要保护长专注走本模型（可连用番茄作热身）。
- **与[心流](../flow/SKILL.md)**：心流是体验状态；深度工作是环境与日程设计。可互相促进。
- **与[刻意练习](../deliberate-practice/SKILL.md)**：深度块提供时间容器；刻意练习填充训练内容。
- **与[艾森豪威尔矩阵](../../efficiency-execution/eisenhower-matrix/SKILL.md)**：先分流重要不紧急，再放入深度块。
- **与[GTD](../../efficiency-execution/gtd/SKILL.md)**：GTD 清空与下一步；深度工作执行高认知下一步。

## 记忆钩子

难而有价值的活，配**无扰连续块**——不是更忙，是更少切换。
