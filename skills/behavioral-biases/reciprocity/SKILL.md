# 互惠原理 Reciprocity Principle

## 这是什么

**人们收到好处后，常感到有义务回报，即使好处是不请自来或不等价。**

赠品推销、免费咨询后强推大单、帮小忙再提大要求（互惠式让步）都利用此压力。互惠是社会润滑剂，也被用作顺从技术。

## 什么时候用

- 感觉“欠了人情必须买”
- 设计用户成长/社区贡献循环

**不要**当主模型：

- 看别人都买所以买 → [`social-proof`](../social-proof/SKILL.md)
- 权威令你服从 → [`authority-bias`](../authority-bias/SKILL.md)

## 怎么用（执行步骤）

1. **列出收到的好处。** 是否不请自来、价值多少、是否可拒。
2. **写清对方随后请求。** 请求与好处是否匹配？不对等则标互惠杠杆。
3. **做独立价值判定。** 若从未收到礼物，你是否仍要该产品/承诺？否 → 互惠在驱动。
4. **回应策略。** 礼貌承认礼物但不自动升级义务；或把回报限定在等量小行为；输出：可接受的回报边界。

## 例证

**超市试吃后购买率上升**：揭示小给予撬动消费。

**互惠式让步**：先极端要求再“让步”到目标价——揭示让步本身被当成恩惠。

## 什么时候不适用（边界）

- **对等合同**：付钱买服务不是“欠人情”。
- **亲密关系规范**：家庭互惠规则不同，勿机械套销售话术。

## 常见误用

- **拒绝互惠=冷血**：拒绝的是不等价勒索，不是拒绝合作。
- **用互惠洗白腐败**：送礼换审批是违法，不是原理应用练习。

## 相关模型

- **与[承诺与一致](../commitment-consistency/SKILL.md)**：先小承诺再升级，常与互惠串联。
- **与[稀缺原理](../scarcity-principle/SKILL.md)**：限时赠品双触发。
- **与[社会认同](../social-proof/SKILL.md)**：另一类顺从捷径。
