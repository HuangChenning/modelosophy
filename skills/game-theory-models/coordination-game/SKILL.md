# 协调博弈 Coordination Game

## 这是什么

**存在多个均衡，关键是大家选同一个（匹配）而非对抗。**

纯协调：匹配成功都好，匹配失败都差；可有帕累托排序的多均衡。驾驶侧、技术标准、约会地点属此类。谢林点、惯例、标准战是选择装置。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "怎么协调到同一选择"
- "标准该跟谁"
- "多重均衡选哪个"

**不要**在以下情况套用本模型：

- 利益对立优势背叛 → ../prisoners-dilemma/SKILL.md
- 安全 vs 合作张力为主 → ../stag-hunt/SKILL.md
- 只要焦点概念 → ../schelling-point/SKILL.md

## 怎么用（执行步骤）

1. **确认匹配收益结构。** 同选更好、异选更差；利益大体一致。
2. **列出所有纯纳什。** 常有两个及以上。
3. **引入选择装置。** 惯例、领导宣告、默认选项、谢林显著点。
4. **输出。** 均衡集合 + 推荐协调装置 + 迁标准的转换成本注意。

## 例证

**靠左/靠右驾驶**：两边都纳什，关键是一致。揭示惯例的价值。

**键盘与接口标准**：技术锁定来自协调成功。揭示转换需临界大众。

## 什么时候不适用（边界）

- **暗含冲突**：标准战常伴随租金争夺——可能混有零和层。
- **转换成本**：已协调系统难迁移。

## 常见误用

- **把冲突博弈当纯协调**：先核对利益是否一致。
- **强推无焦点的新标准**：缺临界群体会失败。

## 相关模型

- **与[谢林点](../schelling-point/SKILL.md)**：无沟通时的焦点选择。
- **与[猎鹿博弈](../stag-hunt/SKILL.md)**：带风险的协调。
