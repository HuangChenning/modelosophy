# 交叉验证思维 Cross-Validation Thinking

## 这是什么

**交叉验证思维**（此处指认知/调查工具，不是 ML 的 k-fold）：对重要主张，主动寻找**相互独立**的证据路径——不同数据源、不同方法、不同观察者或不同理论视角——看结论是否收敛；若分歧，显式处理，而不是挑顺耳的那条。

「独立」是关键词：同一新闻被五家媒体转载，仍可能是一条源。目标是降低**单一通道失败**（说谎、测量偏差、抽样偏差、叙事污染）。

## 什么时候用

- "这个结论太重要，不能只靠一份材料"
- "访谈、数据和竞品说法打架"
- 直接说交叉验证 / 三角互证 / triangulate / 多源核实
- 尽职调查、事故调查、战略假设上会前

**不要**当主模型：

- 已有清晰假说，要设计一次可证伪检验 → [`hypothesis-testing`](../hypothesis-testing/SKILL.md)
- 评估一段论证的推理结构 → [`critical-thinking`](../critical-thinking/SKILL.md)
- 只要分类穷尽 → [`mece`](../mece/SKILL.md)
- 统计模型调参意义上的 cross-validation（另开数据分析流程）

## 怎么用（执行步骤）

1. **写出待核验主张（一句话）。** 含范围与时间。判据：可被支持或削弱，不是态度句。
2. **列出现有证据并标来源图谱。** 每条证据写：来源、方法、是否可能同源（同一新闻稿/同一内部 KPI 口径）。判据：标出「独立簇」数量。
3. **设计至少一条独立路径。** 可选：另一数据系统、对立利益相关方、现场观察、实验/试点、公开注册数据、逆向文档。判据：该路径的失败模式应与原路径不同。
4. **执行并记录收敛/分歧。** 收敛：独立簇指向同方向；分歧：写清差在测量、定义还是世界状态。禁止用修辞抹平分歧。
5. **定置信动作。** 收敛且独立簇≥2 → 可提高行动置信（仍可错）；仅单簇 → 标「低交叉验证」并限制下注；分歧未解 → 先缩小主张或追加路径，不装成已验证。
6. **防伪交叉。** 检查：顾问引用客户、媒体引用通稿、指标互相换算——若共享生成过程，合并为同一簇。

## 例证

**尽职调查**：管理层口述增长 + 银行流水 + 客户抽样回访三簇独立 → 比三份都来自管理层 PPT 更强。揭示：交叉验证看的是**生成过程独立**，不是文件份数。

**事故调查**：日志、当事人访谈、物理痕迹不一致 → 显式分歧推动时间线重建，而不是选「最像故事」的版本。

**（原书卡片）**：若只写「多听各方意见」而无独立性检验，易变成意见平均；本 Skill 以独立簇与分歧处理为准。

## 什么时候不适用（边界）

- **低利害、可逆小决策**：成本高于信息价值时，不必强行三角。
- **真正的单点不可及**：唯一黑匣/唯一证人——承认不可交叉，改用保守决策。
- **伪多元**：刻意找「会同意的人」凑数 → 无效。
- **与统计 CV 混淆**：数据集划分验证模型泛化 ≠ 本认知工具。

## 常见误用

- **计数当独立**：五次转载 → 合并同源。
- **多数暴政**：三个人错口风一致 → 仍可能共有偏见；检查激励与信息源。
- **用交叉验证代替证伪设计**：收敛≠真；关键假说仍要可被打穿。
- **与确认偏差共谋**：只交叉「支持我的源」→ 至少安排一条可能削弱的路径。

## 相关模型

- **与[假设检验](../hypothesis-testing/SKILL.md)**：假设检验设计一次对照检验；交叉验证强调多独立路径是否收敛。可连用：先检验，再多源加固。
- **与[批判性思维](../critical-thinking/SKILL.md)**：批判性思维评论证；本模型评证据通道结构。
- **与[确认偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：交叉验证是对抗确认偏差的操作之一（强制独立与对立源）。
- **与[奥卡姆剃刀](../occams-razor/SKILL.md)**：多源收敛后仍可能过拟合叙事；解释仍要省特设假设。
- **与[类比思维](../analogical-thinking/SKILL.md)**：多个类比不是独立证据；类比启发后仍要实证交叉。

## 记忆钩子

看的不是「有几份材料」，而是有几条**不会一起死**的证据命脉。
