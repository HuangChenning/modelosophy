# 安索夫矩阵 Ansoff Matrix

## 这是什么

**安索夫矩阵**：把增长选项放进四格——**市场渗透**（现产品×现市场）、**市场开发**（现产品×新市场）、**产品开发**（新产品×现市场）、**多元化**（新产品×新市场）——并默认**风险随离现有业务距离上升**。

Igor Ansoff 提出该框架，强调增长战略要显式选择「改产品还是改市场」，避免口头「做大」却未选路径。它是**增长路径菜单**，不是组合份额矩阵（BCG）也不是能力审计（VRIO）。

## 什么时候用

- "明年增长从哪来：老客深挖还是新品/新市场"
- "安索夫 / 要不要多元化"
- 战略会需要把增长选项摊开并比风险

**不要**当主模型：

- 多 SBU 投砍收割 → [`bcg-matrix`](../bcg-matrix/SKILL.md) / [`ge-mckinsey-matrix`](../ge-mckinsey-matrix/SKILL.md)
- 新行业利润结构 → [`porters-five-forces`](../porters-five-forces/SKILL.md)
- 平台双边冷启动 → [`platform-strategy`](../platform-strategy/SKILL.md)

## 怎么用（执行步骤）

1. **钉死「现有产品」与「现有市场」边界。** 用 SKU/解决方案 + 地理/客群/场景定义。判据：团队对边界无争议；否则四格会乱跳。
2. **把候选增长主意落入四格。** 每格至少 0–N 条；无法落入 → 说明未定义清。判据：每条只属一格（主归属）。
3. **按风险阶梯排序讨论。** 默认优先穷尽渗透，再产品或市场单维扩张，最后多元化。判据：若直接跳多元化，必须写「为何单维扩张不够」的证据。
4. **为每条写成功度量与能力缺口。** 渗透看份额/频次；市场开发看渠道与本地化；产品开发看采用与毛利；多元化看新能力与协同是否真实。判据：有领先/滞后指标，禁止只有收入目标。
5. **设杀掉与资源封顶。** 尤其多元化与双重新：预写退出门槛。判据：无封顶预算与复盘日 → 不合格。
6. **输出增长路径包。** 主路径 + 可选试验 + 明确不做的格子。

## 例证

**渗透未尽就多元化**：核心市场份额仍低却跨行业并购——揭示风险阶梯被跳过。

**产品开发服务老客**：在同一客群加模块提升 ARPU——揭示单维扩张常优于双重新。

**与 BCG 连用**：BCG 决定哪些业务要增长；安索夫决定该业务内部用哪条增长路径。

## 什么时候不适用（边界）

- **非增长议题**（收缩、清算、纯效率）：用其他工具。
- **市场/产品边界本质上模糊（强平台生态）**：四格过粗，需补平台/飞轮视角。
- **监管或资本结构主导**：矩阵不回答能否筹资/获批。

## 常见误用

- **多元化浪漫化**：当成长叙事 → 强制写能力缺口与退出。
- **与第二曲线对立**：第二曲线常落在产品/市场开发或多元化格，需标风险而非禁止。
- **假「新市场」**：只换广告受众仍算渗透 → 用渠道/地理/场景硬标准。
- **四格平均撒钱**：无主路径 → 选一条主、一条试验。

## 相关模型

- **与[BCG 矩阵](../bcg-matrix/SKILL.md)**：BCG 管组合位置；安索夫管单业务增长路径。
- **与[第二曲线](../second-curve/SKILL.md)**：第二曲线管切换时机与输血；安索夫标注路径类型与风险。
- **与[核心能力](../core-competence/SKILL.md)**：多元化前先问能力是否可迁移。
- **与[SWOT](../swot/SKILL.md)**：SWOT 找机会；安索夫结构化增长选项。

## 记忆钩子

增长先问两轴：**老/新产品 × 老/新市场**——离家乡越远，风险默认越高。
