# 波特五力 Porter's Five Forces

## 这是什么

Michael Porter 的行业结构框架：一个行业的**平均利润潜力**被五股竞争力量塑造——

1. **现有竞争者之间的对抗**
2. **新进入者威胁**
3. **替代品威胁**
4. **买方议价能力**
5. **供方议价能力**

力量越强，价值越被竞争、客户、供应商或替代方案撕走。它回答“**这个行业结构上好不好赚钱**”，不直接回答“我们公司下一步 SWOT 选项是什么”。

后世补充：互补品、生态系统、数字平台会改写边界——使用时先声明行业定义，并在结构剧变时更新，而不是当永恒真理。

## 什么时候用

- 进入/退出某行业、做市场吸引力判断；
- 战略讨论混淆了“公司优缺点”与“行业结构”；
- 直接提波特五力 / five forces。

**不要**当主模型：
- 某事业部/产品的内外因素清单与匹配 → [`swot`](../swot/SKILL.md)；
- 某公司为何能持续超额利润 → [`economic-moat`](../economic-moat/SKILL.md)；
- 节点网络平方价值 → [`metcalfes-law`](../../systems-classic-effects/metcalfes-law/SKILL.md)。

## 怎么用（执行步骤）

1. **钉死行业边界与利润池。** 过宽（“整个科技”）或过窄都会扭曲五力。写清：谁算同业、地理、客户场景、时间盒。
2. **逐力写等级 + 证据。** 每力评高/中/低，附 1–2 条可观察证据（集中度、转换成本、产能闲置、专利墙、渠道控制、价格敏感度等）。禁止只填形容词。
3. **综合结构吸引力。** 五力整体偏强 → 平均回报承压；偏弱 → 结构上更容许利润。标明最大撕裂来自哪一力。
4. **导出结构含义，不作伪精确打分游戏。** 含义例：需差异化规避纯价格战；或买方极强故必须控成本/捆绑。分数相加当科学无效。
5. **与公司层分流。** 结构吸引仍要问：我们相对对手的位置（可接 SWOT）与壁垒是否可持续（护城河）。好行业里的差位置仍会亏。

## 例证

**航空公司经典课例**：激烈竞争、强买方（旅客比价）、强供方（飞机制造/油）、替代（高铁/视频会议）——结构上难赚稳定超额。揭示五力解释**行业均值**，不否认个别航司阶段性盈利。

**受专利与法规保护的细分药**：进入威胁低、替代有限时，结构更宽裕——但仍受支付方议价与专利悬崖影响。揭示边界与时间。

**伪五力**：把“我们团队执行力强”写进五力——那是公司内部 S，应去 SWOT。揭示层错误。

**（原书卡片）五力示意图**：结构名正确；须强调行业层 vs 公司层，并避免与 SWOT 四格混填。

## 什么时候不适用（边界）

- **行业边界正在被平台改写**：静态五力快照过时快，要情景化。
- **非营利/纯公共品配置**：利润池假设弱。
- **把五力当公司战略选项生成器**：缺 TOWS/定位细节。
- **无限打分表竞赛**：无证据的 1–5 分无决策价值。

## 常见误用

- **行业边界随意伸缩自证结论**：为了让"竞争没那么激烈"或"机会很大"成立，把行业定义得特别宽（"整个互联网"）或特别窄，而不是先钉死范围再打分 → 回到步骤1重新界定边界与利润池，边界一变结论就变。
- **五力分数相加当精确排名**：把五股力量各打1–5分再加权求和，得出"行业吸引力=3.4"这类伪精确数字，当成可跨行业比较的科学结论 → 五力是定性结构诊断，不是可加总的评分公式。
- **拿行业结构当竞对胜负判断**：把五力结果当成"我们能不能打过某个具体对手"的答案，混淆了行业均值层面的分析与公司层面的位置分析 → 公司相对位置要接护城河或SWOT，五力只回答行业整体好不好赚钱。
- **分析完直接跳到行动方案**：五力做完就宣布"所以我们应该做X"，没有经过与自身定位、护城河的对接就把结构判断当成战略选项 → 五力只给结构含义，具体选项要接SWOT/护城河再定。

## 相关模型

- **与[SWOT](../swot/SKILL.md)**：五力=行业结构吸引力；SWOT=特定对象 S/W/O/T + 匹配。先结构后定位，或并行但勿混格。
- **与[护城河](../economic-moat/SKILL.md)**：五力看平均；护城河看你能否在结构中保住超额。
- **与[MECE](../../cognitive-thinking-tools/mece/SKILL.md)**：五力条目内证据尽量不重不漏；五力不是唯一行业分类法。
- **与[系统思维](../../systems-classic-effects/systems-thinking/SKILL.md)**：力量之间有反馈（价格战←→产能），结构剧变时补回路。
