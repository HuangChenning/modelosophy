# 最小最大定理 Minimax Theorem

## 这是什么

**有限二人零和博弈中，最大最小价值等于最小最大价值——存在最优混策略保障水平。**

von Neumann：一方最大化最坏情形，另一方最小化对方最好情形，值相等。给出“不论对手多强，我至少能守住的期望支付”。非零和勿直接套。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "最小最大策略"
- "怎么按最坏情况防守"
- "零和有没有保证值"

**不要**在以下情况套用本模型：

- 非零和互动 → ../positive-negative-sum-game/SKILL.md 或 ../nash-equilibrium/SKILL.md
- 只要零和定性 → ../zero-sum-game/SKILL.md
- 多人合作分配 → ../shapley-value/SKILL.md

## 怎么用（执行步骤）

1. **确认二人零和。** 支付和常数；否则停。
2. **对每一纯策略写最坏支付。** 选最大化该最坏值的策略（纯策略 maximin 直觉）。
3. **引入混合（概念）。** 说明最优常需随机化使对手无法剥削；给出“保障水平”含义。
4. **输出。** 保障目标一句 + 是否需专业求解混策略。

## 例证

**石头剪刀布**：均匀混是最小最大。揭示随机化防被读。

**安防巡查**：随机路线提高最坏情形。揭示保障思维。

## 什么时候不适用（边界）

- **非零和**：定理不直接成立。
- **计算**：大矩阵需算法；本 skill 给决策框架。

## 常见误用

- **生活处处最小最大**：过保守且常非零和。
- **当纳什的同义词**：零和特例关系要说清。
