# 损失函数 Loss Function

## 这是什么

**损失函数（决策语境）**：为每种「世界状态 × 行动/预测」对指定一个**损失（或负效用）** \(L(\theta, a)\)，选择使**期望损失** \(\mathbb{E}[L]\) 最小的行动（或分类阈值）。核心洞见：**错误类型的代价往往不对称**——漏诊与误诊、放过与误杀、过早扩产与过晚扩产，不应被「准确率」一视同仁。

与期望效用：EU 最大化偏好；损失最小化常是同一枚硬币的决策论写法，但本 Skill **聚焦错误类型定价与阈值选择**。

## 什么时候用

- "假阳性/假阴性哪个更贵"
- "损失函数 / 非对称错误代价"
- "检测阈值该严还是松"
- 风控、质检、医疗分诊、内容审核、告警阈值

**不要**当主模型：

- 一般风险厌恶与财富效用 → [`expected-utility`](../expected-utility/SKILL.md)
- 对称金额结果加权 → [`expected-value`](../expected-value/SKILL.md)
- 描述「人对损失更敏感」的行为偏差 → [`loss-aversion`](../../behavioral-biases/loss-aversion/SKILL.md)
- 只要分布模拟 → [`monte-carlo`](../monte-carlo/SKILL.md)

## 怎么用（执行步骤）

1. **列出状态与行动。** 如有病/无病 × 治疗/观察；或真警报/无事 × 停机/忽略。
2. **为每个单元格定价损失。** 用金钱、伤害、监管分；允许数量级估计。判据：团队同意「漏检 ≫ 误报」或相反。
3. **接入概率。** 先验/基率 + 信号质量（可链贝叶斯）；得到各状态下的后验或联合概率。
4. **选最小化期望损失的行动或阈值。** 对连续分数，扫描阈值找期望损失最低点；展示代价比如何移动阈值。
5. **做敏感性。** 损失比在合理范围内是否翻转策略？翻转则优先澄清代价而非精修模型。
6. **落地监测。** 跟踪两类错误实际频率与代价是否漂移。

## 例证

**疾病筛查**：漏诊损失极高 → 阈值偏向敏感（更多假阳性）。揭示：**最优准确率 ≠ 最优阈值**。

**欺诈拦截**：误杀好用户 vs 放过欺诈；电商常显式代价比调阈值。揭示：损失函数是**产品策略**。

**发布门控**：线上事故损失 ≫ 晚发布 → 宁可多挡。揭示：与可逆门联用。

## 什么时候不适用（边界）

- **代价不可比且无代理**：先多属性协商，勿假造单一损失。
- **对抗性对方操纵指标**：损失表面最优会被博弈。
- **训练 ML 模型的技术细节**：本 Skill 不讲反向传播；只讲决策阈值与代价。

## 常见误用

- **用准确率/ F1 替代代价**：隐含对称损失。
- **与损失厌恶混谈**：行为偏差 ≠ 规范损失定价。
- **与 EU 名词混用却不写错误单元**：回到空谈效用。
- **损失表拍脑袋后永不敏感**：假精确。

## 相关模型

- **与[期望效用](../expected-utility/SKILL.md)**：**硬区分。** EU 编码对财富/结果的偏好；损失函数聚焦**错误类型矩阵**。二者可翻译，但用户说「两类错误谁更贵」走本模型。
- **与[期望值](../expected-value/SKILL.md)**：EV 常假设结果已是净损益；本模型在分类/阈值问题里显式拆错误代价。
- **与[贝叶斯更新](../bayesian-updating/SKILL.md)**：后验进期望损失；阈值随后验与代价比移动。
- **与[损失厌恶](../../behavioral-biases/loss-aversion/SKILL.md)**：损失厌恶是描述性偏差；规范决策用显式 L，并警惕被偏差扭曲代价表。
- **与[敏感性分析](../sensitivity-analysis/SKILL.md)**：代价比是最关键敏感输入之一。

## 记忆钩子

先填「错哪边更贵」的表，再谈模型分数——**阈值是代价比的函数，不是准确率的妆容。**
