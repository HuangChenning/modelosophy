# 元学习 Meta-Learning

## 这是什么

**元学习**：把「如何学习」本身当作可改进的对象——建立策略菜单、按任务选型、用小实验比较效果，并沉淀个人播放列表。它回答「下一次该用检索还是交错还是费曼」，而不是直接背某一个知识点。

在自我调节学习（SRL）语境中，计划—策略—评价循环可跨任务迁移；本模型聚焦**策略层的显式管理**。

**鉴别**：[`metacognition`](../metacognition/SKILL.md) 是正在学习时的觉察与调节（「我是不是假懂」）；元学习是**跨会话的方法资产**（「对我而言，概念课默认费曼+检索」）。二者连用：元认知触发换法，元学习更新默认菜单。

## 什么时候用

- "怎样学习如何学习 / 元学习"
- "面对新领域该先用哪套学法"
- 屡次用错方法（只重读、只刷时长）需要系统改法

**不要**当主模型：

- 当下这一题会不会 → [`metacognition`](../metacognition/SKILL.md) 或具体学科方法
- 只要 Anki 怎么排 → [`spaced-repetition`](../spaced-repetition/SKILL.md)
- 只要技能怎么练 → [`deliberate-practice`](../deliberate-practice/SKILL.md)

## 怎么用（执行步骤）

1. **给任务贴类型标签。** 事实保持 / 概念理解 / 程序技能 / 迁移应用 / 去旧习惯。判据：标签决定候选策略，禁止「一律听课」。
2. **打开策略菜单（仓库内真实路径）。** 例：事实→检索+间隔；概念→费曼/精细加工；技能→刻意练习±交错；迁移→变式验收；旧习→去学习。
3. **选 1 个主策略 + 1 个验收指标。** 指标必须可观察（延迟测验正确率、作品标准、时间盒内完成度）。
4. **跑短实验（3–7 天或 3 个会话）。** 只改学法变量；记录成本与结果。感觉良好不算数。
5. **更新个人默认播放列表。** 写成「若任务=X，默认用 Y，验收 Z」；失败则换菜单项，勿只加时长。
6. **每季做一次元复盘。** 哪条默认失效？新领域是否缺横杠（接 T 型）？策略是否过时（接去学习）。

## 例证

**语言学习**：从「只背单词表」实验改为「检索句子+间隔」，两周后延迟测验对比——揭示**元学习是选法实验**。

**编程**：平台期只加刷题时数无效；改为刻意练习弱类型+交错题型——菜单更新。

**（局限）**：无具体策略库存时，「元」会空转——必须下钻到可执行 Skill。

## 什么时候不适用（边界）

- **急性截止且方法已知有效**：直接执行，别开新实验。
- **健康崩溃**：先睡眠/负荷，再谈学法优化。
- **把元学习当拖延**：一直规划不学 → 限时 30 分钟选型后必须进入对象学习。
- **组织强制单一教法且无自主空间**：在约束内微调验收，或另找练习场。

## 常见误用

- **与元认知混名**：当下监控走元认知；跨任务菜单走本模型。
- **收集方法不实验**：收藏夹≠元学习 → 必须有对比指标。
- **永不下钻**：只谈「学会学习」空话 → 立刻链到检索/练习等。
- **每周换法**：噪声过大 → 一次实验窗口内保持主策略稳定。

## 相关模型

- **与[元认知](../metacognition/SKILL.md)**：元认知是实时仪表盘；元学习是导航地图更新。
- **与[检索练习](../retrieval-practice/SKILL.md) / [间隔重复](../spaced-repetition/SKILL.md) / [刻意练习](../deliberate-practice/SKILL.md)**：菜单上的主菜；本模型负责点菜与换菜。
- **与[T 型技能](../t-shaped-skills/SKILL.md)**：T 型定学什么组合；元学习定怎么学。
- **与[去学习](../unlearning/SKILL.md)**：淘汰失效学法（如只重读）也是元学习的一部分。
- **与[成长型思维](../growth-mindset/SKILL.md)**：成长型提供「可变」前提；元学习提供变更方法。

## 记忆钩子

先给任务贴标签，再点菜单——别拿一把锤子敲所有学习。
