# 冰山模型 Iceberg Model（组织/文化）

## 这是什么

冰山隐喻：水面以上是**容易看见**的部分，水面以下是**更大、更慢、却在驱动行为**的部分。本库采用**组织与文化诊断**用法（Schein / Hall 传统），而不是临床自我分析：

| 层（Schein 常用三分） | 例子 | 可观测性 |
|---|---|---|
| **器物与行为 Artifacts** | 着装、工位、仪式、工具、可见流程 | 高 |
| **信奉的价值 Espoused values** | 手册、口号、战略词、公开倡导 | 中（可能口惠） |
| **基本假设 Basic assumptions** | “客户永远扯皮”“加班才忠诚”“失败不可见” | 低，通过模式推断 |

Hall 的文化冰山同类：习俗、技术在上，价值观与思维框架在下。系统思考里的“事件 → 模式 → 结构”也可画成冰山，侧重因果结构而非文化假设——相关但可区分。

**本 skill 明确不做**：弗洛伊德潜意识地形学、萨提亚七层自我冰山的治疗式解读、给用户贴病理标签。

## 什么时候用

- 换了制度/OKR/口号，行为两周后弹回；
- 并购、入职、跨文化协作：看得见的规矩对不上“这里到底怎么回事”；
- 用户直接说文化冰山 / Schein / artifacts-assumptions / 可见层与深层假设。

**不要**当主模型：
- 扩大反馈开放区、缩小盲目区 → [`johari-window`](../johari-window/SKILL.md)；
- 画增强/调节回路与杠杆 → [`systems-thinking`](../../systems-classic-effects/systems-thinking/SKILL.md)；
- 情绪障碍或创伤处理 → 专业心理服务，本模型只谈组织/协作文化。

## 怎么用（执行步骤）

1. **只先描述水面以上。** 列出可观察行为、器物、正式文件原话。禁止第一步就猜“他内心渴望什么”。
2. **对照信奉价值。** 墙上写的、会上说的，与第 1 步是否一致？缺口本身就是数据。
3. **推断基本假设（可证伪写法）。** 写成“这里的人默认：……；若假，我们应看到……”——每条假设配一个可观察检验。
4. **干预对齐层级。** 只改器物（海报、工具）却与假设冲突 → 预期仪式化失败。要动真格：改激励、信息流、谁被奖励/惩罚，让新假设有证据。
5. **保持伦理边界。** 不把同事写成病人；不强迫披露隐私；不确定就停留在行为与结构层。

## 例证

**“拥抱失败”口号 vs 惩罚故障**：器物层有复盘会，信奉价值写创新，基本假设仍是“出事找人”——揭示**三层不一致**时，可见改革是表演。

**跨区销售礼仪**：可见的是名片与宴请次数；下层是“关系优先于合同”或相反。只培训话术不碰假设，冲突会在签约环节爆。

**事件—模式—结构冰山（系统思考变体）**：连续宕机（事件）→ 每月峰值（模式）→ 编制与值班激励（结构）。揭示的是结构层，不必调用人格冰山。

**（原书卡片）萨提亚七层 + 师生冲突**：作为家庭治疗隐喻可自洽，但作本库通用 skill 会越权做临床读心；故只作反例——我们改走组织/文化分层，并拒绝“不要固执”式空洞收尾。

## 什么时候不适用（边界）

- **单一技术故障且根因局部明确**：直接排障，不要文化化。
- **需要法律/合规结论**：假设层讨论不能替代取证与条文。
- **强制心灵鸡汤或治疗**：用户要“挖潜意识/疗愈内在小孩”时，说明本 skill 不适用。
- **把一切归咎文化**：有时是资源、权力、市场约束；冰山是假说生成器，不是万能归因。

## 相关模型

- **与[周哈里窗](../johari-window/SKILL.md)**：周哈里是“谁知道什么”的四格；冰山是“可见到多深”的分层。要反馈盲区走周哈里；要解释制度失灵走冰山。
- **与[系统思维](../../systems-classic-effects/systems-thinking/SKILL.md)**：结构杠杆与文化假设常纠缠；回路图画清机制，冰山标明默认信念。
- **与[黄金圈](../golden-circle/SKILL.md)**：黄金圈管叙事顺序 WHY–HOW–WHAT；冰山检查宣称的 WHY 是否只是信奉价值。
- **与[隐含前提](../implicit-premises/SKILL.md)**：基本假设常以隐含前提形式出现在决策话里；可连用。
