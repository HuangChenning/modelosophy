# IS-LM 模型 IS–LM Model

## 这是什么

**在物价固定的短期，用利率把产品市场（IS）与货币市场（LM）联立求产出。**

提出者/源流：Hicks 对凯恩斯体系的形式化（1937）；教学用短期封闭经济框架。IS：投资—储蓄均衡，利率↑→投资↓→产出↓。LM：货币供需，产出↑→交易需求↑→利率↑。交点给短期 Y 与 r。开放经济需 IS-LM-BP 等扩展。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "「降息为啥能抬产出」"
- "「财政扩张会不会顶高利率」"
- "「流动性陷阱里 LM 是不是平的」"

**不要**在以下情况套用本模型：

- 长期增长/资本积累 → 索洛
- 通胀动态主叙事 → AD-AS + 菲利普斯

## 怎么用（执行步骤）

每一步给出可操作判据；禁止只换说法重复结论。

1. **声明假设。** 物价粘性、封闭经济、货币供给外生等——写在开头。
2. **画清冲击落在 IS 还是 LM。** G↑/信心↑移 IS；M↑/流动性偏好↓移 LM。
3. **读交点比较静态。** 新 Y、r 方向；是否靠近流动性陷阱（LM 平坦）。
4. **翻译政策含义并降级精度。** 定性方向可用；定量乘数需经验。开放经济加注资本流动。

## 例证

**希克斯形式化凯派**：揭示教学模型如何固化直觉。

**流动性陷阱叙事**：揭示货币宽松在陷阱中可能无力，财政更有效（模型内）。

**财政扩张抬利率**：揭示挤出在 LM 向上倾斜时出现。

## 什么时候不适用（边界）

- **浮动物价**：改用 AD-AS。
- **银行信贷渠道、量化宽松**：传统 LM 货币基础粗糙。

## 常见误用

- **当成真实经济地图**：忽略其教学抽象。
- **开放经济硬套**：缺汇率与资本流动。

## 相关模型

- **与[AD-AS 模型](../ad-as-model/SKILL.md)**：加入物价层；IS-LM 常作推导 AD 的中间步骤。
- **与[挤出效应](../crowding-out-effect/SKILL.md)**：IS 右移沿 LM 爬升即挤出机制之一。
- **与[乘数效应](../multiplier-effect/SKILL.md)**：IS 右移幅度与乘数相关。

## 记忆钩子

一条 IS、一条 LM，交点告诉你短期的 Y 和 r。
