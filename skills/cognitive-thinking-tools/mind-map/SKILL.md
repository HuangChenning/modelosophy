# 思维导图 Mind Map

## 这是什么

**思维导图**：从中心主题出发，用主干（主分支）和更细的支脉向外生长，节点多用**短关键词/意象**，依赖联想把相关内容挂到树上。它擅长：**快速外化、记忆编码、会议速记、发散开场**。

Buzan 传统强调单中心、放射结构、层级与视觉刺激；本 Skill 取其**可执行核心**，不绑定特定软件或必须手绘彩色。

## 什么时候用

- "把脑子里的东西先倒出来"
- "读书/听会做放射状笔记"
- 直接说思维导图 / mind map / 脑图
- 复习结构、演讲提纲草稿、头脑风暴可视化

**不要**当主模型：

- 要精确关系命题 → [`concept-map`](../concept-map/SKILL.md)
- 要多维议题盘点（短腕） → [`octopus-diagram`](../octopus-diagram/SKILL.md)
- 要主问题 MECE 分解 → [`logic-tree`](../logic-tree/SKILL.md) + [`mece`](../mece/SKILL.md)
- 要加权选型 → [`decision-matrix`](../decision-matrix/SKILL.md)

## 怎么用（执行步骤）

1. **定中心。** 一词或短短语放中央。判据：后续主干都是它的面向，不是另一个并列主题（多主题就拆多张图）。
2. **先画 3–7 条主干。** 主干是最大分类/章节/问题面。判据：主干名尽量不互相包含；可后改。
3. **用关键词向外长。** 每节点宜短；一句整段改成多个节点。联想优先于完美分类；混乱处先标记再整理。
4. **加深有价值的支脉。** 对要行动或要记忆的枝加一层细节；其余保持浅。判据：图应能在 30 秒内指着讲清结构。
5. **整理pass（可选）。** 合并同义、调整归属、标优先级。若需要关系精确，另开概念图，不要在导图上硬加长句边。
6. **回收。** 输出：主干清单 / 待办 / 待验证假设。导图文件本身不是决策。

## 例证

**读书笔记**：中心=书名，主干=章节论点，支脉=例证与自己的疑问——复习时沿放射路径提取。揭示：导图利于**检索线索**。

**失败用法**：把 PPT 整段贴上节点，或把导图当最终战略论证——失去联想优势又无命题严谨。

**（原书卡片）**：若只强调「好看」，忽略关键词与回收，导图会沦为装饰。

## 什么时候不适用（边界）

- **合规证据链 / 因果鉴定**：需要命题与证据，不靠导图。
- **强决策模型**：概率树、矩阵另用专条。
- **多人实时冲突编辑**：无主持规则时放射图易乱——先定主干主人。

## 常见误用

- **与概念图混淆**：无连接词却声称关系已清 → 改 concept-map。
- **中心过大**：中心是整段计划书 → 缩小或拆图。
- **只美化不回收**：画完无行动 → 强制输出清单。
- **过早 MECE 强迫症**：发散阶段被分类纪律掐死 → 先联想，后整理。

## 相关模型

- **与[概念图](../concept-map/SKILL.md)**：**硬区分。** 联想笔记/发散 → mind-map；命题网络 → concept-map。
- **与[八爪鱼图](../octopus-diagram/SKILL.md)**：八爪强调一次铺维度、腕宜短；导图允许深层级联想。盘点开场可用八爪，记忆深化用导图。
- **与[逻辑树](../logic-tree/SKILL.md)**：逻辑树服务问题解决的「所以什么」；导图服务联想外化。
- **与[水平思考](../lateral-thinking/SKILL.md)**：导图可承载挑衅与随机词支脉，但技法本身在 lateral-thinking。
- **与[菱形六步法](../diamond-six-steps/SKILL.md)**：步 2/4 发散可视化常用导图。

## 记忆钩子

中心一颗种子，主干先定方向，节点用短词往外长——画完要能指着讲，而不是只好看。
