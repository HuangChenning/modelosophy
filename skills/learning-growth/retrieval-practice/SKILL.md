# 检索练习 Retrieval Practice

## 这是什么

**检索练习**：合上材料后，从记忆中主动提取目标信息（默写、口述、闭卷做题），再对照答案修正——比反复重读更能形成长期保持，并暴露「以为会了其实不会」。

心理学中的 **testing effect（测试效应）** 表明：测试不只是测量工具，本身也是学习事件。成功提取会加强痕迹；失败提取若立刻纠正，同样有诊断价值。期望难度（desirable difficulty）适中时收益最大。

**鉴别**：[`spaced-repetition`](../spaced-repetition/SKILL.md) 管「何时再测」的间隔日程；本模型管「怎么学」的默认认知动作——**主动提取**。二者常连用：检索是动作，间隔是排程。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "背了就忘 / 重读很多遍没用"
- "检索练习 / 测试效应 / 闭卷自测怎么做"
- "怎么确认自己真的学会了"

**不要**在以下情况套用本模型：

- 只要 Anki/SRS 间隔算法 → [`spaced-repetition`](../spaced-repetition/SKILL.md)
- 概念从未理解、需要讲清与补洞 → [`feynman-technique`](../feynman-technique/SKILL.md)
- 可演示技能的动作/表演瓶颈 → [`deliberate-practice`](../deliberate-practice/SKILL.md)
- 只问「为何遗忘」的现象解释 → [`forgetting-curve`](../forgetting-curve/SKILL.md)

## 怎么用（执行步骤）

1. **定义可提取的目标单元。** 写成闭卷可答的问题（「X 的定义/步骤/公式是什么」），禁止「再看一遍第 3 章」。判据：合上书后能否在 30–60 秒内给出可核对答案。
2. **先编码、再立刻首提。** 读/听完一段后马上默写或口述；禁止「读完整本再测」。判据：首提正确率可低于 100%，但必须有一次真实提取尝试。
3. **对照标准答案并标错误类型。** 漏项 / 混淆 / 完全不会分开记；只看答案不重提 → 无效。判据：能否说出「错在哪一类」。
4. **错项当日再提一次。** 看答案后合上材料再提取；仍错则缩小单元或改写问题面（更具体线索）。
5. **后续用间隔排程。** 把通过/失败交给 [`spaced-repetition`](../spaced-repetition/SKILL.md)；本步只保证每次复习仍是**检索**而非重读。
6. **穿插变式与迁移抽查。** 换问法、换例子再提一次；只会原文复述 → 补变式题，必要时接 [`transfer-of-learning`](../transfer-of-learning/SKILL.md)。

## 例证

**课堂测验 vs 重读笔记**：同等时间用于低利害小测，期末保持通常优于反复划线——揭示**测试本身是学习**。

**外语词汇**：看中文想目标词（或听写）优于「中英对照扫读」——揭示**再认≠提取**。

**（局限）**：材料尚未形成最小可理解单元时，盲目闭卷只会挫败；先短编码/费曼补洞再检索。

## 什么时候不适用（边界）

- **零基础且无法生成答案线索**：先最小讲解或样例，再闭卷。
- **开放创造任务**：检索适合事实/程序/概念网络；创意生成另设评价标准。
- **高利害唯一考试焦虑**：可用低利害频繁检索作替代，而非一次高压闭卷。
- **动作技能本体感觉**：身体动作以刻意练习+反馈为主，口试检索只能辅助知识点。

## 常见误用

- **把重读/高亮当检索**：眼睛扫过很熟 → 合上材料默写。
- **只测不纠**：做错不看标准答案 → 立即对照并再提。
- **与间隔重复互换**：问「Anki 间隔怎么调」→ 走 SRS；问「学的时候干什么」→ 本模型。
- **一次提整章**：过载失败 → 切原子问题。

## 相关模型

- **与[间隔重复](../spaced-repetition/SKILL.md)**：间隔管日程；本模型管提取动作。说「怎么排」走间隔；说「别只看」走本模型；理想连用。
- **与[遗忘曲线](../forgetting-curve/SKILL.md)**：曲线解释衰减；对抗衰减的操作是检索+间隔。
- **与[费曼技巧](../feynman-technique/SKILL.md)**：费曼用讲解暴露概念洞；检索用闭卷提取暴露记忆/提取洞。概念不懂先费曼，懂了保保持用检索。
- **与[交错练习](../interleaved-practice/SKILL.md)**：交错改变练习题顺序；检索是每次是否主动提取。可叠加。
- **与[精细加工提问](../elaborative-interrogation/SKILL.md)**：精细加工追问「为什么」建联系；检索是提取已编码内容。先加工再检索更稳。

## 记忆钩子

合上书再想一遍，比再读一遍更值钱。
