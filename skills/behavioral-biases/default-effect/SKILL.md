# 默认效应 Default Effect

## 这是什么

**当存在一个预先设定的选项时，显著更高比例的人会最终落在该选项上。**

经典对比：器官捐赠选择加入 vs 选择退出，登记率天差地别。默认利用惰性、暗示“推荐/正常”、以及把偏离编码为损失。助推争论的核心也在此：默认很强，故需伦理约束。

## 什么时候用

- 产品/政策设计默认值
- 用户抱怨“一不小心就同意了”

**不要**当主模型：

- 无预设、纯因习惯不换 → [`status-quo-bias`](../status-quo-bias/SKILL.md)
- 权威背书迫使服从 → [`authority-bias`](../authority-bias/SKILL.md)

## 怎么用（执行步骤）

1. **识别当前默认。** 谁设置、用户是否知情、退出成本（点击次数/羞耻感）。
2. **估默认拉力。** 有默认 vs 强制选择（active choice）的份额差；差值大则默认效应强。
3. **对齐目标与伦理。** 默认是否服务于用户福祉且可轻松退出？若服务于隐藏收费，标操纵风险。
4. **改架构。** 可选：中性强制选择、软默认+清晰披露、定期重选；输出：新旧默认与退出路径说明。

## 例证

**器官捐赠 opt-out**：揭示默认对生死相关登记的巨大影响。

**软件预勾选营销邮件**：揭示商业默认的灰色地带。

## 什么时候不适用（边界）

- **安全硬默认**：安全带式强制可能合法且必要，不叫“要去掉的偏见”，但应透明。
- **专家场景强制选择**：专业用户可能偏好无默认。

## 常见误用

- **默认=永远正确**：默认是架构，对错看目标函数与同意质量。
- **与社会认同混用**：别人都怎样 vs 系统预选哪项。

## 相关模型

- **与[现状偏差](../status-quo-bias/SKILL.md)**：默认制造强现状。
- **与[损失规避](../loss-aversion/SKILL.md)**：改默认像失去被推荐状态。
- **与[稀缺/互惠等说服术](../scarcity-principle/SKILL.md)**：可并行，但默认更“静默”。

## 记忆钩子

大多数人停在出厂设置——所以出厂设置就是政策。
