# Cognitive Thinking Tools

第一性原理、结构化拆解、批判性思维等可执行认知工具 Skill。

与兄弟分类分流：结构化拆解与批判工具；概率决策见 `decision-probability/`，学习方法见 `learning-growth/`，其余通用模型见 `thinking-models/`。

路径：`skills/cognitive-thinking-tools/<skill-name>/SKILL.md`。

当前合计 **17** 个（迁入种子 8 + M1 新建 9，均为可执行 Skill；名录其余条目见 ROADMAP）。

## Skills

- **[critical-thinking](./critical-thinking/SKILL.md)** — 批判性思维：按 Facione Delphi 技能+倾向框架，对论证与证据做有标准的评估并建设性修正。
- **[first-principles](./first-principles/SKILL.md)** — 第一性原理：拆到硬事实/物理约束后重新往上推，而非沿惯例或类比做增量优化。
- **[five-whys](./five-whys/SKILL.md)** — 5Why：沿因果链追问至可行动根因（`v0.x-draft`）。
- **[golden-circle](./golden-circle/SKILL.md)** — 黄金圈：按 WHY–HOW–WHAT 整理沟通与策略叙事，检查由内向外是否一致。
- **[hypothesis-testing](./hypothesis-testing/SKILL.md)** — 假设检验：写成可证伪命题并设计对照证据（`v0.x-draft`）。
- **[inversion](./inversion/SKILL.md)** — 逆向思维：从失败倒推该避免什么，把失败模式落实成可执行的回避动作。
- **[lateral-thinking](./lateral-thinking/SKILL.md)** — 水平思考：用挑衅/跳框技法逃离定势后再垂直评估（`v0.x-draft`）。
- **[logic-tree](./logic-tree/SKILL.md)** — 逻辑树：议题树/假设树分解主问题为可行动叶子（`v0.x-draft`）。
- **[mece](./mece/SKILL.md)** — MECE：把议题拆成相互独立、相对边界完全穷尽的类别，便于分析与分工。
- **[occams-razor](./occams-razor/SKILL.md)** — 奥卡姆剃刀：在多个能解释同一现象的假设中，优先所需特设假设更少、更可证伪者。
- **[pyramid-principle](./pyramid-principle/SKILL.md)** — 金字塔原理：结论先行、上层概括下层、同层 MECE 的论证与沟通结构。
- **[scqa](./scqa/SKILL.md)** — SCQA：情境–冲突–问题–答案的沟通开场与问题定义（`v0.x-draft`）。
- **[six-thinking-hats](./six-thinking-hats/SKILL.md)** — 六顶思考帽：分时处理事实/感受/利益/风险/创意，蓝帽主持过程。
- **[star-method](./star-method/SKILL.md)** — STAR：情境–任务–行动–结果的行为经历叙事（`v0.x-draft`）。
- **[structured-thinking](./structured-thinking/SKILL.md)** — 结构化思维：问题定义→拆解→分析→综合的总流程编排（`v0.x-draft`）。
- **[theory-of-constraints](./theory-of-constraints/SKILL.md)** — TOC 约束理论：识别并聚焦系统吞吐瓶颈的五步法（`v0.x-draft`）。
- **[triz](./triz/SKILL.md)** — TRIZ：将设计矛盾结构化并用分离/发明原理启发非折中解（`v0.x-draft`）。
