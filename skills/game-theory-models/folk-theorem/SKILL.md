# 无名氏定理 Folk Theorem

## 这是什么

**足够耐心时，无限重复博弈可支撑许多优于一次性纳什的结果。**

一组相关结论（“folk”）：贴现因子够高、偏离可被观测并惩罚时，任何可行且个体理性的平均支付都可近似为均衡路径。含义：合作可能，但均衡极多——制度与焦点决定选哪条。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "无限重复是不是一定能合作"
- "无名氏定理什么意思"
- "贴现够高能否维持合作"

**不要**在以下情况套用本模型：

- 要落地报复规则 → ../repeated-games/SKILL.md
- 单次结构诊断 → ../prisoners-dilemma/SKILL.md
- 选哪个均衡靠惯例 → ../schelling-point/SKILL.md

## 怎么用（执行步骤）

1. **确认无限或不确定结束 + 贴现。** 耐心不足则定理前提失败。
2. **写出目标平均支付。** 是否高于一次性纳什（个体理性）？是否可行（凸组合范围内）？
3. **构想惩罚路径。** 偏离后能否回到更差的可执行惩罚？不可执行则不可支撑。
4. **强调选择问题。** 定理说“许多结果可能”，不指定哪一个——补制度、规范或谢林点。输出：可行？前提？仍缺什么选择装置？

## 例证

**卡特尔理论叙事**：耐心厂商理论上可维持高价，但均衡多且违法风险高。揭示可行性≠推荐/合法。

**社区规范**：长期社区用排斥惩罚搭便车。揭示惩罚可信度是关键。

## 什么时候不适用（边界）

- **合法合规**：不提供违法串谋设计。
- **有限重复**：标准 folk 叙述依赖无限/不确定视野。

## 常见误用

- **读成“重复就会自动合作”**：只要前提与均衡选择。
- **忽略观测**：秘密偏离破坏支撑。
