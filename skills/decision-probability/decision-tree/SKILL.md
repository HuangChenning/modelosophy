# 决策树 Decision Tree

## 这是什么

这里的决策树是**决策分析工具**，不是机器学习分类树。它把一个不确定选择拆成三种节点：

- **决策节点**：你能控制的选择，例如“试点 / 直接上线 / 不做”；
- **机会节点**：你不能控制的状态，例如“需求高 / 低”；
- **终点**：每条路径的结果及价值。

在机会节点计算 `EV = Σ(概率 × 结果价值)`；在决策节点选期望值最高的分支，再从树梢向根部折叠。若钱不能代表真实偏好（例如小概率破产），应使用**效用**而非金额。

## 什么时候用

- 有两个以上行动，每个行动可能出现不同结果；
- 能用数据、历史频率或清楚标注的主观判断粗估概率；
- 决策有阶段性，例如“先做测试，看到结果再决定”；
- 想知道成功率超过多少才值得下注，或一份信息最多值多少钱。

不要用于只有一个未知原因的归因问题；那是奥卡姆剃刀。不要把分类审批规则叫成概率决策树，除非分支真的包含选择与不确定性。

## 怎么用

1. **写出决策与时间顺序。** 先列你能控制的行动，再列每个行动之后可能发生、但你不能控制的状态。只要现实允许，就把“不做 / 延后”列为基线，避免树在一组全都不划算的方案中硬选“最好”。不要把“销量下降”画成决策节点，也不要把“换供应商”画成机会节点。
2. **穷举有实质差异的终点。** 给每条完整路径写结果，包含收益、成本、延迟和不可逆后果。概率分支在同一机会节点必须合计为 1。
3. **给概率标来源和区间。** 区分历史频率、专家判断和纯假设。没有数据时写 `20%–50%`，不要伪造 `37%` 的精确感。
4. **把结果换成可比较的价值。** 金额可比时用金额；风险偏好、生命安全或公司存亡介入时用效用，并把归零结果设为硬约束，而不是让小概率被平均收益淹没。
5. **从右向左折叠。** 机会节点求期望值；决策节点保留价值最高分支。展示计算过程，不只报答案。
6. **做敏感性分析。** 改动最不确定的概率和价值，找出结论在哪个阈值翻转。若小幅改动就换答案，结论是“需要更多信息”，不是“选 A”。
7. **计算信息价值。** 比较“先得到信息再选”的期望价值与“现在直接选”的价值。信息价值是你为试点、调研或检测最多该付的上限；还要扣除信息本身的成本和延迟。

## 例证

**药物研发的阶段门**：企业不是一开始就押注完整商业化，而是先做小规模试验，看到安全性与有效性信号后再决定是否进入昂贵阶段。决策树显示的不是“药会不会成功”这一条概率，而是**信息到达后还能改变行动**的价值。

**勘探与钻井**：直接钻井可能高收益也可能全损；先做地质测试会花钱但更新成功概率。若测试带来的期望改进大于测试费，先买信息。这个例子揭示决策树比静态优缺点表多出的关键：**顺序和信息价值**。

**（原书卡片）投资项目**：投入 1000，成功得 10000、失败损失 1000，卡片用期望值求成功概率阈值。它说明了折叠方法，但忽略了资金损失是否会让决策者出局；若 1000 是全部身家，不能用正 EV 为归零风险辩护。

## 什么时候不适用

- **概率不可校准**：树只会把未经检验的信念画得更整齐。先扩大区间或购买信息。
- **结果存在不可逆归零风险**：期望值会平均掉灾难；先用反脆弱限定暴露。
- **极端风险偏好差异**：同样的金额对不同人效用不同，不能拿群体平均替个人决定。
- **树爆炸**：分支过多时应按真正改变行动的状态剪枝；不是所有可能性都值得画。但不能因为一个低概率结果难算，就剪掉可能致命的尾部风险。
- **模型遗漏**：决策树清楚不等于完整。至少让一名反方检查有没有漏掉关键结果。

## 相关模型

- **与[机会成本](../../econ-micro-markets/opportunity-cost/SKILL.md)**：结果基本确定、只需比较互斥行动，走机会成本；结果不确定且需要概率分支，走本模型。
- **与[反脆弱](../../learning-growth/antifragility/SKILL.md)**：能估概率、目标是最大化期望效用，走本模型；深度不确定、重点是下行有限和避免归零，走反脆弱。
- **与[奥卡姆剃刀](../../cognitive-thinking-tools/occams-razor/SKILL.md)**：奥卡姆剃刀给解释排验证顺序；本模型给行动与后果排选择。
- **与[10/10/10](../../thinking-models/ten-ten-ten/SKILL.md)**：本模型量化不确定后果；10/10/10拉开短中长期的价值视角，可用于补全终点价值。
- **与[期望值](../expected-value/SKILL.md)**：**硬区分。** 用户说画树 / 先试点再上 / 信息值多少钱 → 决策树。用户说这笔静态不确定结果的期望 / 点数公平切 / 彩票 EV → 「期望值」。
- **与[期望效用](../expected-utility/SKILL.md)**：树叶结果可用效用折叠；用户主诉风险厌恶/归零而非画树时，可先走期望效用。
- **与[情景规划](../scenario-planning/SKILL.md)**：概率可粗估、要折叠 EV → 本模型；深度不确定、要分歧叙事与稳健选项 → 情景规划。
- **与[贝叶斯更新](../bayesian-updating/SKILL.md)**：机会节点概率随证据更新后再折叠。
