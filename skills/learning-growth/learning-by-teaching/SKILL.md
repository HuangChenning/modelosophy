# 学习中教 Learning by Teaching

## 这是什么

**学习中教**：通过准备并实施教学（讲解、示范、答疑、出题、批改）来学习——教学压力迫使你组织材料、预期误解、主动提取，从而出现 **protégé effect（被指导者效应）**：为教而学往往比只为自己学更深入。

与「读完感觉会了」不同：面向受众的产出有对错与问题回弹。本模型交付**最小可教学单元设计**，不是正式教师资格培训。

**鉴别**：[`feynman-technique`](../feynman-technique/SKILL.md) 可对空气/橡皮鸭讲，核心是浅白+补洞闭环；本模型强调**受众互动与教学任务**（问题、作业、答疑）。[`learning-pyramid`](../learning-pyramid/SKILL.md) 的「教=90%」是误读——此处不引用假百分比。

## 什么时候用

- "讲给别人听是不是学得更快"
- "教中学 / 备课怎么设计才真学到"
- 同伴辅导、分享会、写教程、带实习生讲解

**不要**当主模型：

- 只要个人四步补洞 → [`feynman-technique`](../feynman-technique/SKILL.md)
- 只要闭卷闪卡 → [`retrieval-practice`](../retrieval-practice/SKILL.md)
- 只要拆穿金字塔图 → [`learning-pyramid`](../learning-pyramid/SKILL.md)

## 怎么用（执行步骤）

1. **选定最小可教单元（10–20 分钟能讲完）。** 一个概念/一个程序；忌「整门课一次讲」。
2. **写受众成功标准。** 「听完能独立完成 X / 答出 Y」；无标准则教学变表演。
3. **备课强制提取。** 不看资料列出大纲与易错点；卡壳处标红去补——此即学习发生点。
4. **设计 1 个互动检查。** 提问、小练习或让对方复述；纯独白收益大减。
5. **实施并记录对方误解。** 误解列表=你的知识地图缺口或表达缺口；逐条修补后再教短版。
6. **教后自测。** 合上材料做检索/变式题；「只会讲稿不会做题」→ 补练习，勿停在演讲自信。

## 例证

**同伴辅导数学**：为讲清错因，辅导者必须重组步骤——常出现辅导者进步不亚于被辅导者。

**写技术博文**：读者评论指出边界情况——揭示**受众迫使完备性**。

**（局限）**：教错且无反馈会固化错误；需要标准答案、评审或可检验任务。

## 什么时候不适用（边界）

- **零基础无最小正确模型**：先输入正确材料，再教。
- **高风险领域无监督**：医疗/安全操作勿「自学自教」实操。
- **表演型分享**：只追求场面，无检查点 → 无效。
- **时间只够首次编码**：极短时限可先检索卡片，再安排教。

## 常见误用

- **照念幻灯**：无提取 → 备课必须先默写大纲。
- **与费曼完全等同**：对空气费曼 OK；有互动与成功标准时走本模型（可连用）。
- **引用 90% 金字塔**：纠正为假数字，改谈教中学机制。
- **教完不自测**：讲顺≠会做 → 强制教后检索。

## 相关模型

- **与[费曼技巧](../feynman-technique/SKILL.md)**：费曼是个人浅白补洞；教中学加受众与检查点。可先费曼再面向真人。
- **与[检索练习](../retrieval-practice/SKILL.md)**：备课与答疑本质是高强度提取。
- **与[导师制](../mentorship/SKILL.md)**：正式带教关系容器；单次分享可用本模型。
- **与[学习金字塔](../learning-pyramid/SKILL.md)**：金字塔作纠偏；真正执行教中学用本模型。
- **与[元认知](../metacognition/SKILL.md)**：用听众问题监控「哪里只是流畅错觉」。

## 记忆钩子

为了教清楚而备课，往往比再读一遍更接近真会。
