# STAR 法则 STAR Method

## 这是什么

**STAR**：讲述过往行为与项目的四段结构——

| 段 | 含义 | 听众要听到 |
|---|---|---|
| **S** Situation | 情境 | 背景、约束、时间范围 |
| **T** Task | 任务 | 你的目标/职责（不是小组口号） |
| **A** Action | 行动 | **你**具体做了什么（动词+对象） |
| **R** Result | 结果 | 可核对的结果、学习与可迁移点 |

它让经历可被追问与比较，减少「我们很拼」式空话。STAR 是**叙事与举证结构**，不是战略分析框架。

## 什么时候用

- 面试/述职/晋升答辩需要讲项目
- "经历讲散了，没有重点"
- 直接说 STAR / 行为面试 / Situation Task Action Result

**不要**当主模型：

- 商务汇报问题定义与答案 → [`scqa`](../scqa/SKILL.md)
- 论证塔/结论先行备忘录 → [`pyramid-principle`](../pyramid-principle/SKILL.md)
- 根因分析 → [`five-whys`](../five-whys/SKILL.md)
- Why–How–What 品牌叙事 → [`golden-circle`](../golden-circle/SKILL.md)

## 怎么用（执行步骤）

1. **选一个匹配目标能力的故事。** 对照岗位/问题要的能力（协作、冲突、攻坚…），只选一个主故事。判据：能否在 2–3 分钟讲完？
2. **写 S：最少必要背景。** 行业/团队规模/约束各一句。禁止半分钟铺垫。
3. **写 T：你的责任边界。** 「我负责 X，成功标准是 Y」。若只是「参与」，老实写清角色。
4. **写 A：可观察行动清单（主体是我）。** 每条含动词+对象+关键抉择；团队行动要标明「我提议/我执行/我协调」。判据：去掉「我」后句子是否仍成立？若成立，可能在偷功劳或过空。
5. **写 R：量化或可核实结果 + 反思。** 数字、前后对比、客户反馈；失败故事写清学到什么与之后如何改。禁止无法核对的「极大提升」。
6. **预演追问。** 准备「还有谁参与」「数据来源」「若重来会改什么」；补强薄弱段。

## 例证

**行为面试**：S「上线前两周核心接口失败率升高」→ T「我负责定位与回滚决策」→ A「我拉日志对照发布、冻结发布、修配置」→ R「失败率回落，复盘改了检查单」。揭示：A/R 具体才有信息量。

**失败 STAR**：通篇「我们团队很努力」无 T/A 边界——揭示缺个人行动则无法评估。

## 什么时候不适用（边界）

- **未来规划/策略选择**：STAR 讲过去；前瞻用 SCQA/金字塔/决策模型。
- **机密无法说结果**：用脱敏指标或换故事，勿撒谎。
- **技术深度答辩**：STAR 外壳下仍需硬技术细节，结构不能代替能力。

## 常见误用

- **与 SCQA 混淆**：SCQA 答「该怎么办」；STAR 证「我曾怎么办」。
- **A 段全是「我们」**：评委无法判断你的贡献 → 标明个人动作。
- **R 段只有感受**：补可核查结果。
- **编造**：短期或可被背调拆穿；宁讲小而真。

## 相关模型

- **与[SCQA](../scqa/SKILL.md)**：**硬区分。** 问题定义/商务开场 → SCQA；经历举证 → STAR。
- **与[金字塔原理](../pyramid-principle/SKILL.md)**：金字塔组织主张与论据；STAR 组织单一经历叙事。可在答辩中先一句结论再 STAR 举证。
- **与[黄金圈](../golden-circle/SKILL.md)**：黄金圈讲动机层次；STAR 讲事件四段。
- **与[结构化思维](../structured-thinking/SKILL.md)**：结构化思维管分析；STAR 管讲述。

## 记忆钩子

先画场景，钉你的任务，讲你的动作，甩出可核对的结果。
