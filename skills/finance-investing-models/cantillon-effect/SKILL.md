# 坎蒂隆效应 Cantillon Effect

## 这是什么

**坎蒂隆效应（Cantillon）**：货币供给增加不是对所有价格、所有人同时同比例发生；**注入点与传导路径**决定相对价格与财富再分配。先接触新货币者受益，固定收入、后调价者受损。

## 什么时候用

- "放水到底肥了谁？"
- "为什么资产先涨、工资后涨？"
- "坎蒂隆效应是什么？"

**不要**在以下情况套用本模型：

- 只要名义/实际利率拆解 → [费雪效应](../fisher-effect/SKILL.md)
- 只要股市泡沫情绪阶段 → [泡沫周期](../bubble-cycle/SKILL.md)

## 怎么用（执行步骤）

1. **找到注入点。** 央行→银行→哪些借款人/资产市场？财政→哪些账户？
2. **画传导顺序。** 哪些价格先动（金融资产、大宗、房租、CPI 篮子）？
3. **识别受益/受损群体。** 资产持有者 vs 现金工资者；出口商/进口商等。
4. **区分总量叙事与分配叙事。** 总量“水多了”不够；必须回答顺序。
5. **政策或个人含义。** 个人侧：流动性与资产配置暴露；政策侧：认清再分配而非假装中性。

## 例证

**QE 后风险资产先行**：靠近金融管道者净值先膨胀。揭示“通胀”可先表现为资产通胀。

**地方信贷扩张**：特定行业地价工资先动。揭示路径依赖的价格结构。

## 什么时候不适用（边界）

- **封闭同步直升机撒钱思想实验**：故意抹平路径时效应被设计掉。
- **纯相对价格由技术冲击主导**：勿硬套货币故事。

## 常见误用

- **把一切不平等都叫坎蒂隆**：需证明与货币/信贷注入路径相关。
- **当成阴谋论替代机制分析**。

## 相关模型

- **与[金融加速器](../financial-accelerator/SKILL.md)**：资产价格与信贷互馈放大注入后果。
- **与[费雪效应](../fisher-effect/SKILL.md)**：总量利率-通胀；本条讲分配顺序。
- **与[泡沫周期](../bubble-cycle/SKILL.md)**：注入常为泡沫提供流动性燃料。
