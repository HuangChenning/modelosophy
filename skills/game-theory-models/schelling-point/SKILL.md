# 谢林点（焦点均衡） Schelling Point / Focal Point

## 这是什么

**无沟通（或沟通不足）时，人们靠显著显著性汇聚到的那个选项。**

Schelling《冲突的战略》：多重均衡下，文化显著、唯一、中心、默认选项成为焦点。不是支付最优的数学推导，而是显著性和共同猜想“对方也觉得我觉得…”。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "谢林点"
- "没约定会对到哪"
- "哪个选项最显眼"

**不要**在以下情况套用本模型：

- 唯一均衡已定 → ../nash-equilibrium/SKILL.md
- 靠贵信号分离 → ../signaling-games/SKILL.md
- 规则强制唯一实施 → ../mechanism-design/SKILL.md

## 怎么用（执行步骤）

1. **列出多均衡/多选项。** 支付上多个都可。
2. **打显著性分。** 唯一、中心、圆整、文化默认、标签醒目。
3. **做共同知识测试。** “我会选 X，且我认为你认为我会选 X”。
4. **设计焦点。** 若要汇聚：制造唯一显著默认；若要避免错误汇聚：打破伪焦点。输出：焦点候选 + 理由。

## 例证

**纽约见面实验**：大车站/正午等焦点。揭示文化显著性。

**产品默认选项**：默认成为焦点配置。揭示设计者责任。

## 什么时候不适用（边界）

- **异质文化**：焦点不可移植。
- **冲突利益**：焦点不能消除零和层。

## 常见误用

- **当支付最优证明**：焦点是显著性，不是福利定理。
- **忽略被操纵的默认**：暗模式可滥用焦点。

## 相关模型

- **与[协调博弈](../coordination-game/SKILL.md)**：多均衡母体。
- **与[猎鹿博弈](../stag-hunt/SKILL.md)**：焦点可助迁向合作均衡。
