# 可逆与不可逆决策 Reversible vs Irreversible

## 这是什么

**可逆 vs 不可逆决策**：按**反悔成本**给决策分型——

| 类型 | 隐喻 | 默认节奏 |
|---|---|---|
| 可逆（Type 2 / two-way door） | 推门进去还能出来 | 默认**快**：小范围试、保留退出 |
| 不可逆（Type 1 / one-way door） | 出去很难或代价极高 | 默认**慢**：更重证据、反对意见、批准层级 |

Bezos 强调的组织病是：把大多数双向门当成单向门开层层会议，导致迟缓；或把单向门当成双向门莽撞穿过。

## 什么时候用

- "这件事做错了还能改吗"
- "要不要再对齐一轮 / 能不能先上再调"
- "单向门 / Type 1 / Type 2 / 可逆决策"
- 流程过重或过轻、决策速度与风险不匹配时

**不要**当主模型：

- 已确定可逆、需要最小试验设计 → [`mvp`](../mvp/SKILL.md)
- 对抗环境下的观察—行动循环速度 → [`ooda-loop`](../ooda-loop/SKILL.md)
- 金额期望计算 → [`expected-value`](../expected-value/SKILL.md)

## 怎么用（执行步骤）

1. **写清决策与「反悔路径」。** 若选 A，30/90 天后撤销要付出什么（钱、信誉、合约、安全、数据不可删）？写具体条目。
2. **判定门型（可附条件）。** 反悔成本低且路径清楚 → 可逆；高或路径断 → 不可逆。模糊则拆：把大决策拆成可逆前缀 + 不可逆后缀。
3. **匹配流程重量。** 可逆：单人或小团队拍板、时间盒、默认「先试」。不可逆：书面假设、红队/事前验尸、明确批准人、冷却期。
4. **设计退出与监测（可逆必备）。** 退出触发器、回滚步骤、最大暴露。没有退出器的「可逆」是假可逆。
5. **不可逆的信息购买。** 问能否用试点、分阶段合约、期权式条款把单向门改成「先双向再单向」。
6. **复盘门型是否判错。** 事后若发现「以为可逆其实锁死」，更新组织清单（哪些合同/架构是真单向）。

## 例证

**产品文案/定价小改**：低反悔 → 可逆，A/B 快试。揭示：会议成本常高于试错成本。

**公开永久删除用户数据 / 签署排他长约 / 大规模裁员**：高反悔 → 不可逆，加重审查。揭示：速度美德不适用于单向门。

**架构选型**：选专有协议可能锁死；先用适配层试点是「把单向门拆成可逆前缀」。

## 什么时候不适用（边界）

- **安全与合规红线**：不可用「可逆」合理化违规试验。
- **反悔成本误判**：网络效应、关系破裂、监管记录常被低估 → 偏保守判单向。
- **伪协商一致**：不可逆决策用投票掩饰无人负责 → 仍需明确 owner。

## 常见误用

- **凡事先对齐**：把双向门当单向 → 降流程。
- **凡事先上线**：把单向门当双向 → 加重审查或拆步。
- **口头可逆、系统不可逆**：无回滚、无开关 → 先做工程退出再称可逆。
- **与沉没成本混淆**：已经进去后「因为投入了所以不退出」→ [`sunk-cost`](../../behavioral-biases/sunk-cost/SKILL.md)。

## 相关模型

- **与[MVP](../mvp/SKILL.md)**：判定可逆后，用 MVP 设计最小试验；本模型先分门型。
- **与[事前验尸](../pre-mortem/SKILL.md)**：不可逆决策强烈建议事前验尸。
- **与[红队思维](../red-team/SKILL.md)**：单向门加大红队力度。
- **与[机会成本](../../econ-micro-markets/opportunity-cost/SKILL.md)**：慢决策的代价是错过的选项；双向门过慢时显式算时间机会成本。
- **与[反脆弱](../../learning-growth/antifragility/SKILL.md)**：不可逆归零风险用暴露上限，不只靠「再开次会」。

## 记忆钩子

先问门能否回来；**双向门用速度，单向门用重量。**
