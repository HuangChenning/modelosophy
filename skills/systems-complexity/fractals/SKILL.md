# 分形 Fractals

## 这是什么

**分形**：在一定标度范围内呈现**自相似**——放大局部仍见类似结构；常伴非整维数与标度律。自然例：海岸线、支气管、部分市场波动图；组织隐喻：小队结构重复到事业部。

操作价值：**同一套生成规则在多尺度起作用**时，干预规则可跨尺度复用；否则「分形」只是好看的词。

## 什么时候用

- "放大看还是同一套结构"
- "分形 / 自相似 / 标度不变"
- 城市路网、器官分支、部分层级组织、波动粗糙度

**不要**当主模型：
- 只要统计胖尾 → [`power-law`](../power-law/SKILL.md)
- 只要图的度数/聚类 → [`network-topology`](../network-topology/SKILL.md) / [`scale-free-network`](../scale-free-network/SKILL.md)
- 只要涌现宏观 → [`emergence`](../emergence/SKILL.md)

## 怎么用（执行步骤）

1. **选定尺度窗。** 从哪一尺度看到哪一尺度？（米→公里；小组→公司）。判据：写上下界。
2. **检验自相似。** 局部模式是否重复？定量（相关维、粗视化）或至少结构化对照表。判据：有证据，不靠感觉。
3. **找生成规则。** 分支规则、递归拆分、偏好附着？判据：规则可陈述。
4. **决定推理是否可跨尺度。** 规则真跨尺度 → 试点可外推；仅修辞相似 → 禁止外推。
5. **设计干预。** 改生成规则（分支角度、拆分标准）而非只修剪一个尺度的叶子。
6. **标失效尺度。** 超过物理/制度上下界后自相似破裂——写明。

## 例证

**肺支气管 / 河流网**：分支自相似优化输送。揭示：规则跨尺度。

**「团队是缩小版公司」**：仅当决策权、信息流规则真同构；否则是口号。揭示：组织分形要可检验。

**（原书卡片）**：避免海报式分形图；落到尺度窗与规则。

## 什么时候不适用（边界）

- **有特征尺度主导**：单一工厂节拍、固定批次——非分形主场。
- **尺度窗外强行外推**：会荒谬。
- **只为审美的嵌套图**：无决策价值。

## 常见误用

- **嵌套 = 分形**：要自相似+标度证据。
- **与幂律自动等同**：相关但不等价。
- **无限细分责任**：把分形当甩锅层级。

## 相关模型

- **与[幂律](../power-law/SKILL.md)**：分形测量常伴幂律；幂律不自动等于几何自相似。
- **与[网络拓扑](../network-topology/SKILL.md)**：拓扑是图度量；分形是跨尺度几何/生成。
- **与[涌现](../emergence/SKILL.md)**：分形是结构性质；涌现是跨尺度新性质。

## 记忆钩子

先定放大几级仍相似——相似才借规则，不相似别借结论。
