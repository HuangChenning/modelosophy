# 金融加速器 Financial Accelerator

## 这是什么

**金融加速器（Bernanke, Gertler, Gilchrist 等）**：因代理问题与抵押约束，外部融资溢价随借款人净值反向变化。负向冲击打低资产价格与净值 → 借贷变贵变少 → 支出/投资更弱 → 价格再下——**小冲击被金融渠道放大**。

## 什么时候用

- "为什么房价/股价跌会拖垮信贷与实体？"
- "抵押品贬值怎样自我强化？"
- "金融加速器是什么？"

**不要**在以下情况套用本模型：

- 融资结构从对冲滑向庞氏的叙事主轴 → [明斯基时刻](../minsky-moment/SKILL.md)
- 货币注入分配 → [坎蒂隆效应](../cantillon-effect/SKILL.md)

## 怎么用（执行步骤）

1. **找到关键抵押与净值变量。** 房产、股票质押、企业净资产。
2. **写出信贷条件如何随净值变。** 折扣率、利率加点、额度。
3. **追踪第二轮。** 信贷收缩打击谁的支出/投资？是否回流资产市场。
4. **估计是否“加速”。** 相对无信贷摩擦的世界，冲击是否明显被放大。
5. **政策/个人含义。** 降杠杆、减质押集中度；关注系统性折扣率跳升风险。

## 例证

**房地产抵押链条**：价跌→贷款LTV恶化→强制去杠杆→再砸价。揭示加速器的抵押核心。

**权益质押平仓潮**：净值触发平仓线，价格冲击被杠杆放大。

## 什么时候不适用（边界）

- **纯股权、无杠杆投资者的纸面波动**。
- **信贷渠道被管制完全切断的特殊制度**（机制变形）。

## 常见误用

- **把加速器当成涨跌循环的万能词**。
- **忽视现金缓冲与无质押资产的减震**。

## 相关模型

- **与[明斯基时刻](../minsky-moment/SKILL.md)**：加速器是放大通道；明斯基是脆弱性演化。
- **与[股债跷跷板](../stock-bond-seesaw/SKILL.md)**：风险 off 时加速器可与避险债需求并存。

## 记忆钩子

资产越跌越借不到钱，越借不到钱资产越跌。
