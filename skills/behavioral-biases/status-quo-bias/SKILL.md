# 现状偏差 Status Quo Bias

## 这是什么

**在多个选项中，系统性地偏向当前状态，把现状当参照并夸大改变的损失。**

与默认效应强相关：现状常由默认构成。但现状偏差也可出现在无显式默认、只因“一直这样”而不评估替代的场合。机制常叠损失规避：改变被编码为失去现有。

## 什么时候用

- 订阅、供应商、投资组合多年不审
- "先维持现状再议"却从未再议

**不要**当主模型：

- 讨论的是 UI 预设勾选如何收割同意 → [`default-effect`](../default-effect/SKILL.md) 更贴
- 已投入沉没不肯停 → [`sunk-cost`](../sunk-cost/SKILL.md)

## 怎么用（执行步骤）

1. **写出现状与可行替代。** 至少两个真实可执行替代，含“主动再选一次现状”。
2. **同等框架比较。** 用终态成本/收益表，去掉“我们已经用了”。
3. **标切换成本。** 分真实成本（迁移、学习、违约金）与不适感；仅后者高而净收益仍正则倾向现状偏差。
4. **设复审触发。** 日历、阈值阈值、强制选择日；输出：维持/切换决定 + 下次复审条件。

## 例证

**电力/基金默认方案实验**：多数人留在初始分配——揭示现状/默认的粘性。

**旧工具链**：团队知更好方案仍不迁——揭示组织现状偏差。

## 什么时候不适用（边界）

- **高切换成本超过收益**：维持是理性。
- **稳健性优先**：在极值不确定时“先不折腾”可作显式策略。

## 常见误用

- **把谨慎都叫现状偏差**：要有净收益被无理由放弃的证据。
- **与禀赋混用**：禀赋抬估值；现状偏偏好“不改”。

## 相关模型

- **与[默认效应](../default-effect/SKILL.md)**：默认是制造现状的强力装置。
- **与[损失规避](../loss-aversion/SKILL.md)** / **[禀赋效应](../endowment-effect/SKILL.md)**：改变=失去编码。
- **与[沉没成本](../sunk-cost/SKILL.md)**：历史投入加固现状。

## 记忆钩子

“一直这样”不是优点，除非算过账。
