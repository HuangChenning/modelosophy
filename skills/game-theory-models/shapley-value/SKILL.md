# 夏普利值 Shapley Value

## 这是什么

**按玩家对所有可能联盟的平均边际贡献来分配总剩余的公理化方案。**

Shapley：效率、对称、哑元、可加等公理推出唯一解。计算为所有加入顺序上边际贡献的平均。公平感强，但不一定落在核内。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "夏普利值怎么分"
- "按贡献分公平吗"
- "边际贡献平均"

**不要**在以下情况套用本模型：

- 策略式非合作 → ../nash-equilibrium/SKILL.md
- 要整集稳定分配 → ../core/SKILL.md
- 双边稳定匹配 → ../matching-theory/SKILL.md

## 怎么用（执行步骤）

1. **写 v(S) 全表（小人游戏）。** n 小才可手算；大 n 用抽样/软件并声明。
2. **对每一玩家平均边际贡献。** 概念：所有排列下加入时的增量均值。
3. **检查公理叙事。** 对称者同等、无贡献者零、总和=v(N)。
4. **对照核。** 若夏普利不在核，标出可能被联盟否决的风险。输出：分配向量 + 是否在核。

## 例证

**机场跑道成本分摊**：经典夏普利应用。揭示边际使用。

**三人合伙盈亏**：不同两人组价值不等时，夏普利拉开份额。

## 什么时候不适用（边界）

- **计算爆炸**：n 大难手算。
- **不在核**：“公理公平”仍可能被联盟推翻。

## 常见误用

- **把会计成本当边际贡献**：必须用 v(S)。
- **当作唯一正义**：公理可争议；核是另一标准。
