# SCQA 框架 Situation–Complication–Question–Answer

## 这是什么

**SCQA** 是一套**问题定义与沟通开场**结构（常见于 Barbara Minto 的金字塔写作传统）：

| 字母 | 含义 | 作用 |
|---|---|---|
| **S** Situation | 情境 | 读者已知、双方认同的现状（稳定画面） |
| **C** Complication | 冲突/转折 | 打破情境平衡的变化、缺口或张力 |
| **Q** Question | 问题 | 冲突在读者心中自然浮现的核心问题 |
| **A** Answer | 答案 | 对 Q 的直接答复（常成为后续论证的塔顶） |

它解决的是：**先让读者感到「这个问题值得听」**，并保证 Answer 对准真正的 Question，而不是自说自话。

SCQA **不是**完整论证方法：A 之后通常还要用金字塔/证据展开；本 Skill 专注 S→C→Q→A 四步对齐。

## 什么时候用

- "汇报/邮件/路演不知道怎么开场"
- "材料很多，但读者的问题没对齐"
- 直接说 SCQA / 情境–冲突–问题–答案
- 策略备忘录需要先定义「我们到底在回答什么」

**不要**当主模型：

- 用户要整座「结论先行 + 分组论据」论证塔 → [`pyramid-principle`](../pyramid-principle/SKILL.md)
- 只要分类不重不漏、尚无主张 → [`mece`](../mece/SKILL.md)
- 要讲清 Why–How–What 动机叙事 → [`golden-circle`](../golden-circle/SKILL.md)
- 面试行为故事结构 → [`star-method`](../star-method/SKILL.md)

## 怎么用（执行步骤）

1. **写 S（情境）：双方默认同意的 1–3 句事实。** 判据：去掉后读者是否会问「你在说哪个世界？」；禁止把争议结论塞进 S。
2. **写 C（冲突）：打破 S 的变化或缺口。** 用「但是 / 然而 / 现在」点出张力（机会、威胁、异常数据、截止日期）。判据：若 C 不存在，读者是否没有理由继续听？
3. **从 C 导出 Q（问题）：读者会问的那一句。** Q 必须是疑问句或等价决策问题（「是否进入 X？」「如何在 90 天内止住流失？」）。判据：不同利益相关方是否会问出**同一个**主 Q？若问出多个，先排序或拆文档。
4. **写 A（答案）：对 Q 的直接答复。** 一句话，禁止「情况复杂见下文」。判据：抽掉后文，A 是否仍算回答了 Q？
5. **自检对齐。** S 是否中立？C 是否真的相对 S 构成转折？A 是否答 Q 而非答了旁支？若 A 很精彩但答错问题，重做 Q，不要硬改事实。
6. **交接。** 需要展开论证时，把 A 交给 [`pyramid-principle`](../pyramid-principle/SKILL.md) 做 Key Line；本 Skill 在此可结束。

## 例证

**产品决策备忘录**：S「我们在核心城市场占稳定」→ C「上季度新客获取成本翻倍且留存下滑」→ Q「是否继续加投获客，还是先修留存？」→ A「未来两季度优先修留存，获客预算封顶」。揭示 SCQA 的价值是**把争论从口号拉回可答问题**。

**失败开场**：一上来堆行业趋势（伪 S）却把「我们应该All-in AI」塞进情境——读者未感到冲突，只感到被推销。揭示：S 必须可认同；争议放 C/A。

**与金字塔连用**：同一份材料用 SCQA 开场 4 句，随后以 A 为塔顶展开三点论据——揭示 SCQA 是**引入**，金字塔是**展开**。

## 什么时候不适用（边界）

- **读者已共享问题**：上下文极熟时可直接结论先行，不必每次 SCQA。
- **探索早期无答案**：可以写到 Q 就停，标明「A 待证」；禁止伪造 A。
- **多读者多主问题**：一份 SCQA 只能服务一个主 Q；否则拆篇或先对齐受众。
- **文学/悬念叙事**：故意延迟答案的体裁不适用商务 SCQA。

## 常见误用

- **把 SCQA 当成整篇万能模板**：四段写完就交差、无证据 → 展开时用金字塔并补证据。
- **S 里夹带结论**：情境变成软广告 → 把主张移到 A。
- **Q 与 A 错位**：问的是「要不要做」，答的是「怎么做很酷」→ 重写对齐。
- **与 STAR 混淆**：STAR 讲个人经历故事；SCQA 定义商务问题。
- **与黄金圈混淆**：黄金圈排序目的—方法—产品；SCQA 排序情境—冲突—问题—答案。

## 相关模型

- **与[金字塔原理](../pyramid-principle/SKILL.md)**：**硬区分。** 只要开场/问题定义 → 本模型；要完整论证塔（结论+Key Line+证据）→ 金字塔。金字塔可将 SCQA 作可选引入；专做 SCQA 时走本 Skill，避免整塔流程过重。
- **与[MECE](../mece/SKILL.md)**：MECE 拆分类；SCQA 定义要回答的问题。可先 SCQA 钉 Q，再 MECE 拆分析工作。
- **与[黄金圈](../golden-circle/SKILL.md)**：黄金圈偏信念与动机叙事；SCQA 偏读者问题对齐。用户说「我们为什么存在」走黄金圈；「汇报怎么引出问题」走 SCQA。
- **与[STAR 法则](../star-method/SKILL.md)**：STAR = 情境–任务–行动–结果（经历举证）；SCQA = 情境–冲突–问题–答案（问题定义）。面试故事走 STAR。
- **与[结构化思维](../structured-thinking/SKILL.md)**：结构化思维是总论式拆解习惯；SCQA 是其中一种沟通开场专用结构。

## 记忆钩子

先让读者站在同一幅画里，再撕开裂口，问出那一问，最后给一句真答案。
