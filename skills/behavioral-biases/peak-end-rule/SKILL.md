# 峰终定律 Peak-End Rule

## 这是什么

峰终定律（Kahneman 等）：人们对一段**情感性体验**的事后整体评价，很大程度由**峰值强度**（最好或最坏的时刻）与**结束时的感觉**决定，而不是对每一时刻的苦乐做积分平均。伴随现象是**时长忽视（duration neglect）**：同样峰值与结尾时，过程更长不一定按比例改变回忆评价。

它描述的是 **remembered utility（回忆效用）**，可以系统偏离 **moment utility（当下体验）**。因此“当时不难受但记得很糟”或相反，都可能出现。

## 什么时候用

- 产品/服务/课程/医疗流程的体验设计与复盘；
- “为什么大家只骂最后五分钟 / 只夸高潮瞬间”；
- 直接说峰终 / peak-end / 时长忽视。

**不要**当主模型：
- 幻灯片要点谁记得住 → [`serial-position-effect`](../../systems-classic-effects/serial-position-effect/SKILL.md)；
- 得失框架决策 → [`loss-aversion`](../loss-aversion/SKILL.md) / [`prospect-theory`](../prospect-theory/SKILL.md)；
- 行为是否发生 → [`fogg-behavior-model`](../../thinking-models/fogg-behavior-model/SKILL.md)。

## 怎么用（执行步骤）

1. **界定体验片段。** 从用户感知的开始到结束（一次就诊、一次逛店、一节课），不要混多个无关片段。
2. **标峰值与结尾。** 峰值=强度最大的正或负时刻；结尾=片段结束时的情感状态。各用一句话描述。
3. **对照时长与过程均值。** 问：若只加长中间平稳段，回忆分会不会几乎不变？若会，时长忽视在起作用。
4. **设计或纠偏。** 提回忆评价：抬高（或避免）关键峰、认真设计收尾（确认、总结、小胜利）；降负面回忆：避免在结尾叠加痛点（收费纠纷、冷漠告别）。诚实对待伦理：不靠故意制造痛苦再“温柔收尾”来操纵。
5. **分开当下优化与回忆优化。** 有时应优先减小时刻痛苦（医疗），即使略损“漂亮回忆曲线”。

## 例证

**结肠镜等经典范式**：在不适体验末尾增加一段较轻不适，回忆评价可好于更短但陡然结束的版本——揭示**结尾形状**改变 remembered utility（教学时说明伦理争议与复制边界）。

**宜家逛店**（原书亦用）：迷路与排队痛苦存在，但物有所值的“峰”与出口甜筒式结尾可支撑整体好评。揭示峰终可与过程摩擦共存；也揭示商业应用边界——摩擦仍有流失成本。

**课程设计**：两小时平铺 vs 中间高光演示+课后清晰行动总结，回忆推荐度常后者更高。揭示时长不是回忆分的线性原料。

**（原书卡片）与系列位置“如出一辙”**：必须纠正——近因是列表末项记忆，峰终结尾是情感终点；峰值更不是首因。宜家例保留，励志“反人性植入峰终”语气降级为体验审计工具。

## 什么时候不适用（边界）

- **非情感列表记忆任务**：背单词、记议程走系列位置。
- **安全与伤害**：不可为“好评曲线”故意制造危险高峰。
- **个体与文化差异**：峰终是强启发式，不是人人同一权重的常数。
- **即时决策**：若用户正在体验中要选择，应问当下效用与风险，不只优化未来回忆。

## 常见误用

- **与系列位置“如出一辙”**：近因是列表末项记忆；峰终结尾是情感终点 → 词表/议程走 [`serial-position-effect`](../../systems-classic-effects/serial-position-effect/SKILL.md)。
- **为“好评曲线”故意制造危险高峰再温柔收尾**：伦理越界 → 可抬正峰、设计收尾，不可制造伤害。
- **正在体验中却只优化未来回忆**：医疗等当下痛苦优先 → 分开当下效用与 remembered utility。
- **把峰终当人人同一权重的常数**：个体与文化差异大 → 当启发式审计，不当精确定律。

## 相关模型

- **与[系列位置效应](../../systems-classic-effects/serial-position-effect/SKILL.md)**：列表头尾记忆 vs 体验峰终回忆；勿合并成一条定律。
- **与[损失规避](../loss-aversion/SKILL.md)**：负峰往往比等量正峰更钉在记忆里，可与损失权重叠加。
- **与[前景理论](../prospect-theory/SKILL.md)**：峰终属体验记忆启发式；前景理论管选择价值函数与概率权重。
- **与[可得性启发](../availability-heuristic/SKILL.md)**：峰与终更易提取，可能被误判为“全过程都那样”。
