# 元认知 Metacognition

## 这是什么

Flavell 以来，元认知指**关于认知的认知**：对自身注意、理解、记忆、推理与学习策略的**知识 + 监控 + 调节**。典型活动：

- **监控**：我现在懂了吗？这段推理有漏洞吗？注意力是否飘了？
- **调节**：换策略、重读、分解问题、求助、暂停冲动回答。

它是可训练的过程技能，不是神秘的“第三只眼”。流畅感（读起来顺）≠ 真正掌握——元认知要主动对照外部标准（习题、复述、测验）。

## 什么时候用

- 学习/解题卡住，需要判断是内容问题还是策略问题；
- 想建立“想完再检查”的习惯；
- 直接提元认知 / metacognition / 思维监控。

**不要**当主模型：
- 焦点是“低能力者是否系统性高估自己”的校准争议 → [`dunning-kruger`](../dunning-kruger/SKILL.md)；
- 快慢思维分工 → [`dual-process`](../dual-process/SKILL.md)；
- 用教别人暴露知识空洞 → [`feynman-technique`](../feynman-technique/SKILL.md)（可与元认知连用）。

## 怎么用（执行步骤）

1. **任务前：预测难度与策略。** 写：“成功标准是什么？我打算用哪三步？哪里可能翻车？”
2. **任务中：设检查点。** 每完成一块，强制问：我能不看材料用自己的话复述吗？卡壳标记是概念缺口还是步骤缺口。
3. **对照外部证据。** 做一题、画草图、讲给别人听、对照答案——用表现校准“感觉会了”。
4. **调节：只改一个杠杆。** 换表征、降难度、分段、求助；避免同时改十个习惯导致无法归因。
5. **任务后：短复盘。** 哪条监控问题救了你？下次把哪条检查点前移？

## 例证

**阅读假懂**：段落读着顺，合上书说不出要点——揭示**流畅感不可靠**，需检索练习做监控。

**考试策略切换**：发现一种解法耗时过长，改用另一模型或跳题——揭示**调节**而不只是更用力。

**（原书卡片）认识自己的思维**：方向对；易与“人生觉醒”混写。须保持可操作：预测—检查点—外部校准—调节—复盘；并把与邓克的分工写死。

## 什么时候不适用（边界）

- **急性安全决策需程序化检查单**：用清单/SOP，而不是开放式内省耽误时间。
- **临床级强迫性自我监控**：过度监察造成焦虑时，应减负并寻求专业帮助，本 skill 不做治疗。
- **把元认知当能力等级判决**：监控差 ≠ 人笨；常是缺少反馈设计。
- **与邓克混用**：讨论“是不是井底之蛙效应曲线”时走邓克专条。

## 相关模型

- **与[邓宁-克鲁格](../dunning-kruger/SKILL.md)**：邓克是校准失准的特定现象与争议；元认知是日常监控调节工具箱。改善元认知有助于校准，但不能用四阶段鸡汤替代。
- **与[费曼技巧](../feynman-technique/SKILL.md)**：费曼是强制输出暴露空洞的协议；属元认知调节手段之一。
- **与[双系统](../dual-process/SKILL.md)**：元认知常调用慢系统打断快系统的流畅错觉。
- **与[遗忘曲线](../forgetting-curve/SKILL.md)**：监控“还记得吗”并安排间隔复习，是元认知在记忆域的应用。
