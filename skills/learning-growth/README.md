# Learning & Growth

费曼技巧、心流、元认知、遗忘曲线、反脆弱，以及刻意练习、间隔重复、成长型思维、深度工作、ZPD、一万小时澄清，并含检索/交错/迁移、双重编码、精细加工、组块、T 型技能、学习金字塔（纠偏）、导师制、教中学、元学习、去学习等学习成长 Skill。

与兄弟分类分流：学习、记忆与反脆弱配仓；认知拆解工具见 `cognitive-thinking-tools/`，执行排程见 `efficiency-execution/`（**深度工作主条在本类**，效率类仅互链）。

路径：`skills/learning-growth/<skill-name>/SKILL.md`。

当前合计 **30** 个（迁入种子 5 + M3 新建 6 + 批次新建 12 + 名录扩容新建 7，`v0.x-draft`，达到名录目标数量）。

## Skills

- **[antifragility](./antifragility/SKILL.md)** — 反脆弱：设计能从波动中获益的结构（杠铃、Via Negativa、选择性），而非只抗住风险。
- **[chunking](./chunking/SKILL.md)** — 组块：把离散信息打成可命名的更大单元，降低工作记忆负荷。
- **[cognitive-load](./cognitive-load/SKILL.md)** — 认知负荷理论：工作记忆容量有限，材料呈现须把内在/外在/相关负荷控制在容量内。
- **[deep-work](./deep-work/SKILL.md)** — 深度工作：保护无干扰高认知专注块（名录在效率类亦列出，主条在此）。
- **[deliberate-practice](./deliberate-practice/SKILL.md)** — 刻意练习：针对弱点、有反馈、略超舒适区的训练设计。
- **[dual-coding](./dual-coding/SKILL.md)** — 双重编码：言语与示意表征对齐互译，增加提取线索。
- **[elaborative-interrogation](./elaborative-interrogation/SKILL.md)** — 精细加工提问：对命题追问「为什么合理」以锚进知识网。
- **[feynman-technique](./feynman-technique/SKILL.md)** — 费曼技巧：用简单语言教别人以暴露理解空洞，再回源补洞、类比简化后重讲。
- **[flow](./flow/SKILL.md)** — 心流：挑战与技能大致匹配、目标清晰且反馈及时时的最优体验通道诊断。
- **[forgetting-curve](./forgetting-curve/SKILL.md)** — 遗忘曲线：解释记忆随时间衰减；日程操作见间隔重复。
- **[growth-mindset](./growth-mindset/SKILL.md)** — 成长型思维：把能力视为可发展，改写反馈与目标语言（非努力万能鸡汤）。
- **[habit-formation](./habit-formation/SKILL.md)** — 习惯养成：靠稳定情境线索把行为自动化，而非依赖当次意志力（纠偏「21天养成」流言）。
- **[interleaved-practice](./interleaved-practice/SKILL.md)** — 交错练习：混合易混题型以提升辨别与迁移。
- **[learning-by-teaching](./learning-by-teaching/SKILL.md)** — 学习中教：用真实/模拟教学任务强制提取与组织知识。
- **[learning-pyramid](./learning-pyramid/SKILL.md)** — 学习金字塔（谨慎）：纠偏假百分比，降级为主动参与启发式。
- **[mentorship](./mentorship/SKILL.md)** — 导师制：目标—节奏—反馈—渐撤的带教协议。
- **[meta-learning](./meta-learning/SKILL.md)** — 元学习：跨任务选择并实验「如何学」的策略菜单。
- **[metacognition](./metacognition/SKILL.md)** — 元认知：监控并调节自己的认知过程——觉察是否理解/用错策略并换方法。
- **[peer-learning](./peer-learning/SKILL.md)** — 同伴学习：独立作答→找持不同意见者讨论→独立重答，用认知冲突逼出理解修正。
- **[production-effect](./production-effect/SKILL.md)** — 产出效应：同一份材料里被读出/写出的条目比默读的更好记，但依赖有对照的默读条目。
- **[project-based-learning](./project-based-learning/SKILL.md)** — 项目式学习：围绕真实问题长周期自主推进、产出公开成果，边解决问题边习得知识技能。
- **[retrieval-practice](./retrieval-practice/SKILL.md)** — 检索练习：合上材料主动提取（测试效应），强化保持与诊断。
- **[self-explanation](./self-explanation/SKILL.md)** — 自我解释：研读材料时主动补上「为什么这样成立」的推理句，暴露并修复理解缺口。
- **[sleep-consolidation](./sleep-consolidation/SKILL.md)** — 睡眠与记忆巩固：新编码记忆在睡眠中被主动巩固整合，清醒状态下效率明显更低。
- **[spaced-repetition](./spaced-repetition/SKILL.md)** — 间隔重复：主动检索 + 递增间隔的 SRS/复习日程操作。
- **[t-shaped-skills](./t-shaped-skills/SKILL.md)** — T 型技能：一纵深可交付 + 多横杠可对话的能力组合。
- **[ten-thousand-hours](./ten-thousand-hours/SKILL.md)** — 一万小时定律（澄清）：纠偏时数神话，导流刻意练习。
- **[transfer-of-learning](./transfer-of-learning/SKILL.md)** — 迁移学习：显式设计近/远迁移变式与跨情境验收。
- **[unlearning](./unlearning/SKILL.md)** — 去学习：有管理地退役干扰性旧知识/旧反应。
- **[zpd](./zpd/SKILL.md)** — 最近发展区：独立/支架/做不到三带与渐撤支架。
