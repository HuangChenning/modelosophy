# 自组织 Self-Organization

## 这是什么

**自组织**：系统在**没有中央蓝图或全局协调者**的情况下，由局部互动与约束自发形成并维持可识别的宏观秩序。关键不是「没人管」，而是：**局部规则 + 能量/信息流 + 边界条件**足以生成结构。

与「他组织」（外部设计蓝图强制装配）对照：自组织问的是规则与流能否让秩序**自己长出来**。

## 什么时候用

- "没有总控却出现了稳定分工/队形/惯例"
- "自组织 / 自发秩序 / 能不能靠局部规则长出来"
- 社区规范、开源协作、鸟群、市场撮合、部分敏捷团队节奏

**不要**当主模型：
- 只问开放非平衡过阈值成有序的热力学隐喻 → [`dissipative-structures`](../dissipative-structures/SKILL.md)
- 只问宏观是否可还原到零件 → [`emergence`](../emergence/SKILL.md)
- 要画回路极性 → [`feedback-loops`](../../systems-classic-effects/feedback-loops/SKILL.md) / [`causal-loop-diagram`](../causal-loop-diagram/SKILL.md)
- 路径锁定解释 → [`path-dependence`](../../systems-classic-effects/path-dependence/SKILL.md)

## 怎么用（执行步骤）

1. **确认有无可观察宏观秩序。** 写出模式（聚类、节律、角色分化）。判据：外人能复核「有结构」，不是感觉热闹。
2. **排除中央蓝图。** 是否存在下达全局装配指令的节点？若有且结构完全由指令决定 → 他组织，改流程设计。判据：删掉「总指挥」后结构是否仍可能出现。
3. **写局部规则与互动。** 每个主体看见什么、对邻居做什么。判据：规则可执行、范围局部。
4. **标边界条件与流。** 开放边界、输入输出（人流/信息/预算）。无流的封闭系统难维持自组织有序 → 连到耗散结构检查。
5. **做扰动实验。** 改一条局部规则或切断一条流，看宏观是否重组。判据：有可观察响应，拒绝「自组织所以别动」。
6. **设计最小脚手架。** 只设能催化局部互动的边界（接口、激励、禁区），避免把脚手架做成伪装中央计划。

## 例证

**蚁群觅食信息素**：个体局部规则 → 路径优化。揭示：秩序来自局部更新，非蚁王画地图。

**开源默认分支惯例**：无单一产品经理时，贡献规范+评审规则可自发生成节奏；规范崩则秩序崩。揭示：自组织仍需可执行局部规则。

**（原书卡片）**：若只写「自发形成」而无规则与流，优先补步骤 3–4。

## 什么时候不适用（边界）

- **安全/合规必须中央强制**：航空管制、核安全——可局部授权，不可浪漫化自组织。
- **主体无互动或无反馈**：孤立个人堆叠 ≠ 自组织。
- **已锁定的标准战争**：主因可能是路径依赖/网络效应，见经典效应类。

## 常见误用

- **自组织 = 不管**：不管会熵增混乱；要设计局部规则与流。
- **与涌现混为一谈**：涌现描述跨尺度产物；自组织强调无总控的生成机制。
- **把领导缺位美化为自组织**：先检查是否已有隐性中央节点。

## 相关模型

- **与[耗散结构](../dissipative-structures/SKILL.md)**：耗散给开放非平衡+耗散维持的物理图像；自组织强调无中央蓝图的规则生成。可连用。
- **与[涌现](../emergence/SKILL.md)**：自组织常产生涌现宏观；涌现不问是否有总控。
- **与[复杂适应系统](../complex-adaptive-systems/SKILL.md)**：CAS 强调适应学习；自组织可含非学习的物理/化学秩序。
- **与[熵增](../../systems-classic-effects/entropy-increase/SKILL.md)**：封闭系统趋向无序；自组织需要开放与做功/耗散。

## 记忆钩子

没有总控不等于没有规则——先写局部规则与流，再谈自组织。
