# MECE（相互独立，完全穷尽）

## 这是什么

MECE = **Mutually Exclusive, Collectively Exhaustive**：类别两两不重叠（ME），合起来覆盖议题范围内全部相关情形（CE）。咨询与结构化问题解决用它防止“漏一块”或“同一事实被算两次”。

它是**分类纪律**，不是发现真理的方法。错误的 MECE 树可以很漂亮却指向错误问题。原书结构图把 CE 写成 Collectively Exclusive，属笔误——应为 Exhaustive（穷尽）。

## 什么时候用

- 拆问题、拆市场、拆根因、拆工作流，需要清单完备；
- 发现分类重叠或明显漏洞；
- 用户直接说 MECE / 不重不漏。

**不要**当主模型：检验主张真伪（苏格拉底）；比较已知选项代价（机会成本）；画反馈回路（系统思维）。

## 怎么用（执行步骤）

1. **先钉议题边界。** “我们到底在穷尽什么？”写一句议题句。边界外的不进树。
2. **选一个拆分轴。** 时间、流程步骤、客户群、收入公式、地理……一次只用一个主轴；混轴是重叠的常见来源。
3. **检查 ME（互斥）。** 任一条事实/案例是否可能同时落入两类？若是，改定义或改轴。
4. **检查 CE（穷尽）。** 相对边界，是否存在放不进任何一类的情形？补类或扩“其他（显式定义）”——“其他”必须可检验，不能当垃圾桶。
5. **用树指导下一步，不把树当结论。** 每个叶子变成可验证问题或分析任务。发现轴错了就重建，不要为了保住 MECE 外观而扭曲事实。

## 例证

**利润树**：利润 = 收入 − 成本，再拆量价、固定/变动——经典 MECE 财务拆解。揭示公式轴天然互斥穷尽（在会计定义内）。

**正方形/长方形重叠**：按“四边形形状名”分类时正方形⊂矩形，违反 ME。揭示轴选错（应用边/角属性或层级，而不是平铺俗名）。

**（原书卡片）非独立 vs 未穷尽示意图**：例子有用；务必纠正 CE 的英文笔误，并以议题边界限定“穷尽”。

## 什么时候不适用（边界）

- **概念本征重叠**：身份、共病、多标签文化类；强行 MECE 会造假。
- **探索早期**：先发散再收敛；过早 MECE 会封死异常值。
- **MECE ≠ 正确**：完备分类仍可能问错问题。

## 常见误用

- **混轴造成假重叠**：同一层同时按时间、按客户群、按渠道拆，条目互相交叉后误以为是"分类没做细"要继续加类别 → 根源是违反了第 2 步"一次只用一个主轴"，应先合并轴而不是加类别。
- **"其他"当垃圾桶**：为了凑出穷尽，把归不了类的情形一股脑塞进"其他"，却不给它下可检验的定义 → CE 要求的穷尽必须可判定，不可检验的"其他"等于没穷尽。
- **为保外观扭曲事实**：某个案例明明该跨两类，硬塞进其中一类以维持树的整齐 → 应该改定义或改轴，不能让事实迁就分类。
- **穷尽当成正确**：把分类树打磨到完美不重不漏，却没检验这棵树是否在回答正确的议题 → 发现问题该先问"这棵树在回答对的问题吗"，而不是继续雕琢分类边界。

## 相关模型

- **与[第一性原理](../first-principles/SKILL.md)**：第一性原理拆到硬约束；MECE 保证拆出来的桶不重不漏。常连用。
- **与[奥卡姆剃刀](../occams-razor/SKILL.md)**：奥卡姆排解释优先级；MECE 排分类结构。
- **与[决策树](../../decision-probability/decision-tree/SKILL.md)**：决策树的分支在每一层也应尽量 MECE。
- **与[苏格拉底式质疑](../../thinking-models/socratic-questioning/SKILL.md)**：先问“这棵树在回答正确的问题吗”。
- **与[SWOT](../../strategy-competition/swot/SKILL.md)**：四格内部条目尽量不重不漏；但四格本身不是唯一正确分类。
- **与[波特五力](../../strategy-competition/porters-five-forces/SKILL.md)**：五力条目内证据尽量不重不漏；五力不是唯一行业分类法。
- **与[金字塔原理](../pyramid-principle/SKILL.md)**：MECE 管同层分类不重不漏；金字塔管结论—论据的纵向论证结构。金字塔的每一层内部应尽量 MECE。
