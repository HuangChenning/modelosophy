# 费曼技巧 Feynman Technique

## 这是什么

费曼强调两类“知道”：知道**名字**，与知道**事物如何运作**。流行“费曼技巧”把它收成可执行的学习协议：强迫自己把概念讲给智能但非专家的听众听；**卡壳处**就是理解边界；回源材料补洞，再用类比与例子压进行话，直到能流畅且经得起追问。

它是**以教促学 + 主动检索**，不是神秘加速器。讲解流利仍可能系统性错误（流畅错觉），所以卡壳修复后要用例题、推导或实验对照。

## 什么时候用

- 自学、备考、内训：感觉“看懂了”但讲不出来；
- 要把术语翻译成同事/用户听得懂的话；
- 直接提费曼技巧 / Feynman technique / 大白话教一遍。

**不要**当主模型：
- 怀疑自己是否高估能力 → [`dunning-kruger`](../dunning-kruger/SKILL.md)；
- 冲动 vs 深思的加工模式 → [`dual-process`](../dual-process/SKILL.md)；
- 习惯能不能发生 → [`fogg-behavior-model`](../fogg-behavior-model/SKILL.md)。

## 怎么用（执行步骤）

1. **选定一个概念，写标题。** 范围要窄（“梯度下降的一步更新”而非“整个机器学习”）。
2. **教一遍：面对假想学生。** 只用自己的话写或说；禁用尚未定义的行话；需要行话时先定义。
3. **标记卡壳。** 含糊、循环定义、跳步、只能复述公式符号处，全部打标——这是真正任务清单。
4. **回源补洞，再简化。** 回教材/论文/代码把标记处补实；然后造一个类比或最小例子，删掉仍无法解释的装饰细节。
5. **再讲 + 外部检验。** 重讲应更短更稳；再用一道题、一个反例或一次实现验证——过关标准不是“感觉顺”，是“问得动、做得对”。

## 例证

**名实之辨**：能背“能量守恒”四个字，却算不对封闭系统账——揭示费曼真正攻击的是**标签知识**。

**技术面试白板**：讲不清“哈希冲突怎么处理”时的停顿，比刷题正确率更早暴露缺口。揭示**输出即诊断**。

**把 API 讲给产品经理**：被迫去掉框架黑话后，发现自己也不知道重试与幂等的边界——揭示教学受众约束如何逼出真问题。

**（原书卡片）概念→教人→卡壳→简化**：四步骨架可用；“20 分钟深入理解且难以遗忘”是营销夸大。后半曾国藩日记/大道至简可作“输出得反馈”旁证，但不是费曼技巧本体；芒格多元模型引用与本协议无关，勿混装。

## 什么时候不适用（边界）

- **纯动作技能**：游泳、乐器仍需身体练习；讲解只覆盖认知部分。
- **无可靠源可回**：只有自媒体二手比喻时，技巧会固化错解——先找权威源。
- **表演性流畅**：背稿演讲可通过，却经不起追问；必须加检验步。
- **替代间隔重复与练习量**：费曼暴露缺口；巩固仍要练习与反馈。

## 相关模型

- **与[邓宁-克鲁格](../dunning-kruger/SKILL.md)**：邓克讨论自评偏差机制与争议；费曼是主动制造外部化反馈的练习协议。可连用：先讲，再对照客观测分。
- **与[双系统](../dual-process/SKILL.md)**：讲解时放慢，抑制“眼熟即懂”的快系统。
- **与[复利](../compounding/SKILL.md)**：缺口修复后的反复教/练可积累，但须满足再投入与时间。
- **与[第一性原理](../first-principles/SKILL.md)**：卡壳若因堆惯例，可转第一性原理拆硬约束；费曼本身不负责重建产品方案。
