# 最后通牒博弈 Ultimatum Game

## 这是什么

**提议者分一笔钱，回应者可接受或拒绝（拒绝则双方归零）——常有人宁损己也惩不公。**

标准理性：提议者给最小正份额、回应者接受。实验：提议常近公平，过低份额被拒。揭示公平偏好、惩罚动机与文化差异，挑战“只在乎己方金钱”的假设。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "最后通牒博弈"
- "分钱不公就拒"
- "最低给多少对方才会收"

**不要**在以下情况套用本模型：

- 对方无法拒绝 → ../dictator-game/SKILL.md
- 先付出再看回报 → ../trust-game/SKILL.md
- 多人联盟分配公理 → ../shapley-value/SKILL.md

## 怎么用（执行步骤）

1. **写规则与理性基准。** 拒则双零；金钱自私基准≈最小份额。
2. **引入公平/惩罚偏好。** 问用户是否愿付代价惩不公？标文化与关系情境。
3. **定提议区间。** 结合拒单风险；输出建议份额带而非单点伪精确。
4. **制度含义。** 否决权如何改变事前分配预期。

## 例证

**实验室最后通牒**：低份额高频被拒。揭示惩罚不公的动机。

**并购要价底线**：卖方觉辱可宁可不卖。揭示非金钱效用。

## 什么时候不适用（边界）

- **利害极大时**：高额下行为可能更近自私基准。
- **匿名 vs 熟人**：关系改变拒绝阈值。

## 常见误用

- **宣称人“非理性”了事**：应写入公平偏好效用。
- **与独裁者混淆**：有无拒绝权是关键差。

## 相关模型

- **与[独裁者博弈](../dictator-game/SKILL.md)**：无拒绝权测纯粹给予。
- **与[有限理性与满意化](../bounded-rationality/SKILL.md)**：程序理性另一路。
