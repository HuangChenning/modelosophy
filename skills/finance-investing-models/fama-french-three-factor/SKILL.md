# Fama-French 三因子模型 Fama-French Three-Factor Model

## 这是什么

**Fama-French 三因子（1993）**：股票超额收益由三块风险暴露解释——市场（MKT）、规模（SMB，小减大）、价值（HML，高 B/M 减低 B/M）：

R − Rf ≈ α + βₘ MKT + βₛ SMB + βₕ HML + ε

相对 CAPM，它承认规模与价值相关的平均回报差异，可能是风险补偿或行为/制度结果（解释有争议）。

## 什么时候用

- "这只基金是真 alpha 还是抱了小盘价值？"
- "三因子 / SMB / HML 怎么读？"
- "CAPM alpha 很高，会不会被风格解释掉？"

**不要**在以下情况套用本模型：

- 只要 CAPM 一道 β → [CAPM](../capm/SKILL.md)
- 讨论动量策略机制 → [动量与反转](../momentum-reversal/SKILL.md)

## 怎么用（执行步骤）

1. **取因子序列与资产收益。** 对齐频率与市场（美股因子不可直接套 A 股而不加验证）。
2. **跑多元回归，报告 β 与 α。** α 是否显著？SMB/HML 暴露有多大？
3. **用经济语言翻译暴露。** “像小盘价值”不是褒贬，是风险/风格标签。
4. **对照成本与可投资性。** 纸面因子溢价 − 交易成本/卖空约束后还在否？
5. **决定：归因结束还是加因子。** 残差仍有动量等结构则扩展模型，勿宣称发现永久 alpha。

## 例证

**主动基金归因**：名义跑赢指数，三因子后 α 消失——其实在收规模/价值风险溢价。揭示**风格暴露 ≠ 选股神力**。

**价值长期平均溢价**：HML 历史上多为正但有长回撤。揭示因子是**风险或行为溢价候选**，不是无回撤提款机。

## 什么时候不适用（边界）

- **样本外因子失效或定义漂移**：价值定义、市场结构变化。
- **非股票资产硬套三因子**：模型为股票截面设计。
- **把回测溢价当未来契约**：需风险与拥挤讨论。

## 常见误用

- **"三因子完美定价"**：仍有异象与四/五因子扩展。
- **用因子标签替代基本面研究**：归因工具不是买卖理由本身。

## 相关模型

- **与[CAPM](../capm/SKILL.md)**：单因子基准；本模型是扩展。
- **与[价值效应](../value-premium/SKILL.md)**：价值溢价的现象层；三因子是其建模层。
- **与[Beta 与 Alpha](../beta-alpha/SKILL.md)**：α 相对哪套模型要写清。
