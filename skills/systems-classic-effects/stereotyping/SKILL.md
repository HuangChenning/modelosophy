# 刻板印象 Stereotyping

## 这是什么

**刻板印象**：把群体的概括性特征（常简化、固化、情绪化）**直接套到个体**上，替代对该个体证据的收集与更新。

它是启发式：节省认知，但在方差大的特质上错误率高，并易自我强化（只记符合标签的例子）。与歧视行为相关但并不等同——本 Skill 聚焦**判断流程纠偏**。

## 什么时候用

- "他们部门/那类人就是…"
- "画像替代了面试观察"
- "用地域/学历一句话定性"

**不要**当主模型：
- 单一个体特质外推全能 → [`halo-effect`](../halo-effect/SKILL.md)
- 把自己心思当别人心思 → [`projection-effect`](../projection-effect/SKILL.md)
- 只搜集支持标签的证据 → [`confirmation-bias`](../../behavioral-biases/confirmation-bias/SKILL.md)

## 怎么用（执行步骤）

1. **写出被激活的标签。** 明确群体名与被断言的特质。
2. **降级为先验假设。** 若有可靠基础率，标为可修正先验；若无数据，标为传闻。
3. **收集个体似然证据。** 至少 2–3 条与该人直接相关的行为/产出；与标签冲突的证据必须记录。
4. **贝叶斯式更新（定性即可）。** 问：个体证据后，原标签还应占多大权重？大幅下降则禁止在决策中引用标签。
5. **改决策语言。** 输出改为“该人在 X 任务上的证据是…”，删除“他们那种人”。

## 例证

**招聘国籍/性别捷径**：用群体均值替代作品集。揭示**个体方差被抹平**。

**客户“难搞行业”标签**：未接触先防御性报价。揭示商业刻板的成本。

**媒体典型案例**：极端个案被当成群体本质。揭示可得性×刻板。

## 什么时候不适用（边界）

- **精确定向服务统计**：保险精算等合法使用群体风险，但仍应在个体层更新。
- **自我认同标签**：当事人自愿的文化认同 ≠ 评价者强加刻板。
- **虚构角色创作**：艺术夸张另论，但勿迁回现实人事。

## 常见误用

- **“反刻板”变成反向刻板**：凡某群体必相反 → 仍是标签思维。
- **禁止一切分类**：分类有用；禁止的是**不更新的套用**。
- **与光环混用**：光环是个体亮点外推；刻板是群体→个体。

## 相关模型

- **与[光环效应](../halo-effect/SKILL.md)**：中心特质 vs 群体标签。
- **与[确认偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：刻板常靠确认偏差续命。
- **与[可得性启发](../../behavioral-biases/availability-heuristic/SKILL.md)**：易想起的群体故事喂养刻板。
- **与[投射效应](../projection-effect/SKILL.md)**：刻板用群体；投射用自我。

## 记忆钩子

标签先降成先验——没有个体证据，不许写进结论。
