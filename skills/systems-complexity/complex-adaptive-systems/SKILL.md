# 复杂适应系统 Complex Adaptive Systems

## 这是什么

**复杂适应系统（CAS）**：由多个**异质、可适应**的主体组成，主体按局部信息行动并学习/选择策略，系统整体呈现涌现模式、路径依赖与难预测性。典型域：市场、生态、城市、创新网络、部分组织。

关键词：**适应主体、积木式组合、非线性、共同演化**——不是「很复杂所以随便」。

## 什么时候用

- "多方都在学对方策略，均衡一直在挪"
- "CAS / 复杂适应系统 / 生态型组织"
- 干预后系统「学会绕开」

**不要**当主模型：
- 只要静态产业结构 → 战略五力等
- 只要网络拓扑形状 → [`small-world-network`](../small-world-network/SKILL.md) / [`scale-free-network`](../scale-free-network/SKILL.md)
- 只要非平衡有序物理隐喻 → [`dissipative-structures`](../dissipative-structures/SKILL.md)

## 怎么用（执行步骤）

1. **识别主体与适应规则。** 谁在学？靠什么反馈更新行为？判据：写出适应机制（强化、模仿、退出）。
2. **划局部信息边界。** 主体看见什么、看不见什么。判据：解释为何全局最优难达。
3. **找积木与交互。** 可重组的模块、交易、合作/竞争边。判据：列表非空。
4. **预期涌现与意外。** 列出可能宏观模式（泡沫、分化、韧性）。判据：每条连回主体规则。
5. **设计适应友好的干预。** 改激励、信息、进入退出规则、多样性；避免一次性全局指令幻想。判据：干预后主体仍能适应且监测「绕开策略」。
6. **设探索—利用平衡。** 保留变异/实验配额，防止过早锁死。

## 例证

**平台双边市场**：用户与商家互相适应规则与对手动作 → 宏观渗透与分层。揭示：政策要考虑适应后的新均衡。

**抗菌素耐药**：病原体适应；单次「强力打击」可加速选择。揭示：共同演化。

**（原书卡片）**：避免空喊复杂；落到主体规则。

## 什么时候不适用（边界）

- **机械可分解流程**：标准作业即可。
- **单一决策者完全控制**：决策树/优化足够。
- **需要法律责任清晰归责**：CAS 描述不替代问责设计。

## 常见误用

- **CAS = 无法管理**：可管理规则与多样性。
- **与混沌迷信**：CAS ≠ 任意不可知。
- **忽略选择压力**：无适应机制就不是 CAS 分析。

## 相关模型

- **与[涌现](../emergence/SKILL.md)**：涌现是产物；CAS 提供适应主体机制。
- **与[耗散结构](../dissipative-structures/SKILL.md)**：物理/热力学隐喻的有序；CAS 是主体适应框架。
- **与[路径依赖](../../systems-classic-effects/path-dependence/SKILL.md)**：CAS 常产生锁定；路径依赖专攻历史锁定。
- **与[临界点](../tipping-point/SKILL.md)**：适应主体互动可把系统推向阈值；临界点专攻翻转，CAS 专攻适应机制。
