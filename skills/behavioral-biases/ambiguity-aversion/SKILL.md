# 模糊厌恶 Ambiguity Aversion

## 这是什么

**相对于概率已知的风险，人们系统性地更回避概率未知（模糊）的选项。**

埃尔斯伯格悖论：罐子里红蓝比例已知 vs 未知时，选择违反主观期望效用的一致性。现实中：宁买熟悉股票，回避陌生但可能更优的领域；组织里“没有数据就不启动”。模糊厌恶可部分理性（模型不确定性），但常过度。

## 什么时候用

- "概率说不清就别做"
- 熟悉偏见主导组合

**不要**当主模型：

- 已知概率下的得失痛感 → [`loss-aversion`](../loss-aversion/SKILL.md) / [`prospect-theory`](../prospect-theory/SKILL.md)
- 小样本当规律 → [`law-of-small-numbers`](../law-of-small-numbers/SKILL.md)

## 怎么用（执行步骤）

1. **分离风险与模糊。** 哪些是已知分布，哪些是不知道分布？列表。
2. **埃尔斯伯格式对照。** 问：若人为给模糊选项一个与已知风险相同的中心概率，你是否仍拒？仍拒 → 模糊厌恶。
3. **估信息价值。** 花多少成本可以把模糊降为风险？若便宜，先买信息；若昂贵，用稳健规则（最大最小、仓位上限）而非零接触。
4. **配置暴露。** 对模糊域用小而可学习的试点；输出：已知风险仓 / 模糊试点仓 / 禁止区。

## 例证

**埃尔斯伯格双罐**：揭示**讨厌未知比例本身**。

**本土偏差投资**：本国股票过重——部分由模糊厌恶与熟悉感驱动。

## 什么时候不适用（边界）

- **敌意不确定性**：对手藏信息时回避可能理性。
- **监管禁入**：合规禁止不是偏见。
- **毁灭性下行且无法分散**：模糊下的极保守可作生存策略。

## 常见误用

- **模糊厌恶=胆小**：已知高风险的冒险者仍可能极怕模糊。
- **用伪精确概率掩盖模糊**：拍脑袋填 37% 不是消除模糊，是假装。

## 相关模型

- **与[前景理论](../prospect-theory/SKILL.md)**：概率权重管已知概率扭曲；本条管概率未知。
- **与[控制错觉](../illusion-of-control/SKILL.md)**：有人用虚假控制感掩盖模糊。
- **与[可得性启发](../availability-heuristic/SKILL.md)**：熟悉域显得“不模糊”。
