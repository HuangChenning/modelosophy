# 批判性思维 Critical Thinking

## 这是什么

词源上 *critical* 连着希腊语 *kritikos*（审辨）与 *kriterion*（标准）：**按明示标准做判断**，不是对人开炮。Dewey 的反省思维强调：主动、持续、审慎地考察信念及其依据。

1990 年美国哲学学会委托的 **Delphi 报告**（Facione 执笔）给出教育与测评上最常用的可操作共识：批判性思维 = **认知技能** + **思维倾向（dispositions）**。

| 维度 | 内容 |
|---|---|
| **认知技能** | 诠释、分析、评估、推理、说明、自我校准（self-regulation） |
| **思维倾向** | 求真、思想开放、分析性、系统性、推理自信、认知成熟与公正等习惯 |

它允许你在拆穿弱论证之后，**用更好的证据与推理重建判断**——这是与纯诘问法的分水岭。苏格拉底式 elenchus 是重要历史渊源（提问清场），但**不是**本模型的主操作手册。

## 什么时候用

- 要系统评估一篇方案、报告、评论或决策理由的论证质量；
- 需要明示：主张是什么、证据是什么、推理桥是否 deductive/inductive/abductive、反例是否处理；
- 用户要“按标准审一遍”，而不只是被问倒；
- 直接提批判性思维 / critical thinking / 论证评估。

**不要**当主模型：
- 用户只要压力测试、挑毛病、苏格拉底式连环问，且接受停在困惑 → [`socratic-questioning`](../socratic-questioning/SKILL.md)；
- 主要担心证据被先验过滤 → [`confirmation-bias`](../confirmation-bias/SKILL.md)；
- 多个已成形解释排验证顺序 → [`occams-razor`](../occams-razor/SKILL.md)。

## 怎么用（执行步骤）

1. **外化主张与问题。** 用一句话写清待审结论；若结论含混，先做**诠释**（术语定义、范围、成功标准）。
2. **解剖论证结构（分析）。** 标出前提、隐含假设、推理类型、结论强度声称（“可能 / 必然 / 应该”）。
3. **按标准评估证据与推理（评估）。** 问：来源是否独立可核查？样本与概括是否匹配？相关性 vs 因果是否滑换？反面证据是否被提及？给每条前提标：强 / 弱 / 缺失。
4. **推导与说明。** 从已接受前提能合法推出什么、推不出什么；把评估过程说清楚（说明技能），避免只抛“我觉得不行”。
5. **自我校准 + 建设性修正。** 检查自己的立场偏见与动机；若原结论撑不住，给出**改写后的更弱/更强结论**或补证据清单——目标是更好的判断，不是羞辱作者。
6. **倾向检查（短清单）。** 本轮是否求真而非护短？是否公正对待对方最强表述（steelman）？若只在表演反对，停下来重做第 3 步。

## 例证

**临床指南评级思维（非医学建议）**：区分“个案轶事”“观察性相关”“随机对照”对因果主张的支撑强度不同；批判性思维要的是**证据阶梯与外推边界**，不是“信不信医生”的站队。揭示技能里的**评估**与倾向里的**求真**如何绑在一起。

**商业报表叙事**：营收增长被写成“战略成功”，拆开后可能是一次性补贴或会计口径变更。步骤 2–3 逼出：主张所需的因果证据是否存在。揭示批判性思维攻击的是**推理桥**，不是增长数字本身。

**政策评论的钢人后再批**：先用对方最强合理版本重述，再指出仍缺的比较组或反事实；随后给出“若补上 A、B 数据，结论可升/降级”。揭示本模型可**重建**，不止拆毁。

**历史渊源（一句，不当主例）**：苏格拉底式诘问展示了“按问题清场”的力量；Delphi 框架把它收进更宽的技能+倾向工具箱，并要求评估后可修正判断。细节操作见 [`socratic-questioning`](../socratic-questioning/SKILL.md)。

**（原书卡片）几乎通篇苏格拉底步骤 + “主观判断 vs 批判性思维”对照表**：卡片的技能/倾向维恩图接近 Delphi，可用；但例证与苏格拉底 skill 严重撞车，且对照表易滑向“理性的人=批判、情绪的人=不批判”的人格抹杀。定稿例证必须重写；苏格拉底仅作渊源，不作主操作示范。

## 什么时候不适用（边界）

- **对方需要的是情感支持**：不要强行开论证评审。
- **纯事实查询**：查得到的里程、日期、条文，直接查，不必六技能走一遍。
- **只有证伪、不要重建，且用户点名苏格拉底**：转苏格拉底 skill，并接受 aporia。
- **变成人身攻击或身份审判**：“你这人不会批判思考”不是本模型输出；只评主张与证据。
- **无限怀疑瘫痪**：倾向包含在证据足够时审慎采纳；批判性思维不是永不动手。

## 相关模型

- **与[苏格拉底式质疑](../socratic-questioning/SKILL.md)**：**硬区分。** 苏格拉底 = elenchus 证伪、常止于 aporia、不证成。本模型 = 技能+倾向清单、评估证据标准、可给出改进后的判断。用户说挑毛病/苏格拉底 → 前者；系统审论证质量 → 本模型。可连用：先诘问清场，再 Delphi 重建。
- **与[确认性偏差](../confirmation-bias/SKILL.md)**：确认偏差专攻证据搜集与加权的选择性；本模型覆盖完整论证评估，可调用确认偏差检查作子步骤。
- **与[隐含前提](../implicit-premises/SKILL.md)**：隐含前提专挖未说出的假设；本模型在分析步会用到，但不止于此。
- **与[元认知](../metacognition/SKILL.md)**：自我校准与元认知重叠；元认知更广（对思维过程的监控），本模型锚定论证质量标准。
