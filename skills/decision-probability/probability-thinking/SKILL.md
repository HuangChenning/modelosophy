# 概率论思维 Probability Thinking

## 这是什么

**概率论思维**：把「会不会 / 一定 / 不可能」改写成**对明确事件的概率（或区间）**，并检查样本空间是否定义清楚、条件是否写明、是否误把相关当独立、是否用期望/离散度而非单点叙事做决策。

它是决策与概率类的**入口总论**：帮用户选对下一步专条（基率、贝叶斯、EV、模拟……），而不是用口号替代计算。

## 什么时候用

- "用概率思维看这个问题"
- "别说『肯定』，给我一个数或区间"
- "独立吗？条件概率怎么讲？"
- 用户语言全是确定性，但世界明显不确定

**不要**当主模型（应下钻）：

- 已有先验与新证据要合成后验 → [`bayesian-updating`](../bayesian-updating/SKILL.md)
- 强调「这类事通常怎样」→ [`base-rate`](../base-rate/SKILL.md)
- 已有 \((p,x)\) 要算加权结果 → [`expected-value`](../expected-value/SKILL.md)
- 只要软化非黑即白语气 → [`grey-thinking`](../grey-thinking/SKILL.md)

## 怎么用（执行步骤）

1. **钉死事件定义。** 「成功」指什么可观察结果？到何时？含糊事件无法赋概率。
2. **选表达：点概率 / 区间 / 情景权重。** 信息少用区间或有序档（「低/中/高」并定义含义）；禁止假三位小数。
3. **写清条件。** \(P(A\mid B)\) 的 \(B\) 是什么？换条件是否翻转直觉（检验悖论类）？
4. **检查独立性与样本。** 默认独立要有理由；小样本波动用方差/回归均值直觉警告。
5. **把概率接上决策。** 若只关心加权结果 → 转 EV/EU；若要更新 → 转贝叶斯；若要分布 → 转 MC。
6. **预注册改口。** 何种证据使概率移出当前区间？写下来。

## 例证

**「这次融资一定成」→「在当前条款与管道下，90 天内签约：55–70%」**：揭示：概率思维先**可争论化**。

**连续好结果后「手感热」**：若近似独立，热手多是方差；揭示：独立性检查防迷信。（注：经典"热手谬误"研究本身的方法论后来受到 Miller & Sanjurjo 的挑战，独立性假设要针对具体数据核实，不能不假思索援引结论。）

**医学阳性**：把「阳性」与「有病」分开，引入条件概率。揭示：总论应把用户导向基率+贝叶斯。

## 什么时候不适用（边界）

- **价值/伦理争议**：概率化不能替代价值选择。
- **无法定义事件**：先澄清问题，再谈概率。
- **已进入专条计算**：不要停在总论鸡汤。

## 常见误用

- **空壳总论**：说完「要有概率思维」无数字无下一技能 → 必须下钻。
- **把置信度当客观频率不声明**：说清主观/频率来源。
- **忽视基率**：个案细节淹没类别频率。
- **与灰度认知完全等同**：灰度管信念可修订；本模型管概率语言与结构检查。

## 相关模型

- **与[基率思维](../base-rate/SKILL.md)**：基率是频率锚定；概率思维要求先定义事件再决定是否用基率。
- **与[贝叶斯更新](../bayesian-updating/SKILL.md)**：贝叶斯是条件概率的更新引擎；总论识别「有新证据」后移交。
- **与[期望值](../expected-value/SKILL.md)**：概率齐备后算 EV；本模型不替代求和。
- **与[灰度认知](../grey-thinking/SKILL.md)**：灰度反非黑即白；概率思维进一步要求可操作的 \(p\) 与条件。
- **与[蒙特卡洛](../monte-carlo/SKILL.md)**：多变量不确定要分布时下钻 MC。

## 记忆钩子

先定义事件，再给区间；**说「肯定」之前，问「在什么条件下、到哪天、算成功？」**
