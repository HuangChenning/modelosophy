# 资源基础观 Resource-Based View

## 这是什么

**资源基础观（RBV）**：企业可持续竞争优势主要来自**有价值、稀缺、难以模仿/替代且可被组织运用**的资源与能力 bundle——即优势常常是**内生异质**的，而非仅由产业结构决定。

Birger Wernerfelt、Jay Barney 等奠定该视角，与波特产业组织视角形成经典对照：五力解释「行业平均与结构压力」，RBV 解释「同业为何分化」。**VRIO** 是 RBV 最常用的操作化清单；本 Skill 保留理论透镜与研究式假说，避免与 VRIO 重复成第二份打勾表。

## 什么时候用

- "优势到底来自产业还是我们的资源"
- "RBV / 资源异质性 / 为什么超额利润能持续"
- 需要先建立资源假说再细审计

**不要**当主模型：

- 已要对具体资源打 V/R/I/O → [`vrio`](../vrio/SKILL.md)
- 跨业务能力根干三测 → [`core-competence`](../core-competence/SKILL.md)
- 行业结构压力 → [`porters-five-forces`](../porters-five-forces/SKILL.md)
- 壁垒叙事类型 → [`economic-moat`](../economic-moat/SKILL.md)

## 怎么用（执行步骤）

1. **陈述绩效差异事实。** 相对谁、多长窗口、何种超额（利润、增长质量）。判据：有对照，禁止空喊「我们很强」。
2. **提出资源/能力假说。** 「差异主要由〔具体 bundle〕解释」。判据：假说可被反证（若失去该 bundle 绩效应掉）。
3. **检验替代解释。** 产业风口、管制、短期运气、会计假象。判据：至少排除 1–2 个强替代解释或标不确定。
4. **导向 VRIO/核心能力深潜。** 条目级用 VRIO；跨业务平台用核心能力。判据：本步产出「审计清单」，不是最终形容词。
5. **推导战略含义。** 投资强化、隔离机制、避免稀释（乱外包/乱多元化）。判据：每条含义对应假说。
6. **设复盘：资源是否仍稀缺。** 扩散、模仿、技术替代会侵蚀租金。

## 例证

**同业分化**：同一五力结构下有的企业持续高 ROIC——揭示需要 RBV 式内部解释，而非只叹行业。

**假资源**：把「企业文化好」当解释却无绩效连接——揭示 RBV 要求可检验 bundle。

**与五力连用**：五力判断池子深浅；RBV/VRIO 判断你能否在池中取到可持续份额。

## 什么时候不适用（边界）

- **需要立刻操作化打勾**：直接 VRIO。
- **问题纯属选错行业**：先五力/安索夫进入决策。
- **动态能力/超竞争主导**：静态资源清单不够，需补学习与重配速度（可后续扩展）。

## 常见误用

- **RBV 万能**：忽略结构与宏观 → 与五力并用。
- **事后贴资源标签**：成功了就说有资源 → 先写可反证假说。
- **与 VRIO 重复建两套词**：理论用 RBV，清单用 VRIO。
- **把一切叫能力**：无边界 → 压到关键 bundle。

## 相关模型

- **与[VRIO](../vrio/SKILL.md)**：RBV 是透镜；VRIO 是审计程序——默认「RBV 定假说 → VRIO 检验」。
- **与[核心能力](../core-competence/SKILL.md)**：核心能力聚焦共享能力平台；RBV 更广（含资产、产权、声誉等）。
- **与[波特五力](../porters-five-forces/SKILL.md)**：外生结构 vs 内生资源——战略诊断常两者都要。
- **与[护城河](../economic-moat/SKILL.md)**：护城河偏投资人类型学；RBV 偏战略管理解释机制。

## 记忆钩子

RBV = **超额从异质资源来**——先写可反证假说，再用 VRIO 把假说验成清单。
