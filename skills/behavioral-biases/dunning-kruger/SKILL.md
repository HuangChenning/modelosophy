# 邓宁-克鲁格效应 Dunning–Kruger Effect

## 这是什么

邓宁-克鲁格效应指一类关于**能力与自评校准**的研究发现与解释争议。Kruger & Dunning（1999）的经典主张：在某些任务上，表现落在低端的人倾向于**高估自己的相对表现**；作者将其部分归因于**元认知缺陷**——完成任务所需的知识，往往也是准确评价表现所需的知识。研究还报告：能力很强的人有时会**低估自己的相对独特性**（以为他人也一样容易）。

必须同时记住几件被流行文化抹掉的事：

1. **低表现者的自评绝对值，往往仍低于高表现者的自评**——他们“相对高估”，不是宇宙第一自信天团。
2. 「愚昧之巅 → 绝望之谷 → 开悟之坡 → 平稳高原」是网络/培训示意图，**不是**原论文的科学曲线，不能当人生阶段定律。
3. 后续工作指出：部分图示形态可用**向均值回归、量表边界、更好-than-average 等统计与测量因素**解释；元认知故事并非唯一或在所有域都成立的机制。因此本 skill 把 DK 当作**待检验的校准假说 + 行动清单**，不是人格判决。

## 什么时候用

- 用户怀疑自己或团队“不会的人特别自信 / 会的人反而犹豫”；
- 需要设计反馈、测验或对照来校准自评；
- 直接提到邓克/达克/Dunning-Kruger/井蛙/无知者无畏。

**不要**当主模型：
- 只是被生动案例带跑频率判断 → [`availability-heuristic`](../availability-heuristic/SKILL.md)；
- 按已有立场筛证据 → [`confirmation-bias`](../confirmation-bias/SKILL.md)；
- 该信直觉还是该慢思考 → [`dual-process`](../../thinking-models/dual-process/SKILL.md)；
- 要把主张追到自相矛盾 → [`socratic-questioning`](../../thinking-models/socratic-questioning/SKILL.md)。

## 怎么用（执行步骤）

1. **限定领域与可观测表现。** 写下具体任务（哪门考试、哪类代码评审、哪次谈判），以及可核对的结果指标。禁止空泛贴“你处在愚昧之巅”。
2. **并列表：自评 vs 外部尺度。** 让当事人先给出百分位或等级自评，再对照测验、同行盲评、历史命中率。只看落差方向与幅度，不下人格结论。
3. **区分三种解释，不先锁死元认知。** (a) 真缺技能且缺自评线索；(b) 激励/面子导致口头高估；(c) 测量伪影（题目太难全员低分、回归均值）。缺数据时标注“未知”，而不是讲鸡汤阶段。
4. **给可执行的校准动作。** 优先：短周期带答案的练习、对照优秀样本、请不知情第三方打分、写下“什么证据会让我下调自信”。训练提高能力后，再重新自评——经典论文强调：能力提升常伴随对自己先前无能的更清醒认识。
5. **对高表现者的“低估”单独处理。** 若强者低估相对位置，对策是补充分布信息（他人真实错误率），不是打压自信或神化谦虚。

## 例证

**逻辑谜题/语法测验中的四分位图**：低四分位参与者平均自评高于其实际百分位。揭示的是**相对校准误差**，且须与“其自评仍可能低于高分组”同时读。

**专业反馈循环**：急救规程、编程 kata、语言纠音——有快速对错信号的域，自评可被训练拉近。揭示 DK 相关问题常是**反馈结构缺失**，不只是性格。

**网络“愚昧之巅”漫画**：把复杂测量收成励志爬坡故事。揭示流行传播如何把可争议的实验效应变成不可证伪的人格剧本——本 skill 明确拒绝这种用法。

**（原书卡片）四阶段 + 95% 在愚昧区**：阶段叙事与比例是教学修辞/励志编排，**不是**流行病学数据；原书也写了“能力欠佳者自评并不比能者更高”这一重要限定，应保留，并补上复制/测量争议，避免把卡片当定论。

## 什么时候不适用（边界）

- **禁止当临床或人格诊断标签**（自恋、愚昧人格等）。
- **无表现数据时**：只能建议去测量，不能断言“你就是邓克”。
- **把谦虚美化为智慧、把自信污名为无能**：高自信可能来自真技能或激励结构。
- **跨域滥用**：一域低校准不推出“全盘无知”；专家在外行域同样可能失准。
- **统计争议未消**：向用户诚实说明机制有竞争解释；行动上仍建议客观反馈，不依赖“你缺元认知”骂战。

## 常见误用

- **空泛贴“你处在愚昧之巅”**：无领域、无表现数据 → 只能建议去测量，不能断言“你就是邓克”。
- **当人格/临床诊断标签**：自恋、愚昧人格等 → 禁止；只做自评 vs 外部尺度的校准落差。
- **把谦虚美化为智慧、自信污名为无能**：高自信可能来自真技能或激励 → 并列表对照，不道德化。
- **一域失准推全盘无知 / 励志四阶段当流行病学**：跨域勿外推；漫画阶段叙事不是数据。

## 相关模型

- **与[双系统](../../thinking-models/dual-process/SKILL.md)**：即时自信常由快系统给出；校准需要慢系统对照外部尺度。
- **与[确认性偏差](../confirmation-bias/SKILL.md)**：高估后会更只找支持“我很行”的证据。
- **与[幸存者偏差](../survivorship-bias/SKILL.md)**：只看见成功自信者，会高估“自信=能力”。
- **与[苏格拉底式质疑](../../thinking-models/socratic-questioning/SKILL.md)**：追问“你凭什么知道自己知道”是校准话术，但质疑本身不测量能力。
- **与[周哈里窗](../../thinking-models/johari-window/SKILL.md)**：他人看见而自己不知的盲目区，是获取校准反馈的结构语言；DK 更聚焦表现-自评落差。
