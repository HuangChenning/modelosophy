# 适应度景观 Fitness Landscape

## 这是什么

**适应度景观**：把每个可行配置（策略、设计、基因型）映射到一个「适应度」高度，形成地形。光滑单峰 → 爬山即可；**崎岖多峰** → 易困在局部最优，需要跳跃、重组或改变景观本身。

NK 直觉：元件耦合越多（K 大），景观越崎岖。

## 什么时候用

- "优化了很久却上不去，像卡在小山头"
- "适应度景观 / 局部最优 / 要不要推倒重来"
- 产品形态搜索、组织能力组合、研发路线分叉

**不要**当主模型：
- 只要主体共同演化框架 → [`complex-adaptive-systems`](../complex-adaptive-systems/SKILL.md)
- 只要探索-利用在混沌边缘 → [`edge-of-chaos`](../edge-of-chaos/SKILL.md)
- 只要路径锁定历史 → [`path-dependence`](../../systems-classic-effects/path-dependence/SKILL.md)

## 怎么用（执行步骤）

1. **定义配置空间。** 可变的维度（功能、定价、结构）与非法区。判据：维度列表可写。
2. **定义适应度。** 可观测指标或加权（利润、安全、学习速度）。判据：方向明确，承认多目标冲突。
3. **估计崎岖度。** 小改动是否导致适应度剧烈跳变？相邻配置是否不相关？判据：给出「光滑/中等/崎岖」判断+证据。
4. **识别当前峰。** 你是否在局部最优？（邻域搜索无提升）。判据：列出已试邻域。
5. **选移动策略。** 光滑→局部爬山；崎岖→更大跳跃、模块重组、平行探索、临时降低选择压力。判据：策略与崎岖度匹配。
6. **可选：改景观。** 改规则/约束/耦合（降 K）往往强于在旧山上硬爬。

## 例证

**QWERTY / 技术标准**：可能停在局部峰；历史锁定+网络效应改变有效景观。揭示：逃峰要改耦合或支付跳跃成本。

**深度学习超参/架构搜索**：损失面多峰；随机重启与大规模搜索对应跳跃。揭示：局部梯度不够。

**（原书卡片）**：勿空喊局部最优；先定义适应度与邻域。

## 什么时候不适用（边界）

- **适应度不可观测或被操纵**：景观是幻象。
- **配置空间非法/伦理禁区**：不能「爬」过去。
- **单次不可逆决策**：更像决策树，而非反复搜索。

## 常见误用

- **凡是不满意 = 局部最优**：可能适应度定义错或约束未写。
- **无限跳跃**：无选择压力会漫游；要探索配额。
- **与混沌边缘混用**：边缘谈动态制度；景观谈地形。

## 相关模型

- **与[混沌边缘](../edge-of-chaos/SKILL.md)**：边缘是动力学甜蜜区；景观是搜索地形。
- **与[复杂适应系统](../complex-adaptive-systems/SKILL.md)**：CAS 主体在景观上适应；本模型画地形。
- **与[路径依赖](../../systems-classic-effects/path-dependence/SKILL.md)**：历史可把你钉在某峰；景观解释邻近是否可爬。
- **与[杠杆点](../leverage/SKILL.md)**：改规则/目标常等于改景观，属高杠杆。

## 记忆钩子

先问山平不平坦——崎岖就别只迈小步，准备跳跃或改地形。
