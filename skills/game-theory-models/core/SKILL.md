# 核（Core） The Core

## 这是什么

**没有任何子联盟能靠自己重新分配而让其成员都更好的分配集合。**

分配在核内 ⇒ 满足个体理性与联盟理性（对一切 S，∑_{i∈S} x_i ≥ v(S)）。核可空（如某些投票/多数博弈）。强调稳定，不给单点。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "这个分配在不在核里"
- "会不会有小联盟拆台"
- "核为空意味着什么"

**不要**在以下情况套用本模型：

- 只要公理一点解 → ../shapley-value/SKILL.md
- Gale-Shapley 稳定匹配 → ../matching-theory/SKILL.md
- 非合作 → ../nash-equilibrium/SKILL.md

## 怎么用（执行步骤）

1. **写 v(S) 与候选 x。** ∑x=v(N)。
2. **逐联盟检验。** 任一 S 若 v(S)>∑_{S} x，则 x 不在核；记录威胁联盟。
3. **判断核是否可能空。** 若多套方案皆被否，讨论规则/旁支付/扩大总饼。
4. **输出。** 在核？威胁联盟？或核空诊断。

## 例证

**三人多数分饼**：某些参数核空：总有两人可另分。揭示稳定不可能。

**成本分摊核非空**：合理区间让无人另建。

## 什么时候不适用（边界）

- **旁支付假设**：不可转让效用时更复杂。
- **核大**：稳定集合大时仍需选点（夏普利等）。

## 常见误用

- **核空就说无法合作**：可改 v 或制度。
- **与纳什核心理念混名**：合作稳定≠非合作纳什。

## 相关模型

- **与[夏普利值](../shapley-value/SKILL.md)**：选点；可能在核外。
- **与[合作博弈与联盟](../cooperative-games/SKILL.md)**：母体。

## 记忆钩子

没有小圈子能全体翻盘，才算在核里。
