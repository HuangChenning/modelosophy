# 演绎法 Deductive Reasoning

## 这是什么

演绎推理：若前提为真，且推理形式有效，则结论**必然**为真。经典形态是三段论：

- 大前提：所有人都会死  
- 小前提：苏格拉底是人  
- 结论：苏格拉底会死  

现代逻辑把两件事拆开：

1. **有效 validity**：结论是前提的逻辑后承（形式对）；有效论证仍可因前提假而结论假。  
2. **可靠 soundness**：有效，并且前提实际上为真。  

演绎是**保真传递**工具，不是自动发现新事实的引擎。从经验样本推全体，是归纳；为观察找最佳解释，是溯因——都不是演绎。

## 什么时候用

- 政策、合同、规则、数学/程序：要从已声明的定义与条款推出必然后果；
- 需要检查“是否必然推出”还是“只是好像有关”；
- 用户直接说演绎 / 三段论 / deductive / 大前提小前提。

**不要**当主模型：
- 从惯例归零重建 → [`first-principles`](../../cognitive-thinking-tools/first-principles/SKILL.md)；
- 挑主张毛病、追问假设 → [`socratic-questioning`](../socratic-questioning/SKILL.md)；
- 补全没写出来的前提 → [`implicit-premises`](../implicit-premises/SKILL.md)；
- 样本推总体、黑天鹅风险 → 归纳/反证思维，而非本模型。

## 怎么用（执行步骤）

1. **列出前提与结论，禁止混写。** 每条前提单独成句；标出结论。发现缺腿先走隐含前提补全。
2. **检查形式是否有效。** 问：是否存在一种情况，前提全真而结论假？若存在，推理无效（例如中项不周延、肯定后件等常见谬误）。
3. **分开评估前提真假。** 有效只保证“若前提真则结论真”。大前提是定义、统计全称还是偷偷的归纳？全称统计尤其危险。
4. **下诊断标签。** 输出四种之一：可靠 / 有效但不牢靠 / 无效 / 前提不清。不要用“很有逻辑”这种含混褒奖。
5. **需要行动时补验证。** 演绎结论若依赖经验前提，仍要用观测或实验挑前提；演绎不免除检验。

## 例证

**苏格拉底三段论**：教学用的可靠演绎范例——揭示的是**保真结构**，不是人生哲理。

**假大前提**：“所有会飞的都是鸟；飞机飞；故飞机是鸟”——形式有效，前提假，结论不可用。揭示 **有效 ≠ 可靠**。

**政策蕴含**：“凡超时未缴者取消资格；甲超时未缴；故甲取消资格”——合同/规章场景的演绎；争议应打在前提条款是否被正确适用，而非“感觉不近人情”。

**（原书卡片）天鹅归纳对比 + 福尔摩斯四假设**：与归纳对照有教学价值；但总结把演绎写成“逆向推理”、把侦探假设链并进演绎，属错误——观察—假设—证据更接近溯因/假设演绎法的经验段，不是纯演绎。卡片称“中庸则结论必然为真”不成立。

## 什么时候不适用（边界）

- **前提本身是未完成的经验概括**：把它当全称演绎会制造伪必然。
- **价值冲突**：从“应然”前提推出“应然”结论可以形式有效，但规范前提需单独辩护。
- **创意探索早期**：需要发散选项时，过早演绎封闭会压制假设。
- **把修辞当演绎**：“名人都用，所以你必须用”通常既缺全称前提又形式无效。

## 相关模型

- **与[隐含前提](../implicit-premises/SKILL.md)**：日常论证常先省略前提；补全后再做演绎检验。
- **与[第一性原理](../../cognitive-thinking-tools/first-principles/SKILL.md)**：第一性原理选择硬约束当起点并重建；演绎假定起点已给定，只负责传递。
- **与[苏格拉底式质疑](../socratic-questioning/SKILL.md)**：苏格拉底通过追问暴露矛盾；演绎提供形式判定语言。
- **与[奥卡姆剃刀](../../cognitive-thinking-tools/occams-razor/SKILL.md)**：多条有效解释竞争时，奥卡姆管简洁偏好，不管演绎有效性。
- **与[溯因推理](../abductive-reasoning/SKILL.md)**：演绎保真传递；溯因生成可错最佳解释。
