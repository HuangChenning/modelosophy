# 鲶鱼效应 Catfish Effect

## 这是什么

**鲶鱼效应**：在相对安逸、缺乏竞争压力的群体中，引入强刺激的外部竞争者（“鲶鱼”），促使原有成员提高警觉与产出——源自沙丁鱼运输中放入鲶鱼减少死亡率的传说性商业隐喻。

机制上更接近：**竞争威胁改变激励与注意力**，从而改变努力与创新速度。它是启发式管理故事，不是严格受控的生物学定律；有效性取决于威胁是否可信、规则是否公平、退出是否可选。

## 什么时候用

- "团队躺平，想引入外部标杆/空降"
- "垄断业务线缺乏紧迫感"
- "供应商单一，想引入第二家激活"

**不要**当主模型：
- 仅因被观察而改变行为 → [`hawthorne-effect`](../hawthorne-effect/SKILL.md)
- 小失序诱发大失序 → [`broken-windows`](../broken-windows/SKILL.md)
- 需要系统设计竞争规则 → [`systems-thinking`](../systems-thinking/SKILL.md)

## 怎么用（执行步骤）

1. **诊断惰性来源。** 是垄断、考核无差异、信息封闭，还是能力不足？能力不足时“放鲶鱼”只会制造恐慌。
2. **定义鲶鱼的角色与边界。** 写清：对比指标、资源对等性、是否可替代原成员、观察期——禁止“神秘空降恐吓”。
3. **设定激活信号。** 哪些行为算被激活（交付周期、缺陷率、提案数）？多久看一次？无指标则无法验收。
4. **监控副作用。** 合作崩溃、隐瞒信息、短期主义、人才流失——出现则降强度或改规则（竞赛≠零和羞辱）。
5. **决定内化或撤出。** 目标是把外部压力变成内部标准；鲶鱼不应成为永久恐慌装置。

## 例证

**第二供应商引入**：单一供方交期变慢；引入备选后响应提升。揭示**可信替代威胁**改变努力。

**业务线引入对标团队**：公开可比仪表盘后惰性班组改善。揭示**可见竞争**；若规则不公则变政治斗争。

**传说沙丁鱼舱**：故事好记，但证据轶事——揭示隐喻传播力强于科学精确性。

## 什么时候不适用（边界）

- **高信任协作任务**：过度竞争破坏知识分享。
- **资源极度不对称**：鲶鱼享有特权则激活变成不公叙事。
- **已过载系统**：再加压只提高差错与离职。

## 常见误用

- **恐吓管理**：用裁员传闻当鲶鱼 → 短期绩效↑长期信任↓。
- **忽视能力缺口**：压力≠技能。
- **永久鲶鱼**：永远靠外部敌人维稳，说明内部激励设计失败。

## 相关模型

- **与[霍桑效应](../hawthorne-effect/SKILL.md)**：霍桑是“被关注”本身；鲶鱼是“竞争威胁”。
- **与[皮格马利翁效应](../pygmalion-effect/SKILL.md)**：期望提升表现；鲶鱼用压力/对比。可并用但别混成一套。
- **与[破窗效应](../broken-windows/SKILL.md)**：破窗管失序传染；鲶鱼管竞争激活。

## 记忆钩子

放一条会动的鱼——先问惰性从哪来，再问威胁是否可信且公平。
