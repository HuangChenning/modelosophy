# 平衡计分卡 Balanced Scorecard

## 这是什么

**平衡计分卡（BSC）**：把战略落实为**四类互为因果**的目标与指标——**财务、顾客、内部流程、学习与成长（组织能力）**——并用战略地图画出「能力→流程→顾客→财务」的假设链，再配行动与复盘。

Robert Kaplan 与 David Norton 提出，用以纠正「只看财报滞后指标」的管理近视。BSC 是**战略执行度量系统**，不是竞争战略内容本身，也不是 OKR 的口号式目标语法。

## 什么时候用

- "战略写了，但只有收入指标"
- "BSC / 四维度平衡 / 战略度量体系"
- 需要给已有的战略目标配上指标、目标值、行动方案，并建立定期复盘机制

**不要**当主模型：

- 只想先画出「学习与成长→内部流程→顾客→财务」的因果链条本身，还没到配指标/目标值这一步 → [`strategy-map`](../strategy-map/SKILL.md)（画完地图再回到本 Skill 配指标）
- 写鼓舞性 O + 可度量 KR → [`okr`](../okr/SKILL.md)
- 设计单个指标是否好用 → [`kpi-framework`](../kpi-framework/SKILL.md)
- 组织七要素是否对齐 → [`mckinsey-7s`](../mckinsey-7s/SKILL.md)

## 怎么用（执行步骤）

1. **写清战略主题（1–3 条）。** 例：提高钱包份额、降低单位服务成本。判据：能指向明确顾客与经济逻辑。
2. **画战略地图因果。** 自上而下或自下而上：学习与成长 → 内部流程 → 顾客成果 → 财务成果。判据：每条箭头可写成可证伪假设（「若 X 改善则 Y」）。若这一步本身就是讨论的全部重点（还没准备配指标），可直接用 [`strategy-map`](../strategy-map/SKILL.md) 的执行步骤把地图画细，再回来接第 3 步。
3. **每维选少数目标与领先/滞后指标。** 总数宜可控（常见每维 2–5）。判据：指标可测、有基线；禁止「提升协同」无操作定义。
4. **挂行动方案与责任人。** 指标无行动 = 装饰。判据：每个关键指标有 owner 与复盘节奏。
5. **查冲突与缺口。** 财务要增长但流程指标全是成本砍削且无顾客体验 → 标红。判据：至少做一次跨维一致性检查。
6. **设定复盘：检验因果而非只读数。** 指标动了但下一环不动 → 假设失败，改地图。

## 例证

**只考收入导致杀鸡取卵**：销售冲短期单，顾客满意度与流程质量崩盘后财务回吐——揭示缺顾客/流程维的滞后陷阱。

**战略地图暴露断点**：要「解决方案销售」，但学习维无方案能力、流程仍按单品提成——揭示 BSC 用于发现执行断层。

**与 OKR 连用**：BSC/地图定主题与指标族；OKR 承载季度冲击型目标——勿两套互相矛盾。

## 什么时候不适用（边界）

- **战略本身未定或每周大变**：先稳定战略选项。
- **微团队过度工程**：四维全套过重，改用轻量目标+少指标。
- **把 BSC 当绩效考核打分游戏**：失去战略学习功能。

## 常见误用

- **四维平均凑数**：无因果 → 先地图后指标。
- **BSC = KPI 堆砌**：无战略主题 → 先写主题。
- **与 OKR 双轨打架**：同一行为两套激励 → 统一主系统。
- **只有财务维真管事**：其余装饰 → 把非财务维纳入决策议程。

## 相关模型

- **与[战略地图](../strategy-map/SKILL.md)**：战略地图是本 Skill 第 2 步「画因果」的深潜工具，专注于目标层面的因果链条本身（含 Kaplan & Norton 2004 年补充的无形资产就绪度方法论），不含指标/目标值/行动方案；BSC 是完整的战略度量管理系统——目标+指标+目标值+行动方案+复盘节奏。先用战略地图把因果链画对，再用 BSC 把每个目标配上可执行的指标体系。
- **与[OKR](../okr/SKILL.md)**：OKR 偏季度对齐与挑战目标；BSC 偏战略因果与持续度量体系。
- **与[KPI 框架](../kpi-framework/SKILL.md)**：KPI 框架教怎么设计好指标；BSC 教指标如何服务战略地图。
- **与[麦肯锡 7S](../mckinsey-7s/SKILL.md)**：7S 诊断组织对齐；BSC 翻译战略为度量——先对齐再计分。
- **与[价值链](../value-chain/SKILL.md)**：内部流程维常映射价值链活动改进。

## 记忆钩子

BSC = **战略地图上的因果假设** + 四维少数指标——读数是为了检验箭头，不是为了填表。
