# 耗散结构 Dissipative Structures

## 这是什么

**耗散结构**（Prigogine）：在**开放**、**远离平衡**的非线性系统中，物质/能量持续流过；当控制参量越过临界阈值，小涨落可被放大，系统经**分岔**跃迁到新的时空/功能有序态。该有序靠**持续耗散**（吞吐能量与物质）维持——关掉流，结构塌回。经典物理化学例子：Bénard 对流胞、某些化学振荡。

对组织与社会的借用必须守住条件清单，否则沦为“变化”的华丽别名：

| 条件 | 可观察问法 |
|---|---|
| **开放交换** | 是否有持续的物质/能量/信息进出？ |
| **远离平衡** | 是否被强驱动远离“舒适稳态”（强竞争、强约束、强外部冲击）？ |
| **非线性** | 小变化是否可能不成比例放大（网络、激励、口碑）？ |
| **涨落 + 阈值** | 是否存在可指认的临界点，而非平滑微调？ |
| **耗散维持** | 新秩序是否需要持续输入，一停就退？ |

本模型诊断的是：**是否满足这些条件、分岔附近如何干预**；不是一般地画系统图。

## 什么时候用

- 系统长期僵持后，外部冲击/内部试验可能触发质变；
- 讨论“临界点、分岔、自组织、非平衡有序”；
- 要判断一次重组/开放是“真耗散跃迁”还是表演性折腾；
- 用户直接说耗散结构 / dissipative structure。

**不要**当主模型：
- 只需要存量、流量、反馈与延迟图 → [`systems-thinking`](../../systems-classic-effects/systems-thinking/SKILL.md)；
- 只需要开放输入/排出的有序账 → [`negentropy`](../../thinking-models/negentropy/SKILL.md)；
- 只是“换环境学习成长”的励志叙事，无阈值与耗散条件；
- 把管理口号当物理定律证明。

## 怎么用（执行步骤）

1. **先过条件清单。** 对目标系统逐项勾选开放、远离平衡、非线性、可疑阈值、耗散维持。缺两项以上 → 降级为普通变革或负熵账，不要贴耗散结构标签。
2. **指认驱动参量与现状态。** 写清：什么在“推”系统远离平衡（竞争强度、监管、技术冲击、资源流）？当前宏观模式是什么（稳态官僚、增长飞轮、振荡）？
3. **定位涨落与阈值假说。** 哪些小扰动可能被放大（试点、关键人物离开、一次公开失败、资本进入）？阈值的可检验代理是什么（留存断崖、现金流、合规红线、舆论爆发）？写不出代理就承认“还只是隐喻”。
4. **在分岔附近设计干预，而非假装可精确预测终点。** 分岔后路径常不可唯一预言；可做的是：放大有益涨落（保护试点带宽）、抑制有害正反馈、保证跃迁后仍有能量流维持新结构。禁止承诺“一砸必升维”。
5. **复查耗散成本与伦理。** 新有序靠谁持续付出？若“耗散”等于不可逆压榨或归零风险，停用跃迁叙事，改做风险与边界管理。

## 例证

**Bénard 对流**：液体自下加热越过温差阈值，自发形成对流胞；停止加热则消退。揭示“有序来自流与阈值”，不是心灵鸡汤。

**城市与交通相变式拥堵**：密度/流量越过阈值，流动模式突变；缓解往往需要改结构或降驱动，而非只喊“更努力开车”。揭示社会系统可有类似阈值现象，但仍须数据，不能口头宣布分岔。

**组织试点放大**：在强外部压力下，小范围新流程若被资源与注意力放大，可能成为新常规；若无持续投入，试点烟消云散。揭示耗散维持条件。

**（原书卡片）舒适区同心圆 + 华为“熵减/吐故纳新”**：卡片抓住了“开放、远离平衡、分岔”口号；局限是把任何出舒适区都等同耗散结构，并把管理隐喻写成物理结论。华为话术可作**组织隐喻案例**，须标注：激励与文化设计 ≠ 非平衡热力学证明；“中庸/心流”收尾与 Prigogine 条件无关，本 skill 不采纳。

## 什么时候不适用（边界）

- **近平衡的线性响应**：微调参数、常规优化，不是耗散结构。
- **封闭系统**：无交换则无法维持耗散有序。
- **无阈值的叙事**：“我们一直在变化”不等于越过临界点。
- **预测精确终点**：分岔后多稳态常见；本模型帮识别条件与干预点，不保证指定结局。
- **管理话语绑架**：用“耗散/熵减”回避具体激励、权力与安全问题，视为滥用。

## 常见误用

- **动荡之后变好就贴标签**：不逐项核对开放/远离平衡/非线性/阈值/耗散维持五个条件，只要经历一阵混乱后好转，就宣称"这是一次耗散结构跃迁" → 先过步骤1的条件清单，缺两项以上就降级为普通变革，不贴此标签。
- **把演讲比喻当物理证明**：引用"华为熵减""吐故纳新"之类的管理话术，仿佛这就是非平衡热力学的实证支持 → 组织语境下只能作弱隐喻，须明确标注非物理证明，不能拿来论证决策正确。
- **承诺可预测的确定结局**：声称"这次改革够猛，一定能跃迁到某个具体的更好状态"，把分岔后本质多稳态、不可精确预言的走向说成可规划的单一终点 → 步骤4只能设计放大有益涨落、抑制有害正反馈，不能承诺终点。
- **用"耗散维持"美化压榨**：把员工持续超负荷加班包装成"新秩序需要的必要耗散"，回避真实的激励、权力与安全问题 → 步骤5要求复查耗散成本与伦理，一旦等于不可逆压榨就该停用跃迁叙事，改做风险与边界管理。

## 相关模型

- **与[系统思维](../../systems-classic-effects/systems-thinking/SKILL.md)**：系统思维画反馈、延迟、存量流量；本模型额外要求开放+远离平衡+涨落过阈值的耗散条件，并关注分岔点干预。用户要行为模式与杠杆图 → 系统思维；用户要“是否临界跃迁成新有序” → 本模型。先画清结构再问是否耗散，通常更稳。
- **与[负熵](../../thinking-models/negentropy/SKILL.md)**：负熵是有序维持的输入/排出账；耗散结构是特定非平衡机制名。日常防僵化优先负熵；谈临界跃迁用本模型。
- **与[临界点/引爆点](../tipping-point/SKILL.md)**：引爆点侧重传播过阈值；耗散结构还要求开放流与耗散维持的有序态。可对照，勿混为一谈。
- **与[反脆弱](../../learning-growth/antifragility/SKILL.md)**：反脆弱设计不对称暴露；耗散结构解释某种有序如何在流中自组织。用户问仓位结构走反脆弱。
- **与[自组织](../self-organization/SKILL.md)**：耗散强调开放非平衡与耗散维持；自组织强调无中央蓝图的局部规则生成。
