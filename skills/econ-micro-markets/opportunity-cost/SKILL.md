# 机会成本 Opportunity Cost

## 这是什么

做出选择时，真正的代价不是"我付出了什么"，而是"我放弃的、价值最高的那个替代选项，本可以带给我什么"。这是微观经济学的基础概念（源自奥地利学派 Friedrich von Wieser），公式化表示为：

**机会成本 = 外显成本（实际支出）+ 隐含成本（时间、精力、错失的替代收益）**

## 什么时候用

用户面临一个**具体的、互斥的多选一决策**，并且能说出至少两个现实中真的可选的选项时。典型触发场景：

- "我该把这周末的时间用来读书还是陪家人？"
- "这笔预算投产品A还是产品B？"
- "该继续做这份工作，还是辞职创业？"

**不要**在以下情况套用本模型：
- 用户还没想清楚有哪些选项（先帮用户列选项，再谈机会成本）；
- 只有一个选项、没有真正的替代对象（没有"放弃"就没有机会成本）。

## 怎么用（执行步骤）

1. **列出全部互斥选项**——不要只对比"选与不选"，要对比"选 A 与选 B"。追问用户："除了这个，你现实中真的能选的还有什么？"
2. **排除不现实的选项**——机会成本只计算"现实中真的可选"的替代项，不要用理想化的、根本选不到的选项（比如"如果我当年读了另一个专业"这种无法验证的假设）来夸大代价，那会导致决策瘫痪。
3. **算出机会成本** = 被放弃的最佳替代选项本身的价值（不是两个选项的差值——机会成本恒为正，它衡量的是"放弃了什么"，不是"这次选择净赚了多少"，两者是不同的问题）。同时要求用户分开算外显成本（账面支出）和隐含成本（时间、精力、错失收益），两者都要给出估计，即使是定性的（高/中/低）。
   > 常见错误提醒：不要把机会成本和"选择的净收益"混为一谈。"净收益 = 实际选择的价值 − 机会成本"才是两者的正确关系；机会成本本身不会因为你选对了就变成负数。
4. **把结果讲清楚，不替用户做决定**——机会成本只是让代价可见，最终选择权在用户；如果两个选项都有较高机会成本，如实告诉用户"选什么都有代价，这是正常的"，而不是暗示存在一个零代价的最优解。

## 例证

**读大学的真实成本（经济学教科书经典案例）**：读四年大学的机会成本不只是学费，还包括这四年本可以工作赚到的工资。这也是为什么在薪资高涨的行业（如程序员市场火热期），辍学创业的机会成本计算会和萧条期完全不同——同样的学费，不同时期的真实代价差异巨大。

**巴菲特与芒格的投资筛选标准**：伯克希尔的决策方式是把每一个候选投资都与"当前手上最好的替代机会"作比较，而不是只问"这笔投资本身赚不赚钱"。芒格多次公开表达过这个逻辑：一个能赚 8% 的项目，如果你同时有一个能稳定赚 15% 的选择，那它就是亏的。这正是机会成本从"概念"变成"筛选器"的用法。

**公司理财中的资本成本**：企业评估项目 A 时，用的贴现率本质上就是"这笔资金投向风险相当的替代用途能获得的回报"——机会成本被直接量化进了财务模型，而不是停留在直觉层面。

**（原书卡片）读书 vs 追剧**：选择读书的机会成本是放弃追剧本可能带来的放松收益；反过来也成立。这个例子的价值在于说明——机会成本是双向的，它本身不评判哪个选择"更对"。

## 什么时候不适用（边界）

- **选项之间不可直接比较时**（比如一个是确定收益、一个是高方差的赌博）：单纯做价值减法会掩盖风险偏好的差异，此时应提醒用户，机会成本的比较需要先做风险调整，不能直接减。
- **容易被"理想化选项"污染**：如果用户拿一个现实中根本选不到的完美选项做基准（"要是我当初……就好了"），机会成本会被系统性高估，导致"选什么都觉得亏"的决策瘫痪感——这时候应该把讨论拉回"现实中当时真的可选的是什么"。

## 常见误用

- **“选对了机会成本为负”**：把机会成本与净收益混为一谈 → 机会成本恒为正（放弃的最佳替代本身的价值）；净收益 = 实际选择价值 − 机会成本。
- **“都已经投入这么多了”当机会成本**：那是沉没成本场景 → 转 [`sunk-cost`](../../behavioral-biases/sunk-cost/SKILL.md)；本模型只算面向未来的互斥替代。
- **用“要是当年……”当基准**：理想化、不可再选的反事实会系统性抬高代价 → 只计入当时现实可选的替代项。
- **只比“做 vs 不做”**：漏掉真实互斥的 B、C → 先列出全部可行选项再取最佳放弃项。

## 相关模型

与[沉没成本](../../behavioral-biases/sunk-cost/SKILL.md)关系密切但方向相反：机会成本关注**面向未来**放弃了什么，沉没成本提醒**不要**让过去已经无法收回的投入影响现在的判断。两者容易被用户混用，若用户说"都已经投入这么多了"，应识别为沉没成本场景，不是机会成本场景。

与[决策树](../../thinking-models/decision-tree/SKILL.md)的区别：选项后果基本确定、重点是放弃了哪个最佳替代项，走机会成本；每个行动都有多个不确定结果、需要概率和阶段信息，走决策树。决策树的终点价值仍应包含机会成本。
