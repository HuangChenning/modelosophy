# 煤气灯效应 Gaslighting

## 这是什么

**煤气灯效应**（语出戏剧/电影 *Gas Light*）：一方系统性地否认、扭曲或改写另一方对事件的感知、记忆或判断，使对方怀疑自己的现实感，从而**夺取现实定义权**。常见手法包括反复否认已发生事件、把合理反应说成“过敏/疯了”、甩锅式投射、用“为你好”包裹控制。

Robin Stern（《The Gaslight Effect》）描述的关系动态三阶段，可作**识别启发式**（不是诊断量表）：

1. **质疑**：听到离谱改写后，开始想“是不是我错了？”；
2. **辩解**：努力举证、求对方承认，把自己的现实感押在对方认可上；
3. **压抑**：放弃争辩，接受对方版本以维持关系或安全。

本 skill 处理的是**行为模式识别、证据外置、权力不对称与安全边界**。它**不是**精神障碍诊断工具，也不对他人下人格障碍或临床标签。

## 什么时候用

- 亲密关系、家庭或职场中，反复出现“你的记忆/感受是错的”，且伴随自我怀疑加深；
- 用户怀疑自己在被操纵，需要结构化核对而非贴标签狂欢；
- 直接说煤气灯 / gaslighting / 现实定义权。

**不要**当主模型：
- 单次事实争议、可核对的普通纠正（“会议改到三点了”且有记录）→ 查证据即可；
- 双方各执一词、都可能主观，但无系统剥夺对方现实权 → 冲突调解/沟通，不是煤气灯；
- 用户要给对方贴人格障碍诊断 → **拒绝**；
- 紧急人身安全/家暴 → 优先安全与专业资源，不跑本模型全流程。

## 怎么用（执行步骤）

1. **安全与紧急分流（必须先做）。** 若存在暴力、威胁、跟踪、无法离开的强制控制：停止分析式对话，建议联系当地紧急服务、可信支持人或专业热线；本 skill 不是危机干预。若仅认知困扰、可安全讨论，继续。
2. **外置时间线，不靠脑内对质。** 把争议事件写成：时间、谁说了什么、可核验证据（消息、邮件、第三方、当时笔记）。煤气灯的识别靠**模式 + 证据落差**，不靠“感觉被否定一次”。
3. **对照模式清单（需多项同时出现才提高权重）。**  
   - 反复否认可核验事实；  
   - 把界限表达污名为病态（“你太敏感/你有病”）且拒绝具体讨论行为；  
   - 诱导依赖单一信息源（只准信我）；  
   - 投射（指责你做对方正在做的事）；  
   - 你进入辩解→压抑循环，自尊随互动下降。  
   仅有批评或意见不合 → **不够**。
4. **区分权力结构。** 职场：保留书面记录、走合规/HR/劳动渠道时注意报复风险，本模型不教“斗智”。亲密关系：评估经济/住所/子女依赖是否使“争对错”本身不安全。
5. **恢复现实锚，而非赢得对方承认。** 目标是重建多通道现实（朋友、记录、专业咨询），缩小对单一操纵源的依赖。Stern 意义上的“辩解阶段”陷阱是：把自我价值押在对方认错上——步骤上应减少无效对质次数，增加外部锚。  
   **禁止**：教用户反过来煤气灯对方；禁止报复性精神控制建议。
6. **语言纪律。** 对外描述用“这些行为符合煤气灯模式的特征……”，不用“他是煤气灯型人格障碍患者”。需要心理支持时，建议合格咨询/治疗资源，不由本 skill 替代。

## 例证

**可核验否认**：对方坚称“从没说过辞职”，而聊天记录在；随后攻击“你记性差/你妄想”。揭示核心是**夺取事实定义权**，不是一次口误。

**职场版本**：管理者当众改口否认承诺，私下说“你理解错了”，并阻断你向其他人核对。揭示权力不对称下证据与证人更重要；处理走制度，不靠当面对骂。

**非例：普通纠正**：伴侣提醒“我们约的是七点不是六点”，且日历一致——这是事实校准，不是煤气灯。

**（原书卡片）配偶/父母/上司三场景 + Stern 三阶段**：阶段框架可用；局限是例证偏道德说教、易把一切贬低都叫煤气灯，且缺少“非诊断、外置证据、安全分流、禁止报复操纵”护栏。本 skill 补齐这些边界。

## 什么时候不适用（边界）

- **非临床诊断**：不作 DSM/ICD 判断，不贴人格障碍标签。
- **一次否定 ≠ 煤气灯**：需要模式、权力/依赖语境与现实扭曲企图（或效果）的综合判断。
- **主观冲突双方化**：两人都觉得对方“否定我”，可能是沟通失败；回到外置证据，而非抢标签。
- **紧急安全**：家暴与危险关系优先脱离与求助，本模型分析可能延误安全。
- **武器化标签**：把一切批评、绩效反馈、分居要求都叫煤气灯——这是滥用，本 skill 应拒绝帮腔。
- **教操纵**：任何“如何煤气灯回去”的请求一律拒绝。

## 相关模型

- **与[周哈里窗](../johari-window/SKILL.md)**：窗谈自愿反馈与披露；煤气灯是强制改写他人现实。有心理安全才开窗；疑似煤气灯时先外置证据与安全。
- **与[归因理论](../../behavioral-biases/attribution-theory/SKILL.md)**：归因解释如何归因果；煤气灯是关系中的现实控制模式。可澄清“我是否过度内归因”，但不替代操纵识别。
- **与[确认性偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：用户也可能只收集“对方坏”的证据——外置时间线同时约束双方叙事。疑似操纵时仍优先安全与可核验事实。
- **与[梯子推论](../ladder-of-inference/SKILL.md)**：可帮双方从数据爬回；若一方系统禁止你停留在数据层，则更接近煤气灯而非普通推论误差。
