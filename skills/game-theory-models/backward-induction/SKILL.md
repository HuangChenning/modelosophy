# 逆向归纳法 Backward Induction

## 这是什么

**从博弈终点倒推，逐步确定更早节点的最优行动。**

完全且完美信息有限博弈的标准解法：最后行动者选最优 → 前一人预见到此再优化 → 直至起点。与子博弈精炼紧密相连；有限重复囚徒的“末期拆解”即其推论。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "从最后一步倒推"
- "逆向归纳怎么做"
- "有限次是不是一定拆解"

**不要**在以下情况套用本模型：

- 无限重复可行性 → ../folk-theorem/SKILL.md
- 只要可信威胁概念 → ../subgame-perfect-equilibrium/SKILL.md
- 同时行动 → ../nash-equilibrium/SKILL.md

## 怎么用（执行步骤）

1. **确认有限深度与完美信息。** 节点上谁知道什么必须清楚；信息集复杂则谨慎。
2. **从终节点写最优。** 每个最后决策点选出支付最大行动并标记。
3. **向前折叠。** 前一行动者把后续已定路径当给定，选自身最优；全程记录。
4. **读起点路径与拆解风险。** 若合作依赖“最后仍合作”，标出拆解。输出：倒推路径 + 关键转折点。

## 例证

**有限重复囚徒**：最后一期背叛占优 → 倒数第二期亦然……合作崩塌。揭示终点如何污染全程。

**轮流出价谈判**：终点报价权决定剩余分割；倒推得子博弈精炼份额。

## 什么时候不适用（边界）

- **实验偏离**：蜈蚣博弈中人常不按倒推早停——见蜈蚣博弈。
- **无限/不确定结束**：倒推不适用同一逻辑。

## 常见误用

- **无树空谈倒推**：必须有节点与支付。
- **忽略信息集**：看不清历史时不能当完美信息。

## 相关模型

- **与[子博弈精炼均衡](../subgame-perfect-equilibrium/SKILL.md)**：倒推常用于找 SPE。
- **与[蜈蚣博弈](../centipede-game/SKILL.md)**：理论早停 vs 实验合作。
