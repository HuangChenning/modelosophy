# 灰度认知 Grey Thinking

## 这是什么

**灰度认知**：把命题的态度从「真/假二元」改成**可修订的置信度**（如 15% / 55% / 80%），并承认中间地带。它不是「和稀泥各打五十大板」，而是：**信念强度应匹配证据强度**；新证据到来时，刻度应移动。

与空话「世界是复杂的」不同：灰度要求你写出数字或区间，并写明什么证据会让你 ±20 个百分点。

## 什么时候用

- "这件事别非黑即白"
- "我有大概六成把握，但不敢说死"
- "灰度 / 概率化立场 / 持有观点而非身份"
- 争议判断、早期战略、人事与产品方向尚在证据积累期

**不要**当主模型：

- 已有似然要做正规更新算术 → [`bayesian-updating`](../bayesian-updating/SKILL.md)
- 需要立刻二选一且门是单向的 → [`reversible-irreversible`](../reversible-irreversible/SKILL.md)（可先灰度评估，再定门型）
- 合规/安全已规定禁止事项 → 不适用「灰度执行违规」

## 怎么用（执行步骤）

1. **把问题写成可检验命题。** 「市场会好」→「未来 12 个月付费转化 ≥X%」。判据：事后可对错。
2. **给出当前置信（点或区间）并标理由清单。** 例如 40–60%。列出支持/反对各 2–3 条，禁止只有口号。
3. **标定「移动规则」。** 预先写：若出现证据 A，大致构成 3:1 支持，把置信从当前档**上移一档**；若出现证据 B，构成强反对，**下移到区间 X–Y%**。用粗档移动，不要用固定百分点加减——百分点加减在接近 0% 或 100% 时会直接越界，且同一条证据在先验 10% 和先验 90% 处该移动的幅度本就不同。先验接近端点、或已有可量化似然时，改走 [`bayesian-updating`](../bayesian-updating/SKILL.md) 的正规算术。
4. **分离事实置信与价值选择。** 「会怎样」用灰度；「该不该」可另列价值权重，避免用百分比伪装价值观。
5. **决策时用阈值，不用身份。** 例如置信 <30% 不扩大投入；>70% 才签长期约。阈值写清。
6. **复盘校准。** 事后对账：标 70% 的判断长期是否约七成正确（校准）；系统性偏高则降档。

## 例证

**早期创业方向**：对「企业客户会为 API 付费」标 35%，并规定「3 个付费试点 → 调至 60%」。揭示：灰度让学习速度可见，而非每天情绪化 All-in/放弃。

**公共争论**：把「政策必成/必败」改成概率区间 + 可观察指标，降低身份绑架。揭示：灰度是沟通卫生，不是懦弱。

**（误用对照）「各打五十大板」**：对已有强证据的欺诈指控仍标 50%，是拒绝更新，不是灰度。

## 什么时候不适用（边界）

- **红线问题**：人身安全、明确违法——应用确定性规则，不用灰度稀释责任。
- **需要关闭选项的不可逆高代价门**：灰度评估后仍须按不可逆流程加重审查。
- **过度精细的假精度**：证据粗却报 63.7% → 改用粗档（低/中/高或 20% 档）。

## 常见误用

- **假灰度**：口头说不确定，行动当 100% → 用行动阈值约束。
- **和稀泥**：强证据仍 50% → 必须更新或说明为何似然≈1。
- **与贝叶斯对立**：灰度是表达层；有数据应升级到贝叶斯算术。
- **用灰度逃避承诺**：可逆低成本决策该拍板时仍无限悬置 → 见可逆决策。

## 相关模型

- **与[贝叶斯更新](../bayesian-updating/SKILL.md)**：灰度给信念刻度；贝叶斯给移动的合法算术。
- **与[确认性偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：预注册移动规则对抗只吸收支持证据。
- **与[过度自信](../../behavioral-biases/overconfidence/SKILL.md)**：校准复盘专治自信膨胀。
- **与[可逆与不可逆决策](../reversible-irreversible/SKILL.md)**：置信低且可逆 → 小步试；置信低且不可逆 → 延后或买信息。

## 记忆钩子

立场可以硬，**置信必须软**；软的是百分比，不是原则。
