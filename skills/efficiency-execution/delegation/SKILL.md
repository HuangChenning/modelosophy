# 委派 Delegation

## 这是什么

**委派**：把某项结果的**责任与必要权限**交给他人，同时明确完成定义、约束、资源与跟进节奏。好的委派是「交结果」，不是「丢任务」或「假装授权却步步审批」。

它是**人与责任界面**的执行工具；清单/SOP 提供怎么做；吃青蛙/优先级决定委派什么。

## 什么时候用

- "事必躬亲导致自己成瓶颈"
- "委派 / 授权 / 交接任务"
- 培养下属或释放深度时间

**不要**当主模型：

- ≤2 分钟且应自己清掉 → [`two-minute-rule`](../two-minute-rule/SKILL.md)
- 只写步骤标准 → [`checklist-sop`](../checklist-sop/SKILL.md)
- 情境领导风格全谱 → 可互链思考模型类（若存在）或先把完成定义写清

## 怎么用（执行步骤）

1. **选可委派项。** 标准：他人能学、你非唯一专家、失败可逆或有护栏；保留不可逆高风险最终决策。
2. **写清结果与边界。** Done 标准、期限、预算、质量红线、可否再委派。
3. **匹配权限。** 权限 < 责任 → 假委派；同步告知相关方「找谁」。
4. **移交上下文。** SOP、范例、风险点；一次讲清，约定问问题的通道。
5. **跟进节奏。** 按风险设检查点（非盯梢）；用里程碑式中间门。
6. **复盘与承认。** 成功归执行者可见功劳；失败先查委派质量（定义/权限/支持）。

## 例证

**经理**：周报由成员起草，自己只定标准与例外——揭示释放时间。

**坏例**：口头「你负责」却每步要签字——揭示假授权。

## 什么时候不适用（边界）

- **无人可用或全员过载**：先减范围/加资源，假委派有害。
- **法律/安全必须本人**：不可转。
- **紧急且传授成本 > 自己做且无培养意图**：可暂自做，事后计划培养。

## 常见误用

- **委派活动不委派结果**：只扔步骤清单无 Done。
- **反向委派**：下属把猴子送回你肩上——练「下一步你是谁」。
- **只丢烂事**：摧毁动机；搭配有挑战的任务。
- **无跟进**：交完消失=放弃。

## 相关模型

- **与[清单与 SOP](../checklist-sop/SKILL.md)**：委派常附标准作业。
- **与[里程碑规划](../milestone-planning/SKILL.md)**：中间门作跟进点。
- **与[GTD](../gtd/SKILL.md)**：等待清单跟踪委派项。
- **与[两分钟法则](../two-minute-rule/SKILL.md)**：短闭环可自做；培养性任务仍可委派。
- **与[奥兹原则](../../decision-probability/oz-principle/SKILL.md)**：委派后仍对结果问责（Above the Line）。

## 记忆钩子

委派交的是**结果+权限+跟进**，不是甩手或微观操控。
