# 情景规划 Scenario Planning

## 这是什么

**情景规划**：针对影响重大、**概率难以可靠校准**的不确定驱动因素，构建 2–4 条内部自洽、彼此差异足够大的**未来叙事**，然后问：哪些战略在多数情景下可接受？哪些是情景期权？需要监测哪些预警信号以切换路径？

它不是「乐观/基准/悲观」三个销量数字（那是敏感性），而是：**改变因果逻辑的分歧轴**（例如监管松紧 × 技术路线胜负）。

## 什么时候用

- "未来太不确定，别只给一个预测"
- "情景规划 / 多未来 / 战略韧性"
- 长周期战略、政策/技术巨变、黑天鹅暴露管理的前置

**不要**当主模型：

- 选项与概率可粗估的多阶段选择 → [`decision-tree`](../decision-tree/SKILL.md)
- 只需对参数做 ± 敏感性 → 决策树/财务敏感性，不必全套叙事
- 已失败回放 → 验尸/复盘

## 怎么用（执行步骤）

1. **锁定决策焦点。** 情景为「即将做的战略选择」服务，禁止无焦点科幻。写出 1–2 个待决问题。
2. **列出关键不确定驱动因素，选 2 个主轴。** 主轴应：影响大、结果分歧、相对独立。判据：轴的两端能讲出不同世界。
3. **生成 2–4 个情景（命名+叙事）。** 每条含：世界如何运转、赢家输家、对焦点决策的含义。避免只改一个 KPI。
4. **风洞试验现有战略。** 对每个情景：战略表现如何、脆弱点、致命假设。记录「仅在情景 A 存活」的赌注。
5. **设计稳健项、期权与预警。** 稳健：多情景可接受；期权：低成本保留切换权；预警：领先指标触发预案。
6. **定期刷新，防止情景化石化。** 预警触发或驱动因素结构变了就改轴，不年年复读旧故事。

## 例证

**石油公司经典情景**：不同供给/地缘叙事改变投资组合，使公司在油价剧变中仍有可执行路径。揭示：价值在**预先排练的选项**，不在猜中油价。

**平台监管情景**：「严监管 / 自治宽松」×「技术标准分裂 / 统一」四象限，迫使保留合规与多区域架构期权。揭示：情景驱动的是能力投资，不是公关稿。

**反例：伪情景**： basline±20% 销量三表——这是敏感性，缺少机制分歧。

## 什么时候不适用（边界）

- **短平快可逆试验能消解不确定**：先 MVP/OODA，别开工作坊。
- **概率与结果表已足够**：用决策树更干净。
- **情景变成政治工具**：只保留领导喜欢的未来 → 引入红队攻击情景集合完整性。

## 常见误用

- **情景=预测**：赌哪条会发生 → 错；目标是稳健与期权。
- **十条情景**：无法决策 → 压到 2–4。
- **与黑天鹅迷信**：情景不覆盖一切极端；归零暴露仍要硬限制（反脆弱）。
- **写完不进资源配置**：无效文档。

## 相关模型

- **与[决策树](../decision-tree/SKILL.md)**：树要概率与折叠；情景容忍不可校准概率、重叙事轴。能估 \(p\) 走树；不能则情景。
- **与[黑天鹅](../../systems-classic-effects/black-swan/SKILL.md)**：黑天鹅强调不可预测尾部与暴露；情景是可排练的多种「常规不确定」。
- **与[红队思维](../red-team/SKILL.md)**：红队攻击「遗漏情景/脆弱战略」。
- **与[事前验尸](../pre-mortem/SKILL.md)**：验尸深挖单一失败世界；情景并列多世界。
- **与[反脆弱](../../learning-growth/antifragility/SKILL.md)**：情景期权 + 下行限制，避免单情景 All-in。

## 记忆钩子

情景不是算命条数，是**风洞**：看你的战略在哪些风里散架。
