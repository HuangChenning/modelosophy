# 概念图 Concept Map

## 这是什么

**概念图**：用节点表示概念，用**标注了连接词**的有向边把概念连成**命题**（例如「光合作用 —需要→ 光」）。Novak 传统强调：好概念图能被读成一组真假可讨论的句子，并鼓励**交叉链接**（跨分支的关系）。

它是理解与教学工具：逼你说清「A 与 B 到底什么关系」，而不是只把词放在一起。

## 什么时候用

- "把这块知识的关系画清楚"
- "学生/团队对术语关系混乱"
- 直接说概念图 / concept map / 命题图
- 课纲设计、知识审计、复杂政策关系澄清

**不要**当主模型：

- 快速联想头脑风暴 → [`mind-map`](../mind-map/SKILL.md)
- 多维盘点草图 → [`octopus-diagram`](../octopus-diagram/SKILL.md)
- 主问题拆子问题 → [`logic-tree`](../logic-tree/SKILL.md)
- 沟通结论先行 → [`pyramid-principle`](../pyramid-principle/SKILL.md)

## 怎么用（执行步骤）

1. **定焦点问题（Focus Question）。** 图回答哪一句？（「电动车补贴如何影响供需？」）判据：所有节点应服务该问题。
2. **列出 10–20 个关键概念（名词性）。** 先清单后布点；概念粒度尽量同级，避免一句政策当一个「概念」却含混。
3. **建立层级或集群（可选）。** 较综合概念靠上/居中，较具体靠下——这是辅助，不是强制树。
4. **画连接并写连接词。** 每条边必须能读成命题；禁止无标签连线。连接词例：导致、属于、依赖、限制、由…组成。
5. **加交叉链接。** 至少找 1–2 条跨集群关系；没有交叉链接的图常是伪装大纲。
6. **修订与验读。** 请别人只读命题句，标出含混边；补定义或拆概念。输出：命题列表 + 仍未知的边（标假设）。

## 例证

**生态学入门**：生产者—通过光合作用→有机物；消费者—依赖→生产者。交叉链接揭示物质循环。揭示：连接词让「关系」可被反驳。

**失败图**：把「创新」「协同」「赋能」互连无连接词——不是概念图，是词云。

**（原书卡片）**：若与思维导图混称，以「有无连接词命题」为鉴别。

## 什么时候不适用（边界）

- **纯流程/时序**：用流程图更清晰。
- **情绪风暴**：先 mind-map 再提炼概念图。
- **强决策矩阵**：概念图不自动给出选项权重。

## 常见误用

- **无连接词**：有线无命题 → 补词或删线。
- **整句塞进节点**：节点过大 → 拆成概念 + 边。
- **与思维导图互冒**：要联想速度走 mind-map；要关系精确走本模型。
- **当作已验证知识**：图上假设边要标明，避免教学把假说当事实。

## 相关模型

- **与[思维导图](../mind-map/SKILL.md)**：**硬区分。** 联想笔记/发散 → mind-map；命题+连接词 → concept-map。可先导图后提炼概念图。
- **与[八爪鱼图](../octopus-diagram/SKILL.md)**：八爪盘点维度；概念图深化维度内关系。
- **与[逻辑树](../logic-tree/SKILL.md)**：逻辑树为解决问题而分解；概念图为理解领域而连命题。
- **与[抽象阶梯](../abstraction-ladder/SKILL.md)**：节点高度应大致同级；混高度时用抽象阶梯校准。
- **与[MECE](../mece/SKILL.md)**：同层概念划分可参考 MECE，但交叉链接允许非树关系。

## 记忆钩子

每条线都要能读成一句带动词的命题——读不出来，就还不是概念图。
