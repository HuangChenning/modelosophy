# 康德拉季耶夫长波 Kondratiev Wave

## 这是什么

**主张存在约 40–60 年的技术—价格长周期；证据与机制仍争议。**

提出者/源流：Nikolai Kondratiev（1920s）；后有 Schumpeter 等诠释。长波论把重大技术群（蒸汽、铁路、电气、信息等）与投资浪潮、物价长周期联系起来。统计识别脆弱，宜作启发式情景，不作精密定时。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "「我们是不是在康波萧条/复苏」"
- "「技术革命是不是五六十年一轮」"

**不要**在以下情况套用本模型：

- 库存短周期 → kitchin-cycle
- 设备投资十年周期 → juglar-cycle

## 怎么用（执行步骤）

每一步给出可操作判据；禁止只换说法重复结论。

1. **降级为启发式。** 开场声明争议与识别难题。
2. **绑定技术群证据。** 列出主导技术、扩散曲线、资本开支——而非只看价格曲线拟合。
3. **分时间尺度。** 与朱格拉/基钦对照，避免混周期。
4. **情景而非点预测。** 给出多情景；禁止「某年必崩」神谕。

## 例证

**康波原初物价研究**：揭示长波主张源头。

**熊彼特式技术浪潮叙述**：揭示与创新群集的联想。

**拟合争议**：揭示数据按摩风险。

## 什么时候不适用（边界）

- **制度断裂（战争、货币制度）**：掩盖周期。
- **样本太短**：60 年波在两百年数据里自由度极低。

## 常见误用

- **精确择时**：金融营销滥用。
- **与库存周期混谈**：时间尺度错配。
