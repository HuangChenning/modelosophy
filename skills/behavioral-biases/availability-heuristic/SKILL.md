# 易得性启发 Availability Heuristic

## 这是什么

Tversky 与 Kahneman（1973）把易得性启发定义为：人用相关实例**被想起或构造出来的容易程度**，估计一类事件的频率或概率。常见的事件通常更易想起，所以这条捷径并不愚蠢；问题在于新近、生动、极端、反复报道或亲身经历也会提高易得性，却未必提高真实频率。

它回答的是“我为什么觉得这件事常见”，不是“我为什么只找支持自己观点的证据”。

## 什么时候用

- 最近连续看到几条新闻，就判断趋势已发生；
- 用身边两三个案例估计总体发生率；
- 因空难、犯罪、创业暴富等生动故事调整重大决策；
- 用户主动担心“是不是被个案带跑了”。

## 怎么用

1. **冻结第一直觉。** 先写下用户当前估计和最先浮现的 3 个例子，避免看到数据后改写记忆。
2. **识别易得来源。** 分别检查：最近发生、媒体重复、生动极端、个人关系、情绪强烈、搜索算法推送。说明“容易想起”的机制。
3. **定义分母。** 把模糊问题改成可计算事件：什么人群、什么地区、什么时间窗、什么结果。没有同一分母，案例数没有意义。
4. **找基准率。** 优先使用覆盖总体的数据、长期趋势和与问题同口径的频率；若没有数据，至少扩大样本并标注不确定性。
5. **比较直觉与基准率。** 不直接判直觉错：若二者一致，易得性可能提供了生态上有效的信号；若差异很大，指出是哪种曝光机制制造了偏差。
6. **只校正受污染的部分。** 新近报道影响认知，不等于风险为零；输出校准后的区间和还缺什么数据，不把“别被新闻吓到”变成反向轻视。

## 例证

**英文首字母 vs 第三个字母实验**：人更容易按首字母检索单词，因此高估“某字母出现在开头”的词数，即使它作为第三个字母实际更多。它揭示的是**检索操作本身**在替代频率判断。

**空难与慢性病**：空难画面集中、生动、会重复报道，慢性病死亡分散且没有单一新闻事件。人可能高估前者、低估后者。纠偏不是说空难不危险，而是让风险估计回到“每次出行/每十万人”的一致分母。

**个人网络里的裁员**：三位朋友被裁会显著提高“全行业都在裁”的感受；如果三人来自同一家公司或同一职位，样本高度相关。这个例子揭示易得性与样本独立性可以同时出错。

**（原书卡片）泰坦尼克**：卡片用“永不沉没”的宣传导致忽视危险作为例子，更接近过度自信或权威暗示，不是易得性的标准机制；除非说明反复宣传让“不会沉”这一判断更易提取，否则不要把它当核心例证。

## 什么时候不适用

- **可得性不是天然错误**：频繁发生的事本来更容易记住；没有更好数据时，它可能是合理捷径。
- **不要与代表性混淆**：按“像不像典型人物”判断职业概率，是代表性启发和基准率忽略，不是易得性。
- **不要与确认性偏差混淆**：按立场选择证据走确认性偏差；这里的筛选标准是记忆检索难度。
- **媒体曝光不必然造成高估**：需要比较实际频率，不能看到新闻就反向断言“只是媒体炒作”。
- **基准率口径不一致**：全球数据不能直接回答某地、某年龄段的风险。

## 常见误用

- **“别被新闻吓到＝风险为零”**：校正易得性污染 ≠ 否定真实尾部 → 用同口径基准率给区间，不反向轻视。
- **按“像不像典型人物”判概率却叫易得性**：那是代表性启发/基准率忽略 → 本条只处理“容易想起”替代频率。
- **按立场挑证据却贴易得性**：走确认性偏差；此处筛选标准是记忆检索难度。
- **分母不清仍堆案例**：全球/某地/某年龄混算 → 先定义人群、时间窗与结果，再比基准率。

## 相关模型

- **与[确认性偏差](../confirmation-bias/SKILL.md)**：已有信念决定搜什么，走确认性偏差；没有明确立场，只因案例容易浮现而高估频率，走本模型。
- **与[奥卡姆剃刀](../../cognitive-thinking-tools/occams-razor/SKILL.md)**：本模型校准候选原因的主观频率；奥卡姆剃刀再对已成形解释排序。
- **与[系统思维](../../systems-classic-effects/systems-thinking/SKILL.md)**：易得性容易让人盯住单次事件；系统思维要求看长期行为模式与反馈结构。
- **与[幸存者偏差](../survivorship-bias/SKILL.md)**：易得性管“好不好想起来”；「幸存者偏差」管“样本缺了谁”。常先补分母，再谈媒体曝光。
- **与[代表性启发](../representativeness-heuristic/SKILL.md)**：一个像不像，一个想不想得起。
- **与[模糊厌恶](../ambiguity-aversion/SKILL.md)**：熟悉域显得“不模糊”。
- **与[峰终法则](../peak-end-rule/SKILL.md)**：峰与终更易提取，可能被误判为“全过程都那样”。
