# 假设检验 Hypothesis Testing (Thinking)

## 这是什么

**假设检验（思维版）**：把主张写成明确假设 H，推导「若 H 为真，应观察到 O；若观察到 ¬O，则削弱/否定 H」，再收集对照证据。重点是**事前预测与可证伪性**，不是事后圆说。

本 Skill **不是**统计课的 t 检验操作手册；若需要正式显著性、功效与样本设计，应升级到统计专条（本仓库若无，则明示边界并给定性检验）。它回答的是认知问题：「我们怎样避免自欺？」

## 什么时候用

- "这个商业判断 / 产品想法怎么验证"
- "怎样设计证据，而不是找支持自己的例子"
- "什么结果出现我就认错"
- 直接说假设检验 / 可证伪 / 先假说后数据

**不要**当主模型：

- 评估一篇已写好论证的质量 → [`critical-thinking`](../critical-thinking/SKILL.md)
- 多个解释排简约优先级 → [`occams-razor`](../occams-razor/SKILL.md)
- 沿故障链找根因（尚未成检验设计）→ [`five-whys`](../five-whys/SKILL.md)（可先 5Why 提 H，再检验）
- 纯规范/审美争论（「应不应该」无经验内容）→ 先改写为经验主张或承认不可检

## 怎么用（执行步骤）

1. **写清假设 H（可检验句）。** 含主体、条件、预期方向。禁止空话（「品牌提升」→「未来 4 周，看过广告的队列注册率高于对照 ≥X%」）。
2. **写预测与否证条件。** 「若 H，应看到 O；若看到 ¬O 或相反模式，则 H 削弱」。判据：是否存在**你不愿意看到**但仍可能发生的结果？若没有，假说不可检。
3. **设计对照。** 基线、对照组、前后测、或自然实验。问：没有对照时，结果能否用季节、选择偏差、回归均值解释？能则加强对照。
4. **预先登记成功/失败标准。** 在看结果前写下阈值与停止规则，减少 HARKing（先看数据再改假说却假装事前）。
5. **执行、记录、更新信念。** 结果支持则仍保持可错态度；削弱则改 H 或放弃。新假说须重新走 1–4，禁止把旧预测改写成「其实我早指这个」。
6. **分离探索与确认。** 探索性分析可发散；确认性主张必须用预注册标准。两者切换时明示。

## 例证

**产品文案 A/B**：H「新文案提高点击」→ 随机分流、预定最小可觉差与窗口 → 若无提升则弃用。揭示：**事前标准**防止「差不多也算赢」。

**运营「活动有效」**：只晒活动周高销售额，无对照周与未触达队列——假设未检验，只是叙事。揭示：缺对照 = 不可认真更新信念。

**科学史直觉（一句）**：好假说敢于赌可观察风险；永远不会错的「假说」没有信息量。

## 什么时候不适用（边界）

- **不可观察/纯价值命题**：需先改写或换伦理/偏好框架。
- **高成本不可逆且无法试点**：用更弱的代理指标或阶段门，承认不确定性。
- **数据被污染或激励造假**：先修测量系统，再谈检验。
- **把 p 值神话化**：本 Skill 不授权「p<0.05 即真理」；效应量、偏倚、可重复更重要。

## 常见误用

- **事后编故事**：结果出来再改 H → 必须事前预测。
- **只找支持例**：确认性偏差 → 主动设计否证观察（可连 [`confirmation-bias`](../../behavioral-biases/confirmation-bias/SKILL.md)）。
- **与批判性思维抢戏**：用户丢来一篇报告说「帮我审」→ 批判性思维；用户说「怎么验证我的判断」→ 本模型。
- **一次相关当因果**：相关模式需额外设计（随机、工具变量、机制）才能支撑因果 H。

## 相关模型

- **与[批判性思维](../critical-thinking/SKILL.md)**：批判性思维审已有论证；本模型设计未来证据。用户说「这篇推理行不行」走批判；「怎样证明/证伪」走本模型。
- **与[奥卡姆剃刀](../occams-razor/SKILL.md)**：奥卡姆在竞争解释间排检验顺序；本模型规定每个解释如何赌观察。
- **与[确认性偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：检验设计显式对抗只搜集支持证据。
- **与[5Why](../five-whys/SKILL.md)**：5Why 生成根因候选 H；本模型负责验证。
- **与[第一性原理](../first-principles/SKILL.md)**：重建后的新路径必须当假设检验，无豁免权。

## 记忆钩子

先写下「怎样算我错了」，再去看世界——否则你只是在收集彩蛋。
