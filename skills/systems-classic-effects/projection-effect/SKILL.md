# 投射效应 Projection Effect

## 这是什么

**投射**：将自己的欲望、恐惧、价值观或解释习惯**未经检验地安到他人**身上，误以为“我怎么想，他也怎么想”。

精神分析有防御性投射传统；日常决策里更常见的是**朴素自我中心**：用自我模型当他人模型。结果是错误谈判、错误激励与错误产品假设。

## 什么时候用

- "我觉得好用，用户一定好用"
- "我讨厌 X，所以他提 X 是敌意"
- "按我的动机解释下属行为"

**不要**当主模型：
- 内外因解释结构 → [`attribution-theory`](../../behavioral-biases/attribution-theory/SKILL.md)
- 群体标签 → [`stereotyping`](../stereotyping/SKILL.md)
- 单特质美化整体 → [`halo-effect`](../halo-effect/SKILL.md)

## 怎么用（执行步骤）

1. **分离“我”与“他”。** 两列：我的偏好/恐惧 | 关于对方的主张——禁止混写。
2. **标投射嫌疑句。** 凡“他肯定…”“换作我就会…”且无对方数据的句子，贴红旗。
3. **要对方证据。** 原话、行为、选择、拒绝对方假设的数据；没有就设计一个低成本问题去问。
4. **生成对立假设。** 至少一条与投射相反的解释，强迫竞争。
5. **按对方目标改方案。** 激励、文案、谈判条件对齐对方证据，而非你的自我模型。

## 例证

**产品经理品味**：把自己爽点当用户爽点，上线后留存差。揭示**需求投射**。

**谈判**：以为对方最在意价格，实则在意交期。揭示**偏好投射**。

**冲突**：自己心虚故认定对方指责。揭示情绪投射。

## 什么时候不适用（边界）

- **有访谈/数据支撑的共情**：那是推断，不是投射。
- **角色身份重合**：两人约束几乎相同，可谨慎共用模型但仍要校验。
- **文学分析**：角色解读另论。

## 常见误用

- **把一切共情打成投射**：有证据的理解不是病。
- **与归因混用**：归因管内外因；投射管“用我替换你”。
- **道德化**：投射≠人格污点，是可纠的推理缺陷。

## 相关模型

- **与[归因理论](../../behavioral-biases/attribution-theory/SKILL.md)**：先分清在解释谁；再防把自我动机塞进对方。
- **与[刻板印象](../stereotyping/SKILL.md)**：刻板用群体；投射用自我。
- **与[乔哈里窗](../../thinking-models/johari-window/SKILL.md)**：扩大开放区可减少盲目投射。

## 记忆钩子

两列写出我与他——他那列没有证据就先去问。
