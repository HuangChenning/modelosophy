# 归因理论 Attribution Theory

## 这是什么

归因：人们如何解释“为什么发生了这件事”——常见落点是**内因**（能力、性格、意图、努力）或**外因**（任务难度、他人、规则、偶然）。Heider 指出日常推理像“朴素心理学家”；Kelley 的共变思路用三条线索校准：

- **一致性 consensus**：别人在同一情境是否也这样？
- **一贯性 consistency**：同一人跨时间是否总这样？
- **独特性 distinctiveness**：是否只在这一情境/对象上这样？

高一致 + 高独特 + 高一贯 → 更偏情境/刺激；低一致 + 低独特 + 高一贯 → 更偏 Disposition。这是**启发式**，不是法庭判决。

稳定偏差：

- **基本归因错误（FAE）**：解释他人行为时高估特质、低估情境；
- **行动者—观察者偏差**：解释自己时更易诉诸情境，解释他人时更易诉诸人格。

Weiner 等还把成就结果拆成可控/稳定等维度——本 skill 入门以**内外因 + 共变校准 + 偏差警示**为主，不一次包办动机心理学全书。

## 什么时候用

- 复盘“他是不是不行 / 是不是态度问题”；
- 绩效反馈、冲突叙事里人格攻击与情境因素纠缠；
- 用户直接说归因 / FAE / 情境归因 / attribution。

**不要**当主模型：
- 回溯自己从数据爬到信念的层级 → [`ladder-of-inference`](../../thinking-models/ladder-of-inference/SKILL.md)（若存在）或苏格拉底；
- 证据专找支持已有结论 → [`confirmation-bias`](../confirmation-bias/SKILL.md)；
- 单次行为会否发生 → [`fogg-behavior-model`](../../thinking-models/fogg-behavior-model/SKILL.md)。

## 怎么用（执行步骤）

1. **只写可观察行为与结果。** “迟到 20 分钟”“交付物缺测试报告”——禁止开场就写“不负责”“人品差”。
2. **列出候选归因，分列内/外。** 至少各一条，强迫对抗单一故事。
3. **过共变三问。** 别人同样情境也这样吗？此人历来如此吗？只在这个任务/对象上如此吗？按线索调整权重，标不确定度。
4. **检查偏差开关。** 若在评他人：是否忽略了约束、信息差、激励？若在评自己：是否过度外部化？把被忽略的情境因素补进清单。
5. **输出可检验含义，不做终审判词。** “若主要是任务不清（外），下一步是规格；若主要是技能缺口（内且可控），下一步是训练。”归因服务行动，不服务羞辱。

## 例证

**司机按喇叭**：观察者易判“没素质”；行动者可能正避险。揭示 **FAE / 行动者—观察者不对称**——同一行为，座位不同故事不同。

**新人连续写错工单**：低一致（老人不错）+ 高独特（只在该系统错）+ 尚无一贯史 → 先查文档/权限/培训（外），不宜首日定论“能力差”。揭示共变线索如何改处方。

**（原书卡片）你或他人 × 情境归因示意**：内外二分可用；局限是易励志化为“把失败归因努力就好”，忽略不可控外因与系统责任，且缺少共变操作步骤。

## 什么时候不适用（边界）

- **临床/病理标签**：不在此做人格障碍或精神诊断。
- **系统性问题**：激励、编制、故障架构导致的失败，用个人归因课会二次伤害。
- **道德卸责**：外因解释不能自动免除已知义务下的问责；分开“解释机制”与“责任制度”。
- **证据不足时强行定因**：输出应是假设排序，不是判决。

## 相关模型

- **与[确认偏差](../confirmation-bias/SKILL.md)**：确认偏差扭曲你收集的证据；归因管你把因果钉在人还是情境。
- **与[推论阶梯](../../thinking-models/ladder-of-inference/SKILL.md)**：阶梯管攀升路径；归因常嵌在“赋义→结论”段——可先下阶梯再做共变。
- **与[邓克效应](../dunning-kruger/SKILL.md)**：自评校准问题 ≠ 对他人行为的归因问题。
- **与[冰山模型](../../thinking-models/iceberg-model/SKILL.md)**：文化基本假设可解释“情境压力”，但冰山不替代共变检验。
