# 边际报酬递减 Diminishing Marginal Returns

## 这是什么

**其他投入固定时，再增加某一投入，产出增量终将下降。**

短期生产函数：固定要素（如厂房）约束下，可变要素（如劳动）的边际产量先可能升后降。这是短期成本上升的生产侧根源，区别于边际效用递减（消费）。古典经济学家已讨论土地上的报酬递减。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "加人为什么效率掉了"
- "边际报酬递减"
- "diminishing returns"
- "堆资源没效果"

**不要**在以下情况套用本模型：

- 与边际效用递减混用
- 在所有要素都可变的长期把「短期递减」当永恒诅咒

## 怎么用（执行步骤）

每一步给出可操作判据；禁止空转复述定义。

1. **声明固定要素。** 什么没变？场地、核心设备、管理带宽？没有固定要素就不要谈本定律。
2. **逐单位加可变投入并测边际产出。** 看增量；若连续下降，确认递减阶段。
3. **找瓶颈。** 递减常暴露固定要素瓶颈——对策是放松固定约束，而非只加可变投入。
4. **区分学习曲线。** 若组织在学习，短期曲线可能上移；不要把技术进步误读成「递减消失」。

## 例证

**一块地越来越多的农夫**：经典：土地固定，劳动边际产量下降。

**会议室塞进过多人**：沟通开销上升，决策边际产出下降——组织版。

## 什么时候不适用（边界）

- **规模报酬（长期）**：所有投入按比例变，是另一组概念。
- **强互补与网络跳变**：可能出现局部递增段。

## 常见误用

- **任何加投入都没用**：递减≠负——边际产量仍可为正。
- **用来反对一切投资**：长期可改变固定要素。

## 相关模型

- **与[边际效用递减](../diminishing-marginal-utility/SKILL.md)**：生产 vs 消费。
- **与[规模经济](../economies-of-scale/SKILL.md)**：长期平均成本形态，不是短期边际产量。
