# 因果回路图 Causal Loop Diagram

## 这是什么

**因果回路图（CLD）**：用变量节点与带极性的箭头（+ 同向 / − 反向）描述因果，识别**增强回路（R）**与**调节回路（B）**，并标注**延迟**。它是定性工具：澄清结构与故事，不自动给出数值预测。

## 什么时候用

- "帮我画增强/调节回路"
- "因果回路图 / CLD"
- 解释「为什么越管越乱 / 越努力越失衡」

**不要**当主模型：
- 要库存、流量、单位守恒 → [`stock-and-flow`](../stock-and-flow/SKILL.md)
- 已有故事只想对基模 → [`system-archetypes`](../system-archetypes/SKILL.md)
- 只要事件—模式—结构分层口头说 → 可先 [`iceberg-model`](../iceberg-model/SKILL.md) 再画

## 怎么用（执行步骤）

1. **列 5–12 个关键变量。** 用可增减的名词（库存、需求、缺陷率），避免动词句。判据：每个变量能说「变高/变低」。
2. **连因果并标极性。** A→B：A 增导致 B 增则为 +；导致 B 减则为 −。判据：每条箭头能用一句话说清机制。
3. **找闭合回路并标注 R/B。** 沿环数 − 号：偶数个 − ≈ 增强（R），奇数个 − ≈ 调节（B）（教学近似；复杂图需小心）。判据：至少标出 1 个主导回路。
4. **标延迟。** 在慢链路画 `||` 或注明「周/月」。判据：延迟处能解释震荡或「短期好长期坏」。
5. **讲一个连贯故事 + 干预点。** 指出当前政策强化了哪条回路；提出改极性/加回路/减延迟的候选。判据：干预对应图上具体边或节点。
6. **需要定量时升级。** 变量要守恒、要仿真 → 转 [`stock-and-flow`](../stock-and-flow/SKILL.md)。

## 例证

**质量债**：进度压力 →(+) 赶工 →(+) 缺陷 →(+) 返工 →(+) 进度压力（R），可再加调节：缺陷 →(+) 测试投入 →(−) 缺陷（B，常带延迟）。

**价格战雏形**：份额焦虑 →(+) 降价 →(+) 对手降价 →(+) 份额焦虑（R）。

**（原书卡片）**：若有，仅作示意；以极性与延迟规范为准。

## 什么时候不适用（边界）

- **相关性当因果**：无机制不连箭头。
- **变量爆炸**：先聚合成少量状态变量。
- **要精确预测**：升级存量流量/仿真。

## 常见误用

- **箭头无极性**：禁止。
- **把愿望当变量**：「成功」→ 拆成可观测指标。
- **与流程图混淆**：CLD 不是泳道流程。

## 相关模型

- **与[存量与流量](../stock-and-flow/SKILL.md)**：CLD 定性；S&F 定量守恒。常先 CLD 后 S&F。
- **与[系统基模](../system-archetypes/SKILL.md)**：画完再匹配基模；勿先贴标签。
- **与[反馈回路](../../systems-classic-effects/feedback-loops/SKILL.md)**：反馈回路是概念件；CLD 是完整画法规程。
- **与[系统动力学](../../systems-classic-effects/system-dynamics/SKILL.md)**：SD 含建模范式；本 skill 专攻 CLD 步骤。

## 记忆钩子

变量能升降，箭头有正负，回路标 R/B，延迟画出来。
