# 隐含前提 Implicit Premises

## 这是什么

多数日常论证是**省略三段论（enthymeme）**：表面上只给出部分前提和结论，但推理要成立，还必须依赖一条或多条**未写出的前提**。隐含前提（亦称 suppressed premise）就是这些被默认、被跳过、却在逻辑上托住结论的命题。

两件事不要混：

1. **逻辑角色**：补上它之后，从已给前提到结论的推理才闭合（或暴露本来就不闭合）；
2. **可接受性**：补出来的前提本身是事实、规范还是偏见——闭合了不等于可接受。

它是论证卫生工具：让“听起来顺”的跳跃变成可检验的命题。不是性格分析，也不是潜意识挖掘。

## 什么时候用

- 结论听起来像从已给理由“蹦”出来的，中间缺一跳；
- 广告、政策、会议决议、自我说服话里藏着未声明的价值判断；
- 用户直接说隐含前提 / 默认假设 / enthymeme / “这句话预设了什么”。

**不要**当主模型：
- 要对整个主张做压力测试、六类追问 → [`socratic-questioning`](../socratic-questioning/SKILL.md)；
- 证据搜寻只找支持己见 → [`confirmation-bias`](../../behavioral-biases/confirmation-bias/SKILL.md)；
- 要从硬约束重建方案 → [`first-principles`](../first-principles/SKILL.md)。

## 怎么用（执行步骤）

1. **写出表面论证。** 用两行：`已给前提：…` / `结论：…`。禁止还没写清结论就谈“本质”。
2. **问最小补全。** “还需要哪一句为真，推理才不跳跃？”列出**最短**的候选隐含前提（一条不够再加，勿一次堆十个动机故事）。
3. **分类每条前提。** 至少标：经验事实 / 因果机制 / 价值规范 / 定义约定。规范类常被伪装成事实。
4. **分别检验。** 对事实：证据是什么、反例是什么？对规范：谁同意、冲突时怎么办？任一失败，则原结论对你不再“理所当然”。
5. **决定处置。** 显式写入论证、修正结论、或放弃该推断。沟通场景可改成可观察描述（减少评价性隐含前提），但那是表达策略，不是把前提“变没”。

## 例证

**吸烟三段论缺腿**：“吸烟有害健康，所以你不该吸烟”——隐含规范是“不该做有害健康的事”（还常隐含程度阈值）。揭示的是**事实前提推不出规范结论**，除非补上价值前提。

**迟到对话**：说“你又迟到了”常夹带“迟到=不尊重/应受责”的评价前提；改成“约定 9:00，你 9:30 到”先固定可观察事实，评价前提被逼出水面。揭示隐含前提如何制造情绪对抗。

**产品口号**：“大家都在用 X，所以你也该用”——隐含从众规范或“多数=正确”。补全后可单独攻击。

**（原书卡片）BIC 与生活例子**：把沟通拉回行为—影响—后果、避免主观评价，方向可用；但 BIC 是沟通技法，不是隐含前提的定义。卡片收尾“透过迷雾看本质”过空，应以补全—分类—检验为准。

## 什么时候不适用（边界）

- **无论证可补**：单纯情绪表达、命令、审美偏好，没有“因→果”结构时，不要硬挖前提。
- **合作默认**：团队共享且已书面化的定义，可当作显式前提，不必每次表演式追问。
- **禁止读心**：未说出的恐惧、创伤、人格动机不是本模型对象；那是临床/咨询领域。
- **补全有不止一种**：多种隐含前提都能闭合推理时，要并列写出并说明争议点，不能只塞进对自己有利的那一条。

## 相关模型

- **与[苏格拉底式质疑](../socratic-questioning/SKILL.md)**：苏格拉底含“检验隐含假设”类追问；用户要的是整套证伪流程时走它。本模型只把缺的前提补全并分类。
- **与[确认偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：确认偏差管你搜什么证据；隐含前提管论证结构里缺了什么命题。
- **与[演绎法](../deductive-reasoning/SKILL.md)**：补全后常用三段论检验有效性；先补前提，再谈形式是否有效。
- **与[奥卡姆剃刀](../occams-razor/SKILL.md)**：候选隐含前提多条时，优先最短且非特设的那条，但仍须接受证据检验。
