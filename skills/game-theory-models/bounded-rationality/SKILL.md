# 有限理性与满意化 Bounded Rationality & Satisficing

## 这是什么

**认知与时间有限时，人不求全局最优，而求“足够好”的满意解。**

Simon：有限理性；满意化（satisficing）用抱负水平停止搜索。对照完全理性博弈解（纳什、倒推）的描述缺口——解释蜈蚣、旅行者等实验偏离。策略含义：简化规则、启发式、默认与菜单设计。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "有限理性"
- "满意化"
- "找不到最优就停"
- "西蒙"

**不要**在以下情况套用本模型：

- 要完全理性均衡基准 → ../nash-equilibrium/SKILL.md
- 损失厌恶/前景 → ../../behavioral-biases/prospect-theory/SKILL.md 或 loss-aversion
- 护城河/五力/长线思考 → 仍在 thinking-models，不迁入本分类

## 怎么用（执行步骤）

1. **声明约束。** 时间、信息、计算——哪里使得全局最优不可行。
2. **设抱负水平。** “够好”的可测阈值；达线即停。
3. **选搜索顺序。** 先查哪些选项；避免伪装成已穷尽。
4. **对照完全理性解。** 若需谈判/博弈，标出与纳什/倒推的差距作压力测试。输出：满意解 + 停止规则 + 风险。

## 例证

**工作搜索**：达保留工资即接受。揭示满意化。

**棋类限时**：用启发式非穷尽博弈树。揭示程序理性。

## 什么时候不适用（边界）

- **抱负乱标定**：过低自满、过高瘫痪。
- **被操纵菜单**：满意化易停在默认。

## 常见误用

- **用有限理性当懒惰借口**：仍需显式停止规则。
- **否定所有均衡分析**：完全理性仍是有用基准。

## 相关模型

- **与[蜈蚣博弈](../centipede-game/SKILL.md)**：行为偏离倒推的场景。
- **与[博弈论（入门）](../game-theory/SKILL.md)**：完全理性建模入口。
- **与[预期价值](../../decision-probability/expected-value/SKILL.md)**：能算期望时仍可用；算不动再满意化。
- **与[最后通牒博弈](../ultimatum-game/SKILL.md)**：程序理性另一路。
