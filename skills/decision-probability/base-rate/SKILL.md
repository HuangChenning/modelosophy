# 基率思维 Base Rate

## 这是什么

**基率（base rate）**：在同类参考类中，目标结果出现的**无条件频率或先验比例**。基率思维要求：先回答「像这样的事，历史上通常怎样？」，再决定个案线索能把判断挪多远。

它针对的经典失败是**基率忽视（base-rate neglect）**：人被生动个案、代表性故事带走，忘记母体频率（Kahneman & Tversky）。参考类预测（reference class forecasting）是其工程化版本：用外部可比项目分布校准时间/成本/成功率。

## 什么时候用

- "这类创业/并购/IT 项目一般成功率多少"
- "别被这个故事说服，先看大数"
- "基率 / 参考类 / outside view"
- 计划工期、预算、命中率、疾病/违约等需母体频率的判断

**不要**当主模型：

- 已有清晰新证据要做完整后验合成 → [`bayesian-updating`](../bayesian-updating/SKILL.md)
- 用户在描述「计划总是低估工期」的机制 → [`planning-fallacy`](../planning-fallacy/SKILL.md)（常连用本模型纠偏）
- 纯策略互动、无频率母体 → 博弈类 Skill

## 怎么用（执行步骤）

1. **定义目标结果。** 写清要预测的事件（如「12 个月内上线且不超预算 20%」），禁止模糊「会成功」。
2. **选定参考类并证明可比。** 列出纳入/排除规则（行业、规模、阶段、地区、时代）。判据：至少能说出 5–20 个可比点或一个已发表分布；说不出则标注「参考类弱」。
3. **取出基率（分布，不只均值）。** 成功率、P50/P80 工期、成本超支分位数。优先外部数据，其次内部历史。
4. **列出个案线索，并限制调整幅度。** 每条线索问：它是否已在参考类里平均体现？若是，少调或不调。禁止「感觉特别」就把 10% 基率改成 80%。
5. **输出校准后的预测 + 置信。** 给区间；写「若参考类换为 X，基率变为…」的敏感性。
6. **与行动挂钩。** 若基率很差，默认策略是缩小赌注、买信息或换参考类验证——不是靠叙事抬概率。

## 例证

**出租车问题（经典）**：城市 85% 绿车、15% 蓝车；目击「蓝」且可靠度 80%。忽视基率会高估蓝车概率；正确后验约 41% 量级。揭示：**诊断性证据仍须乘基率**。

**大项目成本**：地铁/IT 大改造的外部视图常显示系统性超支；内部视图「这次我们更懂」反复失败（Flyvbjerg）。揭示：参考类分布比单次乐观计划更可信。

**招聘「明星履历」**：某校某司背景在母体中绩效分布若只中等偏上，个案光环不能直接等同顶尖。揭示：代表性启发式 ≠ 基率。

## 什么时候不适用（边界）

- **参考类崩溃**：技术/制度突变使历史失效 → 缩小权重，改情景或实验。
- **唯一事件、无可比**：强行编「行业平均」有害 → 承认深度不确定。
- **基率本身被操纵**：统计口径粉饰 → 先审计数据生成过程。

## 常见误用

- **拿错参考类**：用消费 App 成功率估硬科技 → 重选类。
- **用基率取消学习**：有强似然仍死抱旧频率 → 转 [`bayesian-updating`](../bayesian-updating/SKILL.md)。
- **只报均值**：忽略厚尾超支 → 至少给 P80。
- **与期望值混淆**：基率是 \(p\) 的来源之一；EV 是用 \(p\) 算结果。

## 相关模型

- **与[贝叶斯更新](../bayesian-updating/SKILL.md)**：基率≈先验；个案证据经似然并入。分流见上。
- **与[计划谬误](../planning-fallacy/SKILL.md)**：计划谬误描述 internally 乐观；纠偏常靠本模型的 outside view。
- **与[代表性启发式](../../behavioral-biases/representativeness-heuristic/SKILL.md)**：故事「像不像」替代频率时，用本模型拉回母体。
- **与[小数定律](../../behavioral-biases/law-of-small-numbers/SKILL.md)**：小样本波动被当成稳定基率 → 先扩样本/扩区间。
- **与[幸存者偏差](../../behavioral-biases/survivorship-bias/SKILL.md)**：可见成功案例会扭曲参考类 → 补失败与未上市样本。

## 记忆钩子

先问「**这类**通常怎样」，再问「**这个**有多特殊」——特殊要付证明税。
