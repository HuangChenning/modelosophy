# 泰勒规则 Taylor Rule

## 这是什么

**按通胀偏离目标与产出缺口系统设定政策利率的基准规则。**

提出者/源流：John Taylor（1993）。i = r* + π + a(π−π*) + b(y−y*)。通胀高于目标或产出过热→加息。提供透明基准，实际央行可偏离但需解释。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "「按泰勒规则现在利率该在哪」"
- "「央行是不是落后于曲线」"

**不要**在以下情况套用本模型：

- 财政乘数主场
- 无利率主权的货币局硬套

## 怎么用（执行步骤）

每一步给出可操作判据；禁止只换说法重复结论。

1. **取参数与缺口测度。** r*、π*、产出缺口方法——全部声明敏感度。
2. **算基准利率。** 给出区间（不同缺口估计）。
3. **对比实际政策利率。** 偏离方向：偏松/偏紧。
4. **解释偏离或建议路径。** 金融稳定、供给冲击、ZLB——写明为何偏离；ZLB 则谈前瞻指引/QE 边界。

## 例证

**Taylor 1993 美联储描述**：揭示规则可拟合历史。

**2010s 低 r* 争论**：揭示自然利率下移使规则下移。

**高通胀期「落后曲线」批评**：揭示规则作问责基准。

## 什么时候不适用（边界）

- **零利率下限**：公式给出负值时改工具。
- **金融稳定目标**：单一通胀—产出规则不够。

## 常见误用

- **唯一正确利率**：参数争论巨大。
- **忽略缺口测量误差**：假精确。

- **与[菲利普斯曲线](../phillips-curve/SKILL.md)**：通胀—闲置资源权衡进入规则。

- **与[不可能三角](../impossible-trinity/SKILL.md)**：无货币独立则无泰勒空间。
