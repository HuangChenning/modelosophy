# 溯因推理 Abductive Reasoning

## 这是什么

溯因（Peirce；今常称 **inference to the best explanation, IBE**）：面对观察 *O*（尤其是惊讶事实），提出假设 *H*，使得“若 *H* 为真，则 *O* 自然可理解”；在候选中选**当前最佳解释**，再交付检验。结论**可错**，不是必然真。

三分对照：

| 形态 | 问题 | 结论地位 |
|---|---|---|
| 演绎 [`deductive-reasoning`](../deductive-reasoning/SKILL.md) | 前提已给，是否必然推出？ | 有效则保真传递 |
| 归纳 | 样本能否概括总体？ | 或然，依赖样本与偏差 |
| **溯因（本模型）** | 什么假设最能解释观察？ | 最佳仍可假，必须可测 |

与[`occams-razor`](../../cognitive-thinking-tools/occams-razor/SKILL.md)：奥卡姆在**解释已经列出**时排验证优先级（少特设、可证伪）；溯因负责**生成候选 + 解释力比较**。常连用：先溯因出表，再用奥卡姆排序去查。

## 什么时候用

- 故障、诊断、调研：现象在，原因不明；
- 需要“先给最像的故事，再设计证伪”；
- 用户直接说溯因 / 最佳解释 / abduction / IBE。

**不要**当主模型：
- “是否必然推出” → [`deductive-reasoning`](../deductive-reasoning/SKILL.md)；
- “多个已有解释先查哪个”可主走 [`occams-razor`](../../cognitive-thinking-tools/occams-razor/SKILL.md)；
- 只补论证缺腿前提 → [`implicit-premises`](../implicit-premises/SKILL.md)。

## 怎么用（执行步骤）

1. **写清观察 O，区分事实与解读。** “服务 14:02 错误率升至 12%”是 O；“肯定是黑客”是解读，后者降为候选 H。
2. **发散至少两个互竞假设。** 强迫第二故事，对抗第一印象阴谋论。
3. **比解释力。** 哪个 H 覆盖更多关键细节？哪个对未解释残差更少？哪个做出**新的可检验预测**？
4. **标先验与代价。** 结合基础概率；高代价领域（安全、医疗、法律）提高举证条，不把“听起来妙”当结案。
5. **输出：最佳候选 + 否证实验 + 开放其余。** 明示“待验”。简单解释被否后转向复杂，不为真爱假说打特设补丁（此处接奥卡姆）。

## 例证

**庭院湿了**：可能下雨、洒水喷头、邻居恶作剧。选“昨晚有雨且地面普遍湿”为当前最佳，并预测雨量计/他处地面——揭示溯因是**可修正的解释竞赛**，不是定论。

**线上故障**：同时发版与流量高峰。最佳解释须预测：回滚是否恢复、是否仅新版本路径出错。揭示要用**区分性预测**，不能停在叙事。

**（原书卡片）与演绎/归纳公式对照**：三分教学有价值；局限是易把侦探假设链误标为演绎（batch-7-A 已批）。本 skill 明确：观察→假设属溯因段。

## 什么时候不适用（边界）

- **已是纯形式推演**：前提结论明确时走演绎，不硬溯因。
- **停在故事**：安全/医疗等禁止未检验就行动于不可逆伤害。
- **阴谋论特设堆砌**：解释力靠无限补丁 → 用奥卡姆降权并要求独立证据。
- **价值选择**：规范“应该怎样”不是溯因能单独决定的。

## 常见误用

- **把"听起来说得通"当"最佳解释"**：只生成一个故事就停下，没有强迫自己想第二个互竞假设，靠叙事流畅度而非解释力做判断 → 回到步骤2，至少发散两个假设再比较。
- **借演绎口吻抬高确定性**：把"观察→假设→验证"的推理链说成"这是演绎推出来的"，用演绎的必然性光环掩盖溯因结论本身可错的性质 → 明确标注"待验"，不借用演绎措辞。
- **只看故事精彩程度，不看先验概率**：因为解释足够戏剧化（阴谋论式）就采信，跳过对基础概率和举证代价的核算 → 走步骤4，高代价领域必须补先验与代价。
- **把当前最佳解释当结案陈词**：诊断/故障场景锁定第一个"最像"的原因就直接动手修复，不设计任何区分性验证 → 走步骤5，必须输出否证实验。

## 相关模型

- **与[演绎法](../deductive-reasoning/SKILL.md)**：演绎保真传递；溯因生成可错最佳解释。
- **与[奥卡姆剃刀](../../cognitive-thinking-tools/occams-razor/SKILL.md)**：奥卡姆排序已有解释；溯因先产表再可比。
- **与[第一性原理](../../cognitive-thinking-tools/first-principles/SKILL.md)**：第一性从硬约束重建方案；溯因解释已发生现象。
- **与[苏格拉底式质疑](../socratic-questioning/SKILL.md)**：可追问“最佳”的判据是否偷换；不替代假设生成。
