# 期望值 Expected Value（费马–帕斯卡）

## 这是什么

1654 年前后，费马与帕斯卡通信解决**点数问题（problem of points）**：一场未完成的公平赌局，如何按当前比分公平分配奖池。关键洞见不是“猜谁会赢”，而是：把尚未打完的可能结局列全（或用组合等价计数），用**概率加权**应得份额——这是古典概率与**期望值**思想的起源之一。

现代写法：若互斥结果价值为 \(x_i\)、概率为 \(p_i\)（\(\sum p_i = 1\)），则

\[
\mathrm{EV} = \sum_i p_i\, x_i
\]

它把“命运不可知”改写成**可计算的不确定**：不是消除随机，而是给行动一个可比较的标量（在风险中性、且无破产约束的前提下）。

**本模型不是决策树**：决策树处理多阶段*决策节点*与*机会节点*的折叠、以及买信息是否值得；本模型处理**已经摆在桌上的结果集**——一次赌局、一次保单、一次抽奖、一次按比分切蛋糕——算清 \(p\) 与 EV，并校准概率来源。

## 什么时候用

- 要公平分配未完成随机过程的权益（点数问题类）；
- 单次或重复同分布赌局：保险、抽奖、简单投资赔率，问“期望上划不划算”；
- 需要显式写出 \(p\) 与 \(x\)，并做粗敏感性（\(p\) 动一点 EV 是否变号）；
- 用户提期望值 / EV / 费马帕斯卡 / 点数问题。

**不要**当主模型：
- “先试点再全面上线”、多阶段选项树、信息价值上限 → [`decision-tree`](../decision-tree/SKILL.md)；
- 深度不确定、重点防归零 → [`antifragility`](../antifragility/SKILL.md)；
- 结果基本确定、只比放弃项 → [`opportunity-cost`](../../econ-micro-markets/opportunity-cost/SKILL.md)。

## 怎么用（执行步骤）

1. **写清行动与结果表。** 列出互斥结局及每个结局的净价值 \(x_i\)（含成本、奖金、损失）。同一机会下概率之和必须为 1。
2. **给每个 \(p_i\) 标来源。** 历史频率、物理对称（公平硬币）、模型推导、或主观信念——分开写。信念概率要写区间，禁止伪造三位小数精确感。
3. **算 EV，并与现状/代价比较。** 例如：买彩票的 EV 对票价；保险的 EV 对保费（再单独讨论风险厌恶与流动性，见边界）。
4. **敏感性与改主意条件。** 问：\(p\) 或 \(x\) 挪到哪条线，结论翻转？写下来，避免事后改口。
5. **检查破产与效用。** 若最坏结局会让决策者出局或不可逆残废，**停止用正 EV 辩护**；改用暴露上限、保险或反脆弱结构。金额效用非线性时，报告期望*效用*而非只报金额 EV。

### 点数问题速算（公平局）

A、B 先到 \(n\) 胜者得奖池；中断时 A 再需 \(a\) 胜、B 再需 \(b\) 胜。最多再打 \(a+b-1\) 局。费马：枚举（或组合计数）这 \(a+b-1\) 局里 A 先凑满 \(a\) 胜的比例，即为 A 应得概率份额。经典例子：先到 3 胜，中断于 2:1 → A 再需 1、B 再需 2 → 最多 2 局，结局 AA/AB/BA/BB 等可能，A 胜概率 \(3/4\)。

## 例证

**点数问题（历史原点）**：未完成赌局按剩余胜场的组合份额分配，而不是“谁领先谁拿走”或“平分不管比分”。揭示期望值的正义来自**对未来可能性的公平加权**，不是对过去付出的补偿（后者滑向沉没成本）。

**保险的粗账**：小概率大损失 × 概率，与确定保费比较；风险厌恶者可买负 EV 的保单换取尾部保护。揭示 EV 是基准线，**不是**唯一决策准则。

**彩票 / 抽奖**：把头奖、固定奖、未中的概率与奖金写入表，算 EV；多数公彩 EV ≪ 票价。揭示“梦想叙事”与概率加权结果的裂缝——原书只算组合数不够，必须落到对票价的 EV。

**蒙提霍尔（概率更新例，不作谜题合集）**：初始选对门 \(1/3\)；主持人揭示一只羊后，换门胜率 \(2/3\)。这里练的是**信息到达后重写 \(p\)**，再谈是否换门；不要停在反直觉故事，也不要借题发挥成决策树教程。

**（原书卡片）蒙提霍尔 + 双色球排列组合 + 金句“从不可知到不确定”**：组合计算可用；但卡片几乎不落到“EV 相对代价如何决策”，且易与决策树、谜题秀混淆。芒格“格栅”引言是动机不是算法。使用时补上 EV 表与破产检查。

## 什么时候不适用（边界）

- **需要顺序决策与信息价值**：用决策树；本模型可给树的叶子提供 EV，但不负责画树。
- **概率无法校准**：EV 只是把偏见算得更整齐；先扩大区间或买信息。
- **归零 / 破产风险**：正 EV 不能为梭哈辩护。
- **频率与信念未标注就混加**：例如把“历史违约率”和“我觉得这次没事”直接相乘——必须分列。
- **效用强非线性或多元目标**：单标量 EV 不够；需效用或多属性框架。

## 相关模型

- **与[决策树](../decision-tree/SKILL.md)**：**硬区分。** 用户说画树 / 先试点再上 / 信息值多少钱 → 决策树。用户说这笔静态不确定结果的期望 / 点数公平切 / 彩票 EV → 本模型。
- **与[反脆弱](../antifragility/SKILL.md)**：能估 \(p\) 且无出局约束时用 EV；深度不确定或要有意保留凸性时用反脆弱。
- **与[沉没成本](../../behavioral-biases/sunk-cost/SKILL.md)**：点数问题按*未来*可能性分配，不按已投入局数；已花成本不进入 \(x_i\) 除非仍改变未来现金流。
- **与[前景理论](../../behavioral-biases/prospect-theory/SKILL.md)**：前景理论描述人对概率与损益的扭曲；本模型给规范基准，可对照“行为权重 vs 客观 \(p\)”。
