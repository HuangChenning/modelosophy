# 菲利普斯曲线 Phillips Curve

## 这是什么

**短期通胀与失业常呈权衡；长期可能垂直于自然失业率。**

提出者/源流：A. W. Phillips（1958 经验关系）；后经预期扩展（Friedman/Phelps）。需求旺盛时失业↓、工资物价↑。一旦通胀预期上移，短期曲线整体移动，长期无永久「高通胀换低失业」免费午餐。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "「要压通胀是不是必须忍受高失业」"
- "「失业这么低为啥通胀还没起来」"

**不要**在以下情况套用本模型：

- 平坦化争论中假装曲线永远稳定可交易
- 奥肯定律的增长—失业经验律单独使用时走 okuns-law

## 怎么用（执行步骤）

每一步给出可操作判据；禁止只换说法重复结论。

1. **分短期/长期。** 是否假设预期固定？若预期已变，勿用旧斜率。
2. **鉴别需求驱动还是供给冲击。** 油价/食品/供应链：曲线移动，不是沿曲线滑动。
3. **估缺口。** 失业相对自然率/U*；产出缺口。缺口为负且通胀升 → 沿曲线叙事弱。
4. **给政策权衡表。** 紧缩：通胀↓失业↑的预期路径；或等待供给修复。写明不确定性。

## 例证

**1958 英国工资—失业散点**：揭示经验规律起源。

**1970s 滞胀**：揭示预期与供给冲击使简单权衡崩溃。

**2010s「平坦菲利普斯」争论**：揭示全球化、锚定预期、测量问题使斜率变小。

## 什么时候不适用（边界）

- **锚定良好的通胀预期**：短期斜率可变平坦。
- **劳动力市场制度差异**：国别不可直接抄斜率。

## 常见误用

- **永久权衡幻觉**：以为可永远用通胀买就业。
- **忽略构成**：核心 vs 食品能源不分。

## 相关模型

- **与[货币主义](../monetarism/SKILL.md)**：自然率与长期垂直曲线。
- **与[理性预期](../rational-expectations/SKILL.md)**：预期内生化改变曲线。
- **与[泰勒规则](../taylor-rule/SKILL.md)**：按通胀与产出缺口设利率，隐含菲利普斯权衡。
- **与[奥肯定律](../okuns-law/SKILL.md)**：增长与失业；本模型是通胀与失业。

## 记忆钩子

短期像跷跷板；预期一变，板子会搬家。
