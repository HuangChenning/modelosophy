# 看不见的手 Invisible Hand

## 这是什么

**分散决策在价格信号下可自发协调资源配置，无需中央指挥官。**

提出者/源流：Adam Smith（1776《国富论》隐喻；后世新古典化）。个人追求自身利益时，价格把稀缺信息传给买卖双方，引导资源流向愿付最高价（边际）用途。斯密用「看不见的手」描述的是协调结果，不是保证公平或零外部性。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "「让市场自己调，政府别插手」"
- "「价格涨了自然会有人增产」"
- "「去中心化怎么能协调这么多人」"

**不要**在以下情况套用本模型：

- 把市场失灵当「看不见的手失败」一刀切——先分清是信息/外部性/公共品问题，再谈干预工具
- 个人/企业微观定价战术 → 走供需与价格歧视等微观技能，不走本宏观隐喻

## 怎么用（执行步骤）

每一步给出可操作判据；禁止只换说法重复结论。

1. **钉住协调问题。** 写清：谁与谁在交换什么？信息是否主要通过价格/数量传递？若主要靠行政配额，本模型不适用。
2. **检验价格是否可承载信息。** 问：价格能否自由变动？是否被冻结、补贴扭曲、或被垄断操纵？任一项「是」→ 标注「手被绑住」，勿宣称自发最优。
3. **扫三类经典失灵。** 逐项勾选：外部性（未计价副作用）、公共品（非排他非竞争）、信息不对称/市场势力。有勾则列出补位机制（产权、税收、规制、公供），而非空喊「相信市场」。
4. **输出可执行结论。** 给出：可依赖价格协调的部分 / 必须制度补位的部分 / 仍缺的事实。禁止把「看不见的手」写成道德口号。

## 例证

**斯密的屠夫面包师隐喻**：揭示的是**分散动机 + 交换**可服务他人，不是主张零监管。现代读法应区分「协调机制」与「分配正义」。

**碳价与排污权**：污染是典型外部性；看不见的手不会自动内化碳成本，需碳税/配额把价格「接上」。揭示**失灵时要给手装传感器**。

**战时配给 vs 和平市场**：极端短缺时配给优先保障基本需求；和平常态下价格更能揭示稀缺。揭示模型有**制度与危机边界**。

## 什么时候不适用（边界）

- **严重市场失灵**：外部性、公共品、自然垄断下「自发」可能系统损害旁人——改谈产权/税制/规制。
- **分配与尊严目标**：本模型管配置效率叙事，不管「谁应得多少」；公平议题需另框架。

## 常见误用

- **把隐喻当证明**：「斯密都说了市场万能」→ 斯密未主张零政府；回到失灵清单。
- **忽略价格被绑**：管制价下仍说「市场会解决」→ 先恢复或承认非价格配给。

## 相关模型

- **与[凯恩斯主义](../keynesianism/SKILL.md)**：需求塌陷、流动性陷阱时价格/工资粘性使自发恢复慢 → 凯恩斯主义；常态价格协调 → 本模型。
- **与[奥地利学派](../austrian-school/SKILL.md)**：都强调自发秩序；奥派更系统反对干预，本模型只作协调隐喻且承认失灵。
- **与[机会成本](../../econ-micro-markets/opportunity-cost/SKILL.md)**：价格协调背后是边际上的机会成本比较；单笔个人决策算代价走机会成本。

## 记忆钩子

价格是信号灯；灯坏了别怪司机不会开。
