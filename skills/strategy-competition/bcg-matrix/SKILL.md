# BCG 矩阵 BCG Matrix

## 这是什么

**BCG 矩阵**：以**市场增长率**（高/低）与**相对市场份额**（高/低）把业务单元放入四象限——明星（高增长高份额）、现金牛（低增长高份额）、问题儿童（高增长低份额）、瘦狗（低增长低份额）——并据此讨论投资、收割或退出。

它是**粗糙的组合启发式**，依赖你对「市场」边界与份额数据的定义；不是估值模型。

## 什么时候用

- "多条产品线，钱往哪投、哪条该砍"
- "BCG / 现金牛 / 明星 / 瘦狗"
- 公司组合战略讨论早期

**不要**当主模型：

- 目标-关键结果对齐 → [`okr`](../okr/SKILL.md)
- 资源是否有价值稀缺难模仿组织支持 → [`vrio`](../vrio/SKILL.md)
- 单业务竞争结构 → [`porters-five-forces`](../porters-five-forces/SKILL.md)

## 怎么用（执行步骤）

1. **定义业务单元与「市场」。** 市场边界写清（否则份额无意义）。判据：单元是否有独立客户/损益。
2. **估增长率与相对份额。** 用可引用数据；不确定则标置信度，禁止假精确到小数。
3. **落入四象限并写默认策略假设。** 明星：投资维持；现金牛：收割输血；问题：选择性加注或放弃；瘦狗：退出或极小维持。
4. **压力测定义敏感度。** 若市场定义一变象限就跳，先争论边界，不争论投资。
5. **连到现金流与能力。** 现金牛是否真有现金？明星是否吸金无上限？补财务约束。
6. **产出组合动作清单。** 每单元一个动作+复盘指标；避免「全是明星」的自欺。

## 例证

**多品类消费品公司**：成熟大单品现金牛输血新品——揭示组合输血逻辑。

**创业公司误用**：只有一条业务还硬套四象限——揭示工具适用规模。

**（局限）**：份额≠利润；数字经济「市场」难画；被批评过度简化。

## 什么时候不适用（边界）

- **单一业务或早期探索**：用实验度量，不硬贴瘦狗。
- **数据不可得**：先取近似区间或改用定性组合讨论。
- **平台生态交叉补贴复杂**：矩阵太糙，需补充网络/飞轮视角。

## 常见误用

- **份额崇拜**：高份额低利润仍当现金牛 → 加利润检验。
- **永不淘汰瘦狗**：情感留存 → 设退出门槛。
- **与第二曲线对立**：问题业务可能是第二曲线候选，需另判。
- **假精确**：增长率差 0.1% 就换格 → 用区间。

## 相关模型

- **与[第二曲线](../second-curve/SKILL.md)**：BCG 看组合位置；第二曲线看切换时机。问题/明星常与第二曲线候选重叠，需显式讨论。
- **与[OKR](../okr/SKILL.md)**：组合决策后，用 OKR 对齐执行目标。
- **与[飞轮](../flywheel/SKILL.md)**：跨业务协同时矩阵不够，补飞轮。
- **与[SWOT](../swot/SKILL.md)**：单业务态势用 SWOT；组合用 BCG。
- **与[护城河](../economic-moat/SKILL.md)**：高份额是否可持续要用护城河检验。

## 记忆钩子

组合启发式：**增长×份额**四格——先问市场边界是否站得住，再谈投或砍。
