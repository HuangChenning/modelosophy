# 演化博弈与 ESS Evolutionary Stable Strategy

## 这是什么

**种群中若被少数突变策略入侵仍能恢复的策略（或策略组合）称 ESS。**

Maynard Smith：不依赖理性最优，而依赖复制动态与适应性。ESS 是演化稳定；与纳什相关但不完全等同。用于惯例、攻击性、合作规范的长期稳定性。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "演化稳定策略"
- "这种规范能不能抗住投机者"
- "ESS"

**不要**在以下情况套用本模型：

- 一次性理性最佳回应 → ../nash-equilibrium/SKILL.md
- 鹰鸽具体支付故事 → ../hawk-dove/SKILL.md
- 西蒙满意化 → ../bounded-rationality/SKILL.md

## 怎么用（执行步骤）

1. **定义种群策略与适应度。** 支付=繁殖/模仿成功率。
2. **做入侵思维实验。** 若 1% 突变策略进入，平均适应度谁高？突变更高则非 ESS。
3. **区分纳什与 ESS。** 某些纳什可被入侵；标注需要更强稳定。
4. **输出。** 候选策略是否 ESS + 何种突变最危险。

## 例证

**鹰鸽混策略 ESS**：一定频率的鹰在 C>V 时稳定。揭示比例而非人人同策。

**合作规范**：无惩罚的利他易被入侵；有惩罚或亲缘结构可稳。

## 什么时候不适用（边界）

- **理性主体组织**：公司董事会不全是复制动态——别滥用生物隐喻。
- **多重 ESS**：历史路径决定落在哪。

## 常见误用

- **把 ESS 当道德正确**：稳定≠正义。
- **与纳什混用无差别**：要做入侵检验。
