# 内稳态 Homeostasis

## 这是什么

**内稳态（稳态）**：系统通过**负反馈**把关键变量维持在设定点（或可接受带）附近。构件：传感器 → 与设定点比较 → 效应器纠偏。生物体温、血糖；工程恒温；组织里的 SLA、库存带、文化规范执法，皆可作稳态回路。

稳态 ≠ 静止：是**动态调节下的相对稳定**。

## 什么时候用

- "如何保持指标在目标附近"
- "内稳态 / 设定点 / 恒温式管理"
- 服务质量、安全水位、个人习惯维持

**不要**当主模型：
- 要分析正反馈狂奔 → [`feedback-loops`](../../systems-classic-effects/feedback-loops/SKILL.md)
- 多盆/回滞 → [`multistability`](../multistability/SKILL.md)
- 延迟导致振荡 → [`delay-feedback`](../delay-feedback/SKILL.md)
- 必须战略转型换设定点 → 战略类模型

## 怎么用（执行步骤）

1. **选受控变量与设定点。** 可测；设定点或带宽写清。
2. **找传感器。** 谁以什么频率读数？盲区在哪？
3. **找效应器与极性。** 偏高时做什么、偏低时做什么；确认是负反馈。
4. **标延迟与增益。** 过慢/过猛 → 振荡（转延迟反馈）。
5. **设可承受带与告警。** 带内不折腾；出带分级响应。
6. **定期审设定点。** 环境变了要改目标，而非加强错误稳态。

## 例证

**体温调节**：出汗/寒战。揭示：传感+效应器完整。

**错误预算 / SLO**：过误差触发减载或修系统。揭示：组织稳态要有明确效应器，不单看板。

**（原书卡片）**：勿把「别变」当稳态；稳态是调节。

## 什么时候不适用（边界）

- **设定点本身有害**：成瘾式稳态、毒性文化——要迁盆/破锁定。
- **开环无传感**：先装仪表。
- **探索/创新阶段需要离开带**：用混沌边缘配额，勿伪稳态。

## 常见误用

- **稳态 = 拒绝变化**：设定点可更新。
- **只有 KPI 无效应器**：不是完整稳态。
- **与多稳态混用**：多盆是多个可维持设定；本模型默认守一个。

## 相关模型

- **与[反馈回路](../../systems-classic-effects/feedback-loops/SKILL.md)**：稳态是调节回路的应用形态。
- **与[延迟反馈](../delay-feedback/SKILL.md)**：稳态振荡常因延迟/增益。
- **与[多稳态](../multistability/SKILL.md)**：多盆 vs 单设定点。
- **与[必要多样性](../requisite-variety/SKILL.md)**：扰动种类多时，调节器也需足够多样。

## 记忆钩子

有传感、有设定、有纠偏——缺一块就只是「希望稳定」。
