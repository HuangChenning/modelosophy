# 乘数效应 Multiplier Effect

## 这是什么

**一笔自主支出可通过收入—消费链条放大为更大产出变动。**

提出者/源流：Keynes/Kahn 传统；财政乘数经验研究持续至今。边际消费倾向（MPC）越高、漏出（储蓄、税收、进口）越少，乘数越大。经济萧条、利率受控、货币被动配合时财政乘数往往更大。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "「政府花 1 块能带动几块 GDP」"
- "「为啥萧条时刺激更值」"

**不要**在以下情况套用本模型：

- 把金融杠杆当财政乘数
- 长期增长核算 → 索洛

## 怎么用（执行步骤）

每一步给出可操作判据；禁止只换说法重复结论。

1. **识别自主冲击。** ΔG、投资自主变化、净出口冲击等。
2. **列漏出渠道。** 储蓄、税、进口——估计 MPC 与边际进口倾向。
3. **情境化乘数大小。** 衰退/流动性陷阱 → 乘数偏大；接近产能 → 偏小甚至变物价。
4. **给出区间与挤出折扣。** 与挤出效应对账后报净效应。

## 例证

**Kahn/Keynes 乘数直觉**：揭示收入流转放大。

**大衰退期财政乘数研究**：揭示状态依存：萧条乘数更大。

**高开放度小国**：揭示进口漏出使乘数变小。

## 什么时候不适用（边界）

- **充分就业**：再支出变通胀。
- **李嘉图等价强成立**：私人储蓄对冲，乘数≈0。

## 常见误用

- **广告式夸大**：政治稿用最大乘数当基准。
- **混淆支出类型**：挖坑填坑与生产性投资乘数不同。

## 相关模型

- **与[凯恩斯主义](../keynesianism/SKILL.md)**：乘数是凯派刺激定量核心。
- **与[挤出效应](../crowding-out-effect/SKILL.md)**：抵消乘数。
- **与[李嘉图等价](../ricardian-equivalence/SKILL.md)**：预期增税对冲支出。

## 记忆钩子

一块钱工资花出去，又变成别人的收入——漏得越少滚得越大。
