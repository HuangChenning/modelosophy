# Finance & Investing

金融与投资常用模型的可执行 Skill。

路径：`skills/finance-investing-models/<skill-name>/SKILL.md`。

本分类合计 **30** 条（需求清单「金融与投资模型」Top 30；保留既有 `compounding`）。

## Skills

- **[beta-alpha](./beta-alpha/SKILL.md)** `v0.x-draft` — 把收益拆成市场（或其他因子）暴露 β 与无法被暴露解释的截距 α：先问“是涨潮带起来的还是真超额”。
- **[black-scholes](./black-scholes/SKILL.md)** `v0.x-draft` — 用布莱克-斯科尔斯框架理解欧式期权定价直觉：价格由标的、行权价、期限、利率、分红与波动率驱动；关键输入常是隐含波动率。
- **[bubble-cycle](./bubble-cycle/SKILL.md)** `v0.x-draft` — 用泡沫周期把狂热拆成可检查阶段：对照杠杆、叙事与估值偏离，而非事后贴标签。
- **[cantillon-effect](./cantillon-effect/SKILL.md)** `v0.x-draft` — 用坎蒂隆效应分析新增货币/信贷的分配效应：先到者受益、后到者承担物价或资产价格上行。
- **[capm](./capm/SKILL.md)** `v0.x-draft` — 用 CAPM 把预期收益写成无风险利率 + β×市场风险溢价；区分可分散风险与系统风险。
- **[compounding](./compounding/SKILL.md)** — 用复利思维评估长期增长是否具备“回报再投入 × 速率可维持 × 时间足够”三条件。
- **[dcf](./dcf/SKILL.md)** `v0.x-draft` — 用贴现把未来现金流折成今日价值；先写现金流、折现率与终值假设再比价格。
- **[dividend-discount-model](./dividend-discount-model/SKILL.md)** `v0.x-draft` — 用股利贴现把股票看成未来股息的现值（Gordon / 多阶段 DDM）。
- **[duration-convexity](./duration-convexity/SKILL.md)** `v0.x-draft` — 用久期衡量债价对利率的一阶敏感，用凸性修正二阶弯曲。
- **[efficient-market-hypothesis](./efficient-market-hypothesis/SKILL.md)** `v0.x-draft` — 用有效市场假说检验价格是否已反映可用信息、主动战胜市场是否可预期（弱/半强/强式）。
- **[fama-french-three-factor](./fama-french-three-factor/SKILL.md)** `v0.x-draft` — 用 Fama-French 三因子把超额收益分解为市场、规模（SMB）、价值（HML）暴露。
- **[financial-accelerator](./financial-accelerator/SKILL.md)** `v0.x-draft` — 用金融加速器解释资产价格与信贷约束的互馈放大。
- **[fisher-effect](./fisher-effect/SKILL.md)** `v0.x-draft` — 用费雪效应拆解名义利率 ≈ 实际利率 + 预期通胀；统一名义/实际口径。
- **[greater-fool-theory](./greater-fool-theory/SKILL.md)** `v0.x-draft` — 用大傻瓜理论识别“买入只为卖给下一个愿出更高价的人”的定价逻辑。
- **[investment-clock](./investment-clock/SKILL.md)** `v0.x-draft` — 用美林投资时钟按增长与通胀组合划分四季，映射大类资产战术倾向。
- **[kelly-criterion](./kelly-criterion/SKILL.md)** `v0.x-draft` — 用凯利公式按胜率与赔率定最优仓位分数；实务常用分数凯利。
- **[limits-to-arbitrage](./limits-to-arbitrage/SKILL.md)** `v0.x-draft` — 用套利限制解释错误定价为何不迅速消失。
- **[liquidity-preference](./liquidity-preference/SKILL.md)** `v0.x-draft` — 用凯恩斯流动性偏好理解持币三类动机与利率。
- **[minsky-moment](./minsky-moment/SKILL.md)** `v0.x-draft` — 用明斯基时刻刻画稳定滋生杠杆与投机、直至再融资断裂的转折。
- **[modern-portfolio-theory](./modern-portfolio-theory/SKILL.md)** `v0.x-draft` — 用马科维茨均值–方差框架做分散化与有效前沿。
- **[momentum-reversal](./momentum-reversal/SKILL.md)** `v0.x-draft` — 用动量与反转组织价格续涨 / 极端回吐的实证规律。
- **[noise-trader-risk](./noise-trader-risk/SKILL.md)** `v0.x-draft` — 用噪音交易者风险解释：正确也可能因非理性推价而被迫亏钱离场。
- **[pe-pb-valuation](./pe-pb-valuation/SKILL.md)** `v0.x-draft` — 用市盈率 / 市净率做相对估值，放到可比组与历史分位中读贵贱。
- **[rebalancing](./rebalancing/SKILL.md)** `v0.x-draft` — 用再平衡把组合权重纪律化拉回目标（时间或阈值触发）。
- **[risk-parity](./risk-parity/SKILL.md)** `v0.x-draft` — 用风险平价按风险贡献（而非资金权重）分配资产。
- **[rule-of-72](./rule-of-72/SKILL.md)** `v0.x-draft` — 用 72 法则快速估算复利翻倍年数（心算层，不替代精确复利）。
- **[sharpe-ratio](./sharpe-ratio/SKILL.md)** `v0.x-draft` — 用夏普比率衡量单位总波动的超额报酬。
- **[stock-bond-seesaw](./stock-bond-seesaw/SKILL.md)** `v0.x-draft` — 用股债跷跷板描述风险偏好切换下股与债常反向的经验结构。
- **[value-premium](./value-premium/SKILL.md)** `v0.x-draft` — 用价值效应理解低估值组合长期平均超额（含长回撤）。
- **[yield-curve](./yield-curve/SKILL.md)** `v0.x-draft` — 用收益率曲线（期限结构）读预期、期限溢价与宏观含义。
