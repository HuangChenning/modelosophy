# Systems & Complexity

冰山模型、杠杆点、临界点、耗散结构，以及涌现、系统基模、因果回路、存量流量、CAS、小世界/无标度网络等复杂系统 Skill。

与兄弟分类分流：复杂系统结构干预与网络/动态建模（本类）；具名经典效应与路径依赖/锁定/网络效应/熵增/反馈等见 `systems-classic-effects/`（**只互链不复制**）。

路径：`skills/systems-complexity/<skill-name>/SKILL.md`。

当前合计 **11** 个（迁入种子 4 + M4 新建 7，新建均为 `v0.x-draft`）。

## Skills

- **[causal-loop-diagram](./causal-loop-diagram/SKILL.md)** — 因果回路图：变量+极性连成增强/调节回路并标延迟（`v0.x-draft`）。
- **[complex-adaptive-systems](./complex-adaptive-systems/SKILL.md)** — 复杂适应系统：多样适应主体、局部规则与共同演化（`v0.x-draft`）。
- **[dissipative-structures](./dissipative-structures/SKILL.md)** — 耗散结构：开放系统远离平衡时经涨落放大越过阈值形成新宏观有序，并靠持续耗散维持。
- **[emergence](./emergence/SKILL.md)** — 涌现：宏观模式由微观互动生成，不可仅用零件属性加总解释（`v0.x-draft`）。
- **[iceberg-model](./iceberg-model/SKILL.md)** — 冰山模型：把器物/行为之下的规范与基本假设分层，避免只改水面以上。
- **[leverage](./leverage/SKILL.md)** — 杠杆点：找系统中小投入、大结构化改变的干预点（Meadows 式），不是鼓励加财务杠杆。
- **[scale-free-network](./scale-free-network/SKILL.md)** — 无标度网络：度数幂律与枢纽；优先连接与韧性含义（`v0.x-draft`）。
- **[small-world-network](./small-world-network/SKILL.md)** — 小世界网络：高聚类 + 短路径；捷径边的双刃剑（`v0.x-draft`）。
- **[stock-and-flow](./stock-and-flow/SKILL.md)** — 存量与流量：浴缸式累积、单位守恒与惯性（`v0.x-draft`）。
- **[system-archetypes](./system-archetypes/SKILL.md)** — 系统基模：增长上限、舍本逐末等可复用反馈结构故事（`v0.x-draft`）。
- **[tipping-point](./tipping-point/SKILL.md)** — 临界点/断裂点：识别临界质量附近的非线性相变——越过阈值后状态可快速翻转。
