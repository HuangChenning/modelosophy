# 情绪 ABC（Ellis / REBT）

## 这是什么

Albert Ellis 的理性情绪行为疗法（REBT）核心切片：**A（Activating event）触发事件 → B（Belief）信念 → C（Consequence）情绪与行为后果**。不是事件本身“造成”了全部 C，而是当事人对事件的评价、要求与解释（B）在中间起决定性作用。常见非理性 B：必须（must）、完蛋了（catastrophizing）、我受不了（low frustration tolerance）、以偏概全的自我贬低。

完整协议常接 **D（Disputing）驳斥** 与 **E（Effective new belief）更有效的新信念**。本 skill 把 ABC + 基础驳斥做成可执行清单，不展开全部临床技术。

原书卡片把 B 标成“根本原因”、收尾成“事件本身没问题只是态度”——方向对一半：**B 是可干预杠杆**，但不等于 A 从未造成真实损失，也不等于“想开就好”。

## 什么时候用

- 怒火、委屈、焦虑明显大于事态本身，需要拆链条；
- 用户反复把责任全部推给外部，或反过来全部内耗自责；
- 直接提情绪 ABC / Ellis / REBT。

**不要**当主模型：
- “亏了特别痛、舍不得止损”→ [`loss-aversion`](../../behavioral-biases/loss-aversion/SKILL.md)；
- “想做却总没做成”→ [`fogg-behavior-model`](../fogg-behavior-model/SKILL.md)；
- 检验论证隐含前提→ [`socratic-questioning`](../socratic-questioning/SKILL.md)。

## 怎么用（执行步骤）

1. **三栏写下 A / B / C。** A：可观察事实（尽量去形容词）。C：具体情绪强度与行为。B：你对 A 的句子——尤其含“必须/绝不/完蛋/都是我废”的句子。禁止跳过 B 直接骂 A。
2. **区分描述信念 vs 评价/要求。** “对方提高了声音”（描述）与“他绝不能这样对我，否则我没法活”（要求）不同。干预优先打在绝对化要求上。
3. **对 B 做三问驳斥（D）。** 证据：有何事实支持/反驳？逻辑：从 A 是否必然推出这个 B？实用：抱着这个 B 是否帮你达成目标，还是只加燃料？
4. **写一条可检验的新 B（E）。** 例如把“必须永远站在我这边”改为“我们有边界分歧，我可以澄清与协商，不舒服不等于被全盘否定”。用下一相似情境验证 C 是否减轻或行为是否更有效。
5. **保留对 A 的现实行动。** 若 A 含侵害、违约、危险，ABC 帮你稳定认知，不替代报警、边界、法律或医疗。

## 例证

**同一迟到，两种 C**：同事迟到五分钟。B1“他故意羞辱我”→暴怒；B2“交通拥堵，我可确认安排”→轻微烦躁+行动。揭示 **C 随 B 变，而非仅随 A**。

**绩效差评**：A=收到需改进评价。非理性 B“我必须被所有人认可，否则一文不值”→羞耻回避。驳斥后 B“这是具体技能反馈，可制定两周实验”→可行动焦虑。揭示绝对化自我价值是杠杆。

**（原书卡片）婆媳冲突 + 驳斥干预**：非理性 B“她总针对我”→迁怒配偶；改为“身份边界议题，经配偶协商界限”。有用；局限是易暗示家庭政治只靠想通——制度与权力不对称仍可能存在，需并行现实策略。卡片总结“事件没问题只看态度”过满，本 skill 不采信。

## 什么时候不适用（边界）

- **急性创伤、自伤/他伤风险、严重抑郁或精神病性症状**：停止自制 ABC 教练，建议专业与危机资源。
- **把受害者责任化**：欺凌、虐待场景下，优先安全与外部追责，不把“改信念”当唯一处方。
- **器质/药物因素**：甲状腺、睡眠剥夺等可驱动情绪，先排查再归因 B。
- **本模型不提供诊断码或疗程方案**。

## 常见误用

- **跳过 B 直接处理 A 或压制 C**：只想着改变触发事件本身，或让自己"别生气/冷静下来"，不写出中间的信念句就无从驳斥 → 走步骤1，必须显式写出 B 再动手。
- **把评价性判断混进 A 栏当事实**：把"他不尊重我"当作触发事件写进 A（应写"他提高了声音"这类可观察事实），导致后续驳斥找不到真正对象 → 走步骤2，严格区分描述性事实与评价/要求。
- **用一句正能量口号顶替真正的驳斥**：不走证据/逻辑/实用三问，直接灌一句"想开点"当新信念，新 B 从未被检验过是否有效 → 走步骤3/4，新信念必须可检验。
- **把"C 随 B 变"泛化成"外部事件不重要"**：因为信念是干预杠杆，就淡化甚至否认真实伤害或合理诉求，滑向精神胜利法 → 步骤5 明确保留对 A 的现实行动，ABC 不替代该有的边界与追责。

## 相关模型

- **与[损失规避](../../behavioral-biases/loss-aversion/SKILL.md)**：损失框架放大痛感；ABC 进一步拆“我必须立刻回本”类信念。
- **与[双系统](../dual-process/SKILL.md)**：激烈 C 常由快系统；驳斥需慢系统写下来。
- **与[福格行为模型](../fogg-behavior-model/SKILL.md)**：ABC 管情绪链条；福格管目标行为是否发生。
- **与[苏格拉底式质疑](../socratic-questioning/SKILL.md)**：驳斥 B 的问法同源；本 skill 固定 A-B-C 表格。
