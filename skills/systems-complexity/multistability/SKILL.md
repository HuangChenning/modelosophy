# 多稳态 Multistability

## 这是什么

**多稳态**：同一套外部条件附近，系统可稳定停留在**多个不同状态**（吸引盆）。要从 A 盆到 B 盆，往往需要足够大的扰动或暂时改变参数；回来的路径可能不同（**回滞 / hysteresis**）——「来时路」≠「回程」。

与单稳态对照：单稳态只有一个盆，扰动后仍回原处。

## 什么时候用

- "明明环境差不多，却能停在完全不同的模式"
- "多稳态 / 双稳态 / 回滞 / 吸引盆"
- 生态清水-浊水湖、习惯-成瘾、组织文化态、市场高信任/低信任

**不要**当主模型：
- 只要「快到阈值要翻」叙事 → [`tipping-point`](../tipping-point/SKILL.md)
- 只要历史偶然锁定 → [`path-dependence`](../../systems-classic-effects/path-dependence/SKILL.md)
- 只要调节回目标 → [`homeostasis`](../homeostasis/SKILL.md)

## 怎么用（执行步骤）

1. **列出候选稳定态。** 可观察、可维持一段时间的模式（≥2）。判据：每态有指标签名。
2. **找自我维持机制。** 每态靠什么正反馈/制度锁住？判据：机制句非空。
3. **估盆地边界。** 多小扰动可恢复、多大扰动会翻盆？可用历史案例近似。
4. **检查回滞。** 参数来回扫时，翻转点是否不同？有则多稳态证据增强。
5. **选策略。** 守盆：减扰动、加固维持机制；迁盆：足够脉冲+临时改变参数+落地加固新态。判据：策略写清成本。
6. **拒绝「轻轻推一下就会回去」。** 回滞下回去可能更贵。

## 例证

**湖泊富营养化**：清水/浊水双稳态；营养物降到原翻转点以下仍可能不回清水。揭示：回滞与恢复成本。

**信任型 vs 戒备型协作**：低信任靠监视自我强化。揭示：迁盆要大动作重建可信承诺。

**（原书卡片）**：勿只说「有两个状态」；落到机制与回滞。

## 什么时候不适用（边界）

- **无自我维持、只是噪声跳变**：非稳态。
- **强外力完全控制状态**：谈调度即可。
- **连续渐变无盆**：用常规优化。

## 常见误用

- **与临界点混用**：临界是越过；多稳态是多盆并存+回滞。
- **小激励妄想迁盆**：低估边界。
- **把路径依赖全部叫多稳态**：路径依赖可不需多盆动力学术语。

## 相关模型

- **与[临界点](../tipping-point/SKILL.md)**：翻盆常经临界；多稳态强调翻完后的盆与回滞。
- **与[路径依赖](../../systems-classic-effects/path-dependence/SKILL.md)**：历史选盆；多稳态给动力学图像。
- **与[稳态/内稳态](../homeostasis/SKILL.md)**：内稳态守单设定点；多稳态是多个可守设定。
- **与[锁定效应](../../systems-classic-effects/lock-in-effect/SKILL.md)**：锁定常是某盆的制度表现。

## 记忆钩子

先数有几个盆，再问回去是否同路——回滞会让「恢复」贵过「跌落」。
