# 双系统 Dual Process（System 1 / System 2）

## 这是什么

人脑同时跑两套加工模式。System 1（快）：自动、快速、几乎不费力，靠联想与模式匹配——认脸、读熟词、习惯反应、专家在熟悉域里的“直觉”。System 2（慢）：费力、串行、可遵循规则——算乘法、比对合同条款、压抑冲动、检查逻辑。

Kahneman 的核心不是“理性好、直觉坏”，而是：**默认由 System 1 提案，System 2 常常偷懒背书**；许多偏见出在 System 2 没有被成功唤起，或唤起后仍在合理化 System 1 的结论。Stanovich 等人强调：个体差异更多体现在**是否愿意/能够调用** System 2，而不只是智商分数。

专家直觉（Klein 再认启动决策）成立的前提是：**高有效度环境 + 大量带反馈的练习**。棋手的“一眼看出好棋”是压缩后的模式匹配；人事、股市、临床里许多“凭感觉”没有稳定反馈，只是偏见穿着直觉的衣服。

原书用“猛张飞 / 懒诸葛”和“95% / 5%”作通俗比喻。比例是教学修辞，不是测得的神经事实——不要当科学数据引用。

## 什么时候用

- 用户说“我觉得就是这样，但说不清理由”，需要判断该信还是该验；
- 高压、疲劳、多任务下做重大选择，怀疑自己在用默认快思考；
- 问“要不要再算一遍 / 再找人审一下”；
- 直接提到 System 1/2、双系统、快思考慢思考。

**不要**在以下情况当主模型：
- 只是在按已有立场筛证据（确认性偏差）；
- 只是被生动案例带跑频率判断（易得性启发）；
- 需要拆惯例重建方案（第一性原理）。

## 怎么用（执行步骤）

1. **标出当前主要在用哪套。** 问：答案是瞬间跳出来的，还是经过逐步推演？有没有说得出的规则或数据步骤？瞬时且说不清规则 → 先按 System 1 提案处理，不立刻当真理也不立刻当错误。
2. **检查环境是否允许“专家直觉”。** 三个条件缺一就降级信任：(a) 规律是否稳定可学；(b) 过去是否有快速、明确的对错反馈；(c) 当事人是否在该域有大量刻意练习。缺反馈 → 直觉只是猜测。
3. **决定要不要强制唤起 System 2。** 满足任一则必须慢下来：后果不可逆或代价高；数字/概率/合同细节；与强烈情绪或身份绑定；多个选项外表相似。日常低成本重复决策可以继续交给 System 1。
4. **给 System 2 具体任务，而非“再想想”。** 可执行动作包括：写出假设与反例、算一遍期望值、对照清单、请无关第三方挑错、把决策推迟到不疲劳的时段。空喊“理性一点”不会启动慢系统。
5. **提防 System 2 的合理化。** 慢思考被唤起后，仍可能只是为 System 1 的结论写辩护词。若“仔细想过”的产物里没有任何可能改变结论的证据，就还在确认性偏差里——转用该模型的预注册/找反例步骤。

## 例证

**视力错觉与信念**：缪勒-莱尔线长错觉说明 System 1 的感知模块即使 System 2 “知道”等长，观感仍可不服。它揭示的是两套系统可以并存、且慢系统未必改写快系统的体验——决策上意味着“我知道有偏见”不等于已经纠正行为。

**临床 vs 消防指挥**：在稳定反馈、可重复模式的领域（如某些急救规程、棋类），经验丰富者的快速再认往往优于外行的慢算。在低反馈、高噪声领域（长期政治预测、部分人事面试），“老手直觉”胜率接近随机。同一“凭感觉”标签，效度天差地别。

**认知吝啬鬼（cognitive miser）**：人倾向于选费力更少的策略。会议里点头通过复杂方案，常常不是同意，而是 System 2 预算耗尽。它揭示组织场景里“没有反对”不可当作“已经过慢思考”。

**（原书卡片）猛张飞 / 懒诸葛与 95%/5%**：比喻有助于记忆默认模式与备用模式，但把比例写成大脑事实会误导；也不要把 System 1 画成莽撞武将——在熟悉且有反馈的域里，它往往比外行的慢思考更准。

## 什么时候不适用（边界）

- **低成本、高重复、可逆的日常选择**：强制全程 System 2 会耗竭，得不偿失。
- **把一切错误归咎 System 1**：动机性推理、激励扭曲、信息缺失也会让慢系统得出坏结论。
- **无反馈环境冒充专家直觉**：年限长 ≠ 有效练习。
- **与“灵感 / 第六感”神秘化切割**：本模型谈的是加工模式与调用条件，不是超感官。

## 相关模型

- **与[确认性偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：双系统解释*何时*默认快结论；确认偏差处理*证据筛选*。慢系统被唤起后仍可能只找支持证据。
- **与[易得性启发](../../behavioral-biases/availability-heuristic/SKILL.md)**：易得性是 System 1 常用的频率捷径之一；纠偏需要 System 2 去对基准率。
- **与[沉没成本](../../behavioral-biases/sunk-cost/SKILL.md) / [损失规避](../../behavioral-biases/loss-aversion/SKILL.md)**：情绪痛感多由快系统放大；止损规则要预写好，不能等现场靠意志力。
- **与[第一性原理](../../cognitive-thinking-tools/first-principles/SKILL.md)**：拆惯例是典型的 System 2 重活；日常套经验则是 System 1。
- **与原书 #03 直觉**：不另建 skill；专家直觉的可信任条件写在本模型第 2 步。
