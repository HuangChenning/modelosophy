# 沉没成本 Sunk Cost

## 这是什么

已经发生、且无论现在怎么选都收不回来的投入，叫沉没成本。规范的决策规则是：**它不应进入当前选择的权重**。真正该比的只有从现在起还要付出什么、还能得到什么。

这不是一句鸡汤。经济学里它是成本概念；心理学把它叫沉没成本效应（Arkes & Blumer, 1985）：一旦已经投入金钱、努力或时间，人就更倾向把这件事做下去。管理学里更宽的现象叫承诺升级（escalation of commitment, Staw 1976）——决策者为了向自己和他人证明"当初没选错"，继续向已经失败的路径加码。前景理论里的损失厌恶能部分解释为什么"放弃已投入"会被体验成损失，痛感大于等量的未来收益。

**关键鉴别**：外部看起来都是"还在坚持"，里面可能是两件完全不同的事——

| | 沉没成本谬误 | 基于新信息的理性坚持 |
|---|---|---|
| 继续的理由 | 已经投了这么多，不甘心浪费 | 以今天的信息，剩余投入仍值得 |
| 判别句 | "都已经……了" | "如果我今天第一次面对，我还会开始" |
| 该怎么做 | 把已投入从理由里拿掉，重算 | 继续，但理由必须是面向未来的 |

沉没成本效应只是承诺升级的驱动之一。项目接近完工（completion effect）、不愿承认错误（自我辩护）也会让人加码——别把所有"不肯停"都诊断成沉没成本。

## 什么时候用

用户**已经在某条路径上有不可收回的投入**，正在纠结要不要因为这些投入而继续：

- "这个项目已经做了大半年，现在看希望不大，但放弃太亏了"；
- "这段关系投入这么多，就这么走掉不甘心"；
- "票已经买了，身体不舒服也得去，不去就浪费了"；
- 用户直接说"止损"、"sunk cost"、"沉没成本"。

**不要**在以下情况套用本模型：
- 决策还没开始、没有过去投入（先用机会成本看放弃了什么）；
- 用户问的是"多个解释哪个更可能"（奥卡姆剃刀），或"主张站不站得住"（苏格拉底式质疑）。

## 怎么用（执行步骤）

1. **把已经收不回来的东西单独列出来，然后停用它当理由。** 写清：已经花掉的钱、已经耗掉的时间、已经搭进去的声誉。这一步不是让用户遗忘过去——过去仍然可以提供关于世界的信息（产品好不好、市场在不在）——而是禁止"因为已经花了，所以必须继续"这条推理。已投入本身不能被"坚持到底"赎回。
2. **做一次从零出发测试。** 问："假如我今天第一次面对这个选择，只看从现在起还要付出什么、还能得到什么，我还会开始吗？" 只用这个答案。不要把"已经投了 X"加回分子或分母。**仍在前面的成本要算进去**：解约罚金、提前离职的通知期、卖掉资产的手续费——这些还没发生，不是沉没成本。从零出发不是假装切换免费，而是把已经沉没的金额从理由里拿掉。
3. **分开两堆信息：新事实 vs 沉没金额。** 只有新信息能支持继续——需求变了、技术突破了、身体状况、关系质量的当前证据。若唯一新增的"理由"仍是投入量本身，就是谬误。若新信息支持继续，明确说：这是理性坚持，不是沉没成本。
4. **把决定说成面向未来的一句话。** 继续：写出那条未来理由（"剩余投入换来的预期收益仍高于机会成本"）。停止：把它叫止损，不要叫"浪费"——Arkes 指出成人比儿童更容易犯这个错，正是因为过度泛化了"不要浪费"规则。停止并不使过去的投入变得更浪费；那些投入无论停不停都已经沉没。
5. **检查反向误用。** "别陷入沉没成本"不是放弃一切长期投入的许可证。研发、创业、训练这些回报周期长的事，过程中本来就会有沉没投入。若面向未来的预期仍为正，用本模型当半途而废的挡箭牌，是同一错误的镜像。

## 例证

**协和飞机（Concorde fallacy）**：英法两国在超音速客机已明显无法商业盈利之后，仍以"已经投入巨资不能半途而废"为由继续拨款。它揭示的是公共政策版的承诺升级：沉没的是纳税人的钱，决策者承担的是承认失败的政治成本，于是加码变成了自我辩护，而不是对剩余航程做净现值判断。

**Arkes & Blumer（1985）剧院季票实验**：同一剧院的季票被随机以全价或折扣卖出；全价买家在随后六个月里到场次数显著更多。票已经买了，边际观剧成本对所有人相同，到场差异只能来自"已经花了多少"。这揭示的是沉没成本效应的微观机制：人用消费行为去"兑现"已经付出的价格，而不是用剩余体验的价值做决定。

**从零出发测试（决策实践）**：面对"项目还要不要做"时，把已花费从表格里抹掉，只留剩余预算和剩余预期收益。若此刻不会批准一个全新的同等项目，就不该只因为旧项目已经花过钱而续命。这一面是可执行的会计操作，不是态度。

**（原书卡片）找对象→结婚→生子的投入升级链**：原书用感情投入说明"不甘心放弃就会继续加码"，并标出选择对象前 / 结婚前 / 生子前三个止损节点。这个例子能说明黑洞循环的形状，但有两处硬伤，不宜当定义来用。第一，子女、婚姻中的义务和感情不是可以"核销"的沉没支出——它们会改变从现在起的收益与责任，属于面向未来的事实，不是已沉没的金额。第二，原书把"A 是 B 的沉没成本、B 是 A 的机会成本"写成对称公式，把两个不同概念绑成一对镜像；沉没成本是**你在当前这条路径上已经收不回的投入**，不是备选项的一种属性。

## 什么时候不适用（边界）

- **新信息支持继续时，不是谬误。** 判断标准永远是"今天第一次面对还会不会做"，不是"投入了多少所以该不该停"。
- **长期、高不确定的投入（研发、创业、基础训练）不能机械止损。** 这些领域的价值本来就后置。过度套用会导致系统性低估需要时间才能验证的事情。此时应缩短的是**下次复核的周期**，而不是禁止沉没投入存在。
- **不要把所有不肯停都叫沉没成本。** 接近完工的完成效应、自我辩护、代理问题（花的是别人的钱）会表现为加码，但处方不同。
- **过去信息仍有用。** "忽略沉没成本"忽略的是不可收回的支出金额，不是历史告诉你的关于产品、市场或对方的事实。把这条做成"过去的一切都不算"，会连有效学习一起扔掉。

## 常见误用

- **“已经花了所以必须继续”**：用沉没金额当未来理由 → 做从零出发测试；解约罚金等尚未发生的成本仍要算。
- **“别陷入沉没成本”当半途而废许可证**：研发/训练等回报后置、面向未来仍为正时继续不是谬误 → 缩短复核周期，而非禁止沉没投入存在。
- **“过去的一切都不算”**：忽略的是不可收回金额，不是历史事实与学习 → 分开“沉没金额”与“新信息”。
- **凡不肯停都贴沉没成本**：完成效应、自我辩护、代理问题处方不同 → 先问唯一理由是否仍是“已投入量本身”。

## 相关模型

- **与[机会成本](../../econ-micro-markets/opportunity-cost/SKILL.md)**：两者最容易被用户混用。机会成本问的是**面向未来放弃了什么**；沉没成本问的是**不要让已经收不回的投入绑架现在**。触发词"该选 A 还是 B / 我错过了什么"走机会成本；"都已经投入这么多了 / 不甘心"走本模型。
- **与[10/10/10](../../thinking-models/ten-ten-ten/SKILL.md)**：本模型移除过去投入对当前判断的绑架；10/10/10 把未来的短、中、长期后果同时摆上桌。若用户反复说"已经花了这么多"先走本模型；若主要是眼前情绪压住长期价值，走 10/10/10。
- **与[反脆弱](../../learning-growth/antifragility/SKILL.md)**：小成本试错里，失败的那几次投入就是该被写下的沉没成本——选择性成立的前提，正是承认这些支出不可赎回、且金额事先被限定在输得起的范围内。
- **与[逆向思维](../../cognitive-thinking-tools/inversion/SKILL.md)**：纠结"要不要停"之前，可以先倒过来问"继续加码会怎样保证失败"，但一旦理由落回"已经投了这么多"，仍应回到本模型。
- **与[损失规避](../loss-aversion/SKILL.md)**：沉没成本管“已投入能不能当理由”；损失规避管“同等得失的痛感不对称 / 框架”。常一起出现：浮亏仓位既有沉没感，又有损失框架。
- **与[心理账户](../mental-accounting/SKILL.md)**：亏损仓常被放进“长期账户”合理化——两模型常联用。
- **与[承诺与一致](../commitment-consistency/SKILL.md)**：常一起锁死坏项目。
- **与[禀赋效应](../endowment-effect/SKILL.md)**：购入成本是沉没；禀赋是拥有状态本身。
- **与[前景理论](../prospect-theory/SKILL.md)**：已投入能否当理由 ≠ 参照点下的得失编码（常并存）。
- **与[现状偏差](../status-quo-bias/SKILL.md)**：历史投入加固现状。
