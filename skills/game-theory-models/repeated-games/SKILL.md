# 重复博弈 Repeated Games

## 这是什么

**同一阶段博弈多次互动，使未来惩罚/奖励约束今天的行为。**

有限或无限重复改变激励：背叛今日可能牺牲明日收益。Axelrod 锦标赛中“一报还一报”（Tit-for-Tat）等策略在适当条件下维持合作。关键条件：足够看重未来、行动可观测、惩罚可信。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "以后还要不要合作"
- "一报还一报管不管用"
- "重复互动能否走出困境"

**不要**在以下情况套用本模型：

- 确认是单次优势背叛结构即可 → ../prisoners-dilemma/SKILL.md
- 要定理级“何时合作可支撑” → ../folk-theorem/SKILL.md
- 信号与类型未知 → ../signaling-games/SKILL.md

## 怎么用（执行步骤）

1. **写清阶段博弈与重复次数/贴现。** 有限已知终点常逆向拆解合作；无限或不确定结束更易合作——先定性。
2. **定义可观测性。** 对方行动能否及时看见？噪声大则朴素 TFT 易误伤，需宽容策略。
3. **设计触发策略。** 合作路径 + 惩罚路径（以牙还牙、严厉触发等）；写启动与结束条件。
4. **压力测试。** 一次性大诱惑、最后一期、观测错误——标出合作崩溃点。输出：策略规则 + 崩溃条件。

## 例证

**Axelrod 一报还一报**：善意、报复、宽容、清晰在重复囚徒中表现好。揭示策略性质重于单次最优。

**供应链长期合同**：违约损害再订单。揭示可观测履约与未来租金是合作支柱。

## 什么时候不适用（边界）

- **有限已知终点**：末期拆解可使合作从后往前崩塌。
- **不可观测**：隐蔽行动需监测或机制设计。

## 常见误用

- **无条件忍让叫重复合作**：缺惩罚的合作常被剥削。
- **把 TFT 当万能**：噪声与多人结构需调整。

## 相关模型

- **与[无名氏定理](../folk-theorem/SKILL.md)**：耐心足够时可持续支付集的理论边界。
- **与[囚徒困境](../prisoners-dilemma/SKILL.md)**：阶段博弈常是 PD。
- **与[博弈论](../game-theory/SKILL.md)**：超出入门四块时换专条，勿把全书塞进「博弈论」。
- **与[信任博弈](../trust-game/SKILL.md)**：声誉与未来。

## 记忆钩子

今天的合作，抵押的是明天的再见。
