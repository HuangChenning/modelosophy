# 纳什均衡 Nash Equilibrium

## 这是什么

**无人愿单方面偏离的策略组合（相互最佳回应）。**

Nash（1950）：给定他人策略，每人选择最佳回应；整组一致即纳什。可纯可混；有限博弈存在性有保证，但不保证唯一、也不保证社会福利最优。优势策略均衡是纳什特例。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "有没有纳什均衡"
- "谁也不想单方面改策略"
- "相互最佳回应是什么"

**不要**在以下情况套用本模型：

- 只要扫盲博弈四件套 → ../game-theory/SKILL.md
- 序贯里威胁不可信 → ../subgame-perfect-equilibrium/SKILL.md
- 只要标囚徒式双输结构 → ../prisoners-dilemma/SKILL.md

## 怎么用（执行步骤）

1. **写出策略剖面候选。** 从支付表挑一格（或混策略描述）；禁止空谈“均衡”不点名行动。
2. **逐人做单方面偏离测试。** 固定他人，问自己是否有严格更好偏离。任一人想偏离 → 非纳什。
3. **搜全表（小博弈）。** 标出所有纯策略纳什；若无纯，说明可能需混策略并交代含义（概率化行动），本草案不强制完整混策略计算。
4. **标注福利。** 对每个纳什写一句：是否帕累托最优？有无更优但非稳定的格？输出：纳什列表 + 福利对照。

## 例证

**囚徒双方招供**：相互最佳回应但是帕累托劣。揭示纳什≠公平/最优。

**协调博弈双纳什**：两格都可纳什，哪一个被选中常靠谢林点或习惯。揭示多重均衡问题。

## 什么时候不适用（边界）

- **不可观测支付**：支付不可估时先调研，不硬编均衡。
- **动态精炼**：含空威胁的纳什需子博弈精炼过滤。

## 常见误用

- **把纳什当“最优解”**：只保证稳定，不保证集体最好。
- **没做偏离测试就宣称均衡**：必须完成单方面偏离检查。
