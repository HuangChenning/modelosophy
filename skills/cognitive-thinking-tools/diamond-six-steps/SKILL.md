# 菱形六步法 Diamond Six Steps

## 这是什么

**菱形六步法**：把问题解决画成「先变宽再变窄」的菱形，并且通常跑**两轮**（探查题面一轮、生成方案一轮），落成六步门控：

| 步 | 名称 | 模式 | 产出 |
|---|---|---|---|
| 1 | 钉题草稿 | — | 初步问题句 |
| 2 | 发散探查 | 发散 | 事实、利益相关方、线索清单 |
| 3 | 收敛定义 | 收敛 | 单一主问题 + 边界 |
| 4 | 发散方案 | 发散 | 多样选项（不评价） |
| 5 | 收敛选型 | 收敛 | 选定方案 + 理由 |
| 6 | 行动验证 | — | 试点/度量/回跳点 |

「菱形」强调：**宽度（选项/信息量）与窄度（决定）交替**；最常见失败是在该发散时批评杀人，或该收敛时继续开脑洞。

## 什么时候用

- "团队要么吵着收口，要么散永不决"
- "先发散再收敛怎么组织工作坊"
- 直接说菱形六步 / 菱形思维 / double diamond
- 产品发现、复杂问题工作坊、创新流程需要阶段门

**不要**当主模型：

- 只要总流程原则、步骤可裁剪 → [`structured-thinking`](../structured-thinking/SKILL.md)
- 只要跳框技法 → [`lateral-thinking`](../lateral-thinking/SKILL.md)
- 会议分色帽角色 → [`six-thinking-hats`](../six-thinking-hats/SKILL.md)
- 已是单点故障复盘 → [`five-whys`](../five-whys/SKILL.md)

## 怎么用（执行步骤）

1. **钉题草稿。** 用一句可修改的问题句开场（允许错）。判据：写在大家可见处。
2. **发散探查（禁止选型）。** 收集事实、用户原话、约束、异常；可用便利贴/八爪鱼图。判据：批评与「我们应该」暂存停车场；先求覆盖。
3. **收敛定义。** 用投票/标准把主问题收成一句 + 非目标清单。判据：不同角色复述同一主问题；否则未收敛。可连用 [`scqa`](../scqa/SKILL.md) 钉 Q。
4. **发散方案（禁止过早可行性否决）。** 目标是选项多样性；水平思考技法可嵌入此步。判据：至少有「非常规」选项入列，否则仍在旧框。
5. **收敛选型。** 事先公布标准（价值、成本、风险、可逆性）；可用 [`decision-matrix`](../decision-matrix/SKILL.md) 或 [`pros-cons-list`](../pros-cons-list/SKILL.md)。判据：写下「为什么不选其他」；无标准的投票不算收敛。
6. **行动验证。** 定试点、成功/失败阈值、回顾日；失败则回到步 3 或 4（标明回跳），禁止假装一次做完。

**门控口令**：每步结束问「我们在扩还是在收？」答不上来就停。

## 例证

**产品工作坊**：步 2 收集到「支付失败」与「找不到入口」两簇痛点；步 3 收敛为「首次支付成功率」；步 4–5 在改文案 vs 改收银台选型。揭示：菱形价值是**防止用方案语言偷换问题**。

**失败模式**：步 4 刚出两个想法就被「领导说不行」收掉——菱形塌成直线。揭示：收敛必须有显式标准与时间盒。

**（原书卡片）**：若卡片只画菱形无门控，易变成海报；以六步产出物与扩/收纪律为准。

## 什么时候不适用（边界）

- **紧急单路径事故**：先止血与根因，不开完整菱形。
- **选项已法定唯一**：合规必须执行项，不必假发散。
- **团队无授权收敛**：发散后无人能拍板 → 先解决治理，再跑菱形。

## 常见误用

- **假发散**：只写早已内定的方案 → 强制非常规席位或外部刺激。
- **假收敛**：无标准投票 → 先写标准。
- **与双钻四步名相混淆**：本 Skill 用六步门控；不必争论商标名词，对齐扩/收节奏即可。
- **跳过定义直接方案**：步 3 空着进步 4 → 退回。

## 相关模型

- **与[结构化思维](../structured-thinking/SKILL.md)**：结构化思维是总论；菱形六步是其中一种固定节奏模板。
- **与[水平思考](../lateral-thinking/SKILL.md)**：水平技法主要服务步 4（及步 2 的视角扩展）。
- **与[六顶思考帽](../six-thinking-hats/SKILL.md)**：帽子管角色并行；菱形管阶段扩收。可在同一步内戴帽。
- **与[SCQA](../scqa/SKILL.md)**：步 3 收敛定义时常写出读者的 Q。
- **与[决策矩阵](../decision-matrix/SKILL.md)** / **[优劣势清单](../pros-cons-list/SKILL.md)**：服务步 5 收敛选型。

## 记忆钩子

两轮「先宽后窄」：先找对问题，再找对方案——扩的时候别杀，收的时候别飘。
