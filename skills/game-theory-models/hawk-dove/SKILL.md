# 鹰鸽博弈 Hawk–Dove Game

## 这是什么

**争夺资源时，攻击（鹰）与退让（鸽）的收益随对手策略与受伤成本而变。**

Maynard Smith：资源价值 V、打架成本 C；若 C>V，混策略或多态为演化稳定。与斗鸡支付同构常见。解释仪式化冲突、升级与分享。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "鹰鸽博弈"
- "强硬派和温和派各多少"
- "抢资源会不会打起来"

**不要**在以下情况套用本模型：

- 两人边缘政策故事优先 → ../chicken-game/SKILL.md
- 要 ESS 不可入侵定义 → ../evolutionary-stable-strategy/SKILL.md
- 不对称搭便车 → ../boxed-pigs/SKILL.md

## 怎么用（执行步骤）

1. **估计 V 与 C。** 资源价值 vs 冲突损伤；C≤V 时鹰可能纯策略占优。
2. **写 2×2 支付。** 鹰对鹰两败、鹰对鸽鹰胜、鸽对鸽分享。
3. **读均衡。** 纯或混；翻译为“强硬频率”。
4. **干预。** 提高 C（执法）、降低 V（另辟资源）、或不对称角色（资产拥有者）。输出：V/C 判断 + 建议。

## 例证

**动物仪式化争斗**：真打成本高则展示多于死斗。揭示 C>V 的稳定。

**职场抢项目**：撕破脸成本高时更多象征性竞争。

## 什么时候不适用（边界）

- **文化支付**：面子可改变 V/C。
- **与斗鸡标签**：同构时选叙事：政策边缘用斗鸡，演化用鹰鸽。

## 常见误用

- **鼓励无脑当鹰**：忽略 C。
- **当成道德分类人**：是策略而非人格本质。

## 相关模型

- **与[演化稳定策略](../evolutionary-stable-strategy/SKILL.md)**：ESS 解概念。
- **与[斗鸡博弈](../chicken-game/SKILL.md)**：二人边缘叙事。

## 记忆钩子

资源值多少、打架疼不疼，决定鹰有多少。
