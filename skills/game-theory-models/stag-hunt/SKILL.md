# 猎鹿博弈 Stag Hunt

## 这是什么

**合作猎鹿收益最大，但需互信；单打兔子更安全。**

卢梭寓言形式化：两个纳什——帕累托优的（鹿,鹿）与风险占优的（兔,兔）。关键不是优势背叛，而是信任与战略风险。契约、保证、小步合作可降低风险。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "猎鹿博弈"
- "想合作但怕对方跑"
- "安全选择压过最优合作"

**不要**在以下情况套用本模型：

- 背叛是优势策略 → ../prisoners-dilemma/SKILL.md
- 硬碰硬最差 → ../chicken-game/SKILL.md
- 只是选同一惯例无风险差 → ../coordination-game/SKILL.md

## 怎么用（执行步骤）

1. **填支付确认双纳什。** 合作合作最优；背叛背叛亦纳什且常更“安全”。
2. **比较风险占优 vs 收益占优。** 对方稍有可能选兔时，我是否也该选兔？
3. **设计信任脚手架。** 保证金、可见行动、分阶段、第三方保证。
4. **输出。** 结构=猎鹿 + 当前卡在哪一均衡 + 迁向猎鹿的具体装置。

## 例证

**卢梭猎鹿**：弃鹿打兔更稳。揭示社会合作的信任瓶颈。

**团队创新 vs 保守 KPI**：一起冲新业务更好，但怕同事躺平则各自保 KPI。

## 什么时候不适用（边界）

- **误标囚徒**：若合作不是纳什，不是猎鹿。
- **文化差异**：风险敏感度改变均衡选择。

## 常见误用

- **只喊愿景不降风险**：迁均衡要改战略风险。
- **与协调博弈无差别使用**：猎鹿强调安全—收益张力。

## 相关模型

- **与[协调博弈](../coordination-game/SKILL.md)**：多均衡汇聚；猎鹿是带安全张力的特例谱系。
- **与[囚徒困境](../prisoners-dilemma/SKILL.md)**：合作非纳什走对方。

## 记忆钩子

鹿更香，兔更稳——缺的是放心。
