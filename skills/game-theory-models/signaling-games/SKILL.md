# 信号博弈 Signaling Games

## 这是什么

**知情方发信号，不知情方据此推断类型并行动。**

Spence 教育信号等：分离均衡（不同信号暴露类型）vs 混同均衡（信号无信息）。关键是信号成本结构——廉价空话难分离。接收方策略含信念更新。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "怎么证明我是好类型"
- "信号够不够贵"
- "分离还是混同"

**不要**在以下情况套用本模型：

- 无信号结构的不完全信息 → ../bayesian-games/SKILL.md
- 设计整套激励兼容规则 → ../mechanism-design/SKILL.md
- 无信息不对称的协调 → ../coordination-game/SKILL.md

## 怎么用（执行步骤）

1. **定义类型、信号集、接收方行动。** 谁知情、谁选择信不信/雇不雇。
2. **比较信号成本是否随类型变化。** 好类型发真信号是否相对更便宜？否则难分离。
3. **检验分离 vs 混同。** 接收方更新后是否还愿按推断行动？发送方是否想模仿？
4. **输出。** 均衡类型（分离/混同/准分离）+ 使信号可信的最小条件。

## 例证

**Spence 教育**：教育成本与能力负相关时可分离。揭示信号不必有直接生产力。

**质保与烧钱广告**：低质厂商更怕兑现质保。揭示成本差异创造可信。

## 什么时候不适用（边界）

- **廉价谈话**：无成本宣言常混同。
- **多重均衡**：同一成本结构可有多均衡，需焦点或制度。

## 常见误用

- **以为有信号就有信息**：混同时信号零信息。
- **鼓励造假信号**：不协助欺诈性披露设计。

## 相关模型

- **与[贝叶斯博弈](../bayesian-games/SKILL.md)**：更广的不完全信息框架。
- **与[机制设计](../mechanism-design/SKILL.md)**：设计者选规则时走对方。
- **与[信任博弈](../trust-game/SKILL.md)**：用贵信号示可信。

## 记忆钩子

信号要够贵，谎言才装不起。
