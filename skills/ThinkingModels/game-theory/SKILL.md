# 博弈论 Game Theory（入门切片）

## 这是什么

博弈论研究**策略相互依赖**的决策：至少两方，每人的收益取决于自己与他人的行动组合。入门只需四块：

1. **参与人 Players**：谁做选择（含“自然”若只是随机，通常另议）。
2. **策略 Strategies**：每人可选行动（可先用离散、同时行动的标准式）。
3. **收益 Payoffs**：每个行动组合下各方得失（数字或明确排序）。
4. **解的直觉**：
   - **优势策略**：无论对方怎么选，某一策略都更好——若存在，应优先识别；
   - **纳什直觉**：一组策略使得每人在对方如此选时都不想单方面偏离（互相最佳回应）；
   - **囚徒困境**：个人理性（优势策略招供）导致集体更差（相对都沉默）——结构示范，不是人生哲学。

本 skill **不是**博弈论全书：不做混策略计算教学、不完全信息贝叶斯博弈、拍卖与机制设计深水、演化稳定策略全文。

## 什么时候用

- 定价战、军备式加班、合作泄密、公共品“搭便车”等互动场景；
- 需要把“我想…但怕对方…”写成矩阵；
- 用户直接说博弈论 / 囚徒困境 / 纳什 / 优势策略。

**不要**当主模型：
- 只有你一人在不确定下选择 → [`decision-tree`](../decision-tree/SKILL.md)；
- 反馈回路与存量 → [`systems-thinking`](../systems-thinking/SKILL.md)；
- 单次习惯行为设计 → [`fogg-behavior-model`](../fogg-behavior-model/SKILL.md)。

## 怎么用（执行步骤）

1. **点名局中人与同时/序贯。** 先两人、有限策略；写清是否看见对方行动。
2. **列出策略与支付。** 画 2×2（或小表）；支付至少做到序数（谁更好）。禁止空谈“双赢”却不写数字/排序。
3. **先搜优势策略。** 对每个参与人：是否有一列/行严格更优？有则标出；双方都有优势策略时，结局常直接读出（如经典囚徒困境的招供—招供）。
4. **用纳什直觉检查稳定。** 问：若对方停在该格，我是否还想单方面改？双方都不想改 → 纳什候选。注意：纳什**不一定**社会福利最优。
5. **若要合作，改博弈而不只改口号。** 重复博弈、可执行契约、第三方执行、改变支付——在模型外引入制度。输出：矩阵 + 优势/纳什判断 + 可选规则改法。不教欺诈催收式骗术优化。

## 例证

**囚徒困境**：两囚犯各有沉默/招供；支付使招供为优势策略，均衡劣于都沉默。揭示**个人理性可与集体理性冲突**——合作解常来自重复或制度，不在一次性矩阵内“感化”。

**价格战**：两家降价都有短期占优诱惑，均衡利润两败；差异化或默契（需合法合规）改变支付结构。揭示先建模再谈“要不要打”。

**（原书卡片）纳什与激励结构**：点名有用；局限是堆术语+励志“人生如棋”，缺少强制写支付矩阵的步骤，也易把纳什误读成“公平/最优”。

## 什么时候不适用（边界）

- **支付不可知且无法估计**：先补 5W1H/调研，不硬编矩阵装懂。
- **零和直觉乱套正和协作**：合伙做大蛋糕场景勿默认你死我活。
- **伦理拒绝**：不协助设计诈骗、串谋违法、剥削性陷阱。
- **超入门范围**：连续策略、混策略计算、拍卖设计等应换专业工具/文献。

## 相关模型

- **与[决策树](../decision-tree/SKILL.md)**：决策树服务单决策者；博弈服务互动依赖。
- **与[系统思维](../systems-thinking/SKILL.md)**：系统看回路与延迟；博弈看策略与支付。
- **与[逆向思维](../inversion/SKILL.md)**：可问“如何让合作崩溃”，用于压力测试制度，但结论需合法。
- **与[机会成本](../opportunity-cost/SKILL.md)**：支付里应体现放弃的替代，避免只算会计利润。
