# Strategy & Competition

波特五力、护城河、飞轮、SWOT，以及蓝海、第二曲线、颠覆式创新、BCG、GE 九宫、麦肯锡 7S、OKR、VRIO，并含安索夫、BSC、价值链、通用战略/战略钟、定位、平台、RBV/核心能力、KPI 等战略与竞争分析 Skill。

与兄弟分类分流：产业与主体竞争战略；博弈专条见 `game-theory-models/`，执行循环见 `efficiency-execution/`。护城河/五力/SWOT **不重建**。

路径：`skills/strategy-competition/<skill-name>/SKILL.md`。

当前合计 **24** 个（迁入种子 4 + M3 新建 6 + 7S/GE 九宫 2 + 本批新建 12，均含 `v0.x-draft`）。

## Skills

- **[ansoff-matrix](./ansoff-matrix/SKILL.md)** — 安索夫矩阵：现有/新市场×现有/新产品四象限增长路径与风险阶梯。
- **[balanced-scorecard](./balanced-scorecard/SKILL.md)** — 平衡计分卡：财务/顾客/流程/学习成长四维因果链与战略地图。
- **[bcg-matrix](./bcg-matrix/SKILL.md)** — BCG 矩阵：增长×相对份额四象限指导组合投砍。
- **[blue-ocean](./blue-ocean/SKILL.md)** — 蓝海战略：价值创新与 ERRC 重建买方效用与成本边界。
- **[core-competence](./core-competence/SKILL.md)** — 核心能力：跨业务共享、难模仿、打开多市场的能力组合。
- **[cost-leadership](./cost-leadership/SKILL.md)** — 成本领先：广阔市场结构性最低成本优势。
- **[differentiation-strategy](./differentiation-strategy/SKILL.md)** — 差异化战略：全市场可感知独特性与溢价/优先选择。
- **[disruptive-innovation](./disruptive-innovation/SKILL.md)** — 颠覆式创新：低端/新市场轨迹与在位者非对称激励。
- **[economic-moat](./economic-moat/SKILL.md)** — 经济护城河：评估企业能否在竞争下维持超额回报及壁垒来源与衰减。
- **[flywheel](./flywheel/SKILL.md)** — 飞轮：设计或诊断互相加强的因果闭环，使每一圈投入提高下一圈效率或需求。
- **[ge-mckinsey-matrix](./ge-mckinsey-matrix/SKILL.md)** — GE-麦肯锡九宫：行业吸引力×竞争实力九格指导投/选/撤（多因子，细于 BCG）。
- **[kpi-framework](./kpi-framework/SKILL.md)** — KPI 框架：少而尖关键指标设计与 Goodhart 警示。
- **[mckinsey-7s](./mckinsey-7s/SKILL.md)** — 麦肯锡 7S：硬三/软三绕共同价值观对齐，诊断战略落地的组织 congruence。
- **[niche-strategy](./niche-strategy/SKILL.md)** — 利基/集中战略：窄战场上的成本或差异化焦点。
- **[okr](./okr/SKILL.md)** — OKR：鼓舞性目标 + 可度量关键结果对齐与复盘（非待办清单）。
- **[platform-strategy](./platform-strategy/SKILL.md)** — 平台战略：多边市场、网络效应、冷启动与治理变现。
- **[porters-five-forces](./porters-five-forces/SKILL.md)** — 波特五力：在行业层面诊断现有竞争、进入、替代、买方与供方议价对利润池的压力。
- **[positioning](./positioning/SKILL.md)** — 定位：目标顾客心智中的清晰可防守位置。
- **[resource-based-view](./resource-based-view/SKILL.md)** — 资源基础观：内生异质资源/能力解释可持续优势。
- **[second-curve](./second-curve/SKILL.md)** — 第二曲线：在第一增长曲线趋缓前启动下一条 S 曲线并管理输血/停投。
- **[strategic-clock](./strategic-clock/SKILL.md)** — 战略钟：价格×感知价值竞争路径，识别夹在中间。
- **[swot](./swot/SKILL.md)** — SWOT：内外部态势结构化盘点并做 SO/WO/ST/WT 匹配导向行动；禁止无证据洗衣单。
- **[value-chain](./value-chain/SKILL.md)** — 价值链：主活动/支持活动拆解成本与差异化落点。
- **[vrio](./vrio/SKILL.md)** — VRIO：资源/能力是否有价值、稀缺、难模仿且有组织支持。
