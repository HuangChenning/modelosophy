# 光环效应 Halo Effect

## 这是什么

**光环效应**（Thorndike 等）：评价者从**一个显著的优良特质**（或差特质）出发，**不当地外推**到其他无关维度，使整体印象被单一光环笼罩。

机制是认知节约：用易得的中心特质当启发式。商业上常见于品牌光环、雇主品牌、教师期望之前的印象污染。

## 什么时候用

- "面试因名校/外表高估全面能力"
- "因为爱品牌所以宽容产品缺陷"
- "一次演讲好就被当成全能"

**不要**当主模型：
- 群体标签套个体 → [`stereotyping`](../stereotyping/SKILL.md)
- 序列记忆首尾 → [`serial-position-effect`](../serial-position-effect/SKILL.md)
- 把己意投射他人 → [`projection-effect`](../projection-effect/SKILL.md)

## 怎么用（执行步骤）

1. **拆维度。** 列出需评价的独立维度（执行、协作、诚信、专业深度…），禁止一个总分开场。
2. **每维独立取证。** 每维至少一条行为证据；找不到就标“未知”，不许用光环填充。
3. **标中心特质。** 写下可能产生光环的显著点（外表、名校、口才、过往雇主）。
4. **做相关性质疑。** 该特质与目标维度有多强的可辩护相关？弱相关则降权。
5. **对照盲评。** 可能时隐藏光环信息（匿名作品、结构化面试）再比一次分数。

## 例证

**Thorndike 军官评定**：各维度评分被高度相关，疑似整体印象污染。揭示**光环统计指纹**。

**品牌延伸**：旗舰好感外溢到周边品。揭示商业光环；也解释劣品被宽容。

**教师印象**：整洁学生被估更高能力（经典社会心理演示取向）。揭示教育场景风险。

## 什么时候不适用（边界）

- **确证的能力簇**：若多维被同一潜变量真实驱动，高相关不是光环错误。
- **快速筛选阶段**：可暂时用粗启发式，但要标注“未拆维”。
- **审美判断本身**：只评“观感”时不存在外推问题。

## 常见误用

- **反向丑化**：一点瑕疵全面否定（负向光环/尖角效应）同样要拆维。
- **与刻板印象混用**：刻板是群体标签；光环是个体中心特质外推。
- **取消一切第一印象**：印象可作假设，不可作证据。

## 相关模型

- **与[刻板印象](../stereotyping/SKILL.md)**：刻板从群体到个体；光环从单特质到全能。
- **与[系列位置效应](../serial-position-effect/SKILL.md)**：首因可启动光环，但记忆位置≠光环机制。
- **与[皮格马利翁效应](../pygmalion-effect/SKILL.md)**：期望可改变表现；光环是评价被污染。
- **与[彼得原理](../peter-principle/SKILL.md)**：本岗光环污染升迁决策。
