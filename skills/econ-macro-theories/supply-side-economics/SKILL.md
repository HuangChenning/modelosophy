# 供给学派 Supply-Side Economics

## 这是什么

**通过减税、放松管制等激励生产端，提高潜在产出而非只刺激需求。**

提出者/源流：1970s–80s 美国供给学派（Laffer、Wanniski 等）；政策实践如里根经济学。产出受劳动、资本、技术与激励约束。高边际税率与繁琐管制抑制工作、投资与创业；改善供给可同时缓解滞胀式「高通胀+低增长」。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "「减税能不能刺激干活和投资」"
- "「滞胀是不是该改供给」"
- "「管制是不是把企业憋死了」"

**不要**在以下情况套用本模型：

- 衰退主因是去杠杆/有效需求不足 → 凯派/资产负债表衰退
- 把「减税」偷换成「永远减、不问税基与公共服务」

## 怎么用（执行步骤）

每一步给出可操作判据；禁止只换说法重复结论。

1. **确认瓶颈在供给。** 证据：产能满、岗位空缺、关键投入短缺、监管合规成本高；而非订单消失。
2. **列激励扭曲清单。** 边际税率、退出成本、准入壁垒、要素流动障碍——每条写「扭曲了谁的边际决策」。
3. **设计可验证的供给措施。** 减税/加速折旧/简化许可等；必须定义 12–24 个月可观察指标（投资、劳动参与、潜在产出代理）。
4. **对账财政与分配。** 静态收入损失 vs 动态税基扩大（接拉弗曲线，但勿假设自筹）；写清谁受益、公共服务是否受损。

## 例证

**1980s 美国减税与去管制争论**：揭示供给激励可影响潜在增长，但赤字与分配效应同期放大——成功叙事常被选择性记忆。

**能源瓶颈期只发消费券**：揭示需求刺激撞上供给墙会变通胀；应先扩产能/疏通。

**创业税率与公司注册摩擦**：揭示「小步放松」也可能改变边际创业决策。

## 什么时候不适用（边界）

- **需求主导衰退**：企业有产能无订单时减税难立竿见影。
- **垄断租金减税**：减税落入垄断租金而非增产 → 先竞争政策。

## 常见误用

- **拉弗万能**：任何减税都自称自筹 → 走拉弗曲线严格检验临界点。
- **忽略公共品融资**：减税砍掉关键公共投资反而伤长期供给。

## 相关模型

- **与[拉弗曲线](../laffer-curve/SKILL.md)**：税率—税收收入关系是供给学派常用图示；本模型更宽（管制/要素）。
- **与[索洛增长模型](../solow-growth-model/SKILL.md)**：长期供给由资本与技术进步决定；供给学派谈激励如何影响积累与创新。
- **与[凯恩斯主义](../keynesianism/SKILL.md)**：需求缺口 vs 供给约束——先诊断再选边。
- **与[涓滴经济学](../trickle-down-economics/SKILL.md)**：政策工具箱重叠；涓滴是分配叙事标签。
