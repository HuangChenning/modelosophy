# 逆向思维 Inversion

## 这是什么

逆向思维在这里取的是决策里可执行的那一层：**先把目标反转到失败空间，列出怎样保证失败，再逐条避免。** 芒格把它压缩成 "Invert, always invert"，并常归到 19 世纪数学家 Carl Jacobi；原话是否出自 Jacobi 本人有争议，但芒格的用法是清楚的——长期优势来自"持续地不变蠢"，而不是"持续地更聪明"。

它和两种常被叫成"逆向"的东西不是一回事：

| | 本模型（Inversion） | 不是本模型 |
|---|---|---|
| 操作 | 列出导致失败的因素，改成回避动作 | 把现行手段对调、唱反调、标新立异 |
| 产物 | 一份可执行的"禁止清单 + 对应动作" | 一个相反的点子 |
| 适用 | 成功/失败边界清楚的目标 | 目标本身还没定义 |

Gary Klein 的事前验尸（premortem）是同一操作的团队版：假设项目已经失败，请每个人写出原因，再针对性设防。**分流判据**：个人/分析场景走本模型；要组织一场会议、需要主持流程与匿名机制 → [`pre-mortem`](../../decision-probability/pre-mortem/SKILL.md)。

## 什么时候用

用户卡在正向路径上，或需要在行动前做失败审查：

- "怎么把这次发布做成功我想不出来"；
- "帮我看看这件事可能怎么搞砸"；
- 新业务、新习惯、投资决策的风险预演；
- 用户说"逆向思维"、"反过来想"、"invert"。

**不要**在以下情况套用本模型：
- 目标是开放的（"做让人喜欢的东西"、"更有创意"）——失败空间极大，列不完，也约束不了方向；先把"失败"定义到可判定，或换第一性原理去拆约束；
- 用户其实在几个具体方案里做取舍（机会成本），或在几个解释里排序（奥卡姆剃刀）。

## 怎么用（执行步骤）

1. **先写清目标，以及怎样算失败。** 失败必须可判定（"三个月内没拿到第二个付费客户"、"上线一周可用性低于 99%"），不能是"做得不好"。若用户给的是开放目标，先帮他把失败收成一条可判定的句子，再往下走；若他坚持目标必须保持完全开放、不肯给失败边界，本模型没有抓手——不要硬编一份失败清单，改问是不是该用第一性原理拆约束，或先把目标本身谈清楚。
2. **把问题反转。** 问："假如一年后这件事已经失败了，最可能的原因是什么？" 或："如果我故意要搞砸，我会怎么做？" 按人、流程、激励、约束四类把失败模式列全，宁多勿少。正向想不出来的时候，失败清单通常仍然写得出——这是本模型成立的经验前提。
3. **每一条失败模式都必须变成一个具体回避动作。** "沟通不好"不是动作；"关键决策以书面纪要在 24 小时内同步，没有纪要就不进入下一步"才是。想出对立面就结束，是最常见的假完成。
4. **在清掉的地雷阵里，再补正向建造。** 本模型不是悲观主义，也不替代目标本身。它负责标出"绝对不要去的地方"；往哪走，仍要有正向路径。只回避、不建造，会停在"不失败"的空台上。
5. **禁止把"反过来做"当成方法。** 对手涨价你就降价、别人做 A 你做非 A，那是对着干，不是 inversion。司马光砸缸那种"换一个被操作的变量"是有用的问题重述，但它只覆盖本模型的一个特例，不能代替失败清单。

## 例证

**芒格 1986 年 Harvard School（洛杉矶预科学校，非哈佛大学）毕业典礼演讲里的"如何保证悲惨一生"**：不讲怎样幸福，而是列出足以毁掉一生的要素——滥用药物、嫉妒、怨恨、不守信、拒绝从别人的错误里学习——然后避免它们。它揭示的是 inversion 的主用法：失败模式往往比成功配方更容易穷举，也更有行动含义。

**事前验尸（Klein）**：项目启动前，让团队假装"已经失败了"，各自写下原因。比起会后复盘，它利用的是前瞻性事后诸葛亮（prospective hindsight）——人在想象"已经发生"时，比在想象"可能会发生"时更能说出具体机制。这揭示的是 inversion 作为**流程**的一面，而不只是个人灵光。

**投资上的"怎样让一家公司破产"**：芒格会倒过来问，若要毁掉这家公司会动哪些杠杆（杠杆过高、激励扭曲、客户集中、文化容不下坏消息），再看管理层是否正在踩这些坑。这比直接罗列"护城河清单"更难自我感觉良好，因为失败清单打的是具体机制，不是优点形容词。

**（原书卡片）司马光砸缸**：正向是"人离开水"，逆向是"水离开人"。这个例子展示的是**约束反转**——换一个被移动的变量，问题变得可解。它有启发，但覆盖面窄：它不产生失败模式清单，也很容易被理解成"凡事反过来做"。原书在品牌/产品/人才上给的"认知 A → 认知 −A"框架，若停在对立面而不落到回避动作，就还停留在思维游戏。

## 什么时候不适用（边界）

- **对"避免失败"类的封闭目标效果最好**（不破产、不上线事故、不失信）；对开放式创造目标效果有限——"不是失败"的空间太大，列失败模式约束不了该做成什么样。
- **不是悲观，也不是只做减法。** 清完地雷之后仍要有正向建造。塔勒布的 Via Negativa 看起来像，但那是反脆弱里"靠移除脆弱性来源，使系统能从波动中获益"的配置原则；本模型是针对**已定义目标**的思考程序，不要求杠铃结构，也不处理尾部收益不对称。
- **想出对立面不是完成。** 没有可执行回避动作，等于没用过。
- **不要和对着干混淆。** 主流为 A 所以选 −A，可能只是另一种未经检验的类比。

## 常见误用

- **把逆向等同于"对着干"**：对手涨价就降价、别人做 A 就做非 A，当成用了逆向思维 → 这只是手段对调，不是失败模式清单；正确操作是先问"怎样保证这件事搞砸"。
- **想出对立面就收工**：写下"沟通不好""执行力差"这类空泛失败原因，不落到第 3 步要求的具体回避动作 → 没有可执行动作等于没用过本模型。
- **对开放目标硬凑失败清单**：给"做一个更好的产品"这种没有失败边界的目标做事前验尸，清单又长又不聚焦 → 应先把目标收成可判定的失败句子，谈不拢就改用第一性原理拆约束。
- **只排雷、不建造**：清完地雷阵后没有第 4 步的正向路径，把"不失败"误当成目标本身已经完成 → 本模型只负责标出禁区，往哪走仍需要正向方案。

## 相关模型

- **与[反脆弱](../../learning-growth/antifragility/SKILL.md)**：Via Negativa 是反脆弱的工具之一，服务于"下行有限、上行无限"的结构；本模型服务于"这个目标怎样避免失败"。用户问"不确定下怎么配置仓位"走反脆弱；用户问"这件事怎么搞砸、我该禁止什么"走本模型。可以连用：先 inversion 列出归零路径，再反脆弱把那些路径压到输得起的一角。
- **与[第一性原理](../first-principles/SKILL.md)**：第一性原理从基本约束往上重建；本模型从失败往回拆。用户面对的是"行业都这么做，但物理上不一定"走第一性原理；用户面对的是"目标清楚但正向路径卡住 / 要做失败预演"走本模型。
- **与[奥卡姆剃刀](../occams-razor/SKILL.md)**：奥卡姆剃刀在解释之间排序；本模型在行动的失败模式上设防。
- **与[苏格拉底式质疑](../../thinking-models/socratic-questioning/SKILL.md)**：苏格拉底式质疑检验主张；本模型设计对失败的回避。
- **与[事前验尸](../../decision-probability/pre-mortem/SKILL.md)**：个人/分析场景走本模型；要组织一场会议、需要主持流程与匿名机制走 pre-mortem。两者是同一操作在不同场景下的变体，不是互相替代。
