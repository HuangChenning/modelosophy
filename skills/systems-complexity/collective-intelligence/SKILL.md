# 集体智能 Collective Intelligence

## 这是什么

**集体智能**：群体在适当条件下，对某些问题的判断/解决方案优于典型个体。经典使能条件（可操作版）：

1. **认知多样性**（不同视角/信息）
2. **独立性**（减少坍缩到同一错误）
3. **分散的本地信息**
4. **公正的聚合机制**（均值、市场、预测市场、结构化辩论——非喊得最大）

缺一条，集体可变成**集体愚蠢**（信息瀑布、极化、迎合）。

## 什么时候用

- "要不要众包 / 集体决策会不会更准"
- "集体智能 / 群体智慧 / 如何聚合判断"
- 预测、诊断、创意筛选、跨职能问题解决

**不要**当主模型：
- 只要宏观涌现描述 → [`emergence`](../emergence/SKILL.md)
- 只要网络连法 → [`network-topology`](../network-topology/SKILL.md)
- 只要投票博弈策略 → 博弈论相关专条
- 路径锁定解释失败 → [`path-dependence`](../../systems-classic-effects/path-dependence/SKILL.md)

## 怎么用（执行步骤）

1. **定义问题类型。** 估计类 / 组合搜索 / 价值冲突？判据：问题可检验对错或可比较方案。
2. **检查多样性。** 成员信息与模型是否同质？同质则先扩样本或红队。
3. **保护独立性。** 先独立作答再讨论；公开领导意见会污染。判据：流程有「独立轮」。
4. **选聚合器。** 数值→去极值均值/中位；方案→多阶段筛选；概率→预测市场/对数评分。判据：聚合规则事先写明。
5. **设计连接。** 小世界式适度捷径利于信息；全连接易瀑布。可链拓扑。
6. **监测失败模式。** 瀑布、极化、免费搭车、被激励扭曲——触发则改流程。

## 例证

**谁想要成为百万富翁式观众投票 / 预测市场**：多样独立时可准。揭示：聚合机制重要。

**灾难中的错误共识**：可见的公共信号压倒私有信息 → 瀑布。揭示：独立性被破坏。

**（原书卡片）**：勿神化「群众」；落到四条件检查表。

## 什么时候不适用（边界）

- **专业门槛极高且不可分解**：专家加权，而非平均素人。
- **价值/伦理冲突**：智能聚合不解规范性分歧。
- **对抗性操纵**：机器人刷票、信息战——先安全。

## 常见误用

- **多数 = 集体智能**：无独立性的多数可错。
- **与涌现混用**：涌现未必「更聪明」。
- **开会等于聚合**：无结构的会常毁独立性。

## 相关模型

- **与[涌现](../emergence/SKILL.md)**：集体智能是一种可设计的认知涌现；要机制不是修辞。
- **与[网络拓扑](../network-topology/SKILL.md)**：连接影响瀑布与传播。
- **与[复杂适应系统](../complex-adaptive-systems/SKILL.md)**：主体适应可改变集体表现。
- **与[红队](../../decision-probability/red-team/SKILL.md)**：刻意注入异议以保多样性。

## 记忆钩子

多样、独立、再聚合——缺一就会变成集体愚蠢。
