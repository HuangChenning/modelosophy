# 周哈里窗 Johari Window

## 这是什么

周哈里窗（Joseph Luft & Harrington Ingham, 1955）是群体动力学里的自我与他人认知模型。按“自己是否知道 × 他人是否知道”切成四格：

| | 自己知道 | 自己不知 |
|---|---|---|
| **他人知道** | **开放区** Open：双方共享的行为/信息 | **盲目区** Blind：他人看得见的习惯/影响，自己未察觉 |
| **他人不知** | **隐藏区** Hidden：有意保留的信息 | **未知区** Unknown：双方皆未觉察，待共同探索 |

常用杠杆：通过**征求反馈**把盲目→开放；通过**自我披露**把隐藏→开放；未知区靠新经验、共同实验与事后复盘慢慢缩小——不是一次“挖潜意识”仪式。

它是**沟通与团队发展工具**，用来减少协作中的误判与提高可预测性；不是人格测验，更不是精神障碍诊断。

## 什么时候用

- 一对一/团队想建立可协作的互知，减少“我以为你知道”；
- 收到重复反馈但当事人不理解盲点；
- 直接提周哈里窗 / Johari / 盲区 / 自我披露。

**不要**当主模型：
- 能力自评 vs 测验落差机制争议 → [`dunning-kruger`](../../behavioral-biases/dunning-kruger/SKILL.md)；
- 会议分角色 → [`six-thinking-hats`](../six-thinking-hats/SKILL.md)；
- 追问主张逻辑 → [`socratic-questioning`](../socratic-questioning/SKILL.md)；
- 临床心理问题 → 转介专业人士，本模型只谈工作/学习反馈。

## 怎么用（执行步骤）

1. **约定议题边界与自愿原则。** 只开放与协作相关的行为（会议打断、交付质量、决策风格），排除强迫披露创伤、私生活、健康细节。无心理安全则先降级为单向书面反馈，不强开窗。
2. **画当前四格（粗即可）。** 每人列出：我已知且愿分享的；我猜测的盲点；我暂不分享的；双方都不确定的。目的是对齐语言，不是精确测量。
3. **选一条反馈路径缩小盲目区。** 请 1–3 个观察者给**具体行为例子**（时间、场景、影响），当事人只复述确认，不辩护。把验证后的条目移入开放区。
4. **选一条披露路径缩小隐藏区。** 当事人自愿分享一条有助于协作的隐藏信息（偏好、约束、目标）。披露深度以“改善协作所需最小充分”为限。
5. **给未知区一个小实验，而非玄学挖掘。** 共同试一种新协作方式或角色轮换，约定观察指标，复盘后把学到的移入开放区。禁止把未知区解释成必须马上做深度治疗。

## 例证

**360° 行为反馈中的盲点**：多人报告“你结束讨论太快”，当事人自以为高效。揭示盲目区靠外部观察进入开放区。

**新团队自愿背景分享（原书李锦记式玩法的结构内核）**：在自愿与议题边界内分享经历，可扩大开放区、增进信任。局限：若权力压力下“自愿”，则变成强制披露，破坏安全。

**隐藏的优先级冲突**：成员不说自己同时扛三线，他人解读为消极。揭示隐藏区过大致协作误判；适度披露约束即可，无需自白一切。

**（原书卡片）开放30%玩 + 道德经自知者明**：团队互知方向对；收成道德训诫与“潜意识”措辞易滑向临床隐喻——本 skill 坚持群体动力学原义，未知≠病理性无意识。

## 什么时候不适用（边界）

- **非临床、非诊断**：不用于给他人贴精神疾病或人格障碍标签。
- **强制坦白 / 羞辱式“打开”**：权力不对等下的开窗是伤害，不是发展。
- **替代绩效制度**：窗模型不解决激励、编制、能力缺口本身。
- **安全保密信息**：合规、隐私、未公开交易信息不得为了“开放区”泄露。
- **把未知区神秘化**：不是要求挖掘童年创伤；工作场景用小实验与复盘即可。

## 相关模型

- **与[邓宁-克鲁格](../../behavioral-biases/dunning-kruger/SKILL.md)**：DK 看表现-自评落差；周哈里窗提供“他人知/己不知”的反馈结构。可组合，不互相替代。
- **与[六顶思考帽](../six-thinking-hats/SKILL.md)**：帽子管会议角色；窗管人际信息分布。
- **与[苏格拉底式质疑](../socratic-questioning/SKILL.md)**：质疑检验主张；窗管理披露与反馈节奏。
- **与[确认性偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：只听顺耳反馈会卡住盲目区。
- **与[双系统](../dual-process/SKILL.md)**：被反馈时的防御常由快系统触发；约定“先复述再回应”给慢系统空间。
