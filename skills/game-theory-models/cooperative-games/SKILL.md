# 合作博弈与联盟 Cooperative Games & Coalitions

## 这是什么

**焦点从非合作策略转向：哪些联盟能形成、集体剩余如何在成员间分配。**

特征函数 v(S) 给出联盟 S 可保证的价值。核、夏普利值、讨价还价集等是解概念。适用于合资、成本分摊、议会联盟——假设可签订有约束力协议。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "要不要组联盟"
- "合作博弈怎么分"
- "特征函数"

**不要**在以下情况套用本模型：

- 不能强制履约的策略互动 → ../nash-equilibrium/SKILL.md
- 只要边际贡献公平公式 → ../shapley-value/SKILL.md
- 只要核稳定性 → ../core/SKILL.md

## 怎么用（执行步骤）

1. **确认可缔约。** 否则回到非合作。
2. **写 v(S)。** 各子集能创造/保证的价值；检查超可加性直觉。
3. **提出分配 x。** ∑x_i=v(N)；对照个体与联盟理性。
4. **选解概念。** 核/夏普利等——指向专条细化。输出：v + 候选分配 + 风险联盟。

## 例证

**三家合资**：两两联盟与大联盟价值不同。揭示谁不可缺。

**成本分摊基建**：联盟分摊避免有人退出另建。

## 什么时候不适用（边界）

- **缔约能力弱**：纸面联盟无执行则退回非合作。
- **外部性**：简单 v(S) 可能不够。

## 常见误用

- **无 v(S) 空谈联盟**：必须量化联盟价值。
- **与正和口号等同**：正和是总量，合作博弈是分配装置。

## 相关模型

- **与[核](../core/SKILL.md)**：联盟无法改进的分配集。
