# 存量与流量 Stock and Flow

## 这是什么

**存量（stock）**：某一时刻的累积量（水位、库存、技能熟练度、用户数）。  
**流量（flow）**：单位时间改变存量的速率（流入/流出）。

核心恒等式（概念）：`存量(t+Δ) ≈ 存量(t) + (流入 − 流出)×Δt`。浴缸隐喻：水位是存量，水龙头/排水是流量——**只拧开讨论「流速」却不看水位，会误判**。

## 什么时候用

- "库存/现金/信任是怎么堆出来的"
- "存量流量 / stock and flow / 水平与速率"
- 要解释延迟、惯性、超调

**不要**当主模型：
- 只要讲故事回路 → [`causal-loop-diagram`](../causal-loop-diagram/SKILL.md)
- 概率决策树 → [`decision-tree`](../../decision-probability/decision-tree/SKILL.md)
- 纯网络拓扑 → [`small-world-network`](../small-world-network/SKILL.md) / [`scale-free-network`](../scale-free-network/SKILL.md)

## 怎么用（执行步骤）

1. **点名存量。** 问「此刻能数出来的量是什么？」判据：有单位（件、元、人、小时债务）。
2. **写流入与流出。** 每个存量至少考虑可能的增减通道。判据：通道有速率单位（件/周）。
3. **做单位与守恒检查。** 流入单位必须匹配存量/时间；禁止「把满意度箭头直接加进库存」除非定义转换。判据：单位方程过关。
4. **连反馈到流量。** 存量如何影响决策进而改变流量（信息反馈）。可与 CLD 对齐。判据：至少一条「存量→决策→流量」链。
5. **读动态含义。** 流量短暂大于流出 → 存量上升；要降存量必须让净流量为负足够久。判据：政策目标写成「目标存量 + 允许过渡时间」。
6. **需要时仿真。** 手算或简单模型；复杂则进入系统动力学工具，仍保持本结构。

## 例证

**技术债**：债务存量；「赶工」流入，「重构」流出。只停功能开发而不流出 → 存量仍高。

**现金**：收入流入、支出流出；利润率叙事不能替代存量跑道。

**（原书卡片）**：若有，检查是否混淆「速度」与「水位」。

## 什么时候不适用（边界）

- **无时间累积的分类问题**：MECE/矩阵即可。
- **瞬时决策且无状态**：期望值树可能更合适。
- **单位无法定义**：先澄清度量，再建模。

## 常见误用

- **把流量当存量**：把「本月新增」当成「用户总数」。
- **忽视流出**：只谈增长流入。
- **CLD 箭头直接当守恒**：定性图≠浴缸方程。

## 相关模型

- **与[因果回路图](../causal-loop-diagram/SKILL.md)**：先定性后定量；或由 S&F 反推回路。
- **与[系统动力学](../../systems-classic-effects/system-dynamics/SKILL.md)**：SD 是更大建模范式；本 skill 专攻存量流量基本功。
- **与[临界点](../tipping-point/SKILL.md)**：存量靠近阈值时流量小扰动可致翻转——可连用。
- **与[杠杆点](../leverage/SKILL.md)**：改流量规则/目标/信息延迟常是杠杆。

## 记忆钩子

先找水位（存量），再找水管（流量），单位对上才能谈政策。
