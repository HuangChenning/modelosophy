# Efficiency & Execution

艾森豪威尔矩阵、PDCA，以及番茄、GTD、看板、敏捷迭代、精益、关键路径、5S，并含批处理、清单/SOP、持续改进、委派、吃青蛙、精力管理、甘特、里程碑、站会、时间块、两分钟法则、WIP 限制等效率与执行类 Skill。

与兄弟分类分流：日程优先级与持续改进循环；战略态势见 `strategy-competition/`，学习成长见 `learning-growth/`。**深度工作**主条在 [`learning-growth/deep-work`](../learning-growth/deep-work/SKILL.md)，本类仅互链、不建第二份。80/20 时间法互链 [`pareto-principle`](../systems-classic-effects/pareto-principle/SKILL.md)。

路径：`skills/efficiency-execution/<skill-name>/SKILL.md`。

当前合计 **30** 个（迁入种子 2 + M3 新建 7 + 批次新建 12 + 名录扩容新建 9，`v0.x-draft`，达到名录目标数量）。

## Skills

- **[agile-iteration](./agile-iteration/SKILL.md)** — 敏捷迭代：短时间盒交付可检视增量并检视适应。
- **[batching](./batching/SKILL.md)** — 批处理：同类任务集中时段，降低上下文切换。
- **[buffer-time](./buffer-time/SKILL.md)** — 缓冲时间管理：拆下各任务的安全余量、集中到少数关键位置，用缓冲消耗速度而非单任务是否按期来预警（关键链 ≠ 关键路径）。
- **[checklist-sop](./checklist-sop/SKILL.md)** — 清单/SOP：关键步骤外部化，降低遗漏与方差。
- **[commitment-devices](./commitment-devices/SKILL.md)** — 承诺机制：在冷静状态下给未来行为绑上外部强制代价，让半途而废比做完更差。
- **[continuous-improvement](./continuous-improvement/SKILL.md)** — 持续改进：小步全员常态化抬高标准（Kaizen）。
- **[critical-path](./critical-path/SKILL.md)** — 关键路径：项目依赖网络中决定最短工期的最长链。
- **[delegation](./delegation/SKILL.md)** — 委派：结果与权限清晰移交并保留跟进。
- **[eat-the-frog](./eat-the-frog/SKILL.md)** — 吃青蛙：当日最高杠杆难事先做完。
- **[eisenhower-matrix](./eisenhower-matrix/SKILL.md)** — 艾森豪威尔矩阵：按紧急×重要分配注意力，优先重要但不紧急（第 II 象限）。
- **[energy-management](./energy-management/SKILL.md)** — 精力管理：按身心高峰匹配任务类型。
- **[five-s](./five-s/SKILL.md)** — 5S：整理整顿清扫清洁素养，稳固现场/数字工作区基础。
- **[gantt-chart](./gantt-chart/SKILL.md)** — 甘特图：时间条与依赖可视化沟通进度。
- **[gtd](./gtd/SKILL.md)** — GTD：收集-澄清-组织-回顾，落到可信的下一步行动。
- **[inbox-zero](./inbox-zero/SKILL.md)** — 收件箱清零法：核心不是未读数字归零，而是把「还没处理」的心智负担清空。
- **[kanban](./kanban/SKILL.md)** — 看板：可视化流 + 限制 WIP 的拉动系统。
- **[lean-thinking](./lean-thinking/SKILL.md)** — 精益思维：价值流与消除浪费（看板/5S 为其工具层）。
- **[meeting-hygiene](./meeting-hygiene/SKILL.md)** — 会议卫生：议程先行、唯一决策责任人、时间盒、控制人数等已验证有效的会议设计规则集合。
- **[milestone-planning](./milestone-planning/SKILL.md)** — 里程碑规划：可验证阶段门对齐范围与日期。
- **[mise-en-place](./mise-en-place/SKILL.md)** — 一切就位：执行前把物料/信息/权限准备到位，避免边做边找导致中断。
- **[pdca](./pdca/SKILL.md)** — PDCA：计划-执行-检查/学习-处理的持续改进循环，不是一次性瀑布。
- **[pomodoro](./pomodoro/SKILL.md)** — 番茄工作法：固定专注-短休时间盒节奏（≠深度工作长块）。
- **[single-tasking](./single-tasking/SKILL.md)** — 单任务处理：一段时间只处理一个任务，切换前主动收尾，而非被打断式切出。
- **[standup](./standup/SKILL.md)** — 站会：短同步昨日/今日/障碍。
- **[structured-procrastination](./structured-procrastination/SKILL.md)** — 结构化拖延：半开玩笑的悖论技巧——用对"大事"的拖延冲动导流去完成其他重要小事（不适用于真拖延成瘾）。
- **[task-switching-cost](./task-switching-cost/SKILL.md)** — 任务切换成本：切换任务后反应变慢、错误率升高，即使给了准备时间也无法完全消除（诊断/解释层，与 single-tasking 互补）。
- **[time-blocking](./time-blocking/SKILL.md)** — 时间块：日历切成专属用途连续时段。
- **[two-minute-rule](./two-minute-rule/SKILL.md)** — 两分钟法则：澄清时立刻完成≤2 分钟行动。
- **[weekly-review](./weekly-review/SKILL.md)** — 每周回顾：固定时间盒清空-核对-重定向三件事，可独立于 GTD 使用。
- **[wip-limits](./wip-limits/SKILL.md)** — WIP 限制：在制品上限暴露瓶颈、缩短周期。
