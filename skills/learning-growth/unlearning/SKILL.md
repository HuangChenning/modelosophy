# 去学习 Unlearning

## 这是什么

**去学习**：主动识别并**削弱、隔离或替换**已经不适用甚至有害的知识、程序与反应，使新学习不被旧组块绑架。它不是「遗忘症」，而是对失效心理模型的**有管理退役**。

旧技能自动化越强，负迁移风险越高（开车换对侧通行、API 大改、管理套路过时）。只加新课不加去学习，常见结果是压力下回到旧法。

**鉴别**：[`transfer-of-learning`](../transfer-of-learning/SKILL.md) 追求正迁移；去学习处理**负迁移/冲突**。[`growth-mindset`](../growth-mindset/SKILL.md) 支持「可变」；去学习给「哪一块必须弃用」的操作。

## 什么时候用

- "旧方法总冒出来干扰"
- "去学习 / 如何忘掉过时技能"
- 工具链大改版、行业范式切换、错误动力定型纠正

**不要**当主模型：

- 单纯没记住新内容 → [`retrieval-practice`](../retrieval-practice/SKILL.md)
- 只要练新法 → [`deliberate-practice`](../deliberate-practice/SKILL.md)（常需与去学习并用）
- 战略放弃业务 → 战略类 Skill，非个人认知去学习

## 怎么用（执行步骤）

1. **点名退役对象。** 写成具体触发→旧反应（「一看到报错就重启服务」），禁止「把以前都忘了」。
2. **判定：弃用 / 降级 / 隔离。** 全错→弃用；少数情境仍对→降级为条件规则；危险→隔离（检查清单强制新路径）。
3. **设计替换反应（若需要）。** 空缺易回潮；写新触发→新动作，并练到可提取。
4. **增加旧反应成本与觉察。** 检查表、同伴喊停、工具默认新流程；记录「差点用旧法」次数。
5. **在干扰情境中练习新法。** 专门设置旧线索出现的情境，练习不执行旧反应（抑制训练）。判据：旧线索下仍走新路径。
6. **验收与日落条款。** 连续 N 次实战无旧法回潮 → 正式退役；若旧法在新证据下又正确 → 更新条件，而非教条永不使用。

## 例证

**编程框架大版本**：生命周期钩子全改；不退役旧心智模型会持续写废弃 API——需对照表+强制 lint。

**运动改动作**：旧挥拍自动化干扰新教练要求——需慢速分解+录像抑制旧型。

**（局限）**：创伤性记忆或临床问题不在本技能范围；需专业帮助。

## 什么时候不适用（边界）

- **旧法仍是最优**：去学习变成追新癖——先证伪旧法。
- **无替换又必须行动**：先设安全默认，再弃旧。
- **把「忘记基础知识」当去学习**：基础仍要保持；弃的是失效程序。
- **组织政治性「否定历史」**：本模型只管认知/技能干扰，不服务清洗叙事。

## 常见误用

- **只学新不拦旧**：课上会、场上旧 → 必须练干扰情境。
- **神秘清空**：无法操作 → 回到触发—反应清单。
- **与迁移对立**：正迁移保留；去学习针对冲突部分。
- **情绪自我攻击**：「我怎么这么僵化」→ 改设计环境与替换，不道德化。

## 相关模型

- **与[迁移学习](../transfer-of-learning/SKILL.md)**：正迁移设计走迁移；负迁移/冲突走本模型。
- **与[刻意练习](../deliberate-practice/SKILL.md)**：新法需要有反馈的练习；去学习负责抑制旧自动化。
- **与[组块](../chunking/SKILL.md)**：错误组块要拆开重建；优质组块可保留。
- **与[元学习](../meta-learning/SKILL.md)**：淘汰失效学法（只重读）是策略层去学习。
- **与[反脆弱](../antifragility/SKILL.md)**：Via Negativa 减害与去学习可呼应，但反脆弱更广（系统获益于波动）。
- **与[成长型思维](../growth-mindset/SKILL.md)**：允许「旧我会错」；去学习给出弃用步骤。

## 记忆钩子

新路要铺，旧岔口也要设路障——否则压力一大就抄近路回旧法。
