# 拉弗曲线 Laffer Curve

## 这是什么

**税率从 0 到 100% 时，税收收入先升后降；过高税率可能少收税。**

提出者/源流：Arthur Laffer（1970s 通俗化；思想可追溯更早）。税率影响税基：过高抑制劳动/投资/引发避税，税基收缩使收入下降。曲线形状与峰值因税种、执法、开放度而异——峰值不是政治口号里的固定点。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "「再减税，税收反而更多？」"
- "「现在税率是不是高过临界点了」"

**不要**在以下情况套用本模型：

- 把分配正义或公共品需求问题伪装成拉弗峰值争论
- 公司战略定价 → 非本模型

## 怎么用（执行步骤）

每一步给出可操作判据；禁止只换说法重复结论。

1. **锁定税种与税基。** 所得税/资本利得/公司税？税基流动性如何（可否跨境迁移）？
2. **估行为弹性。** 找：历史改革后税基变化、学术弹性区间。无弹性证据 → 禁止宣称「自筹减税」。
3. **判断在峰值左还是右。** 若税率↓且税基↑幅度不足以抵消 → 仍在左段，减税减收；只有右段才可能增收。
4. **给出政策条件句。** 「若弹性 ≥ X 且避税渠道显著，则减税可能增收；否则按静态评分」。并列公共服务影响。

## 例证

**餐巾纸曲线的政治传播**：揭示概念易懂但也易被滥用为「任何减税都免费」。

**极高边际税率历史段落**：揭示接近没收性税率时，避税与退出真实发生——右段存在，但少见。

**烟草税等选择性商品**：揭示弹性因品而异；有的税种更接近「总能增收」。

## 什么时候不适用（边界）

- **开放经济资本高度流动**：峰值可能更左，但证据仍要国别化。
- **短期 vs 长期弹性**：长期行为调整更大，勿用一个月数据定峰值。

## 常见误用

- **峰值迷信**：声称「我们已经在右段」却无弹性证据。
- **偷换总福利**：税收增收≠社会福利最优（可能牺牲有价值活动）。

## 相关模型

> 只链到本批或仓库中真实路径；跨分类用相对路径。

- **与[供给学派](../supply-side-economics/SKILL.md)**：拉弗是供给学派的招牌图；供给学派还包括管制等。
- **与[涓滴经济学](../trickle-down-economics/SKILL.md)**：减税惠及上层再渗透——与拉弗「增收」主张常绑在一起，但可分开证伪。

## 记忆钩子

税率 100%，税收是 0——中间某处有个峰，但峰在哪得测量。
