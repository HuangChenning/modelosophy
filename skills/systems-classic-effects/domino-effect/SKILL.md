# 多米诺骨牌效应 Domino Effect

## 这是什么

**多米诺骨牌效应**：系统中单元**依次耦合**，一个单元的状态翻转（倒下）为下一个提供触发条件，形成**可见的连锁崩溃或传导**。

与蝴蝶效应不同：多米诺强调**沿已知拓扑的逐步触发**；蝴蝶强调非线性动力系统中微差导致长期不可预报。与破窗不同：破窗是规范信号，多米诺是能量/状态传递链。

## 什么时候用

- "供应链一环断导致全线停"
- "债务连锁违约"
- "配置变更引发级联故障"

**不要**当主模型：
- 混沌初值敏感 → [`butterfly-effect`](../butterfly-effect/SKILL.md)
- 规范失序传染 → [`broken-windows`](../broken-windows/SKILL.md)
- 低概率叙事冲击 → [`black-swan`](../black-swan/SKILL.md)

## 怎么用（执行步骤）

1. **画出耦合链。** 节点与触发条件（A 失败 ⇒ B 失败的机制）必须写清；画不出链就不要称多米诺。
2. **标临界与缓冲。** 哪些节点有冗余、库存、熔断、隔离区？
3. **找第一张可推倒的牌。** 最脆弱触发点与最大扇出点（倒下影响最多下游的节点）。
4. **设计隔断。** 熔断器、断路、限额、物理隔离、异步解耦——指定插在哪两张牌之间。
5. **压力测试。** 人为推倒一张牌，观察传导深度；传导被挡住才算控制有效。

## 例证

**电力级联停电**：局部过载跳闸导致更多过载。揭示**物理耦合连锁**。

**供应链单源器件**：一厂停摆，多整机停线。揭示产业多米诺。

**银行间拆借**：一家流动性危机传导同业（需结合监管与抵押品，勿简化）。揭示金融链条。

## 什么时候不适用（边界）

- **弱耦合系统**：局部失败可被旁路吸收。
- **纯叙事巧合**：“因为迟到所以人生失败”的故事链。
- **连续混沌放大**：机制是 SDIC 而非逐步牌倒，改用蝴蝶效应。

## 常见误用

- **事后编链**：任何坏事都串成多米诺 → 要事前可检验的耦合。
- **与蝴蝶混称**：不可预报混沌 ≠ 清晰牌阵。
- **只加固第一张**：扇出中心未隔离，连锁仍在。

## 相关模型

- **与[蝴蝶效应](../butterfly-effect/SKILL.md)**：蝴蝶问预报视界；多米诺问可隔断的触发链。
- **与[灰犀牛](../gray-rhino/SKILL.md)**：灰犀牛是可见高概率风险被忽视；多米诺是传导形态。
- **与[系统思维](../systems-thinking/SKILL.md)**：级联常是增强回路；升维看结构。
