# AIDA 框架 Attention–Interest–Desire–Action

## 这是什么

**AIDA** 是一套**面向陌生/冷受众**的四段说服结构：从引起注意开始，逐步建立兴趣、转化为购买欲望，最后引导具体行动。

| 字母 | 含义 | 作用 |
|---|---|---|
| **A** Attention | 注意 | 让原本不打算关注的受众停下来看一眼 |
| **I** Interest | 兴趣 | 讲清是什么、为什么和受众有关，维持关注 |
| **D** Desire | 欲望 | 把"我知道了/我喜欢"转化为"我想要" |
| **A** Action | 行动 | 给出清晰、低摩擦的下一步 |

**诚实说明来源**：AIDA 常被归因为 E. St. Elmo Lewis 在 1898 年发明，但这一归因证据其实薄弱——"AIDA"这个缩写本身要到 1921 年才由 C.P. Russell 在《Printers' Ink》上正式命名，Lewis 1898 年的原始表述能否直接对应现代四段框架存在学术争议。更准确的说法是：AIDA 是数十年间多位从业者（Lewis 提出萌芽思想 → Russell 命名 → Edward K. Strong Jr. 在 1925 年系统化）共同演化的产物，而非单一发明者的一次性创造，本 Skill 不为其编造一个确定无疑的单一起源。

它的核心机制是**为完全不认识你的受众设计一条从零建立认知到促成行动的路径**：Attention/Interest 两段专门服务于"从陌生到认知"，这是它与假设受众已有问题意识的 PAS 最本质的区别。

## 什么时候用

- "帮我写一段面向陌生流量的广告/落地页首屏文案"
- "产品发布/新用户第一次接触的文案怎么开场"
- 直接说 AIDA / 注意力-兴趣-欲望-行动
- 受众完全不认识我们、需要先被"看见"才有后续可能

**不要**当主模型：

- 受众已经知道自己有这个问题（重定向广告、暖名单邮件、直复式销售信）→ [`pas`](../pas/SKILL.md)，可以直接跳过认知建立、放大痛苦
- 用户要整个品牌/文档的叙事骨架 → [`storybrand-sb7`](../storybrand-sb7/SKILL.md)
- 用户要汇报/备忘录的中立问题定义开场 → [`scqa`](../scqa/SKILL.md)

## 怎么用（执行步骤）

1. **写 Attention（注意）：设计一个让受众停下来的钩子，区分"制造好奇"与"制造反感式噪音"。** 判据：受众是否会在原本不打算关注的情况下停下来看一眼，而不是被强行打断后立刻反感划走——耸动但和后续内容无关的标题属于后者，要重写。
2. **写 Interest（兴趣）：讲清"这是什么、为什么和你有关",维持已经被吸引的注意力。** 判据：这一步是否只是重复 Attention 的钩子，还是提供了新信息让受众愿意继续往下看？避免行业黑话，用受众熟悉的语言。
3. **写 Desire（欲望）：把"我知道了/我觉得有点意思"转化为"我想要"。** 判据：是否给出了具体的利益展示、前后对比或社会认同（案例/评价），而不是空泛地重复"我们很好"；情绪基调应是正向吸引（利益、信任），不是负向紧迫（那是 PAS 的 Agitate 的职责）。
4. **写 Action（行动）：给出清晰、低摩擦的下一步。** 判据：受众看完是否明确知道"现在具体点哪里/做什么",且这个动作的摩擦是否匹配受众当前的信任程度（对完全陌生的受众直接要求"立刻付费"摩擦过高，可先设一个更低门槛的过渡动作）。
5. **自检受众冷热。** 通读四段前先确认：这批受众是否真的对问题/产品完全陌生？如果受众已经知道自己有这个问题（例如重定向广告、老客户邮件），从 Attention 重新开始会显得啰嗦拖沓，应改用 PAS 直接进入放大痛苦/给方案。

## 例证

**Duolingo 社媒广告（HubSpot 案例）**：Attention「绿色猫头鹰跳舞的洗脑广告」→ Interest「每天只需 5 分钟」→ Desire「评论区大量用户晒出连续打卡天数的社会认同」→ Action「下载按钮」。揭示 Attention 阶段的"钩子"可以完全无厘头，只要能真正引起注意，后续阶段再补上和产品的关联。

**Calendly 案例研究页（HubSpot 案例）**：用"DMACC 节省 17 万美元成本、消除 100% 重复预订"的具体数字构成 Desire 阶段的核心说服材料。揭示 Desire 阶段最有效的不是形容词堆砌，而是可验证的具体数字/案例。

**AIDA vs PAS 的受众冷热对比（行业交叉验证案例，CrazyEgg 等）**：多篇独立资料一致指出，用 PAS 打完全陌生的冷受众会显得突兀冒犯（还没建立认知就直接放大痛苦），用 AIDA 打已经反复接触过的暖名单/重定向受众会显得啰嗦拖沓（受众已经知道问题，还要从头讲"这是什么"）。揭示两者的分界线不是"文案好坏"，而是受众所处的认知阶段。

## 什么时候不适用（边界）

- **受众已处于漏斗中段/已有认知**：重定向广告、暖名单邮件面对的受众已经知道产品或问题存在，从 Attention 重新开始建立认知是浪费篇幅、拖慢转化 → 改用 [`pas`](../pas/SKILL.md)，直接进入放大已知问题。
- **强调长期信任建立的服务型行业**：AIDA 更适合产品导向、追求单次转化的场景；专业服务（法律/咨询/医疗）等依赖长期信任建立的行业，机械套用"制造欲望→促成行动"的节奏会显得急功近利、损害专业形象 → 需要更长周期的内容/关系建立框架。
- **不覆盖购买后行为**：AIDA 在 Action 完成后就结束，不涉及复购、口碑、客户成功等后续环节 → 需要另外设计留存/复购机制，不能指望 AIDA 覆盖全生命周期。
- **现代路径非线性场景的机械套用**：真实用户可能通过搜索直接进入 Desire 阶段（已经在比较方案），若不判断受众实际所处阶段、机械要求走完四步，会人为拖长不必要的环节。

## 常见误用

- **把 Attention 写成纯噪音式标题党，与后续内容脱节**：受众点进来后立刻感到被欺骗、跳出率升高 → 回到步骤 1，钩子必须和后续内容真实相关。
- **对已有问题意识的暖受众仍从 Attention 讲起**：文案显得啰嗦、受众觉得"这些我都知道" → 改用 PAS，跳过认知建立。
- **Desire 阶段堆砌形容词而非具体证据**：只写"我们是最好的"而没有数字/案例支撑，说服力薄弱 → 回到步骤 3，补充可验证的具体材料。
- **Action 阶段摩擦过高**：对完全陌生的冷受众直接要求"立刻付费购买"，转化率低 → 回到步骤 4，先设置一个更低门槛的过渡动作（如免费试用/下载资料）。
- **误以为 AIDA 是唯一线性真理，忽视真实用户可能跳过阶段**：机械按顺序套用四步，不判断受众实际所处认知阶段 → 先做步骤 5 的自检，确认受众冷热再决定是否套用全部四步。

## 相关模型

- **与[PAS](../pas/SKILL.md)**：**硬区分受众认知阶段。** AIDA 假设受众对问题/产品完全陌生（冷受众，处于认知阶段），必须先靠 Attention/Interest 建立认知；PAS 假设受众已经知道自己有这个问题（暖受众，处于考虑阶段），可以直接跳过认知建立、放大痛苦。面向陌生流量的广告/落地页首屏/产品发布 → AIDA；面向已知道自己有问题的重定向广告/暖名单邮件/直复式销售信 → PAS。用 PAS 打冷受众显得突兀冒犯，用 AIDA 打暖受众显得啰嗦拖沓。
- **与[StoryBrand SB7](../storybrand-sb7/SKILL.md)**：颗粒度不同。SB7 是整个品牌/文档的七段叙事骨架，服务整体定位；AIDA 是单篇文案面向冷受众的四段推进节奏，可以嵌套在 SB7 骨架的具体段落（如落地页首屏）里使用。
- **与[SCQA](../scqa/SKILL.md)**：SCQA 服务理性论证的商务开场，中立呈现情境；AIDA 服务情绪/欲望驱动的营销文案，两者应用领域不同，一般不会混淆。

## 记忆钩子

先让人看见你，再让人愿意听，然后让人想要，最后告诉他现在就点这里。
