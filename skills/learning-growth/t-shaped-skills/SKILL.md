# T 型技能 T-Shaped Skills

## 这是什么

**T 型技能**：能力画像呈「T」——**一竖**是可交付的纵深专长，**一横**是足够与相邻领域对话、协作、定义问题的广度。目标不是百科全书，而是**深到能贡献、广到能对接**。

该说法在设计、咨询、产品与研发协作语境中流行：纯 I 型（只有深井）易成协作瓶颈；纯横杠（样样浅）难以负责关键路径。本模型交付**组合审计与下一季学习投资分配**，不是性格测评。

**鉴别**：[`meta-learning`](../meta-learning/SKILL.md) 管「如何学」；T 型管「学什么组合」。[`zpd`](../zpd/SKILL.md) 管单任务难度带；T 型管长期技能组合。

## 什么时候用

- "技能树怎么点 / 深度还是广度"
- "T 型人才 / 一专多能怎么落地"
- 转岗、组队、个人季度学习计划

**不要**当主模型：

- 单一技能如何练 → [`deliberate-practice`](../deliberate-practice/SKILL.md)
- 如何教/带徒弟 → [`mentorship`](../mentorship/SKILL.md) / [`zpd`](../zpd/SKILL.md)
- 只要信念激励 → [`growth-mindset`](../growth-mindset/SKILL.md)

## 怎么用（执行步骤）

1. **定义纵深：可对外交付的成果。** 写成作品/职责（「能独立交付 X」），禁止「懂点 AI」。判据：能否举出最近一件可展示产出。
2. **盘点横杠：协作接口清单。** 列出必须对话的 3–6 个相邻域（产品、法务、数据、运营…）。每域写「需要听到什么词、问什么问题」。
3. **标缺口类型。** 纵深不够 → 投资专长；横杠缺口导致反复返工/误解 → 投资广度；都虚 → 先选一个纵深主攻。
4. **分配学习预算（例 70/30）。** 一季内多数时间加固竖杠；少数时间用「能对话」标准补横杠（术语、典型坑、一张地图），不做第二纵深除非转轨。
5. **为横杠设「对话级」验收。** 能听懂会议、能提正确问题、能翻译给团队，**不**要求可独立交付该域。
6. **季末复盘 T 形是否变形。** 竖杠无作品 → 收回广度时间；协作仍崩在同一接口 → 定向补该横格。

## 例证

**数据工程师 + 产品/隐私意识**：深井是管道与模型；横杠能和产品/法务对齐需求——减少「技术正确但无人要用」。

**设计师不懂研发约束**：视觉很强但无法对话实现——I 型过窄；补「可行边界」横杠而非改行当程序员。

**（局限）**：组织若惩罚深度、只奖「什么都蹭」，T 型会被扭曲为会议型空心人——纵深验收必须硬。

## 什么时候不适用（边界）

- **危机救火只需立即纵深**：先交付，再谈组合。
- **明确要求双深（π 型）岗位**：按岗位改画像，勿机械坚持单竖。
- **把 T 型当身份炫耀**：无作品无接口清单则无效。
- **学生基础课阶段**：先建可迁移基础，再谈职业 T 形。

## 常见误用

- **横杠刷课不上竖杠**：证书墙 → 先强制纵深作品。
- **把兴趣爱好全算横杠**：与协作接口无关 → 移出职业 T。
- **与「一万小时」对立**：纵深仍需高质量练习，非标签。
- **一年造多竖**：资源稀释 → 一季主攻一竖。

## 相关模型

- **与[刻意练习](../deliberate-practice/SKILL.md)**：竖杠靠刻意练习造作品；本模型决定时间投向哪根杠。
- **与[元学习](../meta-learning/SKILL.md)**：元学习选方法；T 型选主题组合。
- **与[导师制](../mentorship/SKILL.md)**：导师可帮你校准「对话级」横杠该补哪些。
- **与[去学习](../unlearning/SKILL.md)**：转轨时旧竖杠可能要降级为横杠或弃用。
- **与[成长型思维](../growth-mindset/SKILL.md)**：成长型支持「可发展」；T 型给出发展方向结构。

## 记忆钩子

一根竖杠能交货，一根横杠能对接——别做成一条细线或一块薄片。
