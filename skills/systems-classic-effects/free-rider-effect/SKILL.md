# 搭便车效应 Free-Rider Effect

## 这是什么

**搭便车**：在非排他或弱排他的集体收益中，个体有激励**少付成本却享成果**，导致供给不足或少数人过载。Olson《集体行动的逻辑》指出：集团越大、越难选择性奖惩，搭便车越严重。

它是**激励结构问题**，不是单纯道德谴责。公共品（非竞争+非排他）是经典场景；开源、团队文档、联盟广告也会出现。

## 什么时候用

- "开源只有少数人维护"
- "团建/知识库没人更新但人人用"
- "行业标准靠几家扛"

**不要**当主模型：
- 公共资源被过度消耗枯竭 → 公地悲剧逻辑（微观分类若有则链；否则用系统思维画流量）
- 需要画增强/调节回路 → [`systems-thinking`](../systems-thinking/SKILL.md)
- 小失序规范崩溃 → [`broken-windows`](../broken-windows/SKILL.md)

## 怎么用（执行步骤）

1. **定义集体收益与成本。** 谁受益、成本是钱/时间/风险？是否近似非排他？
2. **测贡献分布。** 画出贡献的二八：若少数承担绝大部分且无补偿，搭便车风险高。
3. **找可排他点或选择性激励。** 会员制、私有 fork 权益、署名、晋升挂钩、小集团监督——列可行工具。
4. **改规则试点。** 选一种机制跑一个周期，看供给是否回升、冲突是否可控。
5. **避免羞辱替代设计。** 道德动员可辅助，但不能替代激励相容；否则贡献者耗尽退出。

## 例证

**国防/灯塔类公共品**：难以排除不付费者 → 常由政府或强制分摊。揭示**非排他下的供给难题**。

**公司 Wiki**：人人只读不写。揭示组织搭便车；用“编辑计入绩效”可缓解。

**气候行动**：单国减排惠及全球。揭示大规模集体行动中的搭便车。

## 什么时候不适用（边界）

- **可完全排他的私人物品**：用价格即可，不必套搭便车。
- **自愿利他主导且规模小**：亲密小团体规范可抑制搭便车。
- **分工差异**：有人专职贡献是角色设计，不是偷懒——先看是否约定职责。

## 常见误用

- **道德抹黑**：凡受益多于付出就污名 → 先看规则是否允许/鼓励。
- **忽视大集团逻辑**：以为宣传一波就能解决万人公共品。
- **与马太混用**：头部贡献者累加优势是马太；不付成本白享受是搭便车。

## 相关模型

- **与[帕累托原则](../pareto-principle/SKILL.md)**：贡献二八常伴随搭便车压力。
- **与[系统思维](../systems-thinking/SKILL.md)**：用回路看“贡献者耗尽 → 公共品衰败”。
- **与[博弈论](../../game-theory-models/game-theory/SKILL.md)**：公共品博弈/囚徒结构可形式化同一激励。

## 记忆钩子

灯亮了谁都看见——先问能不能排他，再问谁被选择性激励。
