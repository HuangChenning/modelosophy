# 囚徒困境 Prisoner's Dilemma

## 这是什么

**个体理性优势策略导致集体更差的结局。**

经典 2×2：双方各有合作/背叛；背叛为严格优势策略，唯一纳什是双方背叛，却帕累托劣于双方合作。Flood–Dresher 实验与 Tucker 的故事版同构。合作通常要改博弈（重复、惩罚、契约），不是单次矩阵里劝善。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "这是不是囚徒困境"
- "大家各自最优却一起更糟"
- "价格战/军备式加班两边都招供"

**不要**在以下情况套用本模型：

- 只有一人在不确定下选择 → ../../decision-probability/decision-tree/SKILL.md
- 问题是长期互动如何维持合作 → ../repeated-games/SKILL.md 或 ../folk-theorem/SKILL.md
- 只想扫盲参与人/策略/收益术语 → ../game-theory/SKILL.md

## 怎么用（执行步骤）

1. **确认同时行动与支付结构。** 写出两方、两策略；支付至少做到序数。若一方先动可见，先改走序贯/逆向归纳，勿硬套经典囚徒。
2. **标优势策略。** 对每一方：无论对方选什么，某策略是否严格更好？经典囚徒双方“背叛”皆优势。若无优势策略，可能是猎鹿/斗鸡等，勿贴囚徒标签。
3. **对照帕累托更优格。** 指出存在双方都更好的格（常为合作–合作）却非纳什。输出：矩阵 + 优势/纳什 + 帕累托差距一句。
4. **若要合作，列改博弈选项。** 重复、可验证惩罚、第三方执行、改变支付——写可执行条件，禁止只写“要多信任”。

## 例证

**经典囚犯故事**：沉默/招供支付使招供占优；均衡劣于都沉默。揭示个人理性≠集体理性。

**价格战 / 公共品搭便车**：降价或偷懒短期占优，均衡利润或公共品供给双输。揭示先改支付/制度再谈口号。

## 什么时候不适用（边界）

- **误判结构**：猎鹿（合作风险）、斗鸡（对撞最差）不是囚徒；先核对优势策略是否存在。
- **单次 vs 重复**：无限或足够长重复可支撑合作，见重复博弈/无名氏定理。

## 常见误用

- **把一切双输叫囚徒**：先问是否有严格优势策略背叛；没有则换标签。
- **用劝善代替改支付**：单次矩阵内“感化”通常无效；要改规则或重复。

## 相关模型

- **与[博弈论（入门）](../game-theory/SKILL.md)**：入门扫矩阵与术语；本条专做优势策略→帕累托劣纳什诊断。
- **与[重复博弈](../repeated-games/SKILL.md)**：困境结构确认后要设计长期合作时走对方。
- **与[猎鹿博弈](../stag-hunt/SKILL.md)**：合作也是纳什、风险主导背叛时走猎鹿。

## 记忆钩子

个人最优招供，集体最优沉默——先改局，再谈心。
