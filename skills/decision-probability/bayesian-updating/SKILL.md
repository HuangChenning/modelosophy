# 贝叶斯更新 Bayesian Updating

## 这是什么

**贝叶斯更新**：在收到证据 \(E\) 后，把对假设 \(H\) 的信念从先验 \(P(H)\) 改写为后验 \(P(H|E)\)。核心关系：

\[
P(H\mid E) = \frac{P(E\mid H)\,P(H)}{P(E)}
\]

实践上常用「先验 × 似然 → 归一化得后验」。它不是「更相信自己」，而是：**证据在假设为真/假时出现的相对容易程度**决定该往哪边挪。

与「拍脑袋改口」的差别：必须显式写出先验来源、似然比（或至少方向与量级），并允许后验证据把你拉向反面。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "新数据出来了，概率该怎么改"
- "先验多少、证据支持哪边"
- "贝叶斯 / 后验 / likelihood"
- 诊断、招聘、投资、产品实验等「先有判断、再有信号」的场景

**不要**在以下情况套用本模型：

- 多阶段行动与买信息价值 → [`decision-tree`](../decision-tree/SKILL.md)
- 只算静态结果集的金额期望 → [`expected-value`](../expected-value/SKILL.md)
- 不完全信息下的策略互动 → [`bayesian-games`](../../game-theory-models/bayesian-games/SKILL.md)
- 用户只想强调「先看大类频率」且尚未谈似然 → 可先用 [`base-rate`](../base-rate/SKILL.md)，再并入本模型

## 怎么用（执行步骤）

1. **钉死互斥假设集。** 至少写 \(H\) 与 \(\neg H\)（或少数互斥 \(H_i\)），禁止「感觉有点像」。判据：事后能说清「哪条假设胜出」。
2. **写下先验并标来源。** 参考类频率、历史基线、专家区间或「无知先验」——分列；用区间而非假精确三位小数。
3. **写似然：证据在各假设下有多容易出现。** 问「若 \(H\) 真，看到 \(E\) 的概率？若假呢？」得到似然比 \(LR = P(E|H)/P(E|\neg H)\)。判据：LR 有方向与粗量级（如「约 3:1」），不是口号。
4. **合成后验并归一化。** 先验比值 × LR → 后验比值 → 转回概率。展示一步算术，禁止只报「更新后更确信」。
5. **预注册改主意条件。** 下一条证据若把后验推过阈值 \(T\)，行动如何变？写下来，对抗确认偏差。
6. **检查独立性与选择性抽样。** 多条证据是否相关（会双计）？证据是否只挑支持方？相关则降权或改联合似然。

## 例证

**医学检验（经典教学）**：疾病先验 1%，检验灵敏度 99%、假阳性 1%。阳性后后验约 50% 量级，而非「几乎确诊」。揭示：**似然再强，稀有先验仍会压住后验**——这是基率与贝叶斯的交汇面。

**蒙提霍尔**：先验每门 1/3；主持人按规则揭示羊后，换门后验 2/3。揭示的是**信息结构（似然）改变信念**，不是「直觉反直觉秀」。

**产品实验**：上线前先验「功能提升留存」约 40%；看到对照组持平、实验组 +0.1pp 且噪声大时，似然比接近 1，后验几乎不动。揭示：弱证据不该大幅改信念。

## 什么时候不适用（边界）

- **无法观察的证据**：似然写不出 → 先改造成可观察命题，或承认无法贝叶斯化。
- **假设集漏掉真因**：后验只在错误集合里归一化 → 先扩展假设（模型不确定性）。
- **对抗性数据生成**：对手会操纵你看到的 \(E\) → 先处理激励与选择偏差。
- **需要效用/破产约束**：后验概率正确仍可能不该按 EV 梭哈 → [`expected-utility`](../expected-utility/SKILL.md) / [`antifragility`](../../learning-growth/antifragility/SKILL.md)。

## 常见误用

- **把后验当「更自信」**：没有证据只抬先验 → 禁止。
- **忽略基率**：罕见事件 + 强似然仍可能后验不高 → 连用 [`base-rate`](../base-rate/SKILL.md)。
- **与贝叶斯博弈混淆**：谈的是对手类型与均衡策略 → [`bayesian-games`](../../game-theory-models/bayesian-games/SKILL.md)。
- **双计相关证据**：同一底层信号拆成多条「独立」更新 → 合并。

## 相关模型

- **与[基率思维](../base-rate/SKILL.md)**：基率提供/校准先验；贝叶斯负责把似然并入。用户只说「这类事通常怎样」走基率；说「新证据怎么改信念」走本模型。
- **与[期望值](../expected-value/SKILL.md)**：EV 用（已给定的）\(p\) 算加权结果；本模型负责**改写 \(p\)**。
- **与[假设检验](../../cognitive-thinking-tools/hypothesis-testing/SKILL.md)**：假设检验强调可证伪设计；贝叶斯强调信念连续更新。可连用：先设计 \(E\)，再更新。
- **与[确认性偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：确认偏差会扭曲似然与证据搜索；贝叶斯步骤要求预注册改口条件来对抗。
- **与[决策树](../decision-tree/SKILL.md)**：树的机会节点概率应用本模型更新后再折叠。

## 记忆钩子

先验 × 似然 → 后验；**没写出似然，就没有更新，只有心情。**
