# 蜈蚣博弈 Centipede Game

## 这是什么

**轮流选择“结束拿走较多”或“继续做大”，倒推预言早停，实验却常合作很久。**

有限回合；继续放大总额，结束则当前玩家多拿。逆向归纳：一开始就停。实验：多数人继续多期。张力来自利他、声誉、不完美理性或利他信念。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "蜈蚣博弈"
- "倒推说该停但人不停"
- "要不要继续做大再分"

**不要**在以下情况套用本模型：

- 只要倒推步骤 → ../backward-induction/SKILL.md
- 无限重复理论 → ../folk-theorem/SKILL.md
- 满意化程序 → ../bounded-rationality/SKILL.md

## 怎么用（执行步骤）

1. **画蜈蚣节点与支付。** 确认有限长度与结束/继续。
2. **写倒推预言。** 起点即停。
3. **对照行为。** 用户或实验会继续几期？写入利他/信任信念。
4. **设计。** 若希望做大：加声誉、模糊终点、承诺装置。输出：理论路径 vs 行为路径 + 干预。

## 例证

**实验室蜈蚣**：罕见第一节点停止。揭示标准倒推的描述力上限。

**合伙再投资**：一轮轮把利润留下做大，直到有人撤。

## 什么时候不适用（边界）

- **高利害末端**：接近终点背叛上升。
- **理论用途**：倒推仍是规范基准，不是无用。

## 常见误用

- **嘲笑倒推无用**：应谈假设（共同知识理性）何处失败。
- **鼓励无限画饼**：有限终点仍在。
