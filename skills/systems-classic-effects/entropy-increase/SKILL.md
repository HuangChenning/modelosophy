# 熵增定律 Entropy Increase

## 这是什么

**熵增**：在**孤立系统**中，熵不减少——宏观上趋向更可能的无序/均匀态（热力学第二定律）。迁到组织与信息场景时，只作**受控隐喻**：若切断与环境的物质、能量、信息交换，差异、结构与可用能量差会耗散，表现为流程失效、知识过时、激励失灵。

精确科学表述与组织隐喻必须分开；本 Skill 教你**何时允许用隐喻、何时必须停**。

## 什么时候用

- "团队封闭后越来越僵"
- "不维护的文档/代码必然腐烂"
- "讨论要不要强制外部输入"

**不要**当主模型：
- 具体做开放系统账本（输入/排出）→ [`negentropy`](../../thinking-models/negentropy/SKILL.md)
- 涨落分岔新有序 → [`dissipative-structures`](../../thinking-models/dissipative-structures/SKILL.md)
- 反馈结构诊断 → [`feedback-loops`](../feedback-loops/SKILL.md) / [`systems-thinking`](../systems-thinking/SKILL.md)

## 怎么用（执行步骤）

1. **声明系统边界。** 孤立 / 封闭 / 开放？组织几乎总是开放——若有人说“必然熵增”，先问边界假设。
2. **列出正在耗散的有序。** 标准、客户理解、技能梯度——要可观察衰退。
3. **找被切断的流。** 新信息、异质成员、外部压力、维护预算是否下降。
4. **选择干预类型。** 打开输入（负熵账）、排出废秩序、或降低系统孤立——写出具体动作。
5. **禁止宇宙鸡汤。** 不从宇宙热寂推导个人日程；科学表述止于边界条件。

## 例证

**未维护软件**：依赖过时、知识离职。揭示**无输入下的结构耗散隐喻**。

**封闭官僚**：只内部循环文件。揭示信息封闭≈有效孤立。

**热力学原意**：孤立气体趋向均匀。揭示科学内核；提醒勿直接当管理证明。

## 什么时候不适用（边界）

- **强开放且高投入系统**：可持续局部有序（代价是环境增熵）。
- **用熵增解释一切失败**：懒标签。
- **生命/计算的精确熵核算**：需专业热力学/信息论，不是本草稿范围。

## 常见误用

- **励志绑科学**：“熵增所以你要努力” → 停。
- **否定局部有序**：开放系统可局部降熵。
- **与负熵对立**：负熵是应对策略账本；熵增是孤立趋势陈述。

## 相关模型

- **与[负熵](../../thinking-models/negentropy/SKILL.md)**：熵增说趋势；负熵说如何维持局部有序（互链，不迁入）。
- **与[耗散结构](../../thinking-models/dissipative-structures/SKILL.md)**：远离平衡的新有序机制。
- **与[系统动力学](../system-dynamics/SKILL.md)**：用存量流量看“维护流量是否覆盖耗散”。
