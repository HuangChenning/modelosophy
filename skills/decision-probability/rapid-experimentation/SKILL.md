# 快速试错 Rapid Experimentation

## 这是什么

**快速试错（rapid experimentation）**：在不确定环境中，把大赌注拆成**短周期、低成本、有明确学习目标**的实验序列——每轮事先定义成功/失败阈值与止损，轮末决定加倍、转向或停止。目标是**最大化有效学习速率**，不是鼓励无纪律的蛮干。

「Fail fast」若无可检验假设与止损，只是失败得更快。

## 什么时候用

- "快速试错 / 小步跑通再放大"
- "不确定该押哪边，想用实验序列"
- "学习速率、迭代验证、pivot"
- 可逆或可拆成可逆前缀的产品、运营、流程探索

**不要**当主模型：

- 只要定义「最小学习制品」形态 → [`mvp`](../mvp/SKILL.md)（常为本模型的载体）
- 对抗环境下的感知—行动节奏 → [`ooda-loop`](../ooda-loop/SKILL.md)
- 写清可证伪指标与对照设计 → [`hypothesis-testing`](../../cognitive-thinking-tools/hypothesis-testing/SKILL.md)
- 医疗/航空等试错成本不可接受 → 仿真、评审、监管路径优先

## 怎么用（执行步骤）

1. **陈述最大不确定性。** 一条：若错，当前战略叙事崩。判据：团队同意优先级。
2. **设计本轮最小实验。** 载体可以是 MVP、A/B、销售剧本、concierge；绑定假设与指标。
3. **预注册阈值与时间盒。** 「两周内；指标 ≥X 继续；＜Y 停止；中间区间则…」。禁止事后改门槛。
4. **限敞口执行。** 预算、声誉、合规上限写死；不可逆后果不得用「试错」掩饰。
5. **读学习，不只读输赢。** 记录：假设哪部分被削弱/强化；意外发现；下一条最大不确定性是否转移。
6. **明确下一动作。** Scale / Iterate / Pivot / Kill；写入决策日志。无决策的实验 = 浪费。

## 例证

**增长实验工厂**：每周多个落地页/渠道实验，有统一护栏指标。揭示：**节奏 + 预注册**比单次天才实验重要。

**定价试探**：小流量分区测价，未达标价格带直接淘汰。揭示：试错是**选项价值的实现方式**。

**错误示范**：无假设「先做一堆功能看用户喜不喜欢」→ 不是本模型，是范围蔓延。

## 什么时候不适用（边界）

- **单次致命、不可逆**：改用重审查、仿真、红队。
- **反馈噪声极大**：短周期学不到信号 → 加长窗口或改指标，或先 [`base-rate`](../base-rate/SKILL.md)。
- **组织惩罚诚实失败**：数据会被美化 → 先修激励。

## 常见误用

- **把失败浪漫化**：无学习的失败仍是浪费。
- **与 MVP 划等号**：MVP 是制品策略；本模型是**实验组合与节奏**。
- **无限试错不下决心**：阈值永不触发 Kill。
- **在单向门上「先上线」**：违反 [`reversible-irreversible`](../reversible-irreversible/SKILL.md)。

## 相关模型

- **与[MVP](../mvp/SKILL.md)**：MVP 回答「用什么最小载体学习」；本模型回答「如何串成有止损的实验序列」。常连用。
- **与[OODA](../ooda-loop/SKILL.md)**：OODA 强调对抗节奏与定向；快速试错强调假设—证据—止损。对手少、假设多时偏本模型。
- **与[假设检验](../../cognitive-thinking-tools/hypothesis-testing/SKILL.md)**：假设检验提供可证伪设计；本模型管组合、节奏与杀停规则。
- **与[可逆与不可逆决策](../reversible-irreversible/SKILL.md)**：仅在可逆或可逆前缀上加速试错。
- **与[决策日志](../decision-journal/SKILL.md)**：每轮实验预注册进日志，防止事后改口。

## 记忆钩子

快，是为了**更早证伪**；没有阈值与止损的「试错」，只是冲动。
