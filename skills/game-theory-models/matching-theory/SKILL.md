# 匹配理论（Gale–Shapley） Matching Theory (Gale–Shapley)

## 这是什么

**在双边偏好下，延迟接受（求婚）算法产生稳定匹配——不存在双方都更想彼此的阻断对。**

Gale & Shapley（1962）：一方求婚、另一方暂留优者；最终稳定，且对求婚方最优、对接受方最劣（在稳定匹配集合中）。应用于住院医生匹配、学校选择、器官交换等。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "稳定匹配"
- "Gale-Shapley"
- "哪边先求婚更有利"
- "会不会有阻断对"

**不要**在以下情况套用本模型：

- 拍卖定价 → ../auction-theory/SKILL.md
- 联盟分钱 → ../shapley-value/SKILL.md
- 无偏好序的纯协调 → ../coordination-game/SKILL.md

## 怎么用（执行步骤）

1. **收集双边严格偏好。** 至少序数名单。
2. **选求婚方并跑延迟接受直觉。** 被拒继续向下；接受方持有暂定。
3. **检查稳定。** 有无阻断对（两人互相更偏好对方胜于现行匹配）？
4. **交代偏向。** 求婚方最优稳定匹配。输出：匹配结果 + 哪侧有利 + 战略误报风险一句。

## 例证

**NRMP 医生匹配**：算法版本用于稳定。揭示大规模双边市场。

**学校选择**：学生/学校偏好；操纵动机取决规则。

## 什么时候不适用（边界）

- **偏好误报**：某些机制非策略证明。
- **多边/配额复杂**：基础算法需扩展。

## 常见误用

- **以为唯一公平**：稳定匹配可多；侧别偏向重要。
- **与核混称**：匹配稳定是另一套定义。
