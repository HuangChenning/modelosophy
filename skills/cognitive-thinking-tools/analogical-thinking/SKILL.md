# 类比思维 Analogical Thinking

## 这是什么

**类比思维**：从已理解的**源域**抽取关系结构，映射到待解的**目标域**，从而提出解释、预测或设计选项。认知科学里的核心不是「长得像」，而是 **结构映射（structure-mapping）**：优先对齐关系与高阶关系（谁导致谁、谁约束谁），表面属性相似只是弱线索。

好类比产出的是**可检验假说**；坏类比产出的是修辞说服。类比是启发器，不是证明器。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "别的行业/历史事件有没有可借鉴的结构"
- "打个比方帮我理解这个问题"
- "类比思维 / analogical reasoning / structure mapping"
- 创新、教学、跨域策略迁移，需要从已知推未知

**不要**在以下情况套用本模型：

- 用户要丢掉行业惯例、从硬约束重建 → [`first-principles`](../first-principles/SKILL.md)
- 用户要主动挑衅跳框、不指定源域 → [`lateral-thinking`](../lateral-thinking/SKILL.md)
- 用户要用多源独立证据核验主张 → [`cross-validation-thinking`](../cross-validation-thinking/SKILL.md)
- 把类比当充分证明、拒绝反例检验

## 怎么用（执行步骤）

1. **钉目标域问题。** 写一句：要解释/设计/决策的是什么？列出已知实体与未知关系。判据：外人能否复述「我们在迁什么问题」。
2. **选源域并写候选映射表。** 源域必须你（或团队）更熟。表列：目标实体 ↔ 源实体；目标关系 ↔ 源关系。判据：至少映射 **2 条关系**，不能只有「都叫平台/都叫生态」。
3. **做结构对齐检查。** 优先保留系统化映射（多关系一致）；丢弃只对齐标签/外观的条目。问：若源域中 A 导致 B，目标里对应 A' 是否也应导致 B'？
4. **导出可检验推论。** 每条映射至少写 1 个「若类比成立，则目标域应出现…」的预测或设计动作。判据：预测可否被观察/试点否定。
5. **标失效边界（强制）。** 列出源域有而目标域无的关键前提（监管、成本结构、物理约束、激励）。任一失效 → 该类比降级为修辞，不得当决策依据。
6. **回收。** 保留通过失效检查的推论，交给 [`hypothesis-testing`](../hypothesis-testing/SKILL.md) 或试点；丢弃漂亮但不可证伪的类比故事。

## 例证

**原子与太阳系（教学经典）**：电子↔行星、核↔太阳映射的是「中心引力式轨道」关系，但量子与引力机制不同——揭示类比可入门，不可当物理证明；失效边界写清才算用对。

**跨行业「订阅制」迁移**：把软件订阅的关系（持续交付、低边际成本、流失敏感）映射到硬件服务，若硬件边际成本与退货摩擦很高，映射在成本结构处断裂。揭示：商业口号相似 ≠ 结构可迁。

**（原书卡片）**：若卡片只给「找相似物」金句，属表面类比；本 Skill 以关系映射与失效检验为准，卡片例子仅作提示。

## 什么时候不适用（边界）

- **无可靠源域**：团队对源域一知半解时，类比会放大错误模型。
- **价值/伦理不可迁**：战争、剥削结构的「效率」类比常掩盖规范差异。
- **需要唯一真解证明**：法庭证明、安全认证不能用类比替代证据。
- **目标域约束已清晰**：应优先第一性原理/约束求解，类比最多作辅助灵感。

## 常见误用

- **表面相似当结构**：都叫「生态」→ 要求关系表与失效点。
- **用类比压制反例**：「某某也这样成功了」→ 成功是结果不是映射证明。
- **与第一性原理对立却混用**：一边说从第一性、一边只靠类比抄答案 → 二选一为主，或标明类比仅启发。
- **单一逸事源域**：用一个故事概括全行业 → 换源域交叉，或改走交叉验证。

## 相关模型

- **与[第一性原理](../first-principles/SKILL.md)**：**硬区分。** 「少靠类比、从约束重建」→ 第一性；「主动借源域结构启发」→ 本模型。可连用：类比出候选，第一性筛硬约束。
- **与[水平思考](../lateral-thinking/SKILL.md)**：水平思考可不指定源域地跳框；类比必须有可陈述的源域与映射。
- **与[假设检验](../hypothesis-testing/SKILL.md)**：类比产出假说后必须可证伪验证。
- **与[思维实验](../thought-experiment/SKILL.md)**：思维实验可构造反事实世界；类比迁移的是已有域的结构。
- **与[交叉验证思维](../cross-validation-thinking/SKILL.md)**：多个独立类比仍可能共有偏见；关键决策要独立证据源，不只多个比方。

## 记忆钩子

类比迁的是**关系骨架**，不是马甲；写不出失效点，就还没想完。
