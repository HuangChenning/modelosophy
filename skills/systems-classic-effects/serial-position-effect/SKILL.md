# 系列位置效应 Serial Position Effect

## 这是什么

系列位置效应：在**按顺序呈现的一组项目**（词表、要点、议程）上做自由回忆时，人通常对**开头（首因 primacy）**和**结尾（近因 recency）**记得更好，中间最差——回忆正确率呈 U 形或弓形。经典工作可追溯到 Ebbinghaus 的记忆曲线与 Murdock 等自由回忆实验。

常见机制解释（教学用，非唯一神经定论）：

- **首因**：开头项获得更多复述，更易进入较长时记忆；
- **近因**：结尾项仍在短时/工作记忆中，延迟或干扰作业常削弱近因。

社会认知里的“第一印象”“最近一次接触改观”是**相邻现象**，可以借用首因/近因标签，但实验范式不同，不要把列表记忆定律直接写成人格识人铁律。

## 什么时候用

- 演讲、简历、提案、教学：关键信息放哪；
- “为什么中间那段没人记得”；
- 直接说系列位置 / 首因 / 近因 / serial position / primacy / recency。

**不要**当主模型：
- 体验好不好怎么被记住（峰值+结尾）→ [`peak-end-rule`](../../behavioral-biases/peak-end-rule/SKILL.md)；
- 证据被信念筛选 → [`confirmation-bias`](../../behavioral-biases/confirmation-bias/SKILL.md)；

## 怎么用（执行步骤）

1. **确认材料是“有序列表”。** 词表、三条要求、五页幻灯。若是连续情感体验（排队、疗程），优先峰终，而不是本模型。
2. **画出预期记忆曲线。** 默认：头、尾强，中弱。若有延迟回忆或中间插入干扰，下调近因预期。
3. **配置位置。** 最关键的结论/行动号召：开头定调 + 结尾重复；细节与免责放中段并配外部记忆（讲义、纪要）。
4. **对抗偏差。** 做判断时主动调中间证据与早期/近期权重；写核对清单，避免只被开场或最后一句驱动。
5. **测一次。** 请未参加设计的人回忆三点；若只记得头尾，调整中段编码（故事、视觉、互动），而不是只加时长。

## 例证

**词表自由回忆**：读 15 个无关词后立刻回忆，开头与末尾正确率更高。揭示的是**位置→记忆**，不是内容更重要。

**议程设计**：把决策项放会议开头与结束前，中间塞报告——常导致中段形同虚设。揭示顺序是注意力预算分配。

**Luchins 印象形成（原书引用脉络）**：同一人先描述热情再冷淡 vs 相反顺序，印象不同。揭示**顺序影响整合**；属印象形成，须与词表首因区分标注。

**（原书卡片）王尔德“没有第二次机会留下第一印象”**：修辞可用，但是社会启发式，不是系列位置实验结论；“坏人做一件好事立刻改观”更接近近因/更新启发式，易与峰终、确认偏差纠缠——作反例警示即可。

## 什么时候不适用（边界）

- **无序或同时呈现**（仪表盘并列）：位置效应弱化。
- **深度加工压倒位置**：中间项若被精加工，可胜过头尾。
- **与峰终混用**：痛感峰值在体验中段时，回忆可由峰终主导，不由列表近因公式给出。
- **把第一印象道德化**：首因强≠第一眼正确。

## 常见误用

- **连续情感体验硬套系列位置**：就诊/逛店/疗程优先峰终 → 转 [`peak-end-rule`](../../behavioral-biases/peak-end-rule/SKILL.md)。
- **“首因强＝第一眼正确”**：位置效应是记忆/印象权重，不是真值 → 主动调中间证据，写核对清单。
- **仪表盘并列仍谈头尾优势**：无序/同时呈现时位置效应弱化 → 换编码手段，不迷信顺序。
- **中段重要信息只靠加时长**：深度加工可压过位置 → 用故事/视觉/互动提高中段编码，并实测回忆三点。

## 相关模型

- **与[峰终定律](../../behavioral-biases/peak-end-rule/SKILL.md)**：列表记忆 vs 体验回忆效用；近因≠情感结尾。
- **与[可得性启发](../../behavioral-biases/availability-heuristic/SKILL.md)**：头尾项更易提取，可能被误当成“更重要/更常见”。
- **与[确认性偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：第一印象形成假设后，后续信息被筛选——首因可启动确认偏差。
- **与[双系统](../../thinking-models/dual-process/SKILL.md)**：开场/收尾常走快系统锚定；重要决策用慢系统重看全序列。
- **与[光环效应](../halo-effect/SKILL.md)**：首因可启动光环，但记忆位置≠光环机制。
