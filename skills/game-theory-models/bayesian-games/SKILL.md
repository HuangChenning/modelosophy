# 贝叶斯博弈 Bayesian Games

## 这是什么

**参与人类型不完全可知时，用信念（概率）做期望支付最优化。**

Harsanyi：私有信息=类型；共同先验 + 贝叶斯更新。均衡是贝叶斯纳什——给定信念与他人策略，期望支付最佳回应。适用于隐藏成本、隐藏质量、谈判底线未知等。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "不知道对方底牌怎么博弈"
- "不完全信息博弈"
- "贝叶斯纳什"

**不要**在以下情况套用本模型：

- 完全信息静态 → ../nash-equilibrium/SKILL.md
- 重点是发信号让对方信 → ../signaling-games/SKILL.md
- 支付完全不可估 → 先调研，不硬套

## 怎么用（执行步骤）

1. **列出类型空间。** 对方可能的私有特征（高/低成本等）与自己的类型。
2. **写先验与可观测信号。** 共同先验从何来？看到行动后如何更新（至少定性）。
3. **对每种类型算最佳回应。** 策略是“类型→行动”的映射；用期望支付比较。
4. **输出。** 信念假设 + 贝叶斯纳什候选 + 对先验敏感度一句。

## 例证

**密封拍卖估值私有**：各人知己不知彼；出价相对信念。揭示信息结构改变策略。

**谈判底线未知**：强硬/软弱类型；报价权衡成交率与剩余。

## 什么时候不适用（边界）

- **先验胡扯**：无依据的精确概率制造伪科学；用区间或情景。
- **共同先验过强**：现实常有异质信念——要标注假设。

## 常见误用

- **把不确定性当贝叶斯博弈却不写类型**：必须定义类型与信念。
- **与信号博弈混淆**：信号博弈是贝叶斯博弈的一类（有发送—接收结构）。

## 相关模型

- **与[信号博弈](../signaling-games/SKILL.md)**：发送方主动选信号时走对方。
- **与[拍卖理论](../auction-theory/SKILL.md)**：应用场。

## 记忆钩子

先写“他可能是谁”，再谈最优回应。
