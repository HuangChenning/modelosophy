# 负熵 Negentropy（反熵增）

## 这是什么

**负熵**不是“宇宙变有序”，而是：在**开放系统**里，通过从环境输入低熵资源（自由能、物质、信息、异质反馈），并向外排出高熵废料（热、冗余、失效惯例），使**局部**维持或提高有序度。Schrödinger（《生命是什么》）用“生命以负熵为食”说明生物何以对抗衰变；Brillouin 等把信息获取与负熵联系起来——获得有用信息要付出熵代价。

热力学第二定律对**孤立系统**成立：熵不减。开放系统局部有序，是因为把更大的无序**外包**给环境；总账仍可增熵。组织与个人场景里，本模型只取可操作的“账”：

| 账目 | 问什么 |
|---|---|
| **输入** | 近期有没有新信息、异质人才、外部客户压力、跨界实践进入系统？ |
| **排出** | 有没有正式机制扔掉失效流程、过时产品、封闭小圈子？ |
| **边界** | 系统是开放交换，还是只在内部自循环？ |
| **方向** | 有序是靠持续输入维持，还是靠口号与封闭管控假装有序？ |

它回答的是**有序维持的方向与账**，不是 Prigogine 的分岔机制（那是耗散结构）。

## 什么时候用

- 团队/公司感觉“越来越官僚、同质、听不到坏消息”；
- 个人学习或能力停滞，怀疑输入封闭；
- 讨论 Day 1 / 反僵化 / 熵减 / 要不要强制引入外部刺激；
- 用户直接说负熵、反熵增、熵减。

**不要**当主模型：
- 要判断“是否远离平衡 + 涨落过阈值 → 新有序结构” → [`dissipative-structures`](../dissipative-structures/SKILL.md)；
- 要解释“历史小选择如何经报酬递增锁死” → [`path-dependence`](../../systems-classic-effects/path-dependence/SKILL.md)；
- 要画存量流量与反馈回路 → [`systems-thinking`](../../systems-classic-effects/systems-thinking/SKILL.md)；
- 纯鸡汤式“对抗宇宙”而无系统边界与输入输出账。

## 怎么用（执行步骤）

1. **界定系统与时间尺度。** 写清：谁是系统（个人/团队/产品线）、边界在哪、看的是周/季/年。边界不清，“熵”就会变成无法证伪的情绪词。
2. **做一张负熵账，而不是喊口号。** 列出近一个周期的：**外部输入**（客户访谈、竞品、新人、异地市场、跨学科阅读）、**内部排出**（废弃指标、砍掉的流程、结束的项目）、**封闭回路症状**（只听内部汇报、同一批人评审、信息只向下不向上）。每条尽量可观察。
3. **判读方向。** 若输入稀少且排出失灵，判定为**封闭驱动的有序衰减**（不是“宇宙在惩罚你”）。若输入很多但无排出，可能是信息过载而非负熵——有序需要筛选与遗忘，不是无限堆积。
4. **设计最小开放干预。** 优先可逆、可计量的动作：强制外部评审席、固定比例的跨团队轮岗/20%探索时间、客户现场日、公开失败复盘。每项写清“输入了什么、排出了什么、两周后看哪个领先指标”。
5. **核对热力学边界（防口号化）。** 明确：局部有序**不**等于全局熵减；“努力工作”本身若不改变输入/排出结构，不是负熵。禁止用第二定律给道德训诫背书。

## 例证

**活细胞与开放系统**：细胞不断摄入养分、排出代谢废物，局部保持低熵结构；切断交换即死亡。揭示负熵是**持续账**，不是一次励志事件。

**Bezos “Day 1 vs Day 2”**：Day 2 被描述为僵化与衰落；可操作读法是客户输入衰减、流程自我封闭。揭示组织负熵的关键是**外部现实持续进入决策**，而非永远假装创业。

**强制外部审计 / 红队**：安全与合规里独立审计方输入“坏消息”，打断内部自洽。揭示排出废热常等于允许不舒适信息进入。

**（原书卡片）Google 20% 时间与 Day 1**：方向对——开放与防封闭；局限是把“反熵增”写成“熵值不断减小”，易误解为违背第二定律。正确表述是局部有序靠输入与排出维持，整体熵仍可增。卡片把耗散结构与路径依赖直接并列为手段，本 skill 拆开：账用本模型，机制与锁定分别用兄弟模型。

## 什么时候不适用（边界）

- **孤立/封闭物理系统**：第二定律主导，谈“反熵增”无操作空间。
- **口号化熵减**：任何“我们要熵减”而不写输入/排出账，视为空话，退回步骤 2。
- **把痛苦当负熵**：加班、内耗、焦虑不是自由能输入；往往是废热堆积。
- **信息过载当开放**：无筛选的输入会提高混乱度；负熵需要有用信息与排出。
- **伦理甩锅**：不能用“为了组织有序”合理化压榨或信息封锁——那是假有序、真封闭。

## 相关模型

- **与[耗散结构](../dissipative-structures/SKILL.md)**：本模型管“有序维持的账与开放方向”；耗散结构管“远离平衡、涨落、阈值分岔后的新宏观有序”。防僵化先做负熵账；谈相变式重组用耗散结构。
- **与[路径依赖](../../systems-classic-effects/path-dependence/SKILL.md)**：路径依赖解释为何锁在旧路径；负熵强调用外部输入打破封闭回路。锁定机制清楚时两者可连用。
- **与[系统思维](../../systems-classic-effects/systems-thinking/SKILL.md)**：系统思维画反馈、延迟、存量流量并找杠杆；负熵不替代回路图，只检查边界是否开放、输入/排出账是否足以维持目标有序。用户要“按下葫芦浮起瓢”的结构图 → 系统思维；用户要“封闭僵化怎么开输入” → 本模型。
- **与[反脆弱](../antifragility/SKILL.md)**：反脆弱设计从波动中获益的暴露；负熵确保系统仍在与环境交换。可组合，不互相替代。
