# 现值与贴现（DCF） Discounted Cash Flow

## 这是什么

**贴现 / DCF**：因货币时间价值与风险，未来现金需用折现率 r 折回现值。项目或股权价值常建模为预期自由现金流的现值加终值。

核心不是表格软件，而是：**现金流是否可辩护、r 是否与风险匹配、终值是否吞掉了大部分价值**。

## 什么时候用

- "这个项目/公司按现金流值多少？"
- "该用多大折现率？"
- "DCF / 现值怎么做？"

**不要**在以下情况套用本模型：

- 只要市场倍数快估 → [市盈率市净率](../pe-pb-valuation/SKILL.md)
- 只要股息单一路径 → [股利贴现模型](../dividend-discount-model/SKILL.md)

## 怎么用（执行步骤）

1. **画出明确的现金河流。** 每期 CF 定义（FCFF/FCFE）、预测期长度；禁止“收入增长率”悬空无驱动。
2. **选择与风险匹配的 r。** 可参考 CAPM/WACC；给区间；写清名义/实际、币种。
3. **处理终值。** Gordon 永续或退出倍数；做敏感：终值占比 >70% 要警示假设主导。
4. **算 PV 并与市价/成本比较。** 隐含回报或安全边际；结论用情景（悲观/基准/乐观）而非单点。
5. **压力测试关键驱动。** 增速、利润率、r 各动一点，结论是否翻转——写下翻转阈值。

## 例证

**收购项目立项**：建设期流出、运营期流入，折现后 NPV≥0 才过门槛。揭示纪律是**现金与时间**，不是愿景叙事。

**高增长故事股**：DCF 里远期终值占比极高——模型在定价“故事长度”。揭示要对终值诚实。

## 什么时候不适用（边界）

- **深度不确定、可选性主导**：净现值固定路径不够，需实物期权思维。
- **现金流不可验证的庞氏叙事**：先拒绝输入。
- **恶性通胀/币种错配**：先统一货币与实际量纲。

## 常见误用

- **为了得到目标价倒推增速**：这是圆谎，不是估值。
- **折现率随心情调**：涨就提高 r、跌就降低 r。

## 相关模型

- **与[股利贴现模型](../dividend-discount-model/SKILL.md)**：DDM 是现金回流形式受限的 DCF。
- **与[CAPM](../capm/SKILL.md)**：常为股权折现率提供脚手架。
- **与[市盈率市净率](../pe-pb-valuation/SKILL.md)**：相对法快，DCF 慢但假设显式。

## 记忆钩子

没有折现假设的“未来很大”，今天值多少仍是玄学。
