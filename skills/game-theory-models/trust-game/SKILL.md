# 信任博弈 Trust Game

## 这是什么

**先手把钱交给后手（常被乘倍），后手再决定还多少——测信任与可信。**

Berg et al.：投资额反映信任；返还反映可信/互惠。理性自私零返还则零投资；实验常有正投资与正返还。用于信用、平台担保、组织授权。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "信任博弈"
- "我先投入他会不会还"
- "如何提高先付出意愿"

**不要**在以下情况套用本模型：

- 分饼可拒 → ../ultimatum-game/SKILL.md
- 单方面给予 → ../dictator-game/SKILL.md
- 长期以牙还牙 → ../repeated-games/SKILL.md

## 怎么用（执行步骤）

1. **写清乘倍与信息。** 投资如何放大？后手是否知名/可声誉？
2. **标理性基准。** 一次性匿名自私 → 零还 → 零投。
3. **引入互惠与制度。** 保证金、托管、评价、重复。
4. **输出。** 当前信任缺口 + 最小制度补丁使先手愿投。

## 例证

**经典信任博弈实验**：正投资与部分返还普遍。揭示互惠。

**平台保证金**：降低先付风险。揭示制度替代盲信。

## 什么时候不适用（边界）

- **诈骗场景**：不协助伪装可信骗先付。
- **一次性极端匿名**：信任难自发。

## 常见误用

- **责备先手不信任**：结构上零还是均衡时，不信是理性。
- **与囚徒无差别**：信任博弈关键是序贯投资—返还。
