# Learning & Growth

费曼技巧、心流、元认知、遗忘曲线、反脆弱，以及刻意练习、间隔重复、成长型思维、深度工作、ZPD、一万小时澄清等学习成长 Skill。

与兄弟分类分流：学习、记忆与反脆弱配仓；认知拆解工具见 `cognitive-thinking-tools/`，执行排程见 `efficiency-execution/`（**深度工作主条在本类**，效率类仅互链）。

路径：`skills/learning-growth/<skill-name>/SKILL.md`。

当前合计 **11** 个（迁入种子 5 + M3 新建 6，`v0.x-draft`）。

## Skills

- **[antifragility](./antifragility/SKILL.md)** — 反脆弱：设计能从波动中获益的结构（杠铃、Via Negativa、选择性），而非只抗住风险。
- **[deep-work](./deep-work/SKILL.md)** — 深度工作：保护无干扰高认知专注块（名录在效率类亦列出，主条在此）。
- **[deliberate-practice](./deliberate-practice/SKILL.md)** — 刻意练习：针对弱点、有反馈、略超舒适区的训练设计。
- **[feynman-technique](./feynman-technique/SKILL.md)** — 费曼技巧：用简单语言教别人以暴露理解空洞，再回源补洞、类比简化后重讲。
- **[flow](./flow/SKILL.md)** — 心流：挑战与技能大致匹配、目标清晰且反馈及时时的最优体验通道诊断。
- **[forgetting-curve](./forgetting-curve/SKILL.md)** — 遗忘曲线：解释记忆随时间衰减；日程操作见间隔重复。
- **[growth-mindset](./growth-mindset/SKILL.md)** — 成长型思维：把能力视为可发展，改写反馈与目标语言（非努力万能鸡汤）。
- **[metacognition](./metacognition/SKILL.md)** — 元认知：监控并调节自己的认知过程——觉察是否理解/用错策略并换方法。
- **[spaced-repetition](./spaced-repetition/SKILL.md)** — 间隔重复：主动检索 + 递增间隔的 SRS/复习日程操作。
- **[ten-thousand-hours](./ten-thousand-hours/SKILL.md)** — 一万小时定律（澄清）：纠偏时数神话，导流刻意练习。
- **[zpd](./zpd/SKILL.md)** — 最近发展区：独立/支架/做不到三带与渐撤支架。
