# 优劣势清单 Pros and Cons List

## 这是什么

**优劣势清单**：对一个（或少数）选项，两列写出**利（pros）**与**弊（cons）**（或多选项时每个选项各一套），迫使好处与代价同时可见。Franklin 曾用「分列两端、数日增补再权衡」的做法——要点是**拖延片刻以补全清单**，而不是瞬间站队。

它是轻量决策脚手架：提高全面性与可讨论性；**不**自动给出最优解，条目数量≠权重。

## 什么时候用

- "先把好处和坏处写出来"
- "pros and cons / 利弊列表"
- 个人或小团队快速比较 1–3 个选项
- 需要对话透明，但不想上完整加权表

**不要**当主模型：

- 多标准要显式权重与敏感性 → [`decision-matrix`](../decision-matrix/SKILL.md)
- 概率与期望值 → [`decision-tree`](../../decision-probability/decision-tree/SKILL.md) / [`expected-value`](../../decision-probability/expected-value/SKILL.md)
- 组织战略环境四格 → [`swot`](../../strategy-competition/swot/SKILL.md)
- 只要失败预演 → [`inversion`](../inversion/SKILL.md)

## 怎么用（执行步骤）

1. **写决策问题与选项。** 一句话问题；选项具体。判据：利弊条目能挂回同一问题。
2. **分列 Pros / Cons，先求全再求锐。** 设最短冷静窗（即使 10 分钟）用于补条；邀请反对者加 cons。判据：出现至少若干条「不舒服但真实」的弊。
3. **清洗条目。** 合并同义；把「感觉」改成可观察后果；标重要性（高/中/低）——这是粗权，不是假精确总分。
4. **做配对与抵消检查。** 某 pro 是否以某 con 为隐形成本？某 con 是否有缓解措施（变成条件接受）？
5. **决策或升级。** 若高重要性条目仍纠缠、标准>3 且争议大 → 升级 [`decision-matrix`](../decision-matrix/SKILL.md)；若核心是不确定结果 → 升级决策树。否则写出选择 + 接受的主要代价。
6. **记录。** 留下清单与选择理由，便于事后复盘（是否漏了后来发生的 con）。

## 例证

**跳槽**：pros=薪酬/成长；cons=通勤/风险；标高重要性后发现「学习曲线」被低估。揭示：清单价值是**补全与标重要性**，不是数哪边条数多。

**Franklin 式拖延增补**：第一天清单偏情绪，两天后补上「对家人时间」等——揭示冷静窗的作用。

**（原书卡片）**：若教「哪边条数多为胜」，属误用；以重要性与升级规则为准。

## 什么时候不适用（边界）

- **高利害多属性正式选型**：直接矩阵 + 证据。
- **群体操纵**：只允许写 pros → 无效。
- **已有硬约束否决**：先门槛淘汰，再对剩余做利弊。

## 常见误用

- **数条目当投票**：10 条微利胜过 1 条致命弊 → 看重要性与否决项。
- **与 SWOT 混淆**：SWOT 是内外部战略扫描；利弊清单是对具体选项的代价—收益。
- **只写给自己听的pros**：强制对手方或预尸式 cons。
- **该加权却停在清单**：争议权重时升级矩阵。

## 相关模型

- **与[决策矩阵](../decision-matrix/SKILL.md)**：**硬区分。** 快速利弊、粗重要性 → 本模型；显式权重、打分、敏感性 → 矩阵。两者均可归第七类名录；矩阵更形式化。
- **与[决策树](../../decision-probability/decision-tree/SKILL.md)**：**跨类。** 不确定分叉与概率 → 第八类决策树；确定语境下的利弊扫描 → 本模型。
- **与[SWOT](../../strategy-competition/swot/SKILL.md)**：SWOT 不替代具体选项利弊表；战略环境走 SWOT，选项取舍走本模型或矩阵。
- **与[逆向思维](../inversion/SKILL.md)**：inversion 系统生成失败模式（常充实 cons）；本模型组织利弊并列。
- **与[机会成本](../../econ-micro-markets/opportunity-cost/SKILL.md)**：重要 cons 常包括「放弃的次优选项」——可显式写进清单。

## 记忆钩子

两边都写全，并标哪几条真疼——条数不投票，疼感与否决才投票。
