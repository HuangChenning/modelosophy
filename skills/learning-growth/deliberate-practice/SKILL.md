# 刻意练习 Deliberate Practice

## 这是什么

**刻意练习**：为提升特定技能而设计的训练——目标明确、难度略超当前水平、有及时反馈、专注重复薄弱环节，并据此调整下一步。它回答的是「怎么练才进步」，不是「练了多久」。

Anders Ericsson 等人对专家习得的研究强调：专家表现往往来自**高质量、结构化的练习设计**，而非单纯「热爱+堆时间」。与「好玩的练习」「工作中顺便练」不同，刻意练习常不舒适，且需要可观察的表现标准。

**鉴别**：一万小时定律常被误读为「任意重复满时数即专家」；本模型管**练习设计质量**。ZPD 管教学难度带；心流管体验匹配——刻意练习可与之重叠，但核心判据是「针对弱点 + 反馈闭环」。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "想练某项技能但总停在平台期"
- "帮我设计训练计划 / 刻意练习"
- "每天练很多但进步很慢"
- 音乐、运动、编程、演讲、销售话术等可演示技能的提升

**不要**在以下情况套用本模型：

- 只要复习日程对抗遗忘 → [`spaced-repetition`](../spaced-repetition/SKILL.md) / [`forgetting-curve`](../forgetting-curve/SKILL.md)
- 只问挑战与技能是否匹配的体验状态 → [`flow`](../flow/SKILL.md)
- 只要「天赋 vs 努力」信念框架 → [`growth-mindset`](../growth-mindset/SKILL.md)
- 无法定义可观察表现标准的纯态度/价值观问题

## 怎么用（执行步骤）

1. **钉死可演示的目标表现。** 写成外人可核对的标准（「3 分钟内无笔记讲清 X」「能独立完成 Y 题型」），禁止「更懂/更好」。判据：能否录像/打分对照。
2. **定位当前瓶颈（一个主弱点）。** 用最近失败样本找「总在这里崩」的子技能；一次只攻一个。判据：去掉该子技能后，整体表现是否明显上去。
3. **设计略超能力的练习块（15–60 分钟级）。** 难度调到「稳定会犯错，但错误可归因、能被反馈纠正」：全对 → 提难度；错到无法定位错因 → 拆更小单元。不要追伪精确的错误率阈值。必须含即时反馈源（教练、录音回放、测试用例、对照标准答案）。
4. **专注执行并记录。** 单次练习只盯该弱点；记录错误类型，不做「随便练开心」。判据：本块结束时能否说出「今天错在哪、下一块改什么」。
5. **按反馈改下一块。** 轻松过关 → 提高难度或换下一瓶颈；反复同错 → 拆更小单元或换反馈形式。禁止用「再练两小时」代替改设计。
6. **定期迁移检验。** 在接近真实任务的情境测一次；只会刷练习题不会上场 → 加入变异情境与混合练习。

## 例证

**音乐音阶 vs 演出难点**：只扫曲子「练熟」进步慢；把卡住的两小节拆成节奏/音准/指法分别练并录音对照——揭示**针对弱点 + 反馈**才是刻意练习。

**编程刷题平台期**：盲目刷同难度题；改为「错题归因 → 只练该数据结构变体 → 限时测」——揭示堆题量≠刻意练习。

**（常见局限）**：无合格反馈时「刻意」会变成自我感觉；复杂创造领域需配合真实作品评审，不能只靠孤立 drills。

## 什么时候不适用（边界）

- **无反馈通道**：无法知道对错时，先建度量/找教练，再谈刻意练习。
- **健康与恢复不足**：睡眠崩坏时硬练会固化错误动作。
- **纯知识保持问题**：概念已会但忘 → 间隔检索，不是加难度 drills。
- **目标不可观察**：无法定义表现标准时，先澄清目标或改用元认知诊断。

## 常见误用

- **把重复当刻意**：同一难度无反馈刷一千遍 → 先加标准与反馈。
- **一次攻所有弱点**：训练块发散 → 一次一个瓶颈。
- **与一万小时口号互换**：只问「练够没」→ 改问练习设计质量；见 [`ten-thousand-hours`](../ten-thousand-hours/SKILL.md)。
- **舒适区内打卡**：全对仍加时长 → 提高难度到可犯错区。

## 相关模型

- **与[一万小时定律](../ten-thousand-hours/SKILL.md)**：一万小时是被误读的时长叙事；本模型管练习质量。用户说「要练多久」先澄清质量，再谈累计时间。
- **与[最近发展区 ZPD](../zpd/SKILL.md)**：ZPD 定教学/辅导难度带；刻意练习定训练块设计。辅导支架走 ZPD；自主训练闭环走本模型。
- **与[心流](../flow/SKILL.md)**：心流强调体验匹配；刻意练习常略不适。要「进入状态」可连用心流；要「突破弱点」以本模型为主。
- **与[深度工作](../deep-work/SKILL.md)**：深度工作保专注时段；刻意练习规定时段内练什么。可连用：深度块 + 刻意任务。
- **与[元认知](../metacognition/SKILL.md)**：用元认知监控「策略是否有效」，再改练习设计。
- **与[反脆弱](../antifragility/SKILL.md)**：反脆弱设计从波动中获益的结构；刻意练习是技能获取机制，勿混。

## 记忆钩子

进步靠**可反馈的弱点训练**，不靠舒适区里的时长堆积。
