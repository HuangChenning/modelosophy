# 推论阶梯 Ladder of Inference

## 这是什么

Chris Argyris 的推论阶梯（ladder of inference）：人很少“看见全部事实再理性决策”，而是在瞬间完成一串攀升——

**可观察资料与经验 → 选出部分资料 → 赋予文化/个人含义 → 加入假设 → 得出结论 → 采纳信念 → 据此行动**；行动又改变下一步能看见的资料，形成回路。

它是**元认知脚手架**：把无意识跳跃变慢、变可见，便于团队对齐“我们到底站在哪一级吵架”。它不自动给出正确答案，只防止把假设当成地板上的事实。

## 什么时候用

- 争论激烈但双方引用的“事实”其实已是结论；
- 绩效反馈、冲突调解、战略对齐需要共用语言；
- 直接说推论阶梯 / ladder of inference / 是不是跳太快了。

**不要**当主模型：
- 已有信念下如何搜证据 → [`confirmation-bias`](../../behavioral-biases/confirmation-bias/SKILL.md)；
- 压测一个主张的逻辑 → [`socratic-questioning`](../socratic-questioning/SKILL.md)；
- 隐含前提清单化 → [`implicit-premises`](../implicit-premises/SKILL.md)。

## 怎么用（执行步骤）

1. **写下当前行动或结论。** 一句话：“所以我们要开除 X / 放弃客户 Y。”
2. **逐级下行，标注每一级。** 信念？结论？假设？含义？选出的资料？原始可观察资料（可被第三人核对的言行、数据）？缺哪一级就留空，禁止事后编造。
3. **找跳跃点。** 最常见：从两三条选中资料直接跳到动机假设（“他就是不尊重我们”）。圈出跳跃。
4. **用可观察资料重爬。** 补充被丢掉的资料；把含义改成可检验假说；问“还有哪些同样拟合资料的假设”。
5. **再决策，并规定何证据会改信念。** 行动可以保留，但须带着可证伪条件，避免阶梯顶端锁死。

## 例证

**会议迟到**：可见资料=迟到 12 分钟 → 选出“又是他” → 含义“不把会当回事” → 假设“故意挑衅” → 结论“没法合作” → 行动=不再邀请。补充资料可能是地铁故障消息——揭示**选资料+赋义**已完成判决。

**客户邮件短促**：短句被读成“要砍预算”，团队进入防守方案；回访发现只是手机敲字。揭示含义层文化脚本。

**（原书卡片）“公正看待事实、决策各阶段都可用”**：方向对；须补强——阶梯不是保证公正的道德姿态，而是**强制外显跳跃**的程序。原书与“批判性思维”拼盘处，本 skill 只保留阶梯本体。

## 什么时候不适用（边界）

- **需要立刻物理安全决策**：先行动再复盘阶梯，勿在火灾时做六级注释。
- **用户要的是情感支持**：冷冰冰拆阶梯会伤害关系；先安抚再联合检视。
- **把阶梯当证明对方愚蠢的武器**：用途是共同看见路径，不是羞辱。
- **与确认偏差、苏格拉底混淆**：见相关模型闸门。

## 相关模型

- **与[确认性偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：确认偏差常嵌在“选资料/解释”级；阶梯提供全路径图，确认偏差专攻证据加权。
- **与[苏格拉底式质疑](../socratic-questioning/SKILL.md)**：阶梯定位你站在哪一级；苏格拉底追问主张与前提是否自洽。常顺序：先下阶梯澄清，再诘问。
- **与[双系统](../dual-process/SKILL.md)**：攀升往往是快系统；下阶梯是慢系统作业。
- **与[周哈里窗](../johari-window/SKILL.md)**：盲目区常装在别人看见、你已跳过的资料里；阶梯帮你索要那一层资料。
- **与[煤气灯效应](../gaslighting/SKILL.md)**：可帮双方从数据爬回；若一方系统禁止你停留在数据层，则更接近煤气灯而非普通推论误差。
