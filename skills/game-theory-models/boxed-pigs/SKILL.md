# 智猪博弈 Boxed Pigs Game

## 这是什么

**强者更可能去按按钮（提供公共品），弱者搭便车等待。**

非对称支付的 2×2：按按钮有成本，食物距离使大猪按、小猪等成为典型纳什。寓意：能力/规模不对称时，公共品常由强者提供；不是道德批评小猪，而是支付结构。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "智猪博弈"
- "是不是该让大的去做"
- "小的搭便车合不合理"

**不要**在以下情况套用本模型：

- 对称背叛占优 → ../prisoners-dilemma/SKILL.md
- 对称信任合作风险 → ../stag-hunt/SKILL.md
- 公平分配联盟收益 → ../shapley-value/SKILL.md

## 怎么用（执行步骤）

1. **标出不对称。** 谁行动成本更低/收益更大？写出按按钮成本与抢食优势。
2. **填 2×2 并找纳什。** 典型：小猪等待、大猪行动。若支付改动，纳什可能变。
3. **翻译到现实角色。** 大厂做标准、大股东监督、大同学做组项目——核对是否同构。
4. **改结构选项。** 补贴行动者、惩罚搭便车、降低按钮成本。输出：纳什谁行动 + 改法。

## 例证

**课堂小组**：能力强者包办、弱者挂名。揭示支付（成绩分配）决定谁按按钮。

**行业标准**：主导厂商推标准、小厂商跟随。揭示规模不对称公共品。

## 什么时候不适用（边界）

- **道德绑架**：模型不证明弱者“应该”永远搭；可改规则。
- **多人不对称**：2×2 寓言需推广时谨慎。

## 常见误用

- **美化剥削**：强者过劳不是美德课，是结构问题。
- **与囚徒混用**：智猪关键是不对称，不是双方优势背叛。

## 相关模型

- **与[囚徒困境](../prisoners-dilemma/SKILL.md)**：对称优势背叛走对方。
- **与[鹰鸽博弈](../hawk-dove/SKILL.md)**：不对称冲突/资源争夺另一谱系。

## 记忆钩子

按钮有成本时，常常是大猪去按。
