# 损失规避 Loss Aversion

## 这是什么

损失规避指：相对某个参照点，损失带来的主观痛苦**通常大于**同等幅度收益带来的快乐。Kahneman 与 Tversky 的前景理论把它写进价值函数——在参照点附近，损失侧比收益侧更陡。经验研究里损失/收益敏感度之比常落在约 2 附近，但这是**平均值与实验估计**，不是人人适用的物理常数。

它解释一类稳定现象：人们更努力避免失去已有的，而不是去获取尚未拥有的同等之物；同一结果被描述成“会死 X 人”或“会救 Y 人”时，选择会翻转（框架效应）。在损失框架下，人有时会**更愿意赌一把**以求扳平；在收益框架下则偏保守——这是风险态度随框架变化，不是固定的“胆小”或“赌徒”人格。

相关但不可等同：禀赋效应（拥有后估值上升）、现状偏见、沉没成本谬误（用已投入合理化继续）。损失规避是其中一种心理动力，不是这些标签的总称。

## 什么时候用

- 不愿卖掉已亏损的资产/项目，因为“一卖就真的亏了”；
- 谈判或产品文案在“获得感”与“失去感”之间选框架；
- 用户说同等金额“赚到没感觉、亏了受不了”；
- 直接提到损失厌恶 / loss aversion。

**不要**当主模型：
- 理由是“都已经投入这么多了”（先走沉没成本）；
- 问题是互斥选项各放弃什么（机会成本）；
- 要设计不对称暴露与可选性（反脆弱）。

## 怎么用（执行步骤）

1. **写出参照点。** 损失规避相对“相对于什么”才成立：买入价、昨日净值、同事水位、承诺过的目标。参照点一变，同一现金流可以从“盈利”变成“亏损”。先冻结当前参照，再讨论感觉。
2. **把得失改写成同一会计语言。** 用终态财富、剩余期望值或净影响重述选项，暂时拿掉“亏/赚”标签。若改写后排序大变，说明框架在驱动，而不仅是基本面。
3. **分开两件事：不对称权重 vs 真实下行。** 问：若收益与损失的金额对调，痛苦与快乐是否明显不成比例？若是，标记损失规避。同时检查最坏情形是否归零——若会出局，保守可以是理性，不是“该克服的偏见”。
4. **检查风险态度是否随框架翻转。** 收益区死守小赢、损失区为回本加大赌注，是典型模式。对策：事先写好止损/止盈规则；用“最终组合价值”决策，而不是“这只股票有没有回到成本价”。
5. **改框架时要诚实。** 产品与政策可以用“避免损失”促进行动，但对本用户做决策顾问时，目标是**对齐真实终态**，不是单方面用更痛的框架操纵他自己。指出框架差异，让两边都看见。

## 例证

**硬币赌注拒绝**：期望值为正的小额对赌（输赢各半、赢略多于输）常被拒绝，因为预期痛苦压过预期快乐。它揭示的是**参照点附近的不对称权重**，不是人算错了概率。

**处置效应（disposition effect）**：投资者倾向于过早卖掉盈利仓位、继续持有亏损仓位——“把浮亏变实亏”的痛感阻止止损。成本价作为参照点，使“回本”压过对未来收益的评估。

**框架手术方案**：同一医疗结果表述为“90% 存活”或“10% 死亡”会改变选择比例。揭示的是描述框架激活了收益或损失编码，而非信息集本身不同。

**（原书卡片）损失痛苦约为收益快乐的 2–2.5 倍**：数量级与文献常引估计同向，但不要写成定律；个体、文化、金额大小与领域都会改变斜率。卡片对“收益区风险厌恶、损失区风险寻求”的概括可用，须补上“相对参照点框架”这一前提。

## 什么时候不适用（边界）

- **真实存在归零或灾难性下行时**：加重损失权重可能是适应性的；处方应是限制敞口，不是鼓励“别怕损失”。
- **系数不可当税率使用**：不要用“乘以 2”给用户的人生决策做伪精确换算。
- **不等于风险厌恶人格**：框架一变，同一人可以既保守又爱赌。
- **本模型不覆盖前景理论全文**：敏感度递减、概率权重、四重模式等见 [`prospect-theory`](../prospect-theory/SKILL.md)；此处只处理得失不对称。

## 常见误用

- **“乘以 2～2.5 再比”**：把文献斜率当税率 → 只诊断不对称是否存在，不做定点换算。
- **把真实归零风险叫“该克服的偏见”**：会出局时的保守可能是理性 → 处方是限敞口，不是“别怕损失”。
- **当成固定风险厌恶人格**：框架一变同一人可既保守又爱赌 → 先冻结参照点，再用终态语言重述。
- **要谈概率权重/四重模式却停在本条**：全文框架 → 转 [`prospect-theory`](../prospect-theory/SKILL.md)。

## 相关模型

- **与[前景理论](../prospect-theory/SKILL.md)**：全文框架（参照点+价值函数+概率权重）；本条是其中损失侧更陡的组件专条。
- **与[沉没成本](../sunk-cost/SKILL.md)**：沉没成本管“已投入能不能当理由”；损失规避管“同等得失的痛感不对称 / 框架”。常一起出现：浮亏仓位既有沉没感，又有损失框架。
- **与[机会成本](../../econ-micro-markets/opportunity-cost/SKILL.md)**：机会成本比较面向未来的替代价值；损失规避常让人过度锚定“保住现状”。
- **与[反脆弱](../../thinking-models/antifragility/SKILL.md)**：若问题是如何配置暴露从波动中获益，走反脆弱；本模型只诊断得失权重是否扭曲。
- **与[双系统](../../thinking-models/dual-process/SKILL.md)**：痛感由快系统放大；止损规则需事前用慢系统写好。
