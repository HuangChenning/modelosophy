# 斗鸡博弈 Chicken Game / Game of Chicken

## 这是什么

**谁先让谁丢面，但互不让则两败俱伤——对撞最差。**

两纯策略纳什（我进你让 / 我让你进）+ 常有混策略；与囚徒不同：相互强硬是最差而非占优均衡。边缘政策、刹车对峙、价格战边缘常用此结构。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "斗鸡博弈"
- "谁先让步"
- "硬碰硬会不会同毁"

**不要**在以下情况套用本模型：

- 双方招供占优 → ../prisoners-dilemma/SKILL.md
- 合作风险型信任 → ../stag-hunt/SKILL.md
- 演化攻击/退让比例 → ../hawk-dove/SKILL.md

## 怎么用（执行步骤）

1. **验证支付：对撞最差。** 若相互强硬不是最差，可能不是斗鸡。
2. **标两个纯纳什。** 一进一让的两格；讨论哪一方更可能让。
3. **引入承诺与观众成本。** 扔掉方向盘、当众放话改变支付——标是否可信（SPE）。
4. **给降级选项。** 面子守恒的让步、第三方仲裁、议题拆分。输出：结构确认 + 降级设计。

## 例证

**冷战边缘**：互不退但核战争最差。揭示沟通与红线管理。

**两车窄路**：一方倒车双方更好。揭示协调谁让。

## 什么时候不适用（边界）

- **情绪与观众**：现实支付含面子，模型要写入。
- **伦理**：不协助把对方逼向真实灾难的操纵。

## 常见误用

- **当成囚徒**：斗鸡无严格优势强硬。
- **只鼓励更强硬**：升级对撞违背模型警示。

## 相关模型

- **与[鹰鸽博弈](../hawk-dove/SKILL.md)**：演化版冲突/分享；连续种群叙事走对方。
- **与[猎鹿博弈](../stag-hunt/SKILL.md)**：合作共赢 vs 安全背叛。

## 记忆钩子

面子贵，命更贵——对撞格最红。
