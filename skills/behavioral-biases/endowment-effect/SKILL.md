# 禀赋效应 Endowment Effect

## 这是什么

**一旦拥有某物，卖出愿接受的最低价常显著高于未拥有时愿支付的最高价。**

经典“杯子实验”：随机获得杯子的人索价远高于未获得者愿付价。常见解释把它连到损失规避——卖出被编码为损失。但禀赋效应强调的诊断点是：**所有权本身改变估值**，而不只是一般性的“亏更痛”。

## 什么时候用

- "这股票/这房/这收藏到我手里就不能便宜卖"
- WTP（愿付）与 WTA（愿接受）差距大到阻断互利交易

**不要**当主模型：

- 无所有权变化、只谈框架痛感 → [`loss-aversion`](../loss-aversion/SKILL.md)
- 理由是已投入时间金钱 → [`sunk-cost`](../sunk-cost/SKILL.md)

## 怎么用（执行步骤）

1. **确认所有权是否为关键变量。** 若明天随机决定你是否拥有，估值是否大变？是则进入禀赋诊断。
2. **分别报 WTP 与 WTA。** 未拥有时最多付多少；拥有时最少卖多少。记录差距与原因话术（“有感情”/“市场会涨”）。
3. **剥离特异质价值。** 问：陌生人同样拥有是否也应同价？若只有你因“是我的”加价，标禀赋；若有改装/学习曲线，记真实特异质价值。
4. **用机会成本重估。** 卖出所得可买什么？写下一句替代用途；若替代明显更优仍不卖，禀赋/损失框架在挡道。

## 例证

**杯子与巧克力交换不足**：随机禀赋后交易量低于标准理论预期——揭示**所有权压制互利交换**。

**员工持股“情感溢价”**：拒绝再平衡集中仓，理由是“公司的股票不一样”——需区分信息优势与纯禀赋。

## 什么时候不适用（边界）

- **高转换成本**：手续费、税收、搜索成本使“不卖”理性。
- **不可替代的情感物品**：遗物等允许非市场估值，但应显式承认，不伪装成公允市价。
- **卖方垄断信息**：价差可能来自知情，而非禀赋。

## 常见误用

- **=损失规避**：损失规避更广；禀赋专指因拥有而抬估值。
- **用禀赋效应合理化惜售泡沫**：诊断工具不是护身符。

## 相关模型

- **与[损失规避](../loss-aversion/SKILL.md)**：机制常相关；本条抓所有权→估值跳跃。
- **与[现状偏差](../status-quo-bias/SKILL.md)**：不交易维持现状；禀赋解释“为何觉得现状里的东西更值钱”。
- **与[沉没成本](../sunk-cost/SKILL.md)**：购入成本是沉没；禀赋是拥有状态本身。

## 记忆钩子

东西一进口袋，心里就标了更高价。
