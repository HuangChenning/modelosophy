# 间隔重复 Spaced Repetition

## 这是什么

**间隔重复**：在材料即将难以提取前安排主动回忆，并按成败**拉长或缩短**下次间隔，使同等学习时间更多转化为长期保持。SRS（Spaced Repetition System）是其工具化形态（如 Anki）。

机制要点：**(1) 检索练习**优于再认/重读；**(2) 期望难度**——太易则浪费，太难则挫败；**(3) 间隔效应**——分散优于集中突击。本 Skill 交付的是**日程与卡片操作规程**，不是背诵艾宾浩斯百分数。

**与遗忘曲线**：[`forgetting-curve`](../forgetting-curve/SKILL.md) 解释衰减现象与原则；用户要「怎么排复习/怎么调 SRS」走本模型。

## 什么时候用

- "帮我做间隔复习计划 / Anki 策略"
- "间隔重复 / SRS / spaced repetition 怎么用"
- 词汇、术语、公式、 orthographic 事实等可卡片化材料

**不要**当主模型：

- 只问「为什么会忘」的现象解释 → [`forgetting-curve`](../forgetting-curve/SKILL.md)
- 复杂技能动作/创作 → [`deliberate-practice`](../deliberate-practice/SKILL.md)
- 概念根本没懂 → [`feynman-technique`](../feynman-technique/SKILL.md)

## 怎么用（执行步骤）

1. **切成最小可测单元。** 一面一问（原子卡片）；忌「整章一张」。判据：合上材料能否在 10–20 秒内给出唯一答案。
2. **编码后立刻首测。** 当日主动回忆；错则看答案再测，禁止只标「已读」。
3. **设定初始间隔并只认检索结果。** 例：通过 → 1–2 天；勉强 → 当日/次日；失败 → 缩短并改写问题面。工具默认算法可作起点，但以你的提取成败为准。
4. **按信号调间隔。** 轻松正确 → 显著拉长；犹豫正确 → 小幅拉长或持平；错误 → 重置到短间隔并检查卡片是否歧义/过载。
5. **定期清理坏卡片。** 合并过度细分、拆开「两问一张」、删除过时内容。判据：复习队列是否出现「永远不会」或「永远秒过」的两极。
6. **加入情境提取。** 每周用真实题目/对话提取一次，避免只会卡片语境。

## 例证

**语言 SRS**：生词在遗忘前自测、间隔拉长——揭示**时点与检索**，不是「再读三遍」。

**医学生症状卡片**：把「症状→鉴别」做成双向检索，比只高亮课本——揭示主动提取。

**（局限）**：算法参数因人而异；材料理解空洞时 SRS 会固化错答——先费曼再制卡。

## 什么时候不适用（边界）

- **理解性空洞**：先补理解再间隔。
- **运动与复杂迁移技能**：需刻意练习与变化情境。
- **睡眠严重不足**：巩固受损，先恢复再堆队列。
- **不可原子化目标**：如「成为更好的领导」——先拆可测行为。

## 常见误用

- **重读当复习**：把「又看了一眼」当间隔重复 → 必须合上材料提取。
- **卡片过大**：一卡十个知识点 → 拆原子。
- **与遗忘曲线抢触发**：只想听曲线故事 → 对方；要日程操作 → 本模型。
- **队列爆炸放弃**：新卡无限加 → 限新卡配额，优先到期复习。

## 相关模型

- **与[遗忘曲线](../forgetting-curve/SKILL.md)**：曲线 = 为何衰减；本模型 = 如何排复习。现象解释走曲线；SRS 操作走本模型。
- **与[刻意练习](../deliberate-practice/SKILL.md)**：保持事实走间隔；提升表现走刻意练习。
- **与[费曼技巧](../feynman-technique/SKILL.md)**：制卡前用费曼暴露空洞，避免背错。
- **与[元认知](../metacognition/SKILL.md)**：用提取成败信号调节间隔与策略。
- **与[系列位置效应](../../systems-classic-effects/serial-position-effect/SKILL.md)**：单次列表首因近因；本模型管跨时程复习。

## 记忆钩子

在**快忘未忘**时主动考自己，并对了再拉长间隔。
