# 帕金森定律 Parkinson's Law

## 这是什么

**帕金森定律**（C. Northcote Parkinson, 1955）：**工作会膨胀到填满所有可用时间**；引申到官僚：官员为制造工作而增聘下属，组织在无相应产出增长时膨胀。

可操作内核：时间与编制是**软约束**时，范围与会议会自我生长。对抗方式是硬期限、WIP 限制、编制与产出挂钩。

## 什么时候用

- "两周的活拖成两个月"
- "加人后更忙且更慢"
- "会议与流程自我繁殖"

**不要**当主模型：
- 晋升到不胜任 → [`peter-principle`](../peter-principle/SKILL.md)
- 待遇易升难降 → [`ratchet-effect`](../ratchet-effect/SKILL.md)
- 系统结构杠杆 → [`systems-thinking`](../systems-thinking/SKILL.md)

## 怎么用（执行步骤）

1. **固定交付定义与期限。** 先写 Done 标准与截止，再开口做；无期限则默认会被填满。
2. **测实际耗时分布。** 同类任务历史中位数；若总贴近“给定时间上限”，帕金森嫌疑高。
3. **砍可用时间做实验。** 同范围缩短 30% 窗口，看质量是否真崩；常发现水分。
4. **审编制增量。** 加人必须对应吞吐指标；否则可能进入“制造工作”循环。
5. **设 WIP 与会议预算。** 限制并行与会时，防止膨胀换通道。

## 例证

**学生交作业**：越晚交越拖到死线前。揭示**时间填满**。

**官僚笑话原文**：殖民地机关人员增长与帝国收缩无关的讽刺。揭示组织膨胀叙事源头。

**软件项目**：缓冲一加，范围与返工跟进。揭示工程帕金森。

## 什么时候不适用（边界）

- **真正不确定的探索**：需要缓冲，但缓冲应显式标记为探索预算。
- **合规硬耗时**：外部法定等待不是自我膨胀。
- **人手不足的过载**：那是资源短缺，不是帕金森——先分清。

## 常见误用

- **无脑砍时间**：质量门槛崩溃。要有 Done 标准。
- **攻击所有管理岗**：定律批膨胀机制，不是仇视协调。
- **与彼得混用**：一个时间/编制，一个晋升胜任力。

## 相关模型

- **与[彼得原理](../peter-principle/SKILL.md)**：常共存于官僚，但诊断问题不同。
- **与[棘轮效应](../ratchet-effect/SKILL.md)**：编制/流程升上去难降，可与帕金森叠加。
- **与[艾森豪威尔矩阵](../../efficiency-execution/eisenhower-matrix/SKILL.md)**：用优先级对抗“填满时间的假忙”。

## 记忆钩子

时间桶有多大，活就胀多大——先焊死 Done 和期限。
