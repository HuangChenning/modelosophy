# GE-麦肯锡九宫 GE–McKinsey Matrix

## 这是什么

**GE-麦肯锡九宫（nine-box）**：在二维上评估业务单元——纵轴 **Industry Attractiveness（行业/市场吸引力）**，横轴 **Business / Competitive Strength（本业务相对竞争实力）**——各分高/中/低，得九格；再按格落入三大战略带：**投资成长（Invest/Grow）**、**选择或维持（Selectivity / Earnings）**、**收割或退出（Harvest/Divest）**。

它由麦肯锡在 1970 年代为通用电气（GE）等多业务公司设计，意在改进 BCG 成长-份额矩阵的粗糙处：吸引力与实力都用**多因子加权**，而不是单一「市场增长率」和「相对份额」。它仍是**组合启发式**，不是精确估值模型；因子选择与权重决定结论质量。

与 BCG 的鉴别：BCG 快、两变量；九宫慢、多变量、九格策略更细。同一组合可先 BCG 粗筛再九宫细评，但须统一「业务单元」与「市场」定义。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "GE 九宫 / 麦肯锡九盒 / 九宫格组合"
- "行业吸引力怎么打分、业务实力怎么打分"
- "BCG 太粗，要多因子看投砍"
- 集团/多 SBU 年度组合会、剥离与加注决策

**不要**在以下情况套用本模型：

- 只要四象限快速启发式且数据只有增长与份额 → 可先 [`bcg-matrix`](../bcg-matrix/SKILL.md)
- 单行业利润结构诊断（不谈组合）→ [`porters-five-forces`](../porters-five-forces/SKILL.md)
- 组织能否兑现已定战略 → [`mckinsey-7s`](../mckinsey-7s/SKILL.md)
- 单资源是否构成持续优势 → [`vrio`](../vrio/SKILL.md) / [`economic-moat`](../economic-moat/SKILL.md)

## 怎么用（执行步骤）

每一步必须给出**可操作判据**（问什么、写什么、通过/失败长什么样），禁止只换说法重复结论。

1. **定义业务单元（SBU）与「所在行业」。** 写清客户群、竞品集合、地理。判据：单元是否有可独立讨论的战略与大致损益；行业边界一变分数应重做——若边界不稳，先争论边界，不争论格子。

2. **列出吸引力因子并赋权。** 典型因子（按情境取 5–8 个，勿堆 20 个）：市场规模与增长、行业利润/回报水平、竞争强度、进入壁垒、技术/监管变数、客户集中度等。权重和为 1；写清数据来源。判据：每个因子有可引用证据或显式「低置信度」标记。

3. **列出竞争实力因子并赋权。** 典型：相对份额或份额趋势、品牌/渠道、成本地位、技术/产品能力、管理与执行、对客户关键需求的匹配等。可与护城河/VRIO 证据对齐，但本步输出的是**相对对手的强弱分**，不是壁垒类型论文。判据：对照 1–2 个明确对手，禁止「我们很强」无参照。

4. **打分落入九宫并标注置信带。** 每因子 1–5 分 × 权重 → 两轴综合分 → 高/中/低（阈值事先写死，如各三分位）。对不确定因子做敏感性：权重或分数在合理区间摆动是否换格。判据：换格则输出「争议格」而非假精确坐标。

5. **按战略带写默认动作假设（可被推翻）。**  
   - 高吸引 × 高/中实力偏上：优先投资、巩固优势。  
   - 中吸引或中实力等「对角线」带：选择加注、收割现金或有条件维持——必须写**选择标准**（如 12 个月内份额止跌才续投）。  
   - 低吸引 × 低实力：收割、剥离或极小维持。  
   判据：每个 SBU 一个主动作 + 触发复盘的指标；禁止全员「投资成长」。

6. **交叉检验现金流、能力与组织。** 问：高吸引格是否真有资金与 Skills？低格是否情感绑架？需要组织变革时转 [`mckinsey-7s`](../mckinsey-7s/SKILL.md)。产出组合动作清单与退出/加注门槛。

> 常见错误提醒：把「吸引力」打成「我们喜欢这行业」；把实力打成收入规模（规模≠相对优势）。

## 例证

**多因子纠正份额幻觉**：某业务相对份额尚可（BCG 像现金牛），但行业监管收紧、利润池萎缩（吸引力低）→ 九宫倾向收割而非继续重仓——揭示「份额高」不等于「值得长期投」。

**选择带需要显式门槛**：中等吸引力 × 中等实力的「问题业务」若只写「观察」，资源会被闲置耗尽；应写「N 个月内达到 X，否则退出」——揭示选择性单元的治理要点。

**与 BCG 连用**：集团先用 BCG 把明显瘦狗/明星分开，对「问题儿童」与边界模糊单元再用九宫多因子细评——揭示粗细工具分工，而非互相推翻。

## 什么时候不适用（边界）

- **单一业务或尚无市场边界**：九宫过重；先用实验度量或五力看进入是否值得。
- **因子与权重被政治绑架**：分数服务于已定结论 → 停用矩阵，改开独立红队/预验。
- **平台/生态交叉补贴极强**：单元损益与「行业」难切分 → 矩阵暗示过强，需补飞轮/网络视角。
- **需要组织落地设计**：九宫只排优先级，不设计结构与文化 → 接 7S。

## 常见误用

- **假精确**：小数点分数决定投上亿 → 用区间与敏感性。
- **吸引力=增长率**：忽略利润池与竞争强度 → 补五力类因子。
- **实力=规模**：大而不强仍高分 → 强制相对对手。
- **与 BCG 两套矛盾结论并存**：统一 SBU/市场定义后解释差异（多因子 vs 两变量），选一个主决策框或显式分层使用。
- **九格全挤在「选择」**：回避退出与重仓 → 检查阈值是否被调到永远中庸。

## 相关模型

- **与[BCG 矩阵](../bcg-matrix/SKILL.md)**：BCG 用增长×相对份额四格快速启发式；九宫用多因子九格细评。数据只够两变量或要快筛 → BCG；要多因子/更细策略带 → 九宫。可先粗后细，勿双轨打架。
- **与[五力](../porters-five-forces/SKILL.md)**：五力深入单行业结构，其结论应压缩进「吸引力」因子，而非用九宫替代五力深潜。
- **与[护城河](../economic-moat/SKILL.md)** / **[VRIO](../vrio/SKILL.md)**：实力轴的证据来源；护城河/VRIO 讲可持续性与资源审计，九宫讲组合位置。
- **与[第二曲线](../second-curve/SKILL.md)**：九宫低吸引高实力的现金单元常为输血方；高吸引低实力可能是第二曲线候选，需另判实验门槛。
- **与[麦肯锡 7S](../mckinsey-7s/SKILL.md)**：组合优先级定完，组织对齐用 7S。
- **与[SWOT](../swot/SKILL.md)**：单业务态势用 SWOT；多业务组合定位用九宫/BCG。

## 记忆钩子

**吸引 × 实力 → 九格三带**：投、选、撤——分数服务于因子与权重，权重服务于证据，证据服务于可杀可投的门槛。
