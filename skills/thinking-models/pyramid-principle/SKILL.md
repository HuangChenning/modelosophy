# 金字塔原理 Pyramid Principle

## 这是什么

Barbara Minto 的金字塔原理：思想应组织成**顶层一个清晰结论（或答主问题的答案），其下若干组支撑论点，每组再被更细证据支撑**。规则：

1. **结论先行**（自上而下）：先给答案，再展开理由；
2. **以上统下**：每一层是对下一层的概括，不是清单堆砌；
3. **同层归组且 MECE**：同一层要点互相独立、合起来覆盖该层要回答的问题；
4. **逻辑顺序**：时间序、结构序或重要性序，选一种并贯彻。

可选开场 **SCQA**（Situation–Complication–Question–Answer）：用情境与冲突引出读者心中的问题，再给出金字塔顶的 Answer。

它是**论证与表达结构**，不是发现新事实的方法。空塔可以很整齐却没有证据。

## 什么时候用

- 写汇报、邮件、策略备忘录，需要领导快速抓住结论；
- 材料很多但“不知道先说什么”；
- 直接提金字塔原理 / 结论先行 / SCQA / Minto。

**不要**当主模型：
- 只是把议题拆成不重不漏的桶、尚未形成主张 → [`mece`](../mece/SKILL.md)；
- 检验主张是否自相矛盾 → [`socratic-questioning`](../socratic-questioning/SKILL.md)；
- 从硬约束重建方案 → [`first-principles`](../first-principles/SKILL.md)。

## 怎么用（执行步骤）

1. **写清读者的主问题。** 一句话：“读者读完要带走什么答案？”没有问题就没有塔顶。
2. **先写塔顶结论（Answer）。** 必须是对主问题的直接答复，禁止用“情况复杂、见下文”顶替。
3. **列出支撑该结论的 2–5 个关键论点（Key Line）。** 每个论点应能单独回答“为什么 / 如何证明结论”。同层检查 MECE；混轴则改组。
4. **向下挂证据。** 数据、案例、计算只挂在对应论点下；不能支撑任何 Key Line 的素材删掉或另开问题。
5. **选逻辑序并可选 SCQA。** 对外沟通可用 SCQA 引入；对已对齐上下文的读者可直接结论先行。写完后自检：抽掉任一层，上层是否仍能被正当概括？

## 例证

**战略备忘录**：顶句“建议进入 X 市场”；下挂市场规模、能力匹配、竞争可赢三点——揭示**先答再证**，而不是按调研时间线流水账。

**失败的“漂亮空塔”**：每层标题工整但无数据与可证伪断言——揭示金字塔是结构，**不能代替证据**。

**（原书卡片）结论先行 + 分组论证**：结构方向正确；卡片易把“金字塔”收成万能写作鸡汤。须强调：先想清楚主问题与证据，再套结构；SCQA 是可选引入，不是每段必填模板。

## 什么时候不适用（边界）

- **探索早期 / 头脑风暴**：先发散再收敛；过早定塔顶会封死异常信息。
- **证据尚未支持结论**：禁止为了汇报好看而倒推空论点。
- **纯分类任务**：只要拆桶不要主张时，用 MECE，不必硬上金字塔。
- **文学叙事或悬念文体**：结论先行会破坏体裁；本模型面向商务/分析沟通。

## 相关模型

- **与[MECE](../mece/SKILL.md)**：MECE 管同层分类不重不漏；金字塔管结论—论据的纵向论证结构。金字塔的每一层内部应尽量 MECE。
- **与[演绎法](../deductive-reasoning/SKILL.md)**：演绎检查形式有效；金字塔组织表达顺序。有效推理仍需可读结构。
- **与[隐含前提](../implicit-premises/SKILL.md)**：塔顶结论常依赖未写出的前提；补前提后再建塔。
- **与[黄金圈](../golden-circle/SKILL.md)**：黄金圈偏 Why–How–What 叙事动机；金字塔偏答主问题的论证层级。
