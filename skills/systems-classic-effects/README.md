# Systems & Classic Effects

路径：`skills/systems-classic-effects/<skill-name>/SKILL.md`。

当前合计 **30** 个（目标约 30；含既有成品与 `v0.x-draft` 新建）。

## Skills

- **[barrel-effect](./barrel-effect/SKILL.md)** — 木桶效应 *(draft)*：系统有效容量由最短板 / 最紧约束决定
- **[black-swan](./black-swan/SKILL.md)** — 黑天鹅 *(draft)*：稀有、冲击大、事后可叙事的极端事件
- **[boiling-frog](./boiling-frog/SKILL.md)** — 温水煮青蛙 *(draft)*：渐进恶化中的基线麻木（隐喻）
- **[broken-windows](./broken-windows/SKILL.md)** — 破窗效应 *(draft)*：小失序信号被放任后诱发更大失序
- **[butterfly-effect](./butterfly-effect/SKILL.md)** — 蝴蝶效应：敏感依赖 / SDIC：微小初值差在非线性系统中放大，长期预报失效
- **[catfish-effect](./catfish-effect/SKILL.md)** — 鲶鱼效应 *(draft)*：引入可信竞争刺激以激活惰性群体
- **[domino-effect](./domino-effect/SKILL.md)** — 多米诺骨牌效应 *(draft)*：沿耦合链的逐步连锁触发
- **[entropy-increase](./entropy-increase/SKILL.md)** — 熵增定律 *(draft)*：孤立系统趋向无序；组织隐喻需划清边界

- **[free-rider-effect](./free-rider-effect/SKILL.md)** — 搭便车效应 *(draft)*：享受集体收益却少付成本，公共品供给不足
- **[gray-rhino](./gray-rhino/SKILL.md)** — 灰犀牛 *(draft)*：高概率大冲击且已在视野内却仍被拖延
- **[halo-effect](./halo-effect/SKILL.md)** — 光环效应 *(draft)*：单一突出特质不当外推到整体评价
- **[hawthorne-effect](./hawthorne-effect/SKILL.md)** — 霍桑效应 *(draft)*：被观察本身改变行为，污染因果解释
- **[lock-in-effect](./lock-in-effect/SKILL.md)** — 锁定效应 *(draft)*：转换成本困住用户或组织
- **[long-tail](./long-tail/SKILL.md)** — 长尾理论：分发成本足够低时，利基需求聚合可观
- **[matthew-effect](./matthew-effect/SKILL.md)** — 马太效应 *(draft)*：累积优势使强者愈强、弱者愈弱
- **[metcalfes-law](./metcalfes-law/SKILL.md)** — 梅特卡夫法则：兼容网络潜在连接数近似随节点数平方增长
- **[murphys-law](./murphys-law/SKILL.md)** — 墨菲定律 *(draft)*：可能出错且机会足够则终将出错——用于防呆
- **[pareto-principle](./pareto-principle/SKILL.md)** — 二八定律：少数原因贡献多数结果；先度量集中度再分配精力
- **[parkinsons-law](./parkinsons-law/SKILL.md)** — 帕金森定律 *(draft)*：工作 / 组织膨胀到填满可用时间与编制
- **[path-dependence](./path-dependence/SKILL.md)** — 路径依赖：历史选择经报酬递增等机制锁住未来方向
- **[peter-principle](./peter-principle/SKILL.md)** — 彼得原理 *(draft)*：因胜任而被晋升到不胜任的层级
- **[projection-effect](./projection-effect/SKILL.md)** — 投射效应 *(draft)*：以己度人、把自我模型安到他人头上
- **[pygmalion-effect](./pygmalion-effect/SKILL.md)** — 皮格马利翁效应 *(draft)*：期望通过对待差异塑造实际表现
- **[ratchet-effect](./ratchet-effect/SKILL.md)** — 棘轮效应 *(draft)*：消费 / 待遇 / 标准易升难降
- **[second-order-thinking](./second-order-thinking/SKILL.md)** — 二阶思维 *(draft)*：追问“然后呢”：后果的后果与他人反应
- **[serial-position-effect](./serial-position-effect/SKILL.md)** — 系列位置效应：有序信息中开头（首因）与结尾（近因）更易被记住
- **[stereotyping](./stereotyping/SKILL.md)** — 刻板印象 *(draft)*：用群体标签替代个体证据
- **[system-dynamics](./system-dynamics/SKILL.md)** — 系统动力学 *(draft)*：存量、流量、延迟的动态建模与政策实验
- **[systems-thinking](./systems-thinking/SKILL.md)** — 系统思维：从事件升到行为模式、存量流量、反馈与杠杆点

## Notes

- 本目录均为**可执行** Skill（何时用 / 怎么用 / 边界 / 相关模型）。
- 原「9 字段知识卡」不作主交付；有用字段已吸收进各 `SKILL.md`。
- 新建条目为 `v0.x-draft`，未经 skill-creator 后处理压测；README「目前的进展」勿称为成品。
- 名录第十二类（`systems-complexity`）承接冰山/杠杆/临界点/耗散结构等；本目录保留效应与经典系统条目。`long-term-thinking` 仍留 `thinking-models/`。
- 清单「首因/近因」由 [`serial-position-effect`](./serial-position-effect/SKILL.md) 覆盖；「网络效应」由 [`metcalfes-law`](./metcalfes-law/SKILL.md) 覆盖。
