# 第二曲线 Second Curve

## 这是什么

**第二曲线**：组织或个人的增长常呈 S 形——导入、加速、成熟、减速。第二曲线主张在**第一曲线仍健康、但增长斜率将拐下之前**，投资下一条增长引擎，并处理双曲线并行期的资源与注意力冲突。

它解决的是**时机与过渡**，不是具体的价值曲线设计（蓝海）或低端颠覆路径（颠覆式创新）。

## 什么时候用

- "主业还行但增长变慢，要不要开新业务"
- "第二曲线 / S 曲线切换"
- 产品线迭代、职业转型、平台第二增长引擎

**不要**当主模型：

- 重建买方价值因素 → [`blue-ocean`](../blue-ocean/SKILL.md)
- 低端/新市场颠覆机制 → [`disruptive-innovation`](../disruptive-innovation/SKILL.md)
- 业务组合现金/增长分类 → [`bcg-matrix`](../bcg-matrix/SKILL.md)

## 怎么用（执行步骤）

1. **画第一曲线证据。** 用增长、利润、用户、产能利用率等标出现处阶段。判据：是否已现「增速下降但仍赚钱」。
2. **定义第二曲线候选的成功度量。** 与第一曲线不同的引擎（新客群/新模式/新技术），禁止只是「多做一个同质 SKU」。
3. **估计启动窗口。** 理想区：第一曲线现金流仍能输血，且组织尚未僵化到无法试错。太晚会缺弹药；太早可能饿死主业——写假设。
4. **隔离与输血规则。** 明确独立团队/预算比例、从主业抽资源的上限、冲突升级路径。判据：第二曲线是否有不被主业 KPI 掐死的空间。
5. **设杀伤开关与并表条件。** 何种数据停投；何种数据升为主曲线。禁止无退出标准的情怀项目。
6. **沟通叙事。** 对内解释「不是放弃主业」，减少第一曲线人才流失。

## 例证

**消费电子公司**：功能机利润高峰期投智能手机平台——揭示**高峰前启动**；等到崩盘再转则失去窗口。

**个人职业**：主业技能仍值钱时建立第二技能组合——揭示时间窗口。

**（局限）**：第二曲线常被当成开盲盒；无度量与隔离会变成分心项目。

## 什么时候不适用（边界）

- **第一曲线仍在加速且资源紧**：可小实验，但不必全面第二曲线叙事。
- **生存危机**：先止血，再谈曲线。
- **候选与主业无差异**：那是延伸，不是第二曲线。

## 常见误用

- **见顶才想起来**：窗口已过 → 强调提前信号。
- **并行无限项目**：无杀伤开关 → 补退出标准。
- **与蓝海混称**：有新曲线无价值重建仍可叫第二曲线；价值重建另走蓝海。
- **饿死主业**：输血无上限 → 设比例。

## 相关模型

- **与[蓝海战略](../blue-ocean/SKILL.md)**：第二曲线问何时切换；蓝海问新曲线价值逻辑。
- **与[颠覆式创新](../disruptive-innovation/SKILL.md)**：第二曲线候选若走低端轨迹，用颠覆检验在位者盲区。
- **与[BCG 矩阵](../bcg-matrix/SKILL.md)**：组合层面现金牛输血明星/问题业务；与第二曲线资源逻辑可连用。
- **与[飞轮](../flywheel/SKILL.md)**：新曲线需自我加强时设计飞轮。
- **与[路径依赖](../../systems-classic-effects/path-dependence/SKILL.md)**：切换成本与锁定会阻碍第二曲线。

## 记忆钩子

在**第一曲线还好的时候**播种第二曲线，并写清输血与停投规则。
