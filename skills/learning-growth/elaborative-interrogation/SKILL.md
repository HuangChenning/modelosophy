# 精细加工提问 Elaborative Interrogation

## 这是什么

**精细加工提问**：对要学的事实或主张主动问 **「为什么这一点会成立 / 为什么是这样而不是那样？」**，并给出与已知知识相连的理由——从而加深编码，而不是只复述命题。

它属于精细加工（elaboration）家族：新信息与旧知识的联系越多、越合理，提取越稳。本模型提供的是**可重复的提问规程**，不是「多想一会」的模糊建议。

**鉴别**：[`feynman-technique`](../feynman-technique/SKILL.md) 用完整讲解暴露空洞；本模型用短「为什么」把单点事实锚进知识网。[`retrieval-practice`](../retrieval-practice/SKILL.md) 问「是什么」；精细加工问「为何如此」。

## 什么时候用

- "记了很多事实但串不起来"
- "精细加工 / 为什么提问怎么用"
- 历史事实、科学陈述、商业原则、政策条款的理解型记忆

**不要**当主模型：

- 只要能否背出 → 先 [`retrieval-practice`](../retrieval-practice/SKILL.md)
- 整概念不会讲 → [`feynman-technique`](../feynman-technique/SKILL.md)
- 纯程序性动作瓶颈 → [`deliberate-practice`](../deliberate-practice/SKILL.md)

## 怎么用（执行步骤）

1. **写下目标陈述（一句）。** 例：「植物叶绿体含叶绿素」。判据：是可真可假的命题，不是章节标题。
2. **问「为什么合理？」并写 1–2 句理由。** 必须连到已有知识（功能、因果、对比）。写不出 → 标「缺口」，去查最小资料，禁止空喊「因为课本说」。
3. **再问「为何不是常见替代？」** 例：为何不是「只在根部」？强制对比，减少浅层理由。
4. **检查理由是否可证伪/可举例。** 只能循环定义 → 重写；能举反例边界更好。
5. **合上材料检索：先提事实，再提理由。** 只会口号不会理由 → 加工未完成。
6. **把稳固条目纳入间隔。** 理由可作为卡片反面或口头第二问。

## 例证

**「桥要做成拱形」**：只背形状 vs 追问载荷如何沿拱传向桥墩——揭示**理由成为提取线索**。

**管理原则「现场管理」**：问为何比只开会有效——连到信息滞后与激励，而非背词条。

**（局限）**：对任意约定（「停在红灯」的法规符号）强追物理「为什么」收益有限；改为社会约定+后果加工。

## 什么时候不适用（边界）

- **尚无任何相关先验**：先给最小讲解/类比，再问为什么。
- **需要精确程序且不容改写**：先正确执行，加工放在理解阶段。
- **把辩论当学习**：无限抬杠无结论 → 限时 2 个理由并检索验收。
- **事实本身错误**：精细加工会固化错信 → 先校验命题。

## 常见误用

- **假理由**：编一个听起来聪明但不连已知 → 要求指出连到哪条旧知识。
- **只问不答**：清单式「为什么」却不写答案 → 必须落笔。
- **与费曼互换**：整章不会 → 费曼；单句事实锚网 → 本模型。
- **替代检索**：只讨论为什么从不闭卷 → 加工后仍要提取。

## 相关模型

- **与[费曼技巧](../feynman-technique/SKILL.md)**：费曼要完整浅白讲解；精细加工是点状「为何」锚点。大洞用费曼，锚点用本模型。
- **与[检索练习](../retrieval-practice/SKILL.md)**：加工加深编码；检索巩固与诊断。顺序常为：理解/加工 → 检索 → 间隔。
- **与[双重编码](../dual-coding/SKILL.md)**：理由可用示意图支撑「为何箭头如此」。
- **与[迁移学习](../transfer-of-learning/SKILL.md)**：好的「为何」常是可迁移原则；用迁移任务验收。
- **与[元认知](../metacognition/SKILL.md)**：元认知监控「我是否只有假理由」；本模型提供具体问法。

## 记忆钩子

先问一句「为什么合理」，再往脑子里塞事实。
