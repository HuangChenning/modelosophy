# 定位 Positioning

## 这是什么

**定位**：在目标顾客的**心智阶梯**里，为自己（或品类）占据一个**简单、可对比、难被挤掉**的位置——不是产品功能清单，而是「相对谁、属于哪一类、凭什么被想起」。

Al Ries 与 Jack Trout 在 1970–80 年代系统化该概念：信息过载下，竞争发生在心智而非货架；有效定位常借既有心智格子（第一、对立、重新品类），而非堆砌卖点。

与波特「差异化战略」互补但不等同：定位回答**心智坐标**；差异化回答**价值活动如何支撑溢价**。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "我们到底要在用户脑子里占什么位置"
- "品类第一 / 对标谁 / 一句定位语"
- "功能很多但没人记得我们是谁"

**不要**在以下情况套用本模型：

- 只问行业利润池与议价 → [`porters-five-forces`](../porters-five-forces/SKILL.md)
- 已定心智位，要设计低成本结构 → [`cost-leadership`](../cost-leadership/SKILL.md)
- 已定心智位，要设计可感知差异活动系统 → [`differentiation-strategy`](../differentiation-strategy/SKILL.md)
- 多边平台冷启动与网络效应 → [`platform-strategy`](../platform-strategy/SKILL.md)

## 怎么用（执行步骤）

1. **界定竞争心智场域。** 写清：对谁（细分）、在什么使用情境、顾客会拿你和谁比。判据：能说出 2–3 个真实「替代想起对象」；说不出 → 场域未定义。
2. **画现有心智阶梯。** 对该场域列出顾客口头上的「第一、第二、其他」。判据：来自访谈/搜索/货架/社媒证据，禁止自嗨榜。
3. **选择定位策略类型。** 常见可执行选项：做品类第一；做强势第二的对立面；开辟/窄化新品类；改变比较维度。判据：选一种主策略，写「不做什么」。
4. **压成一句可检验定位。** 格式建议：「对〔谁〕，〔我们〕是〔品类〕里〔差异点〕」。判据：外人能否用该句预测你会拒绝哪些功能/渠道；不能 → 仍是口号。
5. **对齐证据与接触点。** 列出必须一致的产品、价格带、渠道、视觉与话术。判据：任一接触点若与定位冲突则标红并决定改接触点或改正位。
6. **设心智指标与复盘。** 如无提示提及率、品类联想第一提及、对标迁移率。判据：有基线与复测窗口；只用销售当唯一证据不合格。

## 例证

**品类对立定位**：后进者把战场从「更好的 X」改成「不是 X 的那种 Y」，降低与第一名正面对撞——揭示定位常靠重构参照系，而非功能碾压。

**功能堆砌失败**：参数全面却无人记得「是什么」——揭示心智格子比参数表更稀缺。

**与差异化连用**：定位定「专业轻量协作」，差异化再用价值活动保证「轻量」可感知且难抄——揭示定位是坐标，差异化是工程。

## 什么时候不适用（边界）

- **监管/招标规格主导、心智几乎不起作用**：先满足合规与关系，定位次之。
- **品类尚未被顾客理解**：需先教育品类，定位句会空转。
- ** internally 组织能力完全支撑不起该心智承诺**：先 VRIO/核心能力，再喊定位。

## 常见误用

- **口号当定位**：漂亮句子无法预测取舍 → 加「拒绝清单」。
- **人人都是目标顾客**：心智格子被稀释 → 收窄情境与人群。
- **与蓝海混为一谈**：蓝海改价值曲线与成本边界；定位改心智坐标——可先后，勿等同。
- **只改广告不改产品**：接触点冲突 → 先对齐产品与价格带。

## 相关模型

- **与[差异化战略](../differentiation-strategy/SKILL.md)**：定位选心智格子；差异化设计活动系统兑现溢价。
- **与[利基战略](../niche-strategy/SKILL.md)**：利基先选窄市场；定位在该市场内占心智。
- **与[蓝海战略](../blue-ocean/SKILL.md)**：蓝海重建买方效用与成本；定位服务心智沟通。
- **与[SWOT](../swot/SKILL.md)**：SWOT 盘态势；定位做心智决策。

## 记忆钩子

定位 = **在顾客脑子里占一格**：先问「相对谁」，再问「一句话能否预测你会拒绝什么」。
