# 网络拓扑 Network Topology

## 这是什么

**网络拓扑**：把系统看成节点与边的图，用结构度量回答「连法如何影响传播、韧性与协调」。基础清单：

| 度量 | 问什么 |
|---|---|
| 度数 / 中心性 | 谁关键 |
| 聚类系数 | 朋友的朋友是否互连 |
| 平均路径 | 多远能到达 |
| 连通 / 切边 / 桥 | 哪里一断就裂 |

小世界、无标度是常见**特例诊断**；本 Skill 是选型与体检入口。

## 什么时候用

- "先看看谁和谁连、断哪里最痛"
- "网络拓扑 / 中心性 / 结构洞 / 切边"
- 协作网、依赖网、传播网、供应链

**不要**当主模型：
- 已确认高聚类+短路径故事 → [`small-world-network`](../small-world-network/SKILL.md)
- 已确认 hub+幂律度 → [`scale-free-network`](../scale-free-network/SKILL.md)
- 网络价值/外部性定价 → [`metcalfes-law`](../../systems-classic-effects/metcalfes-law/SKILL.md)
- 标准锁定 → [`lock-in-effect`](../../systems-classic-effects/lock-in-effect/SKILL.md)

## 怎么用（执行步骤）

1. **定义节点与边。** 人/系统/组件；边=依赖、沟通、交易？判据：边含义单一。
2. **画或抽样图。** 完整或自我中心网；标注不确定边。
3. **算/估关键度量。** 至少：度数分布直觉、路径、明显桥。判据：写出 3 个结构事实。
4. **匹配家族假说。** 像小世界？像无标度？像随机/分层？再下钻专模。
5. **选结构干预。** 加捷径、护桥、分散 hub、破回音室、加冗余边——与目标一致（加速传播 vs 隔离风险）。
6. **复测。** 干预后路径/切边是否按预期变。

## 例证

**跨部门桥人离职**：桥边消失 → 协作断裂。揭示：中心性≠职位；结构洞重要。

**微服务依赖图**：无标度式 hub 服务；拓扑决定故障域。揭示：先图画再谈 SLA。

**（原书卡片）**：勿只画美图；落到度量与切边。

## 什么时候不适用（边界）

- **关系无法观测**：先做访谈/日志，再谈拓扑。
- **动力学由存量流量主导**：边是次要。
- **法律归责问题**：图不替代责任设计。

## 常见误用

- **度数高 = 最重要**：看中介中心性与桥。
- **直接套小世界/无标度标签**：先度量。
- **加边万能**：边有成本与风险传播。

## 相关模型

- **与[小世界网络](../small-world-network/SKILL.md)**：拓扑体检后的专模。
- **与[无标度网络](../scale-free-network/SKILL.md)**：度数胖尾专模。
- **与[梅特卡夫定律](../../systems-classic-effects/metcalfes-law/SKILL.md)**：价值随规模；拓扑谈结构形状。
- **与[集体智能](../collective-intelligence/SKILL.md)**：智能依赖连接与多样性；拓扑提供连法。
