# 价值链 Value Chain

## 这是什么

**价值链**：把企业看作一系列**创造买方价值并产生成本**的活动——**主要活动**（进料物流、生产运营、出货物流、营销销售、服务）与**支持活动**（采购、技术开发、人力资源管理、企业基础设施）——通过分析活动及其联系，找到成本优势或差异化的真实落点。

Michael Porter 在《竞争优势》中提出：竞争战略最终要落到活动配置，而非口号。价值链是**活动系统解剖图**，不是财务报表科目表，也不是行业五力。

## 什么时候用

- "成本高在哪个环节 / 差异化到底体现在哪"
- "价值链拆解 / 外包还是自营"
- 要对标对手的活动配置而非只比价格

**不要**当主模型：

- 行业利润池与五力 → [`porters-five-forces`](../porters-five-forces/SKILL.md)
- 资源是否稀缺难模仿 → [`vrio`](../vrio/SKILL.md)
- 心智格子 → [`positioning`](../positioning/SKILL.md)
- 多边平台生态 → [`platform-strategy`](../platform-strategy/SKILL.md)

## 怎么用（执行步骤）

1. **画本企业价值链草图。** 按主/支持活动列出真实步骤（可用公司自己的名字，但要映射回波特类别）。判据：每项活动能指出责任组织与主要成本/价值驱动。
2. **标成本驱动与价值驱动。** 对关键活动写：规模、学习、联系、时机、位置、制度等因素。判据：能量化或至少排序；「到处都重要」不合格。
3. **找活动之间的联系。** 例：采购规格影响运营返工；销售承诺影响服务成本。判据：至少标 3 条高影响联系。
4. **对照战略类型检查一致性。** 成本领先应看到结构性成本优势活动；差异化应看到买方愿付溢价的活动与联系。判据：与声称战略矛盾则标红。
5. **决定改进/外包/伙伴。** 非战略且市场更高效的可外包；战略控制点加强。判据：每个外包建议写清失去的控制与风险。
6. **输出活动系统改进包。** 优先级、预期成本/差异化效应、复盘指标。

## 例证

**销售承诺抬高服务成本**：前端过度承诺导致后端安装爆炸——揭示联系比单点优化更关键。

**差异化落在物流而非广告**：准时可达成为买方价值核心——揭示差异化常在「不起眼」主活动。

**与成本领先连用**：成本领先必须指出哪些活动的结构性成本更低，而非只降价。

## 什么时候不适用（边界）

- **纯交易中介/轻资产平台**：经典制造型价值链需改写成平台活动图。
- **问题在产业层而非公司活动**：先五力。
- **无法获得活动级数据**：先做定性，再补数据，勿假精确。

## 常见误用

- **当成组织架构图**：架构≠活动 → 按价值流重画。
- **忽视支持活动**：IT/采购常是成本与差异化来源。
- **与五力混成一张表**：五力看结构；价值链看你怎么做。
- **优化局部损害联系**：单点 KPI 最优 → 检查上下游。

## 相关模型

- **与[成本领先](../cost-leadership/SKILL.md)**：成本领先用价值链找结构性成本优势。
- **与[差异化战略](../differentiation-strategy/SKILL.md)**：差异化用价值链找买方愿付点。
- **与[VRIO](../vrio/SKILL.md)**：价值链找活动；VRIO 审计支撑活动的资源。

## 记忆钩子

价值链 = **活动怎么创造价值又产生成本**——战略要落到活动与联系，不落到标语。
