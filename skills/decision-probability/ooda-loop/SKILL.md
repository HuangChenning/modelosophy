# OODA 循环 OODA Loop

## 这是什么

**OODA**：Observe（观察）→ Orient（定向）→ Decide（决策）→ Act（行动）→ 反馈再观察。John Boyd 强调：优势往往来自**比对手更快、更准确地完成循环**，尤其是 **Orient**——用基因、文化、经验、新信息重建态势图像；定向错误时，加速只是更快撞墙。

商业用法：缩短「感知市场—理解—下决心—交付」的闭环，同时投资定向质量（模型、数据、认知多样性）。

## 什么时候用

- "我们要跑得比对手快"
- "OODA / 态势感知 / 快速闭环"
- 竞争激烈、信息过时快、需要连续小决策的环境

**不要**当主模型：

- 稳态流程质量改进 → [`pdca`](../../efficiency-execution/pdca/SKILL.md)
- 验证产品假设的最小制品 → [`mvp`](../mvp/SKILL.md)
- 单次重大不可逆选择的重量级审查 → [`reversible-irreversible`](../reversible-irreversible/SKILL.md) + 验尸/红队

## 怎么用（执行步骤）

1. **画当前闭环与耗时。** 观察从哪来、定向谁做、决策谁拍板、行动谁交付；标出最长等待。判据：能指出瓶颈阶段。
2. **升级 Observe：信号清单。** 要看哪些领先指标/对手动作/异常；去掉只制造噪声的报表。
3. **重投资 Orient。** 写明心智模型与假设；引入矛盾信息与红队短会；问「若模型错，哪些信号会先出现」。Boyd：定向是重心。
4. **Decide：时间盒与默认。** 可逆决策默认时限内必出；写「若无新信息则选默认项」，反拖延。
5. **Act：小步可回滚。** 行动带监测探针，立刻回到 Observe。无探针的行动不计入有效循环。
6. **相对节奏复盘。** 对比对手/环境变化速度：我们是在内侧转还是外侧被转。只比自己上周快不够。

## 例证

**空战起源直觉**：更灵活的飞行员通过更快循环迫使对手在过时画面上决策。揭示：目标是扰乱敌方定向，不是单次完美计划。

**互联网运营**：每日看漏斗异常 → 定向「渠道质量变差」→ 决定停投 → 行动换素材 → 小时级回看。揭示：OODA 是经营节奏，不是口号墙。

**反例：虚假敏捷**：每天发版但定向从未更新（同一错误叙事）→ 高速空转。

## 什么时候不适用（边界）

- **反馈极慢或实验昂贵**：加速行动浪费 → 先买信息或仿真。
- **安全关键操作**：速度受控于检查单，不能「绕过 Orient」。
- **协作型非对抗问题**：过度军事化语言有害 → 改用 PDCA/MVP。

## 常见误用

- **OODA=越快越好**：牺牲定向 → 强制步骤 3。
- **与 PDCA 混称**：PDCA 重标准化改进；OODA 重对抗与定向。
- **只 Act 不 Observe**：行动主义 → 补探针。
- **个人英雄决策**：定向缺多样性 → 引入短红队。

## 相关模型

- **与[PDCA](../../efficiency-execution/pdca/SKILL.md)**：PDCA 稳态改进；OODA 对抗/高速态势。用户说质量闭环走 PDCA；说抢时间优势走 OODA。
- **与[MVP](../mvp/SKILL.md)**：MVP 提供 Act/Observe 的学习载体；OODA 编排节奏。
- **与[灰度认知](../grey-thinking/SKILL.md)**：定向中的置信度用灰度表达，避免假确定性加速。
- **与[第二序思维](../../systems-classic-effects/second-order-thinking/SKILL.md)**：定向应含二阶后果，否则快速决策制造更大问题。
- **与[可逆与不可逆决策](../reversible-irreversible/SKILL.md)**：循环内优先推可逆行动；遇单向门减速加重审查。

## 记忆钩子

转得快之前，先问 **Orient 是否还指着现实**；否则是高速迷路。
