# 子博弈精炼均衡 Subgame-Perfect Equilibrium

## 这是什么

**在每个子博弈中都构成纳什的均衡——剔除不可信威胁与承诺。**

Selten：整体策略在整棵博弈树的每个节点（子博弈）上仍是纳什。空头威胁（轮到时不会真执行）被剔除。常与逆向归纳一起用于完全信息动态博弈。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "这个威胁可信吗"
- "子博弈精炼均衡"
- "会不会到时候反悔"

**不要**在以下情况套用本模型：

- 同时行动静态纳什 → ../nash-equilibrium/SKILL.md
- 只要从终点倒推步骤 → ../backward-induction/SKILL.md
- 类型未知的序贯 → ../bayesian-games/SKILL.md

## 怎么用（执行步骤）

1. **画序贯树。** 谁先动、信息集、终点支付；标出所有子博弈。
2. **自下而上要求局部纳什。** 每个子博弈内参与人是否仍最佳回应？标出不会执行的威胁。
3. **对照仅整体纳什。** 列出被 SPE 剔除的策略（“若你偏离我就疯狂报复”但轮到自己不划算）。
4. **输出。** SPE 路径 + 被剔除的不可信威胁一句。

## 例证

**进入威慑**：在位者扬言价格战，但进入后打价格战两败，精炼后可能不打。揭示威胁需事成后仍理性。

**谈判最后通牒式还价**：末手出价者权力大；空喊“绝不让步”若末手会让则不可信。

## 什么时候不适用（边界）

- **不完全信息**：信念与类型需贝叶斯精炼（本草案不展开）。
- **承诺装置**：合同/抵押可使原不可信变为可信——那是改博弈。

## 常见误用

- **把任何口头威胁当均衡**：必须做子博弈检验。
- **与逆向归纳混为一谈**：逆向归纳是找 SPE 的常用算法；SPE 是解概念。

## 相关模型

- **与[逆向归纳法](../backward-induction/SKILL.md)**：算法工具；本条是解概念与可信性。
- **与[纳什均衡](../nash-equilibrium/SKILL.md)**：SPE 是动态精炼。

## 记忆钩子

到时候还愿不愿意做，才叫可信。
