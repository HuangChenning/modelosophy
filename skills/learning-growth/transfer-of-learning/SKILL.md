# 迁移学习 Transfer of Learning

## 这是什么

**迁移学习**：把在一个情境中获得的知识、技能或策略，成功用到**另一个情境**。按距离常分 **近迁移**（表面相似）与 **远迁移**（表面不同、结构相似）；失败的常见形态是「课上会、换皮就不会」。

迁移不会自动发生：需要共同元素、抽象原则、变式练习或元认知提示。本模型交付的是**迁移目标设定与检验规程**，不是「多学自然会用」的口号。

**鉴别**：[`interleaved-practice`](../interleaved-practice/SKILL.md) 是促进迁移的常用手段；本模型管「迁到哪里、如何验收」。[`meta-learning`](../meta-learning/SKILL.md) 管学习策略层；迁移管内容/技能跨情境。

## 什么时候用

- "学了用不上 / 换例子就不会"
- "怎么设计迁移练习 / 近迁移远迁移"
- 培训转化、课程设计、从练习场到实战

**不要**当主模型：

- 材料根本没记住 → [`retrieval-practice`](../retrieval-practice/SKILL.md) / [`spaced-repetition`](../spaced-repetition/SKILL.md)
- 单一动作瓶颈 → [`deliberate-practice`](../deliberate-practice/SKILL.md)
- 要废弃旧习惯 → [`unlearning`](../unlearning/SKILL.md)

## 怎么用（执行步骤）

1. **写清源任务与目标任务。** 两列：在 A 会什么 / 在 B 要表现什么。判据：B 的成功标准可观察，且与 A 不完全相同。
2. **判定近或远并标共同结构。** 列出表面差异 vs 深层相同（原则、因果、程序骨架）。写不出共同结构 → 先抽象再练，或降低远迁移期望。
3. **设计阶梯变式。** 由改数字/改外壳 → 改情境 → 跨领域类比。每阶至少 2 个实例。判据：学习者能否指出「变的是表面还是结构」。
4. **练习时显式提示原则（渐进撤除）。** 早期可以说「这和圆锥体积同一类」；后期撤提示，只给新情境。
5. **延迟 + 新情境测验。** 隔日在未见过的外壳上测；只测原题不算迁移验收。
6. **失败归因。** 忘了内容 → 补检索；会内容不会辨类 → 交错；原则未抽象 → 补精细加工/概念图；旧法干扰 → [`unlearning`](../unlearning/SKILL.md)。

## 例证

**物理课摩擦力 → 生活推箱子**：会算题不会解释「为何难推动」——近迁移失败，需显式连原则。

**商务案例框架换行业**：同一「客户—价值—渠道」骨架换到医疗——揭示**远迁移靠结构映射**，非背案例情节。

**（局限）**：无共同元素时硬谈迁移是玄学；应诚实缩小目标或先补中间桥接课。

## 什么时候不适用（边界）

- **源技能本身未掌握**：迁移建立在 A 可靠之上。
- **目标领域规则冲突**：旧法有害时优先去学习/抑制，而非强迁。
- **纯粹记忆保持问题**：记不住公式不是迁移失败。
- **不可观察的「思维升级」口号**：无目标任务标准则无法验收。

## 常见误用

- **只刷原题叫学会**：表面掌握 → 必须新外壳验收。
- **假设自动迁移**：培训结束即完 → 设计职场任务桥接。
- **远迁移一步到位**：挫败 → 近→中→远阶梯。
- **与类比思维混用**：类比是生成映射的认知工具；本模型管学习设计与验收（可连用 `analogical-thinking`）。

## 相关模型

- **与[交错练习](../interleaved-practice/SKILL.md)**：交错是常用迁移促进器；要定义迁向何处与验收标准走本模型。
- **与[组块](../chunking/SKILL.md)**：高质组块携带可迁移结构；碎片事实难迁。
- **与[精细加工提问](../elaborative-interrogation/SKILL.md)**：追问「为何在此成立」利于抽象原则，支撑远迁移。
- **与[元学习](../meta-learning/SKILL.md)**：元学习选「如何学」；迁移检验「学到的能否换场用」。
- **与[去学习](../unlearning/SKILL.md)**：负迁移/旧法干扰时先抑制旧反应再迁新法。
