# 棘轮效应 Ratchet Effect

## 这是什么

**棘轮效应**：某些水平（消费、薪酬、编制、服务标准）像棘轮一样**只能朝一个方向推进**——上升容易，下降会遭遇强烈阻力（习惯、合约、面子、政治成本）。

Duesenberry 等用相对收入/消费习惯解释消费向下刚性；组织中常见于福利、headcount、SLA。机制是**参照点上移 + 损失厌恶式的降级痛感**，不一定是技术锁定。

## 什么时候用

- "奖金/预算上去了再也砍不动"
- "客户习惯了免费增值，收费就炸"
- "编制只增不减"

**不要**当主模型：
- 技术标准/习惯锁死 → [`path-dependence`](../path-dependence/SKILL.md)
- 用户因转换成本出不去 → [`lock-in-effect`](../lock-in-effect/SKILL.md)
- 沉没成本不肯止损 → [`sunk-cost`](../../behavioral-biases/sunk-cost/SKILL.md)

## 怎么用（执行步骤）

1. **指名棘轮变量。** 消费额、薪资带宽、SLA、权限级别——写清单位与当前水平。
2. **验证向下弹性。** 历史上降过吗？降时阻力来自合约、习惯还是舆论？无向下尝试则只是猜测。
3. **拆解刚性来源。** 法律/合约、心理参照、组织政治、运营依赖——分类列表。
4. **设计防棘轮或可控棘轮。** 临时津贴、日落条款、试用档、可逆试点；需要上升时同步写退出条件。
5. **沟通降级框架。** 若必须降，用替换收益、分期、自愿选项降低损失框架；硬砍需评估破裂风险。

## 例证

**消费习惯**：收入暂时下降时消费降幅小于收入升时的升幅（相对收入假说相关讨论）。揭示**向下刚性**。

**SaaS 免费额度**：额度只升不降引发成本棘轮。揭示产品策略里的棘轮。

**公共部门编制**：岗位易设难撤。揭示政治棘轮。

## 什么时候不适用（边界）

- **高弹性市场**：价格与用量可双向调节且无习惯锚。
- **明确临时机制**：人人知道是疫情补贴，撤回预期已嵌入。
- **技术锁定为主**：那是路径依赖/锁入，不是消费棘轮。

## 常见误用

- **标签滥用**：任何难改的东西都叫棘轮 → 先证向下刚性。
- **忽视损失厌恶**：只谈“习惯”不谈参照点与框架。
- **与路径依赖混用**：路径依赖更广（QWERTY）；棘轮特指水平单向。

## 相关模型

- **与[路径依赖](../path-dependence/SKILL.md)**：路径依赖管历史锁定；棘轮管水平易升难降。
- **与[锁定效应](../lock-in-effect/SKILL.md)**：锁定强调转换成本；棘轮强调降级阻力。
- **与[损失厌恶](../../behavioral-biases/loss-aversion/SKILL.md)**：降级被编码为损失，放大棘轮。

## 记忆钩子

棘轮咔一声——上去容易，下来先问参照点和合约。
