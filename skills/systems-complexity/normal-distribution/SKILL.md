# 正态分布 Normal Distribution

## 这是什么

**正态分布**：钟形、左右对称、由均值 μ 与标准差 σ 刻画；落在 μ±2σ 外的概率很小（薄尾）。它常作为**许多独立小扰动叠加**（中心极限）或测量误差的默认模型。

**与幂律对照（本类硬课）**：正态说「极端罕见」；幂律说「极端可主导总量」。选错分布 = 选错风控与资源分配。

## 什么时候用

- "误差/身高/考试分大概钟形"
- "用均值和标准差够不够"
- "和幂律/胖尾比，这次像不像正态"

**不要**当主模型：
- 明显头部垄断、累计前 1% 占大头 → [`power-law`](../power-law/SKILL.md)
- 网络 hub → [`scale-free-network`](../scale-free-network/SKILL.md)
- 只要 80/20 时间法 → [`pareto-principle`](../../systems-classic-effects/pareto-principle/SKILL.md)

## 怎么用（执行步骤）

1. **写生成故事。** 是否「多独立小因素相加」？若有乘法放大、优先连接、病毒传播 → 先验偏向胖尾。
2. **看对称与尾部。** 直方图/分位数：是否单峰对称？极端是否远多于正态预期？
3. **选定 μ、σ 的决策用途。** 过程控制、评分常模、A/B 噪声模型——写清「用 σ 做什么决策」。
4. **设薄尾风控边界。** 仅当尾部不致命时用 ±kσ；尾部致命则叠加极值/情景，勿迷信 3σ。
5. **做一次对照压力。** 问：若其实是幂律，我的结论哪一句会错？写下来。
6. **拒绝强制正态化。** KPI 排名、奖金曲线若扭曲了真实生成机制，改机制而非改分布标签。

## 例证

**测量误差 / 加工尺寸**：多小误差叠加 → 正态常用。揭示：薄尾+对称时 μ±σ 有意义。

**互联网关注度**：常远非正态；用「平均阅读」做预算会系统性低估头部。揭示：必须对照幂律。

**（原书卡片）**：勿把钟形当宇宙真理；先写生成机制。

## 什么时候不适用（边界）

- **乘法过程与破产风险**：对数正态/幂律候选。
- **有硬屏障与截断**：分布变形。
- **样本非独立**：中心极限前提坏掉。

## 常见误用

- **万物正态**：先做幂律对照。
- **用正态为不公辩护**：社会结果常有机制性偏斜，不是「自然钟形」。
- **3σ = 绝对安全**：模型风险本身可大于 3σ。

## 相关模型

- **与[幂律](../power-law/SKILL.md)**：默认成对使用——先判薄尾还是胖尾。
- **与[帕累托法则](../../systems-classic-effects/pareto-principle/SKILL.md)**：80/20 不自动等于非正态；看数据。
- **与[黑天鹅](../../systems-classic-effects/black-swan/SKILL.md)**：薄尾世界观最易被黑天鹅打脸。

## 记忆钩子

钟形好用当故事是「小误差相加」；故事是「赢家通吃」就换幂律。
