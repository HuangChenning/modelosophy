# 学习金字塔 Learning Pyramid（谨慎）

## 这是什么

**学习金字塔**（常与 Edgar Dale「经验之塔」混称）是一张流传甚广的图：声称听讲、阅读、视听、演示、讨论、实践、教授他人对应 **10%–90%** 不等的「平均留存率」。**这些精确百分比缺乏可靠原始研究支撑**，多属培训界口耳相传的简化图。

本 Skill **不是**把金字塔当定律来执行，而是：**(1) 纠偏伪精确；(2) 若仍要用，只保留「越主动、越需提取与产出，通常越利于学习」的弱启发式，并立刻改用可操作的证据型方法**（检索、练习、教学等）。

**鉴别**：真正要「通过教来学」→ [`learning-by-teaching`](../learning-by-teaching/SKILL.md) / [`feynman-technique`](../feynman-technique/SKILL.md)。要设计训练 → [`deliberate-practice`](../deliberate-practice/SKILL.md) / [`retrieval-practice`](../retrieval-practice/SKILL.md)。

## 什么时候用

- "学习金字塔 / 听讲只记得 10% 是真的吗"
- "经验之塔怎么用在培训设计"
- 需要迅速拆穿百分比迷信，并改写学习活动

**不要**当主模型：

- 设计可执行记忆日程 → [`spaced-repetition`](../spaced-repetition/SKILL.md)
- 设计闭卷提取 → [`retrieval-practice`](../retrieval-practice/SKILL.md)
- 组织带教 → [`mentorship`](../mentorship/SKILL.md)

## 怎么用（执行步骤）

1. **先做真实性声明。** 明确告诉用户：金字塔百分比**不是**可引用的科学定论；Dale 原塔强调经验具体—抽象 continuum，**原作未给出那些 %**。
2. **提取可用内核（若有）。** 仅保留：被动接收 < 主动提取/产出/应用（方向性启发式）。删除一切「精确留存率」表。
3. **把活动映射到证据型 Skill。** 讨论/实践/教授 → 分别落到检索、刻意练习、教中学/费曼；禁止停在「改用金字塔更底层」。
4. **改写一节课/一天的学习设计。** 用「输入后多久有一次强制产出」作判据（题、讲、做），而非追求「到达 75%/90% 层」。
5. **用延迟测验验收。** 用实际保持与迁移数据说话；不要用金字塔图自我证明。
6. **若受众只要那张图：** 给纠偏版一句话 + 推荐 1–2 个可执行替代模型，结束。

## 例证

**企业培训海报**：印着「教授他人记住 90%」——揭示**伪精确危害**（决策被图绑架）。

**Dale 原意被扁平化**：具体经验有价值，但不等于「听讲无用」——听力课、故事模型仍有位置，关键是随后有无提取。

**（原书/流行卡片局限）**：若原书或网络卡片把百分比当真理，定稿时必须标注为**流传误读**，不得照抄。

## 什么时候不适用（边界）

- **当作引用依据写进学术/合规材料**：禁止；改引用检索练习等可追溯文献。
- **为「取消一切讲授」辩护**：讲授+随后检索可以很有效；金字塔常被滥用为反讲授口号。
- **替代个体差异与材料难度**：同一活动留存因人因内容而异，无universal %。
- **已有明确技能训练框架时**：直接走刻意练习/ZPD，无需经金字塔中转。

## 常见误用

- **把 % 当科学**：→ 纠正并删除数字。
- **金字塔底层迷信**：以为「只要教别人就 90%」→ 教中学仍需正确反馈与检索设计。
- **与费曼/教中学画等号**：那些是独立可执行模型；金字塔只是常被误用作包装。
- **忽略被动阶段的合理位置**：首次编码可听可读，但须计划随后提取。

## 相关模型

- **与[检索练习](../retrieval-practice/SKILL.md)**：要提高保持，用检索，不用金字塔百分比。
- **与[学习中教](../learning-by-teaching/SKILL.md)**：教作为学习策略的可执行版；替代「90%」神话。
- **与[费曼技巧](../feynman-technique/SKILL.md)**：个人讲解补洞规程。
- **与[刻意练习](../deliberate-practice/SKILL.md)**：「实践」层应落地为有反馈训练，而非口号。
- **与[元认知](../metacognition/SKILL.md)**：监控自己是否被信息图说服而无证据。

## 记忆钩子

金字塔可以提醒你「别只听」——但请撕掉上面的假百分比。
