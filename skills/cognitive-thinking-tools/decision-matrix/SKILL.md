# 决策矩阵 Decision Matrix

## 这是什么

**决策矩阵**：把候选选项排成列（或行），评价标准排成另一维，对每个「选项×标准」给分，常乘权重后汇总，用于**多标准、选项有限**的比较。变体包括：简单加权表、相对基准的 Pugh（+/-/S）矩阵等。

它把偏好**摊开可讨论**：争议应落在「标准、权重、打分证据」，而不是笼统「我感觉 A 更好」。矩阵**不消除**价值判断，只是让判断可审计；输出必须含敏感性，禁止用总分神话替责任人拍板。

## 什么时候用

- "好几个方案，标准还不只一个"
- "想加权评分 / 做个选型表"
- 直接说决策矩阵 / Pugh / scorecard
- 供应商、技术方案、选址等选项集合已清晰

**不要**当主模型（分流）：

- 结果不确定且要算期望值/信息价值 → [`decision-tree`](../../decision-probability/decision-tree/SKILL.md)（**第八类**）
- 只需快速利弊清单、不愿量化 → [`pros-cons-list`](../pros-cons-list/SKILL.md)
- 战略环境四格 → [`swot`](../../strategy-competition/swot/SKILL.md)
- 选项尚未发散出来 → [`diamond-six-steps`](../diamond-six-steps/SKILL.md) 步 4 或 [`lateral-thinking`](../lateral-thinking/SKILL.md)

## 怎么用（执行步骤）

1. **锁选项集。** 列出 2–7 个互斥选项（含「维持现状/不做」若实质可选）。判据：选项描述具体到可执行差异。
2. **锁标准并定义量表。** 每条标准写：含义、高分长什么样、数据来源。标准尽量少而硬（通常 4–8）。禁止把同一偏好拆成多条刷分。
3. **赋权并写理由。** 权重和为 1（或 100%）。判据：能解释「为何该标准更重要」；禁止事后为了让心仪项赢而改权重（先锁权再打分，或双盲）。
4. **打分并附证据一句。** 每格分数旁写依据（数据/试验/专家判断）。无证据的分标为「主观」。
5. **汇总与排序。** 计算加权分；同时看**未加权**与**分标准对比**，防止总分掩盖致命短板（如安全分极低）。
6. **敏感性。** 变动最大争议权重 ±20%（或互换两标准权重），看排名是否翻转。翻转 → 结论是「对权重敏感，需澄清价值或补证据」，不是假装科学最优。
7. **决策声明。** 写：选什么、关键权衡、剩余风险；矩阵是输入不是自动裁决器。

## 例证

**供应商选型**：标准=成本、交付、质量事故率、切换成本；权重争议大时敏感性显示「只在质量权重大时 A 胜」。揭示：矩阵的价值是**定位争论点**。

**Pugh 相对基准**：以现方案为基准，新方案就各标准标优于/劣于/相当——适合概念筛选早期。

**（原书卡片）**：若把矩阵总分神化，忽略权重主观性；本 Skill 强制敏感性与证据标注。

## 什么时候不适用（边界）

- **概率主导的赌博**：用决策树/期望值。
- **标准不可公度且含否决项**：先设硬约束门槛（不合格直接淘汰），再矩阵。
- **政治已内定**：矩阵会被操纵成合法化工具——要么公开操纵风险，要么不做假表。
- **创造新选项比挑选重要**：先发散。

## 常见误用

- **伪造精度**：权重到小数点后三位、分数无证据 → 降精度并标主观。
- **双计标准**：成本与「性价比」同时出现 → 删冗余。
- **用矩阵代替概率**：把「成功率」当确定分数填进矩阵却不做不确定分析 → 改 decision-tree 或显式区间。
- **与利弊清单不分**：不愿加权却硬打分 → 用 pros-cons-list。

## 相关模型

- **与[决策树](../../decision-probability/decision-tree/SKILL.md)**：**跨类硬区分。** 不确定结果+概率+期望值 → 决策树（第八类）；多标准确定比较（或主观分）→ 本矩阵（第七类名录）。可连用：树处理「是否先试点」，矩阵处理「试点成功后选哪供应商」。
- **与[优劣势清单](../pros-cons-list/SKILL.md)**：利弊粗筛或不量化 → pros-cons；要显式权重与敏感性 → 矩阵。
- **与[期望值思维](../../decision-probability/expected-value/SKILL.md)**：单维金钱/效用比较可走 EV；多维非货币标准常用矩阵。
- **与[SWOT](../../strategy-competition/swot/SKILL.md)**：SWOT 扫环境与能力；不直接做选项×标准计分。
- **与[菱形六步法](../diamond-six-steps/SKILL.md)**：服务收敛选型步。

## 记忆钩子

分数可以吵，但要吵在「标准、权重、证据」上——并问问权重一拧，冠军还在不在。
