# 破窗效应 Broken Windows

## 这是什么

**破窗效应**（Wilson & Kelling, 1982）：环境中的**小失序信号**（破碎窗户、涂鸦、逃票）若不被及时修复，会向旁观者传递“这里规范失效”的信息，从而提高更多失序与犯罪的概率。

核心不是“窗子有魔力”，而是**规范与监控的信号**：维护秩序的可见行动，改变人们对“什么行为会被容忍”的预期。后续实证与政策（如零容忍）有激烈争议——作为决策模型，应保留“信号→预期→行为”链条，避免当成万能治安配方。

## 什么时候用

- "办公室小违规蔓延"
- "代码规范/文档腐烂没人修"
- "社区/产品社区氛围变差"

**不要**当主模型：
- 机械式一触即溃的故障链 → [`domino-effect`](../domino-effect/SKILL.md)
- 消费标准只升不降 → [`ratchet-effect`](../ratchet-effect/SKILL.md)
- 低概率极端冲击 → [`black-swan`](../black-swan/SKILL.md)

## 怎么用（执行步骤）

1. **列出可见的“碎窗”。** 具体失序物/行为（未关的门禁、公开辱骂未处理、破损设施）——必须可观察。
2. **推断传递的规范信号。** “在这里，X 没关系”是否正在扩散？找第二起模仿是否出现。
3. **设计最小可信修复。** 24–72 小时内修复/回应，使信号反转；空喊口号不算。
4. **匹配比例原则。** 干预强度应匹配危害；避免把破窗当借口做过度惩罚或选择性执法。
5. **复盘是否降失序。** 看同类事件频率；若无下降，机制可能不是破窗（或根因是贫困/激励等更深结构）。

## 例证

**社区涂鸦与维护**：及时清理常伴随更强非正式社会控制（经典论述）。揭示**环境信号**。

**代码库**：一次“先这样提交”被放任 → 风格与测试崩坏。揭示组织内破窗。

**争议的治安政策**：零容忍若变成指标暴力，揭示**误用边界**——信号理论≠任意严打。

## 什么时候不适用（边界）

- **结构性失业/毒品市场**等深层驱动：只修窗不够。
- **证据不足的因果**：相关≠破窗机制成立。
- **异见与秩序混淆**：把正当抗议当“碎窗”会政治滥用。

## 常见误用

- **严打万能化**：破窗 → 必须重刑。错；关键是及时、公正的规范修复。
- **只罚弱势**：选择性修窗会加剧不信任。
- **与多米诺混用**：破窗是规范传染，不是物理必然连锁。

## 相关模型

- **与[多米诺骨牌效应](../domino-effect/SKILL.md)**：多米诺强调能量传递连锁；破窗强调社会规范信号。
- **与[温水煮青蛙](../boiling-frog/SKILL.md)**：青蛙是渐变麻木；破窗是失序被看见仍放任。
- **与[系统思维](../systems-thinking/SKILL.md)**：若失序由激励结构驱动，升维到回路，不只修表面窗。

## 记忆钩子

第一扇破窗修好了吗——人们看的是“这里什么可以被容忍”。
