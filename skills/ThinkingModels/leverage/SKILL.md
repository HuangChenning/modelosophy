# 杠杆 Leverage（系统杠杆点）

## 这是什么

日常语“杠杆”来自阿基米德隐喻：合适的支点可用较小力产生较大效果。在思维模型库中，本 skill **优先指系统杠杆点（leverage points）**：对复杂系统做干预时，不同位置的效力差几个数量级——改参数往往弱，改反馈结构、信息流、规则与目标往往强（Meadows 谱系，从弱到强大致：数字参数 → 缓冲 → 结构 → 反馈 → 信息 → 规则 → 目标 → 范式）。

财务杠杆（负债放大收益与亏损）只作**风险不对称类比**，本 skill **不是**炒股/配资教程。

## 什么时候用

- 资源有限，想找“撬动整局”的干预点；
- 团队总在调参数却系统行为不变；
- 直接提杠杆点 / 四两拨千斤 / system leverage。

**不要**当主模型：
- 只要容错备份 → [`redundancy`](../redundancy/SKILL.md)；
- 从波动中获益的暴露设计 → [`antifragility`](../antifragility/SKILL.md)；
- 投入产出不均的经验规则 → [`pareto-principle`](../pareto-principle/SKILL.md)（可连用，但二八不等于杠杆点层级）。

## 怎么用（执行步骤）

1. **画清系统目的与边界。** 谁的目标？优化什么指标？边界外的“杠杆”常是幻觉。
2. **列出当前干预落在哪一层。** 只是改 KPI 数字/预算额度，还是改激励规则、信息能否看见、反馈延迟、系统目标本身？
3. **优先上移一层试干预。** 参数无效时，问：缺信息？反馈符号反了？规则奖励了错误行为？目标互相冲突？
4. **估计副作用与可逆性。** 高杠杆点也高风险：改错目标或范式，破坏力同样大。先小范围试点。
5. **拒绝伪杠杆。** “更拼”“加杠杆资金”“再加一个指标”若不动结构，通常不是高杠杆。

## 例证

**交通拥堵只加车道**：参数/容量层干预，常诱发更多需求（Braess/诱导需求类现象）——揭示**低杠杆点空转**。

**改考核与信息透明度**：让真实成本可见并改变奖励规则，行为可系统转向——揭示**规则/信息层**往往高于“再发一次倡议”。

**（原书卡片）阿基米德撬地球 / 借力**：隐喻可用；须把支点解释为系统结构位置，并明确**禁止写成炒股加杠杆指南**。财务杠杆的爆仓是归零风险，与“智慧支点”不是同一处方。

## 什么时候不适用（边界）

- **用户要配资、两融战术、合约倍数**：拒绝实操指导；可一句说明财务杠杆放大双向风险后结束。
- **归零风险场景**：人身安全、破产清算前，先降脆弱性，不找“高杠杆赌命”。
- **简单线性任务**：拧一颗已知的螺丝，不必召唤 Meadows 全谱。
- **伦理不当的操纵**：利用信息杠杆欺骗利益相关方，不在推荐范围。

## 相关模型

- **与[系统思维](../systems-thinking/SKILL.md)**：系统思维提供存量流量与回路语言；杠杆点是在其上选干预层级。
- **与[帕累托](../pareto-principle/SKILL.md)**：二八找“少数重要事实”；杠杆点问“干预层级是否够高”。常先度量集中度，再选层级。
- **与[反脆弱](../antifragility/SKILL.md)**：反脆弱配置暴露；杠杆点选撬动位置。高杠杆≠反脆弱。
- **与[冗余](../redundancy/SKILL.md)**：冗余降单点失效；杠杆常提高效能也可能提高脆弱性——关键系统上要显式权衡。
