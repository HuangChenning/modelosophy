# 有效市场假说 Efficient Market Hypothesis (EMH)

## 这是什么

**有效市场假说（EMH）**：资产价格已充分反映某一信息集，因而基于该信息集难以稳定获得风险调整后的超额收益。

Fama（1970）按信息集分层：**弱式**（历史行情）、**半强式**（公开信息）、**强式**（含私人信息）。“有效”描述的是信息与价格关系，不是“市场永不犯错”，也不等于价格永远等于某套主观内在价值。

| 形式 | 信息集 | 粗含义 |
|---|---|---|
| 弱式 | 历史价量 | 纯靠过去行情难稳定超额 |
| 半强式 | + 公开财报/新闻 | 公开基本面策略难净超额 |
| 强式 | + 内幕 | 连私人信息也无法超额（极强） |

## 什么时候用

用户出现以下意图时启用本 Skill：

- "消息都公开了，我再分析还有没有边？"
- "主动投资能不能长期跑赢指数？"
- "有效市场 / EMH / 随机游走是什么？"

**不要**在以下情况套用本模型：

- 要解释错误定价为何纠不回来 → [套利限制](../limits-to-arbitrage/SKILL.md)
- 只要估值流程 → [DCF](../dcf/SKILL.md) / [市盈率市净率](../pe-pb-valuation/SKILL.md)

## 怎么用（执行步骤）

1. **锁定信息集。** 声称的优势属于历史价、公开基本面还是未公开信息？越强形式对超额要求越苛刻。
2. **写清对比基准。** 相对宽基指数、风格基准还是无风险利率？无基准的“战胜市场”无效。
3. **扣除成本与风险。** 毛超额 − 税费冲击 − 额外风险后是否仍在？只讲毛阿尔法则标记未通过。
4. **区分“市场无效”与“你能兑现”。** 无效不等于个人可套利；接套利限制与噪音交易者风险。
5. **给出可证伪条件。** 何种样本外窗口与成本假设下策略应失效——禁止永远用“还没到有效”辩护。

## 例证

**盈余公告事件研究**：公开盈余后价格快速调整，平均异常收益很快衰减。揭示半强式关心的是**调整速度**，不是“没人能赚钱”。

**低成本指数化**：被动组合成为默认，是对“平均主动难净超额”的实践回应。揭示成本摩擦下的有效性含义。

## 什么时候不适用（边界）

- **把 EMH 当成价格=内在价值**：价格可有效反映信息，仍可偏离某套 DCF。
- **制度摩擦极大**：停牌、做空禁令会破坏检验前提。
- **一次跑赢证伪**：需风险调整、成本与多重检验。

## 常见误用

- **"有效所以不用管理"**：仍需配置、风险与再平衡。
- **"无效所以我一定赚"**：无效是必要非充分条件。

## 相关模型

- **与[套利限制](../limits-to-arbitrage/SKILL.md)**：偏离可存，因资本与风险约束。
- **与[噪音交易者风险](../noise-trader-risk/SKILL.md)**：非理性可让理性者短期亏钱。
- **与[Beta 与 Alpha](../beta-alpha/SKILL.md)**：超额前先剥离市场暴露。
- **与[CAPM](../capm/SKILL.md)**：经典定价基准常与 EMH 实证同检。

## 记忆钩子

价格已消化哪一层信息，就别指望靠那一层稳定超额。
