# 断裂点 / 临界点 Tipping Point

## 这是什么

临界点（tipping point）描述：系统中某个量或耦合条件越过**阈值**后，行为从一种稳态快速转入另一种稳态——扩散“突然铺开”、生态“突然崩塌”、舆论“突然翻转”。机制常涉及**正反馈、网络效应、协同阈值或相变类比**，而不是神秘的命运转折。

Gladwell《引爆点》把概念流行化（个别人物、附着力、环境），但本 skill **去励志化、去营销化**：要求指出可观察的阈值变量、反馈回路与证据，禁止写成“再坚持就会爆发”的鸡汤。

## 什么时候用

- 增长、流行、违约、气候/生态、组织变革：怀疑存在“过线后不一样”；
- 需要判断现在离阈值还有多远、越过是否可逆；
- 直接提临界点 / 断裂点 / tipping point / 临界质量。

**不要**当主模型：
- 初值微小差异导致轨迹发散 → [`butterfly-effect`](../../systems-classic-effects/butterfly-effect/SKILL.md)；
- 飞轮式增强回路如何设计 → [`flywheel`](../flywheel/SKILL.md)；
- 一般存量流量结构 → [`systems-thinking`](../../systems-classic-effects/systems-thinking/SKILL.md)；
- **预设保险丝/熔断/止损以小损防大损**（原书卡片的真正含义）→ 先看 [`antifragility`](../antifragility/SKILL.md)（限敞口）或 [`sunk-cost`](../../behavioral-biases/sunk-cost/SKILL.md)（何时停），不要硬套临界相变。

## 怎么用（执行步骤）

1. **命名两种稳态。** 例如“小众试用”vs“主流默认”；“可控侵蚀”vs“崩溃”。没有双态就不要硬喊临界点。
2. **找出候选阈值变量。** 渗透率、杠杆率、信任度、冰盖温度代理指标……必须可观测或可代理。
3. **写正反馈怎么咬合。** 用户引用户、价格下跌→更多采用、恐慌→抛售→更恐慌。无反馈则更像线性增长。
4. **估计距离与可逆性。** 证据是什么？越过后恢复成本是否不对称？不确定就明说，不编精确百分数。
5. **决策含义。** 若怕崩塌：降低驱动变量或加负反馈缓冲；若求扩散：聚焦真实阈值邻近的条件，而非空喊激情。

## 例证

**传染病 R 与群体免疫阈值**：再生数与免疫比例决定扩散能否自我维持——揭示**可计算的临界质量**，不是鸡汤。

**银行挤兑**：流动性信心跌破阈值后正反馈加速——揭示临界点可致**快速坏稳态**。

**Gladwell 流行书局限**：强调少数连接者、附着力、环境力量等叙事洞见可作启发式，但常被读成「找对网红就能引爆」的营销公式；缺少可检验阈值变量与竞争性机制时，本 skill 降级为假说而非定论。

**（原书卡片）保险丝/熔断 + 弃车保帅**：卡片把「断裂点」写成保护性断路与事后反思，**与 tipping point 学科含义不符**。熔断例（股市停牌）可用作「预设阈值触发动作」，但它是**限损开关**，不是「越过临界质量后系统进入新稳态」的相变分析。励志收尾「困境变垫脚石」丢弃。

## 什么时候不适用（边界）

- **纯线性、无反馈系统**：小因小果，不必召唤临界点。
- **事后诸葛亮**：任何故事都能被说成“过了临界点”；要有事前可监测变量。
- **励志滥用**：禁止用本模型证明“坚持就一定会火”。
- **熔断/止损语义**：用户要的是保险丝式保护而非宏观相变时，改路由，勿混名。
- **与蝴蝶效应混淆**：初值敏感 ≠ 已靠近宏观阈值的相变。

## 相关模型

- **与[蝴蝶效应](../../systems-classic-effects/butterfly-effect/SKILL.md)**：蝴蝶效应强调预报视界与初值敏感；临界点强调阈值附近的宏观翻转。
- **与[飞轮](../flywheel/SKILL.md)**：飞轮是可设计的增强回路；临界点问回路是否已接近翻转阈值。
- **与[系统思维](../../systems-classic-effects/systems-thinking/SKILL.md)**：用回路与存量找阈值；本模型专攻跨越阈值的决策含义。
- **与[复利](../../finance-investing-models/compounding/SKILL.md)**：复利是再投入×速率×时间；临界点是非线性阈值，二者不可混写为同一公式。
- **与[反脆弱](../antifragility/SKILL.md) / [沉没成本](../../behavioral-biases/sunk-cost/SKILL.md)**：保护性熔断与止损属限敞口/何时停；临界点问是否临近不可逆翻转。
