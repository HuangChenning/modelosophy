# 差异化战略 Differentiation Strategy

## 这是什么

**差异化战略**：在**广阔市场**上提供买方认为**重要且独特**的价值，使顾客愿付**溢价**或在相近价格下优先选择，并通过**活动系统的一致性与权衡（trade-offs）**降低可模仿性。

Porter 通用战略之一。关键不是「有特色」，而是特色**对买方有价值**且公司活动**为此服务并接受取舍**。与定位（心智坐标）、蓝海（重建价值曲线）、战略钟（价格-价值组合）相关但执行焦点不同。

## 什么时候用

- "我们凭什么卖贵 / 客户为什么选我们"
- "差异化战略 / 独特性如何落到运营"
- 要避免只靠广告宣称不同

**不要**当主模型：

- 全市场最低成本结构 → [`cost-leadership`](../cost-leadership/SKILL.md)
- 先收窄市场 → [`niche-strategy`](../niche-strategy/SKILL.md)
- 只做心智一句话 → [`positioning`](../positioning/SKILL.md)
- ERRC 重建产业边界 → [`blue-ocean`](../blue-ocean/SKILL.md)

## 怎么用（执行步骤）

1. **选买方价值维度。** 性能、可靠性、体验、品牌意义、服务速度等，用证据排序。判据：有顾客愿意付/优先选的证据，非内部自嗨。
2. **设计独特性来源。** 产品、渠道、服务、互补、生态等。判据：写「若去掉 X，溢价是否消失」。
3. **用价值链配置活动。** 哪些活动强化该独特性，哪些必须弱化（权衡）。判据：存在明确 trade-off；「既要又要无放弃」不合格。
4. **测溢价与成本增量。** 差异化通常提高成本；溢价须覆盖。判据：粗算贡献与敏感度。
5. **防模仿与稀释。** 一致性、复杂性、历史路径；抵制为扩量破坏独特性。判据：有「不可让步」清单。
6. **输出差异化系统说明。** 价值主张、活动图、权衡、KPI（溢价维持、独特性感知、模仿监测）。

## 例证

**活动系统一致性**：独特性来自多环节匹配（设计+供应+零售体验），单点抄袭无效——揭示差异化靠系统。

**假差异化**：包装不同但买方不在乎——揭示缺「愿付」检验。

**与定位连用**：定位占心智「最稳的 X」；差异化保证交付与运营真的「稳」。

## 什么时候不适用（边界）

- **买方只买价、规格同质且透明**：差异化难成立，考虑成本或利基。
- **无力支撑溢价成本**：财务上走不通。
- **需要产业级价值创新**：考虑蓝海，而非在旧曲线上贴独特性。

## 常见误用

- **特色清单症**：功能多≠差异化。
- **无权衡**：样样都做 → 被夹在中间（stuck in the middle）。
- **与成本领先同时全市场追求**：Porter 警示中间化；若混合需战略钟级别的清醒设计。
- **只改传播不改活动**：溢价不可持续。

## 相关模型

- **与[成本领先](../cost-leadership/SKILL.md)**：溢价独特性 vs 结构性低成本——广谱上不宜假装两者通吃。
- **与[利基战略](../niche-strategy/SKILL.md)**：范围广 vs 范围窄。
- **与[定位](../positioning/SKILL.md)**：心智 vs 活动系统。
- **与[战略钟](../strategic-clock/SKILL.md)**：战略钟把价格与价值感知放到连续选项上。
- **与[价值链](../value-chain/SKILL.md)**：差异化必须落到活动。

## 记忆钩子

差异化 = **买方愿付的独特性 + 有权衡的活动系统**——没有放弃，就难有真正不同。
