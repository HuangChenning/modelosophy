# 遗忘曲线 Forgetting Curve

## 这是什么

Ebbinghaus（1885）用无意义音节等材料测量到：**停止练习后，可回忆量随时间下降，且早期下降往往更快**。后人把这一经验形态通俗称为“遗忘曲线”。现代学习科学的可执行推论不是背公式，而是：

1. **记忆会衰退**（尤其是未经检索的新编码）；
2. **主动检索**（自测）优于被动重读；
3. **间隔重复（spaced repetition）**：在即将遗忘前复习，并逐渐拉长间隔，比一次性突击（massed practice）更利长期保持。

示意百分比（“一天后忘 70%”等）来自特定实验条件，**不是**你个人大脑的物理常数。

## 什么时候用

- 备考、语言、专业术语：背了就忘；
- 设计复习计划 / Anki 类卡片；
- 直接提遗忘曲线 / 艾宾浩斯 / 间隔重复 / spaced repetition。

**不要**当主模型：
- 监控理解策略本身 → [`metacognition`](../metacognition/SKILL.md)；
- 用教别人简化概念 → [`feynman-technique`](../feynman-technique/SKILL.md)；
- 行为能不能发生（动机×能力×提示）→ [`fogg-behavior-model`](../fogg-behavior-model/SKILL.md)。

## 怎么用（执行步骤）

1. **界定要保持的最小单元。** 一问一答、一张卡片、一个可演示技能——忌整章当一个记忆目标。
2. **编码后尽快做第一次检索。** 合上材料，默写或口述；错了再看，看完再测。
3. **排递增间隔。** 例：当日 → 1–2 天 → 约 1 周 → 约 1 月（按难度与遗忘信号调整）。工具可用 SRS；无工具用手写日程亦可。
4. **以回忆成败调间隔。** 轻松想起 → 拉长；犹豫/错 → 缩短并改进线索质量（更清晰的问题面）。
5. **混合练习与情境变化。** 纯机械卡片之外，在真实题目/场景中提取，减少“只会背卡片”。

## 例证

**语言词汇 SRS**：生词在遗忘前自测，间隔拉长——揭示**检索时点**比“再读三遍”更关键。

**考前通宵 vs 分散复习**：同等总时数下，分散通常更利长期保持——揭示对抗的是**时间衰减 + 缺乏检索**，不是“不够用心”。

**（原书卡片）艾宾浩斯曲线 + 复习抗遗忘**：结论方向对；卡片上的精确百分数勿当定律。应补上：主动检索、间隔可调、个体与材料差异。

## 什么时候不适用（边界）

- **理解性空洞当记忆问题**：概念没懂，刷卡片只会固化错误；先费曼/例题。
- **运动技能与复杂迁移**：需要刻意练习与反馈，不单靠闪卡间隔。
- **伪精确曲线**：禁止用“你已遗忘 66.3%”做人生决策。
- **健康/睡眠崩坏时硬堆复习**：睡眠巩固是记忆的一部分；透支无效。

## 相关模型

- **与[元认知](../metacognition/SKILL.md)**：用监控判断“是否仍可提取”，再触发间隔复习。
- **与[费曼技巧](../feynman-technique/SKILL.md)**：深度理解与暴露空洞；遗忘曲线管保持日程。
- **与[复利](../compounding/SKILL.md)**：间隔复习是学习上的再投入；须真实检索发生才复利。
- **与[系列位置效应](../serial-position-effect/SKILL.md)**：首因近因影响单次列表记忆；本模型管跨时间衰减与复习节律。
