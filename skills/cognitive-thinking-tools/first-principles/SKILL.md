# 第一性原理 First Principles

## 这是什么

亚里士多德把本原（archê）说成"认识一件事物时所由出发的起点"：一门学问里不能再被进一步证明、必须当作起点接受的基本命题。当代工程语境里，马斯克把它操作成一句对照——**靠类比推理**（因为别人这么做、过去这么做，所以我们略作改动）vs **从基本事实往上推**（这件事在物理/逻辑上真正不能再拆的是什么，再重新组合）。

两层不要并成一层：

1. **哲学层**：起点命题本身无法再被证明，否则会陷入循环论证、无穷回溯或武断终止（明希豪森三难）。所以"第一性"不是"必然为真"，只是"我们决定停在这里"。
2. **工程层**：把现行做法拆成硬约束（物理、逻辑、真正有约束力的法规、可测量的事实）和惯例（路径依赖、供应商报价习惯、"航天级就必须贵"），丢掉惯例，只从硬约束重建路径。马斯克算火箭/电池的原材料成本，是这一层的一种操作，**不是第一性原理的全部**。

类比推理不是敌人。马斯克 2013 年 TED 里说得很直白：不靠类比，一天都过不下去；只是当你要做新东西时，必须付一次归零的成本。本模型的价值是知道**何时付这笔成本**，以及归零时把惯例误当成物理。

## 什么时候用

用户面对的是可能已经过时的行业共识，或需要非增量突破：

- "电池/发射/获客成本就是这个价，一直如此"；
- "能不能从底层重算，而不是按对手的报价倒推"；
- 成本结构颠覆、从零设计一条产品或组织路径；
- 用户说"第一性原理"、"first principles"、"这是物理限制还是习惯"。

**不要**在以下情况套用本模型：
- 日常运营、已有成熟且仍有效的解法——对每件事归零是不现实的认知税；
- 用户其实在问"怎样避免失败"（逆向思维），或"我是不是在给自己的结论找证据"（确认性偏差）；
- 用户只是想用"第一性原理"当口号，跳过领域里已经验证的专业知识；
- 用户拿着一套已经写好的结论请你挑毛病、问它站不站得住——即使结论自称来自第一性原理，主技能仍是苏格拉底式质疑。本模型最多辅助检查起点是不是被标成了惯例。

## 怎么用（执行步骤）

1. **先过门：这是不是高价值、非常规、共识可能已经腐坏的问题？** 若不是，明确建议继续用经验/类比，并说明为什么——不是模型无能，是成本不划算。若用户坚持对常规问题归零，把代价说清楚再继续。
2. **写下当前共识答案，给每条前提贴标签。** 两类标签就够：**硬约束**（物理定律、逻辑必然、真正绑住你的法规、测过的事实）vs **惯例**（"业界都这样报价"、"必须用航天级零件"、"获客只能靠这个渠道"）。贴标签的判据不依赖"是不是物理题"：问"假如所有相关的人明天都同意换一种做法，除了协调成本以外，还有什么挡着？"——若答案是自然定律、逻辑矛盾、或一份会实际被执行的罚则，标硬约束；若答案只是习惯、报价单和害怕与别人不一样，标惯例。软件、组织和市场问题用同一条判据，不要硬找一条物理学。
3. **丢掉惯例，只保留你能独立辩护的起点。** "独立辩护"指不引用"大家都这么说"，而能指向测量、推导或约束本身。若你发现所谓起点其实还依赖另一条惯例，继续往下拆。拆到你愿意作为公理接受、并承认它仍可能错的那一层为止。
4. **只从留下的起点重新组合路径。** 允许得出和行业完全不同的结构；也允许得出"原来惯例碰巧就是硬约束，现有做法成立"。后一种也是成功应用——第一性原理的产出是重建，不是必须颠覆。
5. **把重建结果当成新假设，拿现实去打。** 从第一性原理推出来的东西没有豁免权。设计一个能证伪它的观察（成本是否真能落到材料价附近、原型是否在约束内可造），过不了就回到第 2 步检查是不是起点选错了。

## 例证

**SpaceX 的火箭材料账**：当时买现成火箭的报价在数千万美元量级，行业类比是"航天就是贵"。马斯克把火箭拆到铝合金、钛、铜、碳纤维等大宗商品，材料成本大约只占当时售价的 2%。其余是管理费用、供应商利润和"火箭必须这么贵"的累积假设。它揭示的是工程层第一性原理最干净的一面：把价格里的物理和价格里的惯例分开。局限也要说清——这是**成本分解**，还不是亚里士多德意义上的本原；若材料加工、可靠性和认证的真实约束被低估，2% 这个数字会骗人。所以第 5 步的现实检验不能省。

**Tesla 电池包的材料成本 vs 市场价**：公开表述里，市场价约 600 美元/kWh，材料拆开大约 80 美元/kWh。Gigafactory 赌的是：差额主要来自制造规模和供应链，而不是锂、镍、钴的物理下限。它和火箭例子是同一操作在另一个部件上的重复，说明这种方法在"价格被当成自然法则"的领域反复有效，而不是只能讲一次航天故事。

**亚里士多德的本原 vs 无穷回溯**：科学要从不可再证的起点出发，否则证明无法开始；但任何起点都可以再被追问。原书卡片自己写过"元起点本身也是一种假设，不存在必然为真的第一性原理"——这是全书少数点到哲学边界的地方，比电池故事更重要。它揭示的是：本模型降低的是**对惯例的盲从**，不是把结论升级成真理。

**（原书卡片）特斯拉电池材料成本远低于市场共识**：与上面第二条是同一案例的压缩版。卡片的真正贡献其实是那句对元起点的自我限制；例子本身只覆盖成本分解这一种操作，没有覆盖"重建组织、重建约束、重建问题定义"。不要让读者以为第一性原理 = 把报价拆成原材料。

## 什么时候不适用（边界）

- **认知成本高，默认不用于常规问题。** 多数决策继续用类比是理性的。把本模型当成人格标签（"我只用第一性原理思考"）通常是在跳过别人已经付过的学习成本。
- **起点仍是假设。** 归零到错误的基本命题，只会自信地错。物理约束选错、测量选错、把尚未验证的信念标成硬约束，都比沿用惯例更危险，因为重建之后缺少常识刹车。
- **不是无视专业。** 领域知识往往已经是别人做过的第一性原理工作。本模型要挑战的是未被检验的惯例，不是每一条专家判断。
- **推出来不等于对。** 第 5 步不是附加润色，是模型的一部分。少了检验，第一性原理就退化成修辞。

## 常见误用

- **拿结论当护身符**：说"这是我从第一性原理推出来的"就当作不可挑战的真理，跳过第 5 步的现实检验 → 重建结果仍是新假设，必须被证伪打过，否则第一性原理退化成修辞。
- **把专业知识当惯例一并清空**：为了显得"从零想"，把领域内已验证的工程/科学结论也当路径依赖丢掉 → 这是在重新发明轮子，不是本模型要挑战的对象（见边界"不是无视专业"）。
- **只做一次成本拆解就自称用了第一性原理**：套用材料成本拆解的模板算出一个更低的数字，却没有走完"贴标签→丢惯例→重建路径→现实检验"整套流程 → 成本分解只是工程层的一种操作，不是方法本身。
- **常规决策也逢事必归零**：把"第一性原理思考"当自我标榜的人格标签，对已有成熟解法的日常问题也要求推倒重来 → 见边界，多数决策继续用类比是理性的，归零是要专门付的认知税。

## 相关模型

- **与[逆向思维](../inversion/SKILL.md)**：第一性原理从硬约束往上建；逆向思维从失败往回拆。用户说"行业都这样但未必是物理"走本模型；用户说"怎样保证搞砸 / 先别做蠢事"走逆向思维。两者可连用：用本模型丢掉假约束，用逆向思维给真约束下的路径做失败预演。
- **与[系统思维](../../systems-classic-effects/systems-thinking/SKILL.md)**：本模型把共识拆成硬约束与惯例，再从起点重建；系统思维分析存量、流量、反馈和延迟如何持续产生行为。用户问"这条行业规则真不可改吗"走本模型；用户问"为什么改一个点总在别处反弹"走系统思维。
- **与[奥卡姆剃刀](../occams-razor/SKILL.md)**：奥卡姆剃刀在现成解释里排优先级；本模型在现成解释之外重建。已经有几个假说要排序，走奥卡姆剃刀；现有假说都建在类比上、需要拆地基，走本模型。
- **与[确认性偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：归零之后仍可能只搜集支持你所选起点的证据。第一性原理不豁免确认性偏差。
- **与[苏格拉底式质疑](../../thinking-models/socratic-questioning/SKILL.md)**：苏格拉底式质疑清掉撑不住的主张，本身不负责重建。笛卡尔式普遍怀疑（原书 #12，尚未蒸馏）更接近"先怀疑再重建"；若用户只要拆、不要建，应走苏格拉底式质疑而不是本模型。
- **与[马斯洛需求层次](../../thinking-models/maslow-hierarchy/SKILL.md)**：需求层次提供动机类别；第一性原理检查“员工只为钱工作”等组织惯例是不是伪约束。
- **与[正确与非共识](../../thinking-models/contrarian-and-right/SKILL.md)**：边常来自硬约束重算，而非抬杠。
