# 双重编码 Dual Coding

## 这是什么

**双重编码**：同一观念同时建立**言语表征**（词句、定义）与**非言语表征**（图示、空间关系、时间线、简笔画、手势意象），两条通道互相提供提取线索，通常优于单通道死记文字。

Allan Paivio 的理论强调意象系统与言语系统可联合；实践中关键不是「多贴图」，而是**图文指称同一结构且可互译**（能看图说出命题，能据命题画出结构）。

**鉴别**：[`elaborative-interrogation`](../elaborative-interrogation/SKILL.md) 用「为什么」加深语义联系；双重编码用**第二通道表征**加深可提取性。[`chunking`](../chunking/SKILL.md) 管信息打包；双重编码管打包时的模态。

## 什么时候用

- "文字背不住，能不能用图记"
- "双重编码 / 图文结合怎么做"
- 流程、解剖结构、因果链、地理/系统关系等空间性内容

**不要**当主模型：

- 只要闭卷自测规程 → [`retrieval-practice`](../retrieval-practice/SKILL.md)
- 抽象证明且强行配无关萌图 → 无效，改精细加工或费曼
- 装饰性幻灯片美化 → 非本模型

## 怎么用（执行步骤）

1. **选出核心命题（1–3 句）。** 先写清「要记住的主张」，禁止先找图。判据：离开图也能念出命题。
2. **画最小示意（非艺术）。** 框、箭头、时间轴、简笔关系图即可；元素须对应命题中的名词/关系。判据：每个图形元素能指回一个词。
3. **做互译检查。** 盖住文字据图复述；盖住图据文字重画。任一失败 → 对齐缺失环节。
4. **检索时交替线索。** 有时只给词提图，有时只给图提词；避免永远「看彩页回忆」。
5. **控制无关细节。** 删除装饰、多余色彩、与结构无关图标（减少分裂注意）。
6. **与间隔检索挂钩。** 图文对作为卡片两面或口头复述材料，交给间隔日程。

## 例证

**血流路径**：只背段落易混；画心腔箭头图并口述——揭示**空间表征补言语**。

**项目里程碑**：日期列表 vs 时间线+关键依赖箭头——揭示双重编码利于关系提取。

**（局限）**：高度形式化符号操作（某些代数变形）图形可能帮不上；不要为双而双。

## 什么时候不适用（边界）

- **无空间/形象对应的纯约定记号**：优先检索+精细加工。
- **图文不一致**：图说 A 文说 B 会制造错误记忆。
- **工作记忆已过载**：先组块减元，再双编码。
- **版权/敏感图像**：用自绘示意，不依赖复杂照片。

## 常见误用

- **装饰插图**：好看但不对应命题 → 删掉或重画结构图。
- **只看图不命题**：无法说出主张 → 先写 1–3 句再画。
- **与思维导图等同**：导图是一种工具；本模型判据是言语↔非言语互译。
- **堆叠过多通道**：旁白+字幕+动画全开 → 遵循必要通道，避免冗余冲突。

## 相关模型

- **与[组块](../chunking/SKILL.md)**：先把元素打成组块，再为组块配示意，避免一图五十个标签。
- **与[精细加工提问](../elaborative-interrogation/SKILL.md)**：图解释「为何箭头如此」时连用精细加工。
- **与[检索练习](../retrieval-practice/SKILL.md)**：双编码后仍须合上材料提取，看彩页不算会。
- **与[费曼技巧](../feynman-technique/SKILL.md)**：费曼可用示意图作讲解支架；核心仍是讲清与补洞。

## 记忆钩子

一句话配一张能互译的糙图，胜过十张装饰海报。
