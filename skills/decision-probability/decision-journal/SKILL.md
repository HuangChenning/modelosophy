# 决策日志 Decision Journal

## 这是什么

**决策日志**：在承诺行动**之前或当时**，用固定字段写下：情境、选项、关键信念与置信度、预期后果、成功/失败的可观察标准、以及「何种新信息会让我改主意」。事后按同一字段对照实际，区分**好决策坏运气**与**坏决策好运气**。

它训练的是**校准与过程质量**，不是写日记抒情。

## 什么时候用

- "我想提高判断准确度 / 校准"
- "决策日志 / 把当时的理由钉死"
- "事后总觉得『早该知道』，怎么对抗"
- 重复性高、反馈延迟但终会到来的决策（招聘、投资、产品赌注、个人重大选择）

**不要**当主模型：

- 计划尚未锁定、要集体挖失败模式 → [`pre-mortem`](../pre-mortem/SKILL.md)
- 事件已结束、团队要结构化复盘 → [`after-action-review`](../after-action-review/SKILL.md)
- 只要更新概率公式 → [`bayesian-updating`](../bayesian-updating/SKILL.md)
- 一次性且永不反馈 → 日志无法校准，改用清单/红队

## 怎么用（执行步骤）

1. **在行动锁定前开一条记录。** 最低字段：日期、决策问题、选项、选定项。判据：事后不能「改写当时想法」。
2. **写下关键信念与置信度。** 如「需求真实存在：70%」「对手不会跟进：55%」。用百分比或有序档位，禁止「觉得还行」。
3. **写可检验预测与时间盒。** 「90 天内付费率 ≥X」「若指标 Y 跌破 Z 则认错」。无预测 = 无法校准。
4. **记录信息状态与反悔成本。** 已知/未知、门可逆否（可链 [`reversible-irreversible`](../reversible-irreversible/SKILL.md)）。
5. **到期强制回填结果。** 对照预测：命中/未命中；过程是否遵循预定规则；情绪标签（可选）。
6. **做校准回顾（按批）。** 每月/每季：置信度 70% 的判断是否约七成正确？系统偏差写进下一条的检查项。

## 例证

**招聘**：记录「6 个月绩效达标：65%」与观察信号；半年后对照。揭示：**结果好不等于当时信息充分**——可分开评过程。

**产品赌注**：写下「假门转化 ≥8%」；未达标按日志止损，而非叙事合理化。揭示：日志是**预注册**，对抗事后编故事。

**投资 tip**：记录论点、失效条件与仓位规则；行情波动后只改规则不改历史条目。揭示：防 hindsight 篡改。

## 什么时候不适用（边界）

- **无反馈闭环**：永远看不到对错 → 无法校准，改用原则清单。
- **合规禁止留痕**：按组织政策改用脱敏摘要或口头预注册见证人。
- **替代分析**：日志不产生选项；选项生成仍需别的工具。

## 常见误用

- **事后补记冒充当时**：污染校准 → 时间戳/只追加。
- **只有结论没有置信度与预测**：变成日记。
- **用结果惩罚过程**：好运气的坏决策被表扬 → 分开评。
- **与 AAR 混用**：个人校准日志 ≠ 团队四步复盘。

## 相关模型

- **与[复盘四步法](../after-action-review/SKILL.md)**：AAR 是事件后团队学习；日志是决策时个人/小组的前瞻记录。可连用：日志提供「当时预期」原料给 AAR。
- **与[事前验尸](../pre-mortem/SKILL.md)**：验尸在批准前挖失败；日志在承诺时钉信念。验尸条目可写入日志的风险栏。
- **与[贝叶斯更新](../bayesian-updating/SKILL.md)**：日志存先验与预测；证据来了用贝叶斯改信念，并回填后验。
- **与[灰度认知](../grey-thinking/SKILL.md)**：灰度要求可修订置信度；日志把置信度落盘。
- **与[事后偏差](../../behavioral-biases/hindsight-bias/SKILL.md)**：日志是对抗「我早知道」的主工具。

## 记忆钩子

先写下「我会错在哪、怎样算对」——**没有预测的复盘，只是叙事。**
