# 思维实验 Thought Experiment

## 这是什么

**思维实验**：设定一个（通常简化或极端的）反事实情境，在**不实际做实验**的情况下，依据已接受的原则做推理，以：澄清概念、检验原则是否自洽、暴露隐含前提，或提出值得实证的假说。

伽利略斜面、爱因斯坦追光、哲学里的「电车难题」都属此类。它的力量来自**推理透明度**；它的危险是把「在想象中说得通」误当成「在世界中为真」。

## 什么时候用

- "原则在极端情况下还成立吗"
- "先假想一个干净世界，看矛盾在哪"
- 直接说思维实验 / Gedankenexperiment / 假想如果
- 教学澄清、伦理原则压测、理论自洽检查

**不要**当主模型：

- 已有可测假说要设计实证 → [`hypothesis-testing`](../hypothesis-testing/SKILL.md)
- 要跳框找点子但不必严格反事实推理 → [`lateral-thinking`](../lateral-thinking/SKILL.md)
- 要从失败列回避 → [`inversion`](../inversion/SKILL.md)

## 怎么用（执行步骤）

1. **写目的一句话。** 澄清概念 / 压测原则 / 启发假说——三选一为主。判据：结束后要交出什么（矛盾点、修订原则、候选假说）。
2. **设定世界与规则。** 列出：保留哪些现实约束、故意忽略哪些（摩擦、交易成本、信息不完备）。判据：读者能否复述「这个宇宙的物理/制度」。
3. **引入干预或极端情形。** 一次改一个关键旋钮（速度→光速、人数→无限、信息→完全透明）。记录直觉答案与推理步骤分开写。
4. **强制显式推理。** 每步引用你承认的原则；禁止「显然会…」无推导。若两人直觉冲突，回到哪条原则分叉。
5. **导出三类产出（标类型）。** (a) 概念澄清；(b) 原则需加边界；(c) 可转实证的假说。只有 (c) 可进入现实检验队列。
6. **写限度声明（强制）。** 「本结论依赖设定 S；若现实违反 S，不适用。」禁止把思维实验结果直接写成事实断言。

## 例证

**伽利略式落体思想**：若重物更快，组合物将导致矛盾——揭示的是**惯性/落体概念自洽**，最终仍由实验传统巩固。说明思维实验可暴露理论裂缝。

**政策「完全信息」假想**：若监管者拥有完全信息，某规则是否还必要？若答案依赖该不可能设定，说明论证偷运了全知前提。揭示：用来抓隐含假设。

**（原书卡片）**：若把著名思想实验当鸡汤故事复述，无设定与限度，不算执行本模型。

## 什么时候不适用（边界）

- **安全/医疗等高代价主张**：不能仅靠思维实验批准行动。
- **设定偷偷塞进结论**：循环论证的「假想」。
- **需统计规律的问题**：想象个例推翻流行病学结论无效。
- **纯娱乐脑洞**：无澄清/压测目的时不必套本 Skill 外壳。

## 常见误用

- **幻想当证据**：「我想应该会…」→ 标为未检验假说。
- **一次拧太多旋钮**：无法定位哪条假设致命 → 单变量原则。
- **与水平思考混用**：只求荒诞刺激无推理链 → 走 lateral-thinking。
- **道德直觉绑架**：电车题直觉当普遍伦理证明 → 至多澄清冲突，不作立法证据。

## 相关模型

- **与[假设检验](../hypothesis-testing/SKILL.md)**：思维实验可生成假说；声称关于世界则必须转假设检验。
- **与[第一性原理](../first-principles/SKILL.md)**：第一性从硬约束重建；思维实验常**暂时拿掉**部分约束以看原则。
- **与[类比思维](../analogical-thinking/SKILL.md)**：类比映射已有域；思维实验构造反事实域。
- **与[批判性思维](../critical-thinking/SKILL.md)**：产出的论证仍要接受证据与推理标准审视。
- **与[逆向思维](../inversion/SKILL.md)**：inversion 列失败路径；思维实验可构造「若失败已发生的世界」作澄清，但回避清单仍归 inversion。
