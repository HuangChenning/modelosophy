# 蒙特卡洛模拟 Monte Carlo Simulation

## 这是什么

**蒙特卡洛模拟**：对不确定输入按约定分布（及相关结构）**反复随机抽样**，把每个样本推进同一模型，得到**输出的经验分布**——中位数、分位数、尾部损失、目标达成率等——而不是一个「最可能」的单点。

它回答的是：「在我写下的不确定性下，结果大概长什么样、坏到什么程度有多常见？」不是「宇宙的真概率」。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "别给我一个数，给我分布 / P50–P90"
- "蒙特卡洛 / Monte Carlo / 跑 N 次"
- "成本、工期、NPV、库存同时不确定，怎么看风险"
- 多变量耦合、非线性、难以闭式积分的决策模型

**不要**在以下情况套用本模型：

- 静态结果集、风险中性、只要一个加权平均 → [`expected-value`](../expected-value/SKILL.md)
- 少数可信分歧未来、强调叙事与预警指标 → [`scenario-planning`](../scenario-planning/SKILL.md)
- 只想找「哪个假设最敏感」且输入少 → [`sensitivity-analysis`](../sensitivity-analysis/SKILL.md)
- 更新对假设的信念 → [`bayesian-updating`](../bayesian-updating/SKILL.md)

## 怎么用（执行步骤）

1. **写清决策问题与输出指标。** 如「完工日」「期末现金」「NPV」。判据：指标可计算，且与决策挂钩（过线/止损）。
2. **列出不确定输入并赋分布。** 每个变量：来源（历史/专家区间）、形状（三角/对数正态等）、上下界。禁止「随便 Normal(均值, 瞎编σ)」。
3. **声明相关与约束。** 哪些变量同向/反向相关？物理约束（工期≥0）？相关忽略会系统性错估尾部。
4. **固定模型与抽样次数。** 同一公式跑 \(N\) 次（如 5k–50k）；记录随机种子以便复现。判据：再加抽样，关键分位数变化可忽略。
5. **读分布，不只报均值。** 至少给出 P10/P50/P90（或 VaR/ES 类尾部）、目标达成率、与基准单点预测的差距。
6. **压力与失效检查。** 改分布形状/相关是否翻转决策？若「垃圾进、精美分布出」——标为不可信，改收集数据或改用情景/反脆弱结构。

## 例证

**项目工期**：任务工期与依赖不确定；单点 CPM 说「90 天」，模拟显示 P80=120 天。揭示：**路径合并与右偏使均值/众数严重低估尾部延误**。

**投资组合回撤**：收益与波动抽样得最大回撤分布，用于设定杠杆上限。揭示：关注的是**可接受尾部**，不是期望收益 alone。

**库存与需求**：需求与提前期联合抽样得到缺货率。揭示：非线性服务水平对相关结构敏感。

## 什么时候不适用（边界）

- **模型错误主导**：结构错了，多抽样只是高清错答案 → 先校准机制或用情景。
- **深度不确定 / 未知未知**：分布族不可辩护 → [`scenario-planning`](../scenario-planning/SKILL.md) 或 [`antifragility`](../../learning-growth/antifragility/SKILL.md)。
- **需要规范偏好而非分布**：已有分布仍要在破产约束下选 → [`expected-utility`](../expected-utility/SKILL.md)。
- **计算预算为零且输入极少**：手工敏感性可能更透明。

## 常见误用

- **把模拟均值当「答案」**：丢掉分位与尾部 → 禁止。
- **假精确尾部**：输入是拍脑袋却报「99.7% VaR」→ 降级为区间讨论。
- **与情景规划混用口号**：情景是少数故事；MC 是分布采样。
- **忽略相关性**：独立抽样低估/高估联合尾部。

## 相关模型

- **与[期望值](../expected-value/SKILL.md)**：EV 是分布的一阶矩（或离散加权）；MC 输出整段分布。只要均值且线性可加 → EV；要尾部/非线性 → MC。
- **与[敏感性分析](../sensitivity-analysis/SKILL.md)**：敏感性一次动少数输入看弹性；MC 同时扰动多输入看联合分布。先敏感性定位关键驱动，再 MC。
- **与[情景规划](../scenario-planning/SKILL.md)**：情景选少数分歧世界；MC 在给定概率模型内抽样。模型可信用 MC；模型不可信用情景。
- **与[决策树](../decision-tree/SKILL.md)**：树节点概率可用模拟估计；树适合显式决策/信息节点。
- **与[计划谬误](../planning-fallacy/SKILL.md)**：MC 的外部视图分布常用于纠偏乐观单点工期。

## 记忆钩子

单点是幻影；**抽样看分布，决策看尾部与过线率。**
