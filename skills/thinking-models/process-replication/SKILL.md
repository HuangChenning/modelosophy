# 可复制化 Process Replication

## 这是什么

**可复制化**指：从一次（或少数次）成功中抽出**可迁移的因果步骤、约束与度量**，改写成适合本地资源与约束的方法论，再通过实践与反馈把它固化——复制的是**过程逻辑**，不是品牌、口号、界面或偶然好运。

它回答的问题是：「别人（或过去的我）做成了，我该抄什么、改什么、不抄什么？」窄义“拷贝文件”或“仿产品外观”不是本模型；宽义“把剧本改编成电影”才接近——同一故事逻辑，不同媒介约束。

## 什么时候用

- 要对标竞品/标杆组织，想抽出可执行的做法而非口号；
- 团队里某人特别会做某事，需要沉淀成 SOP / playbook；
- 试点成功，准备扩到更多地区、产品线或客户群；
- 用户直接说可复制化 / 复制成功经验 / 方法论迁移。

**不要**当主模型：
- 只想检验自己是否真懂 → [`feynman-technique`](../../learning-growth/feynman-technique/SKILL.md)；
- 流程已在跑、要持续改进环 → [`pdca`](../../efficiency-execution/pdca/SKILL.md)；
- 要设计自我加强的增长闭环 → [`flywheel`](../../strategy-competition/flywheel/SKILL.md)；
- 要论证优势**为什么别人抄不走** → [`economic-moat`](../../strategy-competition/economic-moat/SKILL.md)。

## 怎么用（执行步骤）

1. **选定被复制的“成功单元”。** 写清：在什么目标、什么约束下、什么结果算成功。范围要窄（“把首单转化率从 X 提到 Y 的获客漏斗”），忌“复制某某公司的成功”。
2. **拆因果，不拆表象。** 列出假设的关键步骤、前置条件、资源投入、度量指标。把品牌光环、一次性政策红利、不可复制的个人关系、纯运气标成**不可迁移项**并剔除出方法论草案。
3. **写本地适配矩阵。** 对照本地：缺什么资源、多什么约束、法规/文化/规模差在哪。对每条关键步骤标：直接用 / 改参数 / 替换机制 / 放弃。忽略本地条件的“全盘照搬”视为失败用法。
4. **小范围实践迁移。** 按适配后的步骤跑最小可行试验；预先写好成功/失败判据与观察窗口。
5. **反馈→修订→方法论。** 用结果改步骤与约束说明；稳定有效后再写成可教可检的 SOP（含适用边界与反例）。反馈本身是下一轮“学习”，不是装饰性复盘会。

## 例证

**丰田生产方式的跨厂迁移**：后来者若只抄看板挂牌与“看板墙”，常失败；真正可迁移的是拉动、消除浪费、停线授权等机制，且必须按本地产能与供应商成熟度改参数。揭示**复制机制而非视觉符号**。

**餐饮连锁开新店**：总部把出餐动线、备料节拍、投诉升级路径写成手册并带店辅导；若把“某网红店装修风格”当可复制核心，扩店后口碑崩盘。揭示**SOP 要绑定可观测质量指标**。

**开源项目的贡献流程**：从一次成功合并请求反推：模板、CI、代码审查清单、发布节奏——他人可按同一流程贡献。揭示可复制化产出的是**他人能独立执行的协议**。

**（原书卡片）以本书自身与 MVP 作例**：卡片把“把理论画成图让普通人能用”和“MVP 迭代”都叫复制，方向对（学习→提炼→反馈），但把**出版物本身**当成功证明是循环论证；MVP 更接近试验设计，只有“把验证过的步骤抽成可扩方法论”那一段才是本模型。勿用“我们出过书”替代步骤 2–5。

## 什么时候不适用（边界）

- **成功不可归因**：样本=1 且关键因素混杂（政策、垄断、偶然曝光）时，先做归因，再谈复制；否则会固化迷信。
- **合规或伦理禁止复制**：例如抄袭专有数据、仿冒商标——本模型不覆盖违法“复制”。
- **目标是制造不可复制壁垒**：那是护城河分析；本模型假设你*想*迁移能力。
- **只需讲清概念**：费曼技巧；本模型要的是可执行流程，不是讲解流畅。
- **已有稳定流程只欠改进环**：直接 PDCA，不必重贴“可复制化”标签。

## 相关模型

- **与[费曼技巧](../../learning-growth/feynman-technique/SKILL.md)**：费曼用输出来暴露理解空洞；本模型在“已确认有效的做法”上抽迁移步骤。可连用：先讲清机制，再写 SOP。
- **与[PDCA](../../efficiency-execution/pdca/SKILL.md)**：PDCA 是循环改进引擎；本模型的反馈步常*调用* PDCA，但主任务是跨情境迁移与适配，不是对已有标准作业做微调。
- **与[飞轮](../../strategy-competition/flywheel/SKILL.md)**：飞轮问闭环是否自我加强；本模型问步骤能否在新约束下复现。飞轮本身也可被“提炼—迁移”，但是不同问题。
- **与[护城河](../../strategy-competition/economic-moat/SKILL.md)**：护城河评估*难以*被复制的结构优势；本模型做*如何*合法地复制过程能力。方向相反，勿混用。
