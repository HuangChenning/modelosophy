# 马斯洛需求层次 Maslow's Hierarchy

## 这是什么

Maslow（1943）提出，人受到多类需求驱动；常见五类是：

1. **生理**：食物、睡眠、身体基本条件；
2. **安全**：稳定、免受威胁、可预期性；
3. **归属**：关系、接纳、群体连接；
4. **尊重**：能力感、认可、自主与地位；
5. **自我实现**：发挥潜能、创造与成长。

大众常画成严格金字塔，但后续综述只发现有限、部分支持，没有证据证明所有人必须按同一顺序逐层满足。最稳妥的用法是**防漏项的需求地图**：检查当前干预解决的是不是当事人真正受阻的那一类需求。

## 什么时候用

- 加钱、福利或惩罚没有产生预期行为；
- 产品功能齐全但用户仍缺乏黏性或认同；
- 团队成员说“不安全”“没有归属”“不被尊重”，却被统一解释成薪资问题；
- 需要系统枚举动机，而非诊断某个人“处于第几层”。

## 怎么用

1. **先描述可观察情境。** 写出行为、原话和约束，不先把人塞进某一层。
2. **逐类扫描，不做单选题。** 对五类需求分别列“已有证据 / 反证 / 未知”。一个人可以同时缺安全与尊重，也可能在匮乏中追求意义。
3. **找出被当前方案命中的需求。** 例如加薪主要改善资源与部分安全，不会自动修复被羞辱、孤立或无自主权。
4. **提出每类至少一个可验证假设。** “离职是因为缺归属”必须能推出可观察预测，例如同团队关系改善后意愿变化，而不是循环解释。
5. **选择最小干预并测量。** 用访谈、行为指标或小范围试验验证，不把模型名称当证据。
6. **保留文化与个体差异。** 让当事人自己排序当前重要性；群体主义、家庭责任、宗教信念或经济环境都可能改变优先级。

## 例证

**涨薪仍留不住人**：员工收入已足够，但每天被微观管理、贡献不被承认。继续加钱只重复命中安全/资源维度，真正假设可能是自主和尊重受损。这个例子揭示模型的价值在于**发现错层干预**，不是宣布员工“升级到了第四层”。

**灾难中的利他行为**：人在安全尚未恢复时也会保护家人、维护尊严或投入共同目标。这类反例击穿“低层未满就不可能追求高层”的强版本，却不否定不同需求类别有分析价值。

**产品设计**：工具稳定性解决安全与可预期；社区归属、成就徽章和创作空间命中不同需求。但“加徽章 = 尊重”只是设计假设，仍要看用户行为。

**（原书卡片）五层金字塔**：层名大体忠实，但金字塔视觉强化了严格顺序。使用时应主动把它改画成可重叠的五类需求，而不是阶级台阶。

## 什么时候不适用

- **不是普遍定律**：Wahba 与 Bridwell（1976）回顾十项因子研究、三项排序研究及多种横纵向研究，只得到部分或无支持。
- **不是人格等级**：不能说“穷人只配谈生理需求”或“自我实现的人更高级”。
- **不是诊断工具**：抑郁、焦虑、创伤等问题不能靠需求层次替代专业评估。
- **需求会并行和冲突**：安全、归属、尊严可能同时驱动相反行动。
- **标签不能替证据**：“这是尊重需求”若没有可观察预测，只是换词重述。

## 相关模型

- **与[第一性原理](../../cognitive-thinking-tools/first-principles/SKILL.md)**：需求层次提供动机类别；第一性原理检查“员工只为钱工作”等组织惯例是不是伪约束。
- **与[确认性偏差](../../behavioral-biases/confirmation-bias/SKILL.md)**：管理者容易只搜支持自己激励方案的反馈；逐层扫描仍需主动找反证。
- **与[六顶思考帽](../../cognitive-thinking-tools/six-thinking-hats/SKILL.md)**：需求地图分析“什么在驱动人”；六帽组织团队从不同模式讨论方案。
