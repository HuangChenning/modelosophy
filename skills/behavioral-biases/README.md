- **[authority-bias](./authority-bias/SKILL.md)** `v0.x-draft` — 用权威效应检查用户是否因头衔、制服、专家光环而降低独立核验标准。
- **[availability-heuristic](./availability-heuristic/SKILL.md)** — 用易得性启发检查用户是否把“容易想起、最近看到、生动极端”的案例误当成“更常见、更可能”；
- **[commitment-consistency](./commitment-consistency/SKILL.md)** `v0.x-draft` — 用承诺与一致原理检查小承诺如何升级为大顺从，或用公开承诺帮助对抗现时偏差。
- **[confirmation-bias](./confirmation-bias/SKILL.md)** — 用确认性偏差思维模型帮用户检查自己是不是在按已有信念筛选证据——人会不成比例地搜索、记忆、
- **[decoy-effect](./decoy-effect/SKILL.md)** `v0.x-draft` — 用诱饵效应检查不对称劣势的第三选项是否被加入以操纵两选项间的份额。
- **[default-effect](./default-effect/SKILL.md)** `v0.x-draft` — 用默认效应检查或设计“预设选项”如何左右大多数人的选择（器官捐赠、养老金、隐私勾选）。
- **[dunning-kruger](./dunning-kruger/SKILL.md)** — 用邓宁-克鲁格效应帮用户检查能力自评是否可能失准：经典主张是表现较差者常高估相对水平，
- **[endowment-effect](./endowment-effect/SKILL.md)** `v0.x-draft` — 用禀赋效应检查用户是否仅因“已经拥有”就显著抬高物品估值，阻碍交易与换仓。
- **[framing-effect](./framing-effect/SKILL.md)** `v0.x-draft` — 用框架效应检查同一客观结果是否因表述方式（救活/死亡、折扣/罚款）而改变选择。
- **[gamblers-fallacy](./gamblers-fallacy/SKILL.md)** `v0.x-draft` — 用赌徒谬误检查用户是否误以为独立随机序列会自我纠错（“该出反面了”）。
- **[hindsight-bias](./hindsight-bias/SKILL.md)** `v0.x-draft` — 用事后聪明偏误检查用户是否在结果揭晓后，夸大自己“事先就知道”的程度，从而扭曲学习与问责。
- **[hot-hand-fallacy](./hot-hand-fallacy/SKILL.md)** `v0.x-draft` — 用热手谬误检查用户是否把随机或弱相关的连胜当成“状态火热、应加码追击”。
- **[hyperbolic-discounting](./hyperbolic-discounting/SKILL.md)** `v0.x-draft` — 用双曲贴现检查用户是否对近未来的奖励/成本过度敏感，导致时间不一致（计划明天、今晚破功）。
- **[illusion-of-control](./illusion-of-control/SKILL.md)** `v0.x-draft` — 用控制错觉检查用户是否高估自己对随机或不可控结果的影响力（仪式、选号、频繁操作）。
- **[law-of-small-numbers](./law-of-small-numbers/SKILL.md)** `v0.x-draft` — 用小数定律（小样本谬误）检查用户是否把过小样本的波动当成稳定规律。
- **[loss-aversion](./loss-aversion/SKILL.md)** — 用损失规避帮用户识别“同等得失下，损失被加权更重”如何扭曲选择：相对参照点，损失的痛苦常大于
- **[mental-accounting](./mental-accounting/SKILL.md)** `v0.x-draft` — 用心理账户检查用户是否把本可互换的钱/资源分进不同心理抽屉，导致不一致决策。
- **[overconfidence](./overconfidence/SKILL.md)** `v0.x-draft` — 用过度自信检查用户是否高估自己的知识精度、控制力或相对排名，导致仓位过大或计划过满。
- **[peak-end-rule](./peak-end-rule/SKILL.md)** — 用峰终定律评估“一段体验事后会被记得怎样”：回忆评价大致由峰值（最强时刻）与结尾主导，
- **[prospect-theory](./prospect-theory/SKILL.md)** — 用前景理论完整框架分析风险决策：参照点依赖、价值函数（收益凹/损失凸、敏感度递减）、
- **[reciprocity](./reciprocity/SKILL.md)** `v0.x-draft` — 用互惠原理识别“先给予再索取”如何制造回报压力，用于防操纵或正当合作设计。
- **[representativeness-heuristic](./representativeness-heuristic/SKILL.md)** `v0.x-draft` — 用代表性启发检查用户是否用“像不像典型故事”代替概率与基率来判断。
- **[scarcity-principle](./scarcity-principle/SKILL.md)** `v0.x-draft` — 用稀缺原理检查“限量/倒计时/独家”是否在抬高主观价值，而非反映真实约束。
- **[social-proof](./social-proof/SKILL.md)** `v0.x-draft` — 用社会认同（社会证明）检查用户是否因“别人都这样”而跟从，尤其在不确定情境。
- **[status-quo-bias](./status-quo-bias/SKILL.md)** `v0.x-draft` — 用现状偏差检查用户是否仅因“现在如此”就偏好维持，哪怕切换的期望净收益更高。
- **[sunk-cost](./sunk-cost/SKILL.md)** — 用沉没成本思维模型帮用户判断"要不要因为已经投入而继续"——已经发生且不可收回的投入
- **[survivorship-bias](./survivorship-bias/SKILL.md)** — 用幸存者偏差检查用户是否只从“活下来的样本”推断成功法则：筛选机制消灭了失败者的声音，
