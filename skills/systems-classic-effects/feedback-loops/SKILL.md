# 反馈回路 Feedback Loops

## 这是什么

**反馈回路**：存量变化影响流量，流量再改变存量，形成闭环。

- **增强回路（正反馈）**：偏离被放大——增长螺旋或崩溃螺旋；
- **调节回路（负反馈）**：把系统拉向目标或均衡——恒温、库存补货、市场供需调节。

延迟会让调节变成振荡。本 Skill 专攻**回路极性与干预点**；更大方法见系统思维，形式化方程见系统动力学。

## 什么时候用

- "越管越糟 / 越成功越成功"
- "指标一压就反弹"
- "怀疑自己在喂正反馈"

**不要**当主模型：
- 完整冰山/杠杆点旅程 → [`systems-thinking`](../systems-thinking/SKILL.md)
- 存量流量方程与仿真 → [`system-dynamics`](../system-dynamics/SKILL.md)
- 马太式资源再分配叙事 → [`matthew-effect`](../matthew-effect/SKILL.md)

## 怎么用（执行步骤）

1. **选 1–2 个关键存量。** 用户数、信任、库存、债务——可测。
2. **画闭环箭头并标极性。** 每箭“同向+ / 反向−”；绕环乘积决定增强或调节。画不出闭环则还不是反馈问题。
3. **标延迟。** 哪里结果来得慢？延迟旁注周/月。
4. **判断当前主导回路。** 增长失控还是调不过来？找主导环。
5. **选干预。** 增强环：加目标、限速、引入调节；调节环：改目标、减延迟、防过度矫正。写清改的是信息、规则还是流量。

## 例证

**病毒传播**：感染↑→传播↑→感染↑（增强）；免疫/隔离引入调节。揭示极性切换。

**库存震荡**：延迟订货导致过冲。揭示**调节+延迟**。

**内容推荐**：点击喂推荐再点击。揭示产品增强环（可连马太）。

## 什么时候不适用（边界）

- **单向因果且无回流**：先别硬画环。
- **纯统计相关**：无机制箭头。
- **细节工程 PID**：可类比调节，但要工程师工具链。

## 常见误用

- **正反馈=好事**：正反馈只表示增强，可好可坏。
- **负反馈=批评**：这里是调节，不是人际负面评价。
- **环上堆 30 个节点**：先最小闭环。

## 相关模型

- **与[系统思维](../systems-thinking/SKILL.md)**：系统思维是总方法；本 Skill 专练回路。
- **与[系统动力学](../system-dynamics/SKILL.md)**：动力学把回路写成存量流量模型。
- **与[飞轮](../../strategy-competition/flywheel/SKILL.md)**：飞轮是有意增强环设计。
- **与[杠杆](../../systems-complexity/leverage/SKILL.md)**：杠杆点常落在回路结构上（互链不迁入）。
- **与[二阶思维](../second-order-thinking/SKILL.md)**：二阶常显影为回路。
