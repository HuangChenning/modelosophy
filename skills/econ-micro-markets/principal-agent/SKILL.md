# 委托-代理问题 Principal–Agent Problem

## 这是什么

**代理人不完全按委托人利益行事，因目标与信息不同。**

股东与经理、雇主与员工、选民与官僚：委托人难完美监测，代理人有私人目标。合同理论用激励相容、参与约束设计薪酬、股权、晋升与监督。本质常是组织内的道德风险（及部分逆向选择）。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "委托代理"
- "代理人不听话"
- "principal agent"
- "如何给CEO设指标"

**不要**在以下情况套用本模型：

- 没有利益冲突也硬套代理问题
- 只加 KPI 不顾可操纵与多任务扭曲

## 怎么用（执行步骤）

每一步给出可操作判据；禁止空转复述定义。

1. **写清委托人目标与代理人私利。** 两者差异是什么？冲突点列出来。
2. **列信息与控制权。** 谁观测产出/努力？谁有决策权？
3. **设计激励相容。** 薪酬、分成、延期支付、竞业、审计——检查是否鼓励操控指标。
4. **加治理补充。** 董事会、市场竞争、声誉、退出权——合同不是唯一工具。

## 例证

**经理追求规模而非利润**：经典企业理论案例。

**外包商赶工牺牲质量**：难监测质量时的代理扭曲。

## 什么时候不适用（边界）

- **目标本就一致且易监测**：代理问题很弱。
- **多智能体政治过程**：可能需要机制设计/政治经济学，不单是双边代理。

## 常见误用

- **代理问题=人性恶**：先改信息与激励。
- **单一指标治理复杂任务**：Goodhart 效应：指标被优化到失真。
