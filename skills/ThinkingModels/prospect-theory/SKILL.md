# 前景理论 Prospect Theory

## 这是什么

前景理论（Kahneman & Tversky, 1979；累计前景理论, 1992）描述人在风险下如何评价**相对参照点的得失前景**，而非按期望效用对终态财富做线性加权。决策大致分编辑与评价两阶段：先把结果编码为相对参照点的收益/损失并简化，再用**价值函数**与**决策权重（概率权重）**打分。

价值函数要点：相对参照点；收益区通常凹、损失区通常凸（反映敏感度递减）；损失侧往往更陡——这一“更陡”即**损失规避**，本库已有专条 [`loss-aversion`](../loss-aversion/SKILL.md)，此处只把它当作组件调用，不另写一套同质步骤。

概率权重要点：客观概率被非线性变换——**小概率常被高估，中高概率常被低估**；接近确定的结果被额外加权（确定效应相关）。由此出现常见的四重模式：高概率收益→偏保守；高概率损失→偏冒险；低概率收益→偏买彩票式冒险；低概率损失→偏买保险式规避。

它解释的是**描述性规律**（人常怎样选），不是规范建议（人应该怎样选）。顾问目标是让用户看见框架与权重如何驱动选择，再对齐真实终态与约束。

## 什么时候用

- 需要同时处理参照点、得失形状与概率编码（不只“亏更痛”）；
- 用户提到确定效应、反射效应、概率权重、四重模式、前景理论；
- 保险/彩票/止损加码/“见好就收 vs 赌一把翻本”交织出现。

**不要**当主模型：
- 只谈同等得失痛感不对称、处置效应、框架成亏/赚 → 走 [`loss-aversion`](../loss-aversion/SKILL.md)；
- 已投入绑架继续 → [`sunk-cost`](../sunk-cost/SKILL.md)；
- 互斥选项各放弃什么 → [`opportunity-cost`](../opportunity-cost/SKILL.md)；
- 要画概率树算期望值作为规范工具 → [`decision-tree`](../decision-tree/SKILL.md)（可先用前景理论诊断扭曲，再换期望值语言）。

## 怎么用（执行步骤）

1. **冻结参照点。** 写出当前编码用的锚：买入价、预算、承诺目标、同事水位、现状。同一现金流相对不同锚可以是“赚”或“亏”。先冻结，再讨论感觉。
2. **把选项改写成相对参照点的前景表。** 每列：结果（收益/损失金额或后果）、客观概率、是否接近“确定”。暂时用同一会计语言（终态财富或净影响），去掉情绪标签。
3. **标价值函数形状（含敏感度递减）。** 问：同等增量在靠近参照点时是否更“刺痛/爽快”，远离后是否钝化？若用户为小亏极度反应、为大额边际变化麻木，记下敏感度递减。损失侧是否明显更陡 → **转调** [`loss-aversion`](../loss-aversion/SKILL.md) 专条步骤，不在此重复长文。
4. **检查概率权重。** 标出极小概率（灾难/中奖）与接近 1 的概率。问：是否把“几乎不可能”当“值得一搏”，或把“几乎确定”当“板上钉钉到容不得波动”？对照四重模式，看当前选择落在哪一格。
5. **用终态/期望语言重排，再决定是否改框架。** 用期望值或终态财富重述后，若排序大变，说明框架+权重在驱动。对策：事先规则（止损/止盈、保险额度上限）、拉长评价窗口、合并或拆分多次消息时要诚实——**对本用户做顾问时对齐真实后果，不单方面用更痛框架操纵他自己**；对他人沟通则须披露意图与边界。

## 例证

**亚洲疾病问题式框架翻转**：同一统计结果写成“救活”或“死亡”会改变风险态度。揭示的是**参照编码 + 收益/损失区不同曲率**，不是信息集不同。

**买保险又买彩票**：对低概率损失愿付溢价规避，对低概率收益愿付溢价追逐。揭示**概率权重两端同时高估小概率**，单用“胆小”或“赌徒”人格解释不了。

**高概率收益见好就收 / 高概率损失赌翻本**：确定效应与反射效应。揭示风险态度随框架与概率区位翻转，而非固定风险偏好参数。

**（原书卡片）四结论 + 教孩子“少玩一天 vs 扣半年零花钱”**：四结论与文献同向，但须绑到参照点与概率权重，不能收成“趋利避害阴阳道”。亲子话术例子展示的是**参照点操纵**（以更大损失为锚，使小约束显得像收益）；伦理上对依赖关系中的对象应谨慎，且卡片把前景理论收成博弈操控手册是局限——顾问场景优先自检自己的扭曲，而非教人暗中框架他人。

## 什么时候不适用（边界）

- **真实归零/灾难性下行**：加重尾部损失权重可能是适应性的；处方是限制敞口与破产约束，不是“克服偏见去赌”。
- **系数不可当税率**：价值函数斜率、损失/收益比、权重函数参数是实验估计，禁止用固定倍数给人生决策做伪精确换算。
- **不等于“人非理性所以随便骗”**：描述理论可被滥用于操纵；本 skill 默认用途是诊断与自我校正。
- **不替代期望效用/决策树作为规范算法**：要做可审计的概率决策，仍用期望值工具，并把前景扭曲当作偏差清单。
- **与 loss-aversion 分工**：只问痛感不对称 → 专条；要完整框架（含概率权重/敏感度递减/四重模式）→ 本条。

## 相关模型

- **与[损失规避](../loss-aversion/SKILL.md)**：前景理论的损失侧更陡组件；专条处理得失不对称与框架，本条覆盖全文并调用它。
- **与[沉没成本](../sunk-cost/SKILL.md)**：已投入能否当理由 ≠ 参照点下的得失编码（常并存）。
- **与[决策树](../decision-tree/SKILL.md)**：规范侧画树算 EV；本模型诊断人为何偏离 EV。
- **与[双系统](../dual-process/SKILL.md)**：框架与痛感多由快系统放大；规则与终态重述需慢系统。
- **与[反脆弱](../antifragility/SKILL.md)**：若目标是配置不对称暴露，走反脆弱；本模型只解释评价扭曲。
