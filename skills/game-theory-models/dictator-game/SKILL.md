# 独裁者博弈 Dictator Game

## 这是什么

**提议者单方面决定分配，对方无拒绝权——测利他、规范与实验需求。**

相对最后通牒去掉惩罚威胁：若仍给予，更接近利他/公平规范或实验注目效应。平均给予低于最后通牒但仍常 >0。用于拆解“怕被拒”vs“真心分”。

## 什么时候用

用户出现以下意图时启用本 Skill：

- "独裁者博弈"
- "单方面决定怎么分"
- "没有否决权还会不会给"

**不要**在以下情况套用本模型：

- 对方可拒绝 → ../ultimatum-game/SKILL.md
- 先送后还 → ../trust-game/SKILL.md
- 要设计迫使说实话的规则 → ../mechanism-design/SKILL.md

## 怎么用（执行步骤）

1. **确认无拒绝权。** 否则改走最后通牒。
2. **对照零给予基准。** 纯自私应给 0；观察实际或用户意向。
3. **拆动机。** 利他、公平规范、被观察、未来关系——用匿名/注目条件区分（定性）。
4. **输出。** 给予是否>0 + 最可能动机 + 对制度（透明度）的含义。

## 例证

**实验室独裁者**：平均仍给予但少于最后通牒。揭示惩罚威胁不是唯一驱动。

**单方面奖金池**：经理分配无申诉时的规范压力。

## 什么时候不适用（边界）

- **实验假象**：被实验者注目会抬高给予。
- **外部效度**：真实高利害可能更冷。

## 常见误用

- **把给予当纯粹圣贤**：忽略规范与注目。
- **与最后通牒混称**：拒绝权改变结构。

## 相关模型

- **与[最后通牒博弈](../ultimatum-game/SKILL.md)**：有拒绝权。
- **与[信任博弈](../trust-game/SKILL.md)**：投资—回报链。

## 记忆钩子
