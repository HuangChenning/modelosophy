# 水平思考 Lateral Thinking

## 这是什么

**水平思考（Lateral Thinking）**：de Bono 提出的一组技法，与「垂直思考」（沿逻辑链深入、求正确）对照——水平思考刻意**横移**到旁支视角，用暂时不合理的挑衅打断定势，以增加候选想法的多样性，之后再回到垂直评估。

它不是「不要逻辑」，而是承认：逻辑很擅长**发展**已有路径，不擅长**发现**被框架藏起来的路径。

## 什么时候用

- "方案都在同一条老路上打转"
- "需要更多非常规选项再筛选"
- 直接说水平思考 / lateral thinking / 换轨道想

**不要**当主模型：

- 会议需要分角色同步思考 → [`six-thinking-hats`](../six-thinking-hats/SKILL.md)
- 工程矛盾要消除权衡 → [`triz`](../triz/SKILL.md)
- 从硬约束重建 → [`first-principles`](../first-principles/SKILL.md)
- 只要严谨证伪论证 → [`critical-thinking`](../critical-thinking/SKILL.md) / 苏格拉底

## 怎么用（执行步骤）

1. **写清当前框架与「显然解」。** 把大家默认的问题定义与前 3 个常规方案写下来。判据：是否承认「我们困在这里」？
2. **选一种跳框技法（每次一种）。**  
   - **挑衅（Po）**：故意说一句「不合理」句（「假如我们不收费会怎样」）  
   - **反转**：把关键假设取反  
   - **随机切入**：从无关词/图强制建立联系  
   - **剥离焦点**：只改问题中的一个词（客户→非客户）  
3. **从挑衅「提取」可行动片段。** 不问「这句对不对」，问「它暗示什么机制/约束可松动？」每条挑衅至少落地 1 个可试概念。
4. **垂直回收。** 用约束、成本、伦理、证据过滤；标「可试点 / 需研究 / 丢弃」。水平阶段禁止过早用「行不通」杀人；回收阶段禁止继续用荒诞当结论。
5. **记录框架迁移。** 写下「我们原来以为问题是 X，现在可选定义为 Y」——水平思考的产物经常是**重定义问题**。

## 例证

**零售增长**：困在「多开促销」→ 挑衅「假如禁止打折」→ 引出会员体系、稀缺场次、联名体验等非折扣路径。揭示：跳框改的是**手段集合**。

**会议空转**：同一反对意见循环 → 随机词「电梯」强制联想 → 「楼层分区服务」试点。揭示：随机输入是工具不是迷信，价值在强制新连线。

## 什么时候不适用（边界）

- **安全关键、规程已定的操作**：不要用挑衅破坏合规执行。
- **需要立即收敛决策且选项已够**：水平思考增加熵，有成本。
- **把荒诞当交付**：停在段子而未垂直回收 = 失败。

## 常见误用

- **与六帽混淆**：六帽管会议角色时序；水平思考管跳框技法。
- **用水平思考逃避证据**：奇思妙想仍要检验 → [`hypothesis-testing`](../hypothesis-testing/SKILL.md)。
- **全程否定垂直思考**：两者是接力，不是敌对。

## 相关模型

- **与[六顶思考帽](../six-thinking-hats/SKILL.md)**：六帽用绿帽时段可嵌入水平技法；用户要整场分帽 → 六帽；只要跳框练技法 → 本模型。
- **与[TRIZ](../triz/SKILL.md)**：TRIZ 有矛盾与原理清单；水平思考更自由。已形成技术矛盾优先 TRIZ。
- **与[第一性原理](../first-principles/SKILL.md)**：第一性追求硬约束上的重建；水平思考不保证科学性，只保证多样性。
- **与[逆向思维](../inversion/SKILL.md)**：逆向从失败倒推回避项；水平思考横移生成新选项。可连用。
- **与[批判性思维](../critical-thinking/SKILL.md)**：水平之后必须垂直评估。

## 记忆钩子

先允许「不对」的一步横移，再把有用的碎片竖着长成可试方案。
