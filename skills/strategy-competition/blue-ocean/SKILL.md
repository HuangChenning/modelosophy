# 蓝海战略 Blue Ocean Strategy

## 这是什么

**蓝海战略**：通过**价值创新**（同时追求差异化与低成本）重建市场边界，创造新需求与无人竞争空间；相对的「红海」是在既有产业边界内争夺份额。工具上常见战略布局图（价值曲线）与 **ERRC 四行动框架**（Eliminate / Reduce / Raise / Create）。

它不是「做没人做的奇葩产品」口号，而是：相对行业常规因素，系统决定删减什么、减什么、增什么、创什么，使买方效用曲线与成本结构同时移动。

## 什么时候用

- "红海太卷，想换赛道 / 重建品类"
- "蓝海战略 / 价值曲线 / ERRC / 四行动框架"
- 新品类定义、商业模式重构早期

**不要**当主模型：

- 诊断现有产业利润结构 → [`porters-five-forces`](../porters-five-forces/SKILL.md)
- 评估企业可持续超额回报壁垒 → [`economic-moat`](../economic-moat/SKILL.md)
- 内外部态势清单匹配 → [`swot`](../swot/SKILL.md)
- 低端/新市场颠覆路径 → [`disruptive-innovation`](../disruptive-innovation/SKILL.md)

## 怎么用（执行步骤）

1. **画出行业常规价值曲线。** 列出买方真正比较的竞争因素（价格、功能、服务…），标出行业平均与主要对手的高低。判据：因素是否来自买方决策，而非内部KPI癖。
2. **做 ERRC 草表。** 对每个因素判定：消除 / 降低 / 提升 / 新建。至少各有一项「消除或新建」，否则易变成微调红海。
3. **检查价值创新是否同时动效用与成本。** 消除/降低应可解释成本下降；提升/新建应可解释效用上升。只加功能不加成本纪律 = 差异化堆料，不是蓝海。
4. **写非顾客转化假设。** 谁今天不买、为何不买、新曲线如何拉他们进来。判据：有可访谈的非顾客画像。
5. **最小试点验证曲线。** 用可回滚实验测支付意愿与成本，禁止一上来全公司押注新叙事。
6. **设定红海回流警报。** 若对手可快速复制且无重建壁垒，补飞轮/护城河问题，而非只喊蓝海。

## 例证

**经典教学案例（马戏团品类重建思路）**：削减明星动物等成本项、提升剧场体验——揭示 ERRC 改变价值曲线，而非在马戏红海加更多表演。

**工具类 SaaS**：砍掉企业销售复杂度、创造自助与模板生态——揭示同时降获客成本与提升中小买方效用。

**（局限）**：畅销书案例常事后叙事；执行失败多因未验证非顾客或成本未真降。

## 什么时候不适用（边界）

- **强监管/高度同质化的刚需品类**：重建边界空间有限，先五力。
- **已有强护城河收割期**：优化运营可能优于冒险开蓝海。
- **无法同时动成本与效用**：只讲故事无结构 = 营销话术。

## 常见误用

- **蓝海=蓝海市场口号**：无 ERRC → 补价值曲线作业。
- **与颠覆混称**：低端切入走颠覆式创新。
- **忽视模仿**：开蓝海后不做壁垒 → 连护城河/飞轮。
- **内部自嗨因素**：曲线全是公司在意的指标 → 回到买方效用。

## 相关模型

- **与[成本领先](../cost-leadership/SKILL.md) / [差异化战略](../differentiation-strategy/SKILL.md)**：**这是一处真实的理论分歧，不是本库措辞不统一**——Porter 认为在既有产业竞争维度上同时追求低成本与差异化会"夹在中间"；蓝海认为可以兼得，但前提是先用 ERRC 重建了竞争维度集合（消除/新增了因素，成本下降来自砍掉行业标配而非压缩同一套活动）。判据：用户想在**现有维度**上既便宜又有特色 → 按 Porter 视为中间化风险，走成本领先或差异化二选一；用户愿意先问"能不能整个重新定义这个品类的竞争要素" → 走蓝海。
- **与[波特五力](../porters-five-forces/SKILL.md)**：五力看既有产业利润压力；蓝海试图重建边界。产业内厮杀诊断走五力；品类重建走蓝海。
- **与[护城河](../economic-moat/SKILL.md)**：蓝海开局后需问能否维持；评估壁垒走护城河。
- **与[颠覆式创新](../disruptive-innovation/SKILL.md)**：颠覆强调低端/新市场轨迹与在位者激励；蓝海强调价值曲线重建。路径与激励走颠覆；ERRC 重建走蓝海。
- **与[第二曲线](../second-curve/SKILL.md)**：第二曲线管增长 S 曲线切换时机；蓝海管新曲线的价值逻辑。
- **与[飞轮](../flywheel/SKILL.md)**：新空间要自我加强闭环时连用飞轮。
- **与[长尾](../../systems-classic-effects/long-tail/SKILL.md)**：长尾是需求分布形态；战略用法互链，不在本类重建。

## 记忆钩子

少在红海里加戏；用 **ERRC** 同时改买方效用与成本。
