# 交错练习 Interleaved Practice

## 这是什么

**交错练习**：在一次训练中**混合**多种相关题型、策略或技能变体（A-B-C-A-C-B…），迫使学习者每次先**辨别「这是哪一类问题」**再选方法，而不是在同一题型上机械连刷（blocked practice）。

机制常称 **contextual interference（情境干扰）**：练习中表现可能暂时变差、感觉更难，但延迟测验与迁移往往更好——属于期望难度的一种。交错不是无结构乱练，而是有意识的类别混合。

**鉴别**：[`deliberate-practice`](../deliberate-practice/SKILL.md) 管「针对哪一弱点 + 反馈」；本模型管「多类别如何排程」。[`retrieval-practice`](../retrieval-practice/SKILL.md) 管是否主动提取；交错管提取/解题的**序列结构**。

## 什么时候用

- "刷同类题很顺，一混就不会"
- "交错练习 / 混合题型怎么安排"
- 数学题型、运动动作变体、诊断分类、外语语法点混用等

**不要**当主模型：

- 全新技能连基本动作都不会 → 先短 blocked 建最小能力，再交错
- 单一瓶颈的反馈闭环设计 → [`deliberate-practice`](../deliberate-practice/SKILL.md)
- 卡片记忆间隔 → [`spaced-repetition`](../spaced-repetition/SKILL.md)

## 怎么用（执行步骤）

1. **列出 2–4 个易混类别。** 写清每类的辨别特征（不是只写题号）。判据：能否用一句话说明「看到什么线索选 A 而非 B」。
2. **每类先有最小成功样例。** 各类至少能独立做对 1–2 题；全零基础禁止直接大交错。
3. **设计交错序列。** 同一次练习内切换类别，避免「整页全是同类」；可用伪随机或轮转。判据：连续两题类别相同的比例应明显低于 blocked。
4. **每次先辨类再求解。** 强制口头/书面标「本题类型」再动笔。漏辨类直接重做该步。
5. **接受练习中正确率短期下降。** 若仅因过难崩盘（错误率 >60% 且无学习感）→ 减类别数或插入微型 blocked 巩固。
6. **用混合测验验收。** 延迟 1–7 天做乱序卷；只会固定顺序不会乱序 → 继续交错并加强辨别线索表。

## 例证

**几何求面积**：连续 20 道全是圆柱，再考圆锥就懵；圆柱/圆锥/球交错练迫使先认形状——揭示**辨别先于计算**。

**网球**：正手连打很爽，比赛中正反手切换失误；训练中交错落点——揭示**情境干扰换迁移**。

**（局限）**：初期教学演示可用短 blocked；过早交错会打击动机，需按掌握度切换。

## 什么时候不适用（边界）

- **类别尚未可区分**：特征表都写不清时，先对照学习再交错。
- **安全关键程序**：急救步骤等需先可靠固化，再在模拟中交错干扰。
- **纯粹速度自动化阶段**：少数需要极高自动化的子技能可阶段性 blocked，再回到交错保迁移。
- **无关技能硬混**：英语单词与深蹲交错无辨别收益——类别须相关易混。

## 常见误用

- **把乱序瞎练当交错**：无易混类别集合 → 先定义类别。
- **全程 blocked 到考前**：课堂爽、考试崩 → 考前两周起加重交错。
- **与刻意练习对立**：可先对弱点 blocked 短练，再放入交错序列。
- **忽视辨类步骤**：只求算对 → 强制标注题型。

## 相关模型

- **与[刻意练习](../deliberate-practice/SKILL.md)**：刻意练习定弱点与反馈；交错定多弱点/多题型的编排。突破单一瓶颈可先刻意，防「只会一种题」用交错。
- **与[检索练习](../retrieval-practice/SKILL.md)**：交错序列中的每一题仍应尽量闭卷提取策略，而非翻笔记。
- **与[迁移学习](../transfer-of-learning/SKILL.md)**：交错常促进近/中迁移；要显式设计远迁移任务走迁移模型。
- **与[组块](../chunking/SKILL.md)**：组块降低工作记忆负荷；交错增加选择负荷——先有组块再交错更有效。

## 记忆钩子

练的时候混一点、难受一点，考的时候才分得清。
